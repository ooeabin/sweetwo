## 1. 처리하는 개인정보

| 구분 | 항목 | 목적 |
| --- | --- | --- |
| 필수 | 로그인 정보(소셜 제공자, 계정 식별자), 이메일, 호칭 | 계정 관리, 알림 메일 발송 |
| 필수 | 월급, 월급 계획, 자산, 부채, 저금 입력값(이름, 매달 금액, 목표 금액, 기한, 시작할 때 모은 금액), 월급 체크 기록 | 월급 계획의 여유 자금, 저금 진행과 예상 달성일, 순자산 계산 |
| 필수 | 파트너와 우리 둘 공간 공유 | 두 사람 공동 사용 |
| 필수 | 접속 기록, 기기 정보(앱 버전 포함) | 보안, 부정 이용 방지, 앱 업데이트 안내 |
| 선택 | 양가 가족 정보 | 경조사 |
| 선택 | 사진 | 경조사 기록 |
| 선택 | 프로필 사진(직접 올린 사진, 카카오·구글 계정 프로필 사진) | 우리 둘 공간에서 나를 알아보기 |
| 선택 | 마케팅 수신 | 혜택 안내(월 1회) |
| 선택 | 분석 수집(화면 ID, 선택지 ID, 소요 시간, 금액 원값 없음) | 서비스 개선 |

계좌번호, 카드번호, 주민등록번호, 금융사 비밀번호는 받지 않아요.

카카오나 구글로 로그인하면 그 계정에 있는 프로필 사진을 처음 한 번만 받아 내 프로필 사진으로 써요. 카카오는 로그인할 때 ‘프로필 사진’ 제공에 동의한 경우에만 받아요. 받은 사진은 정사각형으로 줄이고 위치 정보를 지운 뒤 보관하고, 원본과 주소는 남기지 않아요. 앱 설정에서 언제든 바꾸거나 지울 수 있고, 지우면 다시 받지 않아요.

## 2. 보관 기간

- 계정을 삭제하면 30일 뒤 완전히 지워요. 백업은 30일이 지나면 사라져요.
- 법으로 정한 기록은 따로 보관해요: 계약·결제 기록 5년, 소비자 불만·분쟁 처리 기록 3년, 접속 기록 3개월.

## 3. 파트너와 가족 정보

- 합류 전에 내가 적은 파트너 정보는 파트너가 합류할 때 본인이 확인하고 이어 쓰거나 지울 수 있어요.
- 양가 가족 정보는 우리 둘 공간 밖으로 내보내지 않아요. 메모와 가족 정보는 한 번 더 암호화해요.

## 4. 처리 위탁과 국외 이전

| 받는 곳 | 맡기는 일 |
| --- | --- |
| Supabase | 데이터베이스, 인증, 파일 보관 |
| Amazon Web Services | 파일 보관, 메일 발송, 암호화 키, 배포 |
| 네이버웍스 | 고객 메일 |
| Better Stack | 가동 확인, 상태 페이지 |

모든 데이터는 국내(서울) 서버에 보관하고 국외로 옮기지 않아요. 분석과 오류 기록은 자체 운영하는 서울 서버에 둬요.
