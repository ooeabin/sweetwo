# ADR 0005: 온보딩은 월급 입력까지, 월급 계획은 추천값으로 만들고 홈에서 확인

- 날짜: 2026-11-02
- 상태: 확정(ADR 0003 3장, ADR 0004의 온보딩 끝부분을 고침)

## 맥락

- ADR 0004로 목표 금액을 홈으로 옮긴 뒤에도 온보딩 끝에 월급 계획(O-50)와 결과(O-60)가 남아 있었음
- 목표 금액이 없는 상태라 월급 계획은 비상금 한 줄만 추천값이 들어가고, 결과도 대부분 비상금 기준이라 첫 인상으로 약함
- 월급 계획은 줄이 많아 처음 쓰는 사람에게 부담. 홈에서 체크리스트와 함께 보는 편이 이해가 쉬움

## 결정

- 온보딩: O-10 → O-03 → O-06 (→ O-07) → O-11 (→ O-12) → O-13 → O-21 → O-30 → O-31 → O-32 → O-60(준비 끝) → 홈
- 월급날은 O-32 한 화면으로 나눔(2026-11-02). O-32의 주 버튼은 “시작할게요”. 누르면 월급을 저장하고, 추천값(17 O-50 추천값 표)으로 월급 계획을 만들고, 비상금 목표 금액 = (고정지출 + 생활비) × 3(기한 1년 뒤)을 넣고, 월급날이 있으면 첫 체크리스트를 만든 뒤 홈으로
- 이미 월급 계획이 있으면(연결 해제 뒤 다시 온보딩 등) 그대로 둠
- O-60 결과 화면은 없앰. 대신 홈에 들어가기 전 ‘준비 끝’ 한 장(O-60 ID를 다시 씀, 2026-11-02): 해 둔 것(월급 계획, 체크리스트)과 홈에서 할 것(목표 금액) → “홈으로 갈게요”
- 홈 할 일 ‘월급 계획 확인’: “추천으로 나눈 월급 계획을 확인해 주세요” → W-01. W-01을 한 번 열면 끝남(기기에 기록). 순서는 월말 확인 다음, 배우자 초대 앞
- 예전 O-50에 멈춰 있던 사람은 다시 열면 O-31부터

## 고른 대안

- 월급도 통째로 빼기: 체크리스트가 월급날로 만들어져서, 월급 없이는 홈의 ‘이번 달 월급’이 비어 버림
- 월급 계획만 건너뛸 수 있게: 길이 문제가 그대로

## 결과

- 온보딩은 8~9화면, 질문만 있고 표가 없음
- 첫 홈에서 할 일 한 줄이 월급 계획 확인을, 목표 카드가 금액 정하기를 이끎
- ‘월급 계획 확인’을 끝낸 기록은 기기에만 있어 다른 기기에서는 한 번 더 보일 수 있음


## 바뀐 점(2026-11-03)

- 홈 할 일 ‘월급 계획 확인’은 없앰. 홈 맨 위가 이번 달 체크리스트(H-03)라서 ‘월급 계획 고치기’ 링크로 충분하고, 할 일 띠가 홈 첫 줄을 차지해서. 추천값으로 만든 월급 계획은 그대로이고 W-01에서 고침.
