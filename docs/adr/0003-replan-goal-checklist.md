# ADR 0003: 목표 중심으로 다시 짠 기획(월급 체크리스트, 짧은 온보딩)

- 날짜: 2026-10-25
- 상태: 제안(기획서 반영 뒤 확인)

## 맥락

- 온보딩이 길었음: 챕터 4개, 첫 결과까지 30화면 안팎(약 8분), 결과 화면 7장, 첫 주 할 일 7일
- 홈에 개념이 많았음: 월급 플랜, 월급 나누기, 통장 역할, 월말 정리, 제안, 할 일, 목표, 비상금, 순자산, 일정, 배우자 활동. 대부분 앱 안에서만 쓰는 말
- 목표가 주인공이 아니었음: 홈의 주 버튼은 ‘월급 나누기’, 목표는 오른쪽 단 카드
- 앱이 답해야 할 질문은 세 가지로 좁힘
  1. 우리 목표, 얼마나 모았지?
  2. 이번 달 월급, 정한 대로 나눴지?
  3. 우리 자산, 지금 얼마지?

## 결정

### 1. 핵심 개념

| 개념 | 정의 | 사용자에게 쓰는 말 |
| --- | --- | --- |
| 목표 | 이름, 목표 금액, 기한, 모은 돈, 우선순위, 종류(우리 목표 / 내 목표, 9장). 비상금은 처음부터 있는 기본 목표(우리 목표) | 목표, 모은 돈, 우리 목표, 내 목표 [확인 필요] |
| 월급 분배표 | 월급을 어디에 얼마씩 보낼지 정한 표. 저금 줄(목표마다 1줄) + 쓰는 돈 줄(고정지출, 생활비, 용돈) + 남는 돈(자동) | 월급 분배표 [확인 필요] |
| 이번 달 월급 체크리스트 | 월급날마다 분배표로 만드는 할 일 목록. 보냈으면 체크 | 이번 달 월급 [확인 필요] |
| 자산 | 직접 적은 통장, 투자, 부동산, 대출 잔액. 순자산 = 자산 − 부채 | 우리 자산 |
| 챙길 날 | 생일, 기념일, 명절, 양가 행사를 모두 같은 종류로 직접 입력 | 챙길 날 |

- 저금 줄을 체크하면 그 금액이 바로 연결된 목표의 모은 돈에 더해짐. 체크를 풀면 다시 빠짐
- 쓰는 돈 줄(고정지출, 생활비, 용돈)은 체크만 하고 끝. 얼마를 썼는지는 묻지 않음
- 목표의 모은 돈 = 처음에 적은 이미 모은 돈 + 체크한 저금 + 직접 넣은 돈 − 꺼내 쓴 돈
- 순자산은 자산 탭에 적은 값으로만 계산. 목표의 모은 돈은 순자산에 따로 더하지 않음(실제 돈은 통장에 있고, 통장 잔액은 자산 탭에서) [확인 필요]

### 2. 월급 관리 방식(부부)

- 온보딩에서 한 번 물음: “각자 월급을 따로 관리해요” / “합쳐서 같이 관리해요”. 기본 ‘각자’. 설정에서 언제든 바꿈, 바꿔도 목표의 모은 돈은 그대로
- 각자: 분배표와 체크리스트가 사람마다 하나. 우리 목표는 같이 씀(두 사람 저금 줄이 같은 목표를 가리킴), 내 목표는 주인 분배표에만(9장). 배우자 체크리스트는 보기만 + ‘대신 체크’
- 합쳐서: 분배표와 체크리스트가 하나. 수입 = 두 사람 실수령 합, 누구나 체크. 용돈은 사람마다 1줄
- 배우자가 들어오기 전에는 어느 방식이든 내 월급만으로 분배표를 만듦. 들어오면 배우자가 자기 월급을 넣고, 합쳐서면 공동 분배표에 배우자 줄이 더해짐

### 3. 온보딩: 9화면, 약 2분

O-10 첫 화면 → O-03 내 이름 → O-06 초대(초대하기 → O-07 코드 시트 / 나중에 할게요) → O-11 결혼 상태 → O-21 목표 고르기 → O-23·O-24 1순위 목표 금액·기한 → O-30 월급 관리 방식 → O-31 월급(실수령 + 월급날) → O-50 월급 분배표 → O-60 결과 한 장 → 홈

- 결혼 상태는 남김. ‘준비 중이에요’면 목표 고르기에서 ‘결혼 비용’을 맨 앞에 추천하는 데만 씀. 예비부부 전용 모드와 결혼일 전환 흐름은 없앰
- 나이 확인: 생년월일 질문을 없애고 가입 약관 동의(A-05)에 “만 18세 이상이에요” 필수 체크 [확인 필요]
- 그 밖의 정보(결혼기념일, 생일, 사는 집, 자산·대출, 배우자 이름·월급)는 필요한 자리에서 물음
- 2026-10-26 고침: 결혼한 날·예정일(O-12)과 출생연도(O-13)를 다시 물어 질문 화면 11개(→ 10장)

### 4. 홈(탭 이름 ‘홈’) [확인 필요]

위에서 아래 순서: 인사 → 목표(1순위 크게 + 나머지 작게) → 이번 달 월급 체크리스트 → 우리 자산 → 다가오는 일정(최대 3개). 꼭 필요한 할 일은 맨 위 한 줄로만(초대 대기, 분배표가 비었음 등)

### 5. 탭

홈 / 목표 / 우리 자산 / 캘린더. 설정은 아바타(넓은 창)·톱니(좁은 창)

### 6. 한 달 흐름

- 월급날 0시에 그 달 체크리스트 생성(각자: 사람마다 자기 월급날, 합쳐서: 두 사람 중 늦은 월급날, 설정에서 바꿈)
- 다음 월급날 3일 전 오후 8시 “체크 안 한 항목이 n개 있어요” 알림 → 월말 확인(W-05)에서 체크하거나 ‘이번 달은 못 했어요’
- 새 체크리스트가 생기면 지난 달 체크리스트는 읽기 전용. 체크 안 한 저금 줄은 목표에 더하지 않고, 목표 예상 달성일이 늦어짐

### 7. 부부: 제안·승인 없음

- 누구나 바로 고침. 상대에게 알림 + 활동 기록, 고친 사람에게 Toast ‘되돌리기’
- 초대는 온보딩에서 바로 묻고, 나중에도 홈 할 일 한 줄·설정에서
- 공개 범위, 계정 삭제 규칙은 유지. 연결 해제는 10장에서 바꿈

### 8. 없애거나 미루는 것

| 없앰 | 대신 |

| 생활비 체크(W-03) | 없음 |
| 월말 정리 전체(W-04a~p: 지출 입력, 저축 확인, 정산 요약, 꼼꼼 모드, 다음 달 조정), 놓친 달·쉬어가기 | 월말 확인(W-05): 체크 안 한 항목만 |

| 재정 진단, 생활비 예산 보정, 변동 수입 기준 갱신 | 없음 |

### 9. 목표 종류(우리 목표, 내 목표)

- 날짜: 2026-10-26 추가 결정
- 맥락: 부부라도 한 사람만 모으는 돈(자기계발, 개인 취미 등)이 있음. 모든 목표를 같이 쓰면 이런 돈을 목표로 만들기 어렵고, 각자 모드에서 상대 분배표에 쓸모없는 줄이 생김
- 결정
  - 목표는 ‘우리 목표’(둘이 같이) 또는 ‘내 목표’(만든 사람 혼자). 비상금은 우리 목표로 고정. 혼자 쓰기에서는 구분 없이 모두 내 목표
  - 목표 추가에서 템플릿 다음에 “누구 목표예요?”(G-03e, “우리 둘” / “나”, 기본 없음) [확인 필요]. 온보딩 O-21에서 고른 목표는 모두 우리 목표(화면을 늘리지 않음)
  - 분배표: 우리 목표는 각자 모드면 두 사람 분배표 모두에(0원 줄은 체크리스트에 안 보임), 합쳐서면 1줄. 내 목표는 각자 모드면 주인 분배표에만, 합쳐서면 주인 이름을 붙인 줄. 추천 채움 순서 비상금 → 우리 목표 → 내 목표 [확인 필요]
  - 모은 돈·예상 달성일: 우리 목표는 두 사람 저금 줄 합, 내 목표는 주인 것만
  - 권한: 우리 목표는 둘 다 바로 고침 + 상대 알림 + 되돌리기. 내 목표는 주인만 고치고 배우자는 보기만, 변경 알림·활동 기록 없음(달성만 알림 [확인 필요]). 체크리스트 ‘대신 체크’는 다른 줄과 같음
  - 공개: 내 목표도 기본 전체 공개. 공개 범위 ‘합계만’이면 “개인 목표” + 금액만(아래 열린 점 정리)
  - 바꾸기: G-02 ⋯ “우리 목표로 바꾸기” / “내 목표로 바꾸기” [확인 필요]. 우리 → 내는 상대가 체크한 저금 줄과 상대가 직접 넣은 돈이 없을 때만
  - 화면: 목표 탭은 우리 목표 / 내 목표 / 배우자 목표(보기만) 묶음, 우선순위는 묶음마다. 홈 큰 카드는 우리 목표 1순위, 배우자 내 목표는 홈에 없음
  - 연결 해제가 확정되면 우리 목표, 내 목표 모두 지워짐
- 고른 대안: 담당 지정(옛 G-03e, 목표마다 담당자)은 목표를 같이 쓰면서 책임만 나눠 헷갈려 버림. ID G-03e는 ‘누구 목표’ 질문에 다시 씀
- 고친 기획서: 03, 06, 08, 09, 14, 16, 17, 18, 19, 20, 22, 25(S-13), 29, 31, 36
- 2026-10-26 열린 점 정리
  - 내 목표 공개는 ‘전체 공개’ / ‘합계만’ 두 가지(비공개 없음). 합계만이면 배우자 화면의 분배표·체크리스트 줄 이름도 “개인 목표”
  - 배우자는 상대 분배표의 상대 내 목표 줄 금액을 고칠 수 없음(그 줄만 잠금, 대신 체크는 가능)
  - 우리 → 내 바꾸기는 상대가 체크한 저금 줄과 상대가 직접 넣은 돈이 없을 때만(합쳐서도 ‘체크한 사람’ 기준)
  - 종류를 바꾼 목표는 새 묶음 맨 아래. G-01 맨 위 합계는 내가 볼 수 있는 목표만(배우자 내 목표는 전체 공개일 때만). W-01 ‘추천값으로 다시 채우기’(각자)의 우리 목표는 상대 줄을 뺀 만큼. 내 목표 변경은 배우자 활동 기록에 남기지 않음
  - 관리 방식 바꾸기의 분배표 합치기·나누기 규칙, 배우자 변경 알림의 묶기와 바로 알림·주간 요약 구분을 정함(→ 08 2장·4장, 20 ‘다시 계산되는 때’, 14)

### 10. 연결 해제: 나누지 않고 모두 지움

- 날짜: 2026-10-26 추가 결정
- 맥락: 자산 정리 안(공동 명의 자산·부채·목표를 항목마다 몫으로 나누고, 상대가 한 번 다르게 정하고, 14일 뒤 기본안 반반)은 화면 4개와 기한 알림이 필요했음. 목표의 모은 돈은 순자산에 더하지 않아 자산과 목표를 같이 나누면 같은 돈을 두 번 나누는 문제도 있었음. 앱은 돈을 옮기지 않으므로 실제 재산 분할은 앱 밖의 일
- 결정
  - 한 사람이 S-12에서 요청 → 상대 알림 → 상대가 확인하거나 14일이 지나면 확정. 요청자는 확정 전까지 취소
  - 요청 화면에 지워지는 것(목표, 분배표, 체크리스트, 자산·부채, 챙길 날, 활동·알림 기록) + ‘먼저 내보내기’(S-18)
  - 대기 중: 체크는 계속, 분배표·관리 방식·체크리스트 만드는 날 고치기 비활성
  - 확정: 두 사람 계정은 남고 부부 공간 데이터는 모두 지움(나누지 않음). 다음에 앱을 열면 혼자 쓰기로 온보딩 O-11부터 다시(O-06 초대 건너뜀) [확인 필요]. 자산은 새로 입력
  - 서버는 지운 데이터를 확정 후 30일 동안만 복구용으로 보관. 30일 안 두 사람이 다시 연결하면 복구, 지나면 영구 삭제 [확인 필요]
- 없앤 것: 자산 정리 안, 기본안(반반), 다르게 정리하기, 기본안 적용 예정 알림, 화면 S-12b, S-12e, S-12f
- 고친 기획서: 01, 03, 08, 09, 14, 16, 19, 22, 25, 26, 29, 31, 32, 33, 36, CLAUDE.md

### 10. 비슷한 부부와 비교(F-08)를 남기고 나이·결혼한 날을 다시 물음

- 날짜: 2026-10-26 추가 결정
- 맥락: 3장에서 생년월일·결혼일 질문을 없애 F-08 비교 그룹(연령대 × 결혼 단계)을 만들 수 없게 됨. F-08은 출시 후 무료 기능으로 남기기로 함
- 결정
  - 온보딩 O-11 다음에 O-12 결혼한 날·예정일(Q4 날짜, 준비 중만 ‘아직 미정이에요’), O-13 출생연도(Q4 연도, 월·일은 받지 않음)를 물음. 순서 O-10 → O-03 → O-06 (→ O-07) → O-11 → O-12 → O-13 → O-21 → O-23 → O-24 → O-30 → O-31 → O-50 → O-60. 질문 화면 9개 → 11개, 시간은 약 2분(2분 남짓) [확인 필요]
  - 합류한 배우자는 P-03a에서 출생연도만. 결혼한 날은 부부 공간 값이라 다시 묻지 않음
  - 결혼 단계(예비, 신혼 첫해, 2~3년차, 이후)는 묻지 않고 계산(→ 계산·배분 7-1). 예비부부 모드, 결혼일 전환 흐름은 여전히 없음
  - 18세 확인은 그대로 A-05 체크. 출생연도는 비교 통계용
  - ‘했어요’면 결혼한 날로 캘린더 결혼기념일 챙길 날을 자동으로 하나 만듦 [확인 필요]
  - F-08 그룹 = 연령대 × 결혼 단계, 필터는 월 수입 구간만(사는 집, 맞벌이는 묻지 않아 뺌)
- 고른 대안: F-08을 결혼 상태 × 월 수입으로만 비교 → 비슷한 부부라고 보기 어려워 버림
- 고친 기획서: 01, 03, 06, 08, 09, 10, 12, 16, 18, 23, 24, 25, 29, 31, 32, 35

## 고른 대안

- 월급 나누기를 고급 기능으로 남기기: 핵심 흐름과 같은 일을 두 이름으로 하게 돼 헷갈림이 남아 버림
- 지출 금액 입력(월말 합계, 예산 자동 추정): ‘얼마 썼는지’보다 ‘정한 대로 나눴는지’가 핵심이라 버림
- 재기획 문서를 따로 두기: 기획서가 정본이라 같은 내용이 두 곳에 생겨 버림. 이 ADR은 결정과 이유만

## 결과
