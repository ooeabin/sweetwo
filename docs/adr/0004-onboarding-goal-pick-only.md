# ADR 0004: 온보딩에서 목표는 고르기만, 금액과 기한은 홈에서

- 날짜: 2026-11-02
- 상태: 확정(ADR 0003의 3장 온보딩 순서를 고침)

## 맥락

- ADR 0003 온보딩은 목표 고르기(O-21) 뒤에 1순위 목표의 금액과 기한(O-23, O-24)을 물었음. 목표에 따라 2~5화면이 더 붙어 온보딩 길이가 들쭉날쭉했음(내 집 마련 3화면, 여행 4화면)
- 금액을 모르는 사람이 많아 ‘잘 모르겠어요’ 추정값으로 시작하는 경우가 잦았음
- 2순위부터는 이미 금액 없이 만들고 홈 할 일, 목표 카드의 ‘금액 정하기’로 받고 있었음

## 결정

- 온보딩은 목표를 고르기만 함. 1순위도 2순위부터처럼 금액 없이 만듦
- 순서: O-10 → O-03 → O-06 (→ O-07) → O-11 (→ O-12) → O-13 → O-21 → O-30 → O-31 → O-50 → O-60 → 홈
- O-23·O-24의 목표별 질문은 그대로 두고, 홈 할 일 5번 ‘목표 금액 정하기’와 목표 카드 ‘금액 정하기’(G-03b → G-03c)에서 씀
- O-21의 ‘+ 직접 만들기’는 온보딩에서 뺌(이름부터 물어야 해서). 목표 탭 G-03a에서 만듦
- O-50 분배표: 금액이 없는 목표의 저금 줄은 0원(기존 규칙). 비상금만 추천값이 들어감
- O-60 결과: 금액을 정한 1순위 목표가 있으면 그 목표, 없으면 비상금 기준으로 언제 이루는지 보여 줌
- 예전 O-23·O-24에 멈춰 있던 사람은 다시 열면 O-30부터

## 고른 대안

- 목표 통째로 빼기(온보딩은 월급과 분배표만): 앱이 ‘목표 중심’인데 첫 화면부터 목표가 없어짐. 고르기는 한 화면이라 남김
- 건너뛸 수 있게만(‘나중에 정할게요’): 길이 문제는 그대로

## 결과

- 온보딩 화면 수가 목표와 상관없이 같아짐(결혼 상태에 따라 9~10화면)
- 첫 결과(O-60)가 대부분 비상금 기준이 됨. 1순위 목표의 금액은 홈에서 바로 정하도록 할 일 맨 위 쪽(5번)에 뜸
