# ADR 0007: 목표를 월급 체크리스트의 저금 항목 아래로(목표 탭 없앰)

- 날짜: 2026-11-08
- 상태: 확정(2026-11-08 사용자 답). ADR 0003 1장 ‘목표’와 ADR 0004·0005의 목표 단계를 고침. 2026-11-09 아래 ‘고침’ 절로 일부 고침(첫 저금 빈 줄, 만들 때 이미 모은 돈, 파트너 것 보기만, 말)

## 맥락

- 같은 것이 두 이름으로 두 곳에 보였음: 목표 탭의 ‘목표’와 월급 계획·체크리스트의 ‘저금 줄’. 목표를 만들면 저금 줄이 생기고, 저금 줄을 체크하면 목표에 쌓이는 구조라 사용자가 둘을 헷갈림(2026-11-08 사용자 판단)
- 앱이 매달 하는 일은 월급 체크리스트. 목표는 그중 저금 항목이 어디까지 모였는지를 보여 주는 보조 정보면 충분함

## 결정(2026-11-08 사용자 답)

### 1. 개념

| 전 | 후 |
| --- | --- |
| 목표(이름, 목표 금액, 기한, 모은 돈, 우선순위, 우리 목표 / 내 목표, 템플릿 22종, 사진) | 없음. 체크리스트 항목 종류 중 **저금**에 ‘목표 금액’(+ 선택 기한)을 붙일 수 있음 |
| 저금 줄(목표마다 1줄) | **저금 항목**: 이름 + 매달 금액 + (선택) 목표 금액·기한. 목표 금액이 있으면 줄에 진행 막대 |
| 목표의 모은 돈 = 이미 모은 돈 + 체크한 저금 + 직접 넣은 돈 − 뺀 돈 − 꺼내 쓴 돈 | 저금 항목의 모은 돈 = 그 항목을 체크한 금액의 합(체크 풀면 뺌, ‘못 함’은 더하지 않음) |

- ‘목표’라는 말은 저금 항목 안의 ‘목표 금액’으로만 씀. ‘우리 목표’, ‘내 목표’, ‘목표 탭’은 없앤 말
- 남기는 목표 기능: **달성 축하**(모은 돈이 목표 금액에 닿으면 축하 화면 1회)
- 없애는 목표 기능: 넣기·빼기와 이미 모은 돈(G-02a, G-03d), 꺼내 쓰기(G-02b, Y-08 목표 부분), 우리 둘 / 내 것 구분(G-03e), 템플릿 22종과 지정 그림·올린 사진(O-21, G-03a·b, G-02p), 우선순위 화면(G-06), 수익률 시뮬레이션

### 2. 탭

- 하단 탭(좁은 창)과 사이드바(넓은 창): **홈, 월급, 우리 자산, 캘린더**. 목표 자리에 ‘월급’
- 월급 탭 = 이번 달 체크리스트(W-02) + 월급 계획(W-01) + 저금 항목 상세(달성 축하 포함). + 버튼 = 항목 추가

### 3. 온보딩

- 목표 고르기(O-21)를 뺌. 온보딩은 월급까지(O-10 → O-03 → O-06 (→ O-07) → O-11 (→ O-12) → O-13 → O-30 → O-31 → O-32 → O-60 → 홈)
- 홈에서 저금 항목 추가를 가볍게 권함(저금 항목에 목표 금액이 하나도 없을 때 한 줄)

### 4. 세부(2026-11-08 사용자 답)

- 비상금 없앰: 처음부터 있던 기본 목표 ‘비상금’과 그 목표 금액 계산((고정지출 + 생활비) × 3)을 없앰. 온보딩이 끝나면 저금 항목 없이 시작하고, 홈에서 추가를 권함
- 기한은 선택: 목표 금액을 정할 때 기한도 정할 수 있음. 있으면 “매달 OO원이 필요해요” 안내와 캘린더 ‘목표 기한’ 일정, 없으면 둘 다 없음
- 달성 뒤 물어봄: 축하 → “이 저금 항목을 어떻게 할까요?” ‘계속 모을게요’(목표 금액·기한만 지우고 줄은 그대로) / ‘그만할게요’(다음 체크리스트부터 줄 없음, 모은 기록은 남김) [확인 필요]
- 각자 모드는 각자 따로: 저금 항목은 그 사람 월급 계획에만. 두 사람이 같이 모으려면 각자 항목을 만듦. 합쳐서 모드는 공동 월급 계획에. 파트너 체크리스트는 지금처럼 보기만

### 5. 데이터

- 출시 전이라 스테이징 데이터만. 이미 있는 목표는 그 저금 줄에 목표 금액·기한을 옮기고 모은 돈은 체크 합으로 다시 셈. 비상금 목표는 목표 금액 없는 저금 항목으로 남기거나(체크한 기록이 있으면) 지움
- 스키마는 추가만 규칙: 목표 테이블은 그대로 두고 새 코드에서 쓰지 않음. 지우는 것은 2단계(쓰는 곳 0 확인 뒤 다음 마이그레이션)
- 위젯·홈 카드·알림에서 ‘목표’를 보여 주던 곳은 목표 금액이 있는 저금 항목으로

## 고른 대안

- 목표 탭 유지 + 이름만 바꾸기: 두 곳에 같은 것이 보이는 문제가 그대로라 고르지 않음
- 탭 3개(홈, 우리 자산, 캘린더): 매달 하는 일인 체크리스트가 탭에 없어 고르지 않음

## 고침(2026-11-09, 기획·UX 검토 뒤 사용자 결정)

검토(첫 사용자가 저금 0줄로 시작, 이미 모은 돈을 넣을 길이 없음, 각자 모드 권한이 화면마다 다름)를 받아 위 결정 일부를 고침.

1. **첫 저금**: 온보딩은 짧게 그대로. 체크리스트(첫 체크리스트 포함)와 홈 H-03 저금 묶음에, 내 저금이 없으면 빈 줄 “+ 저금 추가 (남는 돈 {n})” [확인 필요] → W-11. 조건은 사람마다 ‘내 저금이 없을 때’(각자 = 내가 주인인 것, 합쳐서 = 공동 월급 계획의 것)라 합류한 파트너도 봄. 파트너에게 저금이 있으면 “{파트너}님처럼 나도 모을 곳을 만들어 볼까요?” [확인 필요]. 3장 ‘홈에서 저금 항목 추가를 가볍게 권함(목표 금액이 하나도 없을 때 한 줄)’과 H-02 회색 제안 문장은 이 줄로 바꿈. O-60 셋째 줄도 이 줄을 가리킴
2. **이미 모은 돈은 만들 때만**: W-11c(목표 금액) 화면 아래 선택 칸 “이미 모은 돈이 있어요” [확인 필요]. 시작값으로 저장(`goal.start_saved`, 앱이 나중에 못 고침)하고 모은 기록 맨 아래(가장 처음 기록) ‘시작할 때 모은 돈’ [확인 필요]. **모은 돈 = 시작할 때 모은 돈 + 체크한 저금 합**(1장 표의 ‘후’ 고침). 매달 넣기·빼기, 꺼내 쓰기는 없앤 그대로
3. **각자 모드 파트너 것은 모두 보기만**: 파트너 월급 계획(W-01 파트너 탭, 쓰는 돈 줄 포함), 체크리스트(이미 보기만), 저금(W-10). 탭 맨 위 회색 한 줄 “{파트너}님 월급 계획이에요 / 체크리스트예요 / 저금이에요. 보기만 할 수 있어요” [확인 필요], 잠긴 줄은 자물쇠, 체크한 줄은 취소선 대신 흐린 글자 + 체크 표시. 서버도 막음(save_split `not_owner`). ‘제안·승인 없이 누구나 바로 고침’은 같이 쓰는 것(합쳐서 모드, 공동 명의 등)에만
4. **말**: 사용자에게는 ‘저금 항목’ 대신 ‘저금’(‘+ 저금 추가’, 홈 ‘저금’, ‘저금 보기’). ‘월말 확인’과 캘린더 ‘월급 확인’은 ‘월급 전 확인’ 하나로. 축하 머리글 ‘목표 달성’ → “다 모았어요” [확인 필요]. 공개 범위는 3단계(모두 보여 주기 / 금액만 보여 주기 / 숨기기, 자산·부채. 저금은 월급 계획에 늘 보여서 앞 두 단계)
5. **오프라인 체크**: 막음(지금 동작 그대로). 기획서·FAQ를 같게 맞춤

나중(기획서 20·19 ‘다음 개선’ 목록): 묶음 ‘모두 보냈어요’, 월급 탭 저금 목록, 저금 금액 바로 바꾸기, 첫 주 할 일 순서·순위 줄 숨김, P-04 결과 요약 + 확인, S-11f 미리보기, W-12a 선택지 설명 + ‘목표 금액을 새로 정할게요’
