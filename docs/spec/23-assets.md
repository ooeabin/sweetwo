# 우리 자산

## 흐름 요약

우리 자산 메뉴(아이콘 wallet) 첫 화면 = 한눈에(F-01). 자산·부채 목록(F-02)에서 추가(F-03)·상세 수정(F-04), 한눈에의 ‘이번 달 계획’ 카드 또는 이번 달의 ‘월 수입·지출 수정’에서 F-05, 수입 기간 변경은 F-05f → F-07c. 이번 달은 할 일, 우리 자산은 현황 보기·기록, 캘린더는 날짜(자산 만기일은 캘린더에 읽기 전용으로 표시, 누르면 F-04). 사실값·배분 결정 구분과 알림 → 핵심 규칙 › 부부·제안·권한. 앱 틀 → 화면 설계 › 이번 달, 여기서는 본문 영역만 그림.

예외·오류

- 빈 상태: F-01·F-02 모두 “자산을 하나씩 적어볼까요?” + 자산 추가(틀 → 공통 › 공통 상태)
- 부채 없음: 부채 합계 칸 “0원”, F-02 부채 탭은 “갚을 돈이 없어요” + “+ 부채 추가”. 자산만 있고 부채 없는 것은 정상 상태라 할 일·안내 없음
- 배우자 미합류·혼자 쓰기: 배우자 합계 줄 없음
- 순자산이 음수면 “−1,200만 원”처럼 “−”를 붙이고 그래프에 0선. 합계가 999억 원을 넘으면 “999억+”(→ 공통 6장)

- 배분(매달 비상금에 모을 돈)은 바뀌지 않음: 잔액이 기준에 못 미치면 저축 가능 금액에서 먼저 채움, 기준에 닿으면 멈춤
