# 우리 자산

## 흐름 요약

우리 자산 탭(아이콘 wallet) 첫 화면 = 한눈에(F-01). 자산·부채 목록(F-02)에서 추가(F-03)·상세 수정(F-04). 직접 적은 통장, 투자, 부동산, 대출 잔액으로 순자산 = 자산 − 부채를 보여 줌. 앱의 세 질문 중 ‘우리 자산, 지금 얼마지?’에 답하는 탭. 목표는 목표 탭, 월급은 월급 체크리스트, 날짜는 캘린더(자산 만기일은 캘린더에 읽기 전용으로 표시, 누르면 F-04). 누가 고쳐도 바로 반영 + 상대 알림(→ 핵심 규칙 › 부부·권한). 앱 틀 → 홈, 여기서는 본문 영역만 그림. 결정 이유 → `docs/adr/0003-replan-goal-checklist.md`.

- 순자산은 이 탭에 적은 값으로만 계산. 목표의 모은 돈은 순자산에 따로 더하지 않음(실제 돈은 통장에 있고, 통장 잔액은 이 탭에서 적음) [확인 필요]
- 금액은 직접 고칠 때만 바뀜. 월급 체크리스트 체크, 목표 넣기·꺼내 쓰기는 자산 금액을 바꾸지 않음 [확인 필요]

예외·오류

- 빈 상태: F-01·F-02 모두 “가진 돈을 적으면 순자산을 보여 드려요” + “가진 돈 추가하기” → F-03a(틀 → 공통 › 공통 상태). 홈 H-04 빈 상태와 같은 문구
- 부채 없음: 부채 합계 칸 “0원”, F-02 부채 탭은 “갚을 돈이 없어요” + “+ 부채 추가”. 자산만 있고 부채 없는 것은 정상 상태라 할 일·안내 없음
- 배우자 미합류·혼자 쓰기: 배우자 합계 줄 없음
- 순자산이 음수면 “−1,200만 원”처럼 “−”를 붙이고 그래프에 0선. 합계가 999억 원을 넘으면 “999억+”(→ 공통 6장)

- 배우자 명의 항목: 값 비활성, 누르면 “예빈님 항목이라 볼 수만 있어요”. 합류 전 대신 입력한 항목은 입력한 사람이 수정

## F-04b\~d 팔았어요

> 화면 그림: F-04b 받은 금액, F-04c 받은 통장, F-04d 결과 (그림은 기획서 페이지 사본에 있어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 받은 금액 | “받은 금액은 얼마예요?” | Q3. 통장에 실제 들어온 금액 |
| 2 | 일부만 팔았어요 | “일부만 팔았어요” | “남은 평가금액은요?” 칸 추가. 자산은 남은 평가금액으로 유지 |
| 3 | 받은 통장 | 내 통장·공동 통장 목록 | Q1, 고르면 바로 F-04d. 그 통장 금액 + 받은 금액(자산끼리 옮긴 돈, 수입 아님) |
| 4 | 결과 | “입출금 통장 +1,130만 원” / “실현 손익 +150만 원” | 실현 손익 = 받은 금액 − 원금, 원금 없으면 줄 없음. ‘확인’ → F-02, 판 자산은 ‘매도 완료’로 보관(목록에서 빠짐, 과거 순자산 기록 유지) |

- 저장 즉시 반영 + 예빈에게 알림(비공개 항목은 없음)

## F-08 비슷한 부부와 비교 (출시 후)

출시 후 무료 기능, MVP 밖. 그룹(연령대 × 결혼 단계), 지표, 안전장치, 참여 규칙은 → 핵심 규칙 › 계산·배분 7장. 여기서는 화면과 문구만. 2026-10-26 결정으로 다시 넣음(출생연도 O-13·P-03a, 결혼한 날·예정일 O-12를 다시 물음, → ADR 0003).

> 화면 그림: F-08 참여 전(2단계부터), 진입 줄과 참여 안내, 한 사람만 켠 상태 / F-08 보는 중, 넓은 창과 좁은 창 (그림은 기획서 페이지 사본에 있는 재기획 전 예시예요. 지표 카드가 5개, 진입 줄이 재정 진단 아래인 옛 형태라 구현할 때 이 문서의 요소 표가 기준이에요.)

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 진입 줄 | F-01 맨 아래 “비슷한 부부와 비교해 볼까요?” | 배우자 미합류·혼자 쓰기면 줄 숨김. 1단계(공공 통계)는 동의 없이 바로 F-08, 2단계(앱 데이터)부터 참여 중이면 F-08, 아니면 2번 [확인 필요] |
| 2 | 참여 안내 | “이름 없이 통계에 들어가요. 두 분 모두 켜야 볼 수 있어요”, “언제든 설정에서 끌 수 있어요” + ‘참여할게요’ / ‘괜찮아요’ | 2단계부터. 한쪽만 켜면 “예빈님이 켜면 볼 수 있어요”, 카드 자리에 “비교 카드는 예빈님 동의 뒤에 보여요” |
| 3 | 그룹 표시 | “30대 초반, 신혼 첫해 부부 1,240쌍과 비교했어요” | 그룹을 넓혔으면 “30대 초반 부부 전체와 비교했어요”. 1단계는 “공공 통계 기준” 배지 + “30대 가구와 비교했어요”, 보조 “앱 데이터가 모이면 비슷한 부부로 바뀌어요”. 1단계는 연령대(10세 구간)만, 결혼 단계는 2단계부터 |
| 4 | 더 좁혀 보기 | 칩: 월 수입 구간 | 2단계부터(1단계는 숨김). 100쌍 미만이면 칩 비활성 + “아직 비교할 부부가 적어요” |
| 5 | 지표 카드 4개 | 순자산, 월 저금액, 저금 비율, 부채 비율 | 카드마다 Distribution: 종 모양 곡선을 10% 칸으로 나눈 그림, 초록(투자 계열색) 한 가지. 상위로 갈수록 진하고 우리 칸만 진하게, 곡선 위 검정 점과 “우리” 알약 + 축 가운데 ‘중간’ 글자(곡선 가운데 아래, 중앙값 선 없음). 와이어프레임은 옛 형태(10% 칸 띠), 다시 그리지 않음 |
| 6 | 위치 문구 | 상위 50% 안 “비슷한 부부 가운데 상위 30% 안이에요” / 아래 “중간보다 조금 아래예요”, “아직 시작 단계예요” | 10% 구간만, 정확한 순위와 점수 없음 |
| 7 | 중앙값 | “비슷한 부부 중앙값은 월 120만 원이에요” | 금액 가리기 켜면 우리 값과 중앙값 모두 “•••” |
| 8 | 기준 안내 | “지난 월급 체크리스트 기준, 매달 1번 새로 계산해요” [확인 필요] | 보조 “비공개 항목은 계산에서 빠졌어요” |

- 문구는 사실만. “부족해요”, “뒤처졌어요” 같은 압박 문구 금지(→ 브랜드 1장, 공통 6장)
- 찬우 화면과 예빈 화면은 같은 부부 값을 보여 줌. 배우자끼리 비교 없음
- 통계 참여 끄기는 설정 S-18

예외·오류

- 체크리스트를 한 번도 끝내지 않았으면 월 저금액, 저금 비율 카드 대신 “첫 월급 체크리스트를 마치면 보여 드려요” [확인 필요]
- 계산 전이거나 실패하면 지난달 결과 + “지난달 기준이에요”
- 그룹 부족(전체 그룹도 100쌍 미만이고 공공 통계에도 없는 지표): 그 카드 자리에 “비슷한 부부가 더 모이면 보여 드려요”. 모든 카드가 그러면 진입 줄 숨김
- 순자산이 음수면 “−”를 붙여 표시하고 분포 그림에 0선
