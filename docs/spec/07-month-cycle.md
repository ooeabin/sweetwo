# 월 사이클

기준일 0시에 월급 플랜이 생기고, (통장을 나눠 쓰는 부부만) 월급 나누기 → (선택) 생활비 체크 → 월말 정리로 한 사이클을 닫음. 매일 기록 없음.

## 1. 기준일과 사이클

- 기준일: 사용자 선택, 기본 = 두 사람 월급일 중 늦은 날. 결과 화면(O-63/O-66)·설정 S-11d에서 변경. S-11d 변경은 배분 결정이라 제안(미합류·혼자 쓰기면 즉시). 월급일은 각자 등록
- 그 달에 없는 날(29\~31일)이면 말일. 월급일도 같음
- 월급날이 주말·공휴일이면 직전 영업일로 앞당겨 표시(W-02, 캘린더 돈 날짜). 표시만 바뀌고 기준일·사이클은 그대로. 설정 S-11d에서 끌 수 있음. 공휴일은 특일 API holiday 표
- 모든 날짜·사이클 경계·알림 시각·방해 금지 시간은 한국 시간(KST) 기준, 기기 시간대는 무시(해외에서 써도 같음)
- 사이클 = 기준일 0시 \~ 다음 기준일 전날 자정
- 이름: 플랜 ‘{기준일의 월}월 월급 플랜’, 정리 ‘{같은 월}월 월급 플랜 정리’(“10월 월급 플랜 정리 끝!”). 달력의 월과 사이클이 다름을 이름으로 표시. ‘이번 달 월말 정리’·‘월말 정리 주간’ 문구 쓰지 않음
- 기준일이 바뀌면(배우자 합류·월급날 변경·S-11d 변경) 다음 사이클을 기다리지 않고 현재 사이클부터 조정: 현재 사이클 끝 = 새 기준일 전날, 현재 사이클의 안 나눈 돈(아직 체크 안 한 것)만 새 기간에 맞춰 재계산, 체크한 나누기는 그대로. 조정된 사이클이 15일 미만이면 다음 사이클과 합침
- 배우자 사이클 중간 합류: 이번 사이클은 임시 플랜 유지, 배우자 입력값으로 안 나눈 돈만 재계산. 새 플랜은 다음 기준일부터

## 2. 한 달 흐름

| 시점 | 앱 동작 | 사용자 행동 | 예상 소요 |
| --- | --- | --- | --- |
| 기준일 | 0시에 그 시점 값(적용된 제안·연간 이벤트 포함)으로 ‘{월}월 월급 플랜’ 생성, 오전 9시 알림(월급 나누기를 쓰면 월급날 “오늘은 월급 나누는 날이에요” → W-02 하나로 대체, 안 쓰면 “이번 달 월급 플랜이 나왔어요” → W-01). 통장별 월급 나누기 체크리스트(W-02), 행마다 날짜 = 각자 월급날 | 플랜 확인, 월급 나누기 완료 체크 | 2분 |
| (선택) 사이클 중간일 | 생활비 체크(W-03)를 켠 경우만 질문 | “여유 있어요” / “딱 맞아요” / “넘칠 것 같아요” 중 1탭 | 10초 |
| 월말 정리 기간 (다음 기준일 3일 전 \~ 전날) | 3일 전 오후 8시 알림, 전날 오후 8시 리마인드. 월말 정리(W-04) | 지출 입력(W-04j), 저축 확인(W-04k), (받은 제안·함께 정하기가 있으면) 다음 달 조정(W-04h), 정산 요약(W-04g). 통장 잔액 입력은 꼼꼼 모드에서만 | 5\~10분 |
| 다음 기준일 | 적용일이 된 제안을 묶어 다시 계산 후 적용, 다음 달 플랜 생성 | — | — |

## 3. 플랜 생성

- 기준일 0시에 그 시점 값으로 생성, 따로 확인하는 단계 없음. 월말 정리 없이 다음 달이 돼도 계획값으로 생성. 생성 중 도착한 편집 처리 → 기술·운영 › 동기화 5장
- 개인 통장으로 나누는 돈은 W-02 목록에서 제외. 통장 잔액은 묻지 않음
- ‘임시’ 배지: 배우자 미합류 또는 추정값(배우자 수입·예식일 등)이 있을 때만. 혼자 쓰기는 배지 없음
- 미합류 플랜: 배우자 수입 추정값(구간 중간값) 있으면 그 값으로 부부 플랜 + O-52에서 고른 분담 방식, ‘추정’ 표시. 없으면 ‘내 몫’ 기준 = 내 수입 − 내 용돈 − 공동 지출 × 내 분담 비율(반반, ‘버는 만큼’ 계산 불가). 배우자 용돈은 내 용돈과 같은 금액으로 가정(P-07에서 본인 입력). 합류 시 P-11에서 재계산

### 3-1. 첫 사이클

- 온보딩 결과 직후 ‘이번 달 남은 기간 플랜’으로 바로 시작(예비부부도 같음)
- 첫 플랜 금액 기본값 = 월 배분액 × 남은 일수 ÷ 사이클 일수. O-66 “이번 달 옮길 수 있는 돈”에서 1회 조정 가능(공동 생활비는 유지, 목표자금·비상금을 같은 비율로 증감)
- 남은 기간 15일 미만이면 첫 월말 정리를 건너뛰고 다음 사이클과 합침(첫 정리 = 다음 사이클 끝)
- 첫 월말 정리 기준선 = O-63에서 받은 통장별 잔액. O-63을 건너뛰었으면 기준선 없이 W-04k 납입액부터 누적

### 3-2. 생활비 체크 (선택)

- 기본 꺼짐, 부부 단위. 한 사람이 설정 > 알림에서 켜면 둘 다 카드·알림, 한 명이 답하면 둘 다 카드 사라짐
- 체크일 = 기준일 + 사이클 길이의 절반(반올림), 알림은 그날 오후 8시
- ‘내 용돈에서’(W-03c)는 즉시 적용 + 상대 알림, 나머지 선택은 월말 정리에 반영
- 결과는 생활비 예산 보정에 쓰지 않음(보정은 월말 정리 3개월 평균)

## 4. 월말 정리

- 기간 = 다음 기준일 3일 전 \~ 기준일 전날. 화면에 기간 이름 노출 없음, 화면 문구 “{월}월 월급 플랜 정리할 때예요”
- 한 사람이 해도 완료. 정리는 한 번에 하나만 진행(동시 진입 → 기술·운영 › 동기화 3장)
- 끝낸 뒤 7일 안에는 ‘정리 고치기’로 다시 열 수 있음, 고치면 결과 재계산. 다음 기준일이 지난 뒤 고치면 이미 생긴 다음 플랜은 안 나눈 돈(체크 안 한 것)만 다시 계산
- 반영 순서(기본): 실제 수입(W-04j 소득 확인, 변동 수입자는 W-04a2) → 지출 입력(W-04j) → 저축 확인(W-04k, 연결 자산 금액에 ‘추정’으로 더함) → (조건) 다음 달 조정(W-04h) → 정산 요약(W-04g) → 목표 보유액 재계산 → 순자산·재정 진단 재계산. 꼼꼼 모드는 W-04k 뒤에 통장 잔액 입력(한 화면 목록) → 목표에서 쓴 돈 확인(차액만) → 비상금 사용(잔액 감소 시만) → 투자 평가액(분기 1회, 건너뛰기 가능) → 대출 잔액 확인(월 상환액만큼 자동 차감) 추가, 맞춘 잔액이 ‘추정’ 값을 대체. 우리 자산 메뉴에서 같은 금액 재질문 없음
- 미달·초과·목표 사용 처리 → 핵심 규칙 › 계산·배분
- 변동 수입 실제(W-04a2): 수입 당사자에게만 질문. 배우자가 정리하면 당사자에게 1문항 카드(H-02), 기준일 전날까지 응답 없으면 기준 수입대로 들어온 것으로 처리. 그 뒤 응답은 ‘정리 고치기’(7일 이내)로 반영
- 함께 모드 = 두 계정이 동시에 접속해 진행(웹 가능). 다음 달 조정(W-04h)에서 바꾼 값은 바로 확정(‘함께 정하기’ 항목 포함, 표시 해제)
- 혼자 정리 = 바뀐 값 전체가 ‘월말 정리 제안’ 묶음 1건(적용 규칙 → 핵심 규칙 › 부부·제안·권한)
- 예비부부 월말 확인(H-P7): 같은 기간·알림. 결혼 비용 지출(W-04j) + 결혼 자금 저축(W-04k) + 정산 요약(W-04g)만(1\~2분). 결혼 준비 통장 잔액은 꼼꼼 모드에서

## 5. 놓친 달·쉬어가기

기준일이 지나도 정리하지 않았으면 이번 달 맨 위 ‘지난달 정리’. 새 플랜은 기준일 0시에 그대로 생성.

| 선택지 | 처리 |
| --- | --- |
| 지금 정리하기 | 기본 모드는 W-04j·W-04k에 그달 쓴 돈과 넣은 돈을 적고 W-04g. 꼼꼼 모드는 오늘 잔액 기준, W-04b에 ‘이번 사이클에 옮긴 돈 빼기’ 버튼(체크된 나누기 금액 자동 차감). 새 플랜이 이미 있어 W-04h 이름 = ‘이번 플랜 조정’, 바뀐 값은 안 나눈 돈 재계산. 응답 규칙은 평소와 같음, 함께 모드면 즉시 확정. 이 달은 생활비 실제·보정 평균(3개월) 계산에서 제외 |
| 이번 달은 쉬어가기 | 기본 모드는 W-04j·W-04k에 그달 합계만 적고 넘어감. 꼼꼼 모드는 오늘 잔액(W-04b 목록)을 새 기준선으로, W-04c는 기록 확인 1화면만, 쉰 기간 목표자금 통장 증감은 누적으로 나눈 비율대로 목표에 배분, 저축액은 합계로 한 번만 표시. 쉰 달은 미달·지연 계산에서 제외 |

- 2개월 이상 밀리면 ‘이번 달은 쉬어가기’만 제안
- ‘쉬어가기’는 놓친 달 전용. 미달 처리는 ‘이번 달만 넘어가기’

## 6. 월 플랜 상태

| 상태 | 바뀌는 조건 |
| --- | --- |
| 생성 | 기준일 0시(첫 사이클은 온보딩 결과 직후 남은 기간 플랜) |
| 월급 나누는 중 | 첫 월급 나누기 |
| 정리 기간 | 다음 기준일 3일 전 |
| 정리 완료 | 한 사람이 월말 정리 끝. 이후 7일간 수정 가능 |
| 쉬어감 | 놓친 달에 ‘이번 달은 쉬어가기’ 선택 |

- 월급 나누기 없음(미합류·혼자 쓰기·통장 하나, W-02 대상 아님): ‘월급 나누는 중’ 없이 생성 → (선택) 생활비 체크 → 정리 기간 → 정리 완료
- 첫 사이클 15일 미만이면 정리 기간·정리 완료를 다음 사이클 끝으로 합침
- 지난 플랜은 읽기 전용
- 연결 해제 대기 중 기준일이 오면 지난 플랜 그대로 연장(새 제안 적용 없음), 월급 나누기·기록·월말 정리 가능(→ 핵심 규칙 › 부부·제안·권한 1장). 해제 확정 시 사이클 종료
