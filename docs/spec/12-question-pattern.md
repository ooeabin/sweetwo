# 질문 화면 패턴

‘한 화면 한 질문’ 화면의 공통 틀과 입력 패턴 7가지, 금액·목록 입력 규칙의 정본(질문 화면 밖 금액 칸도 같은 규칙). 화면 탭은 ‘패턴’ 칸에 Q1\~Q7만 적고 다른 점만 정의함.

| 패턴 | 이름 | 쓰는 곳 (예) | 넘어가는 방식 |
| --- | --- | --- | --- |
| Q1 | 단일 선택 | O-04·O-06·O-11·O-15·O-16·O-18·O-38b·O-52·O-53 | 고르면 0.3초 뒤 자동 다음 |
| Q2 | 다중 선택 칩 | O-36·O-41·O-44·O-35b, O-21(분류별 카드 변형) | 주 버튼 ‘다음’ |
| Q3 | 금액 입력 | O-19a·O-19c·O-23·O-31·O-37·O-38·O-39·O-42·O-45·O-47·O-51 | 주 버튼 ‘다음’ |
| Q4 | 날짜·월 선택 | O-12·O-13·O-19d·O-24·O-32 | 주 버튼 ‘다음’ (연도만 받으면 4자리 입력 시 자동). 생년월일(O-13, P-04)은 3열 휠, 월급날(O-32)은 숫자 판 |
| Q5 | 짧은 텍스트 | O-03·O-05, O-23의 이름 질문 | 주 버튼 ‘다음’ |
| Q6 | 목록 입력 | O-35·O-23 연간 고정 지출·O-63 통장 잔액·W-04j 지출 입력·W-04k 저축 확인·W-04b·W-04e | 주 버튼 ‘다음’ |
| Q7 | 안내·확인 | 파트 시작(O-{파트}0), 결과 직전(O-61\~O-67), P-04·P-10 확인 | 주 버튼 (O-61은 자동) |

## 공통 틀

> 화면 그림: 질문 화면 공통 틀 (그림은 기획서 페이지 사본에 있어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 진행 표시 | 6칸 막대(숫자·파트 이름 없음) | 필수 파트 6칸(첫 주로 미루는 파트 4 제외, 내부 파트 번호 0\~6은 그대로). 끝난 파트 채움, 현재 파트 옅게. 첫 주 할 일은 카드 안 화면 수, 단독 질문은 숨김 |
| 2 | 뒤로 | < (꺾쇠) | 직전 화면을 저장된 답과 함께 열기. O-03에서는 숨김 |
| 3 | 나중에 할게요 | “나중에 할게요” | 온보딩은 파트 단위: 파트 5에만 표시, 누르면 기본값으로 계산하고 이번 달 ‘할 일’ 등록. 첫 주 할 일·단독 질문은 질문 단위: 오른쪽 ‘닫기’(답 저장, 할 일 유지) |
| 4 | 제목 | 질문 1줄, 해요체 | 28px(title-1) 굵게. {나}·{배우자}는 O-03·O-05 호칭. 최대 2줄 |
| 5 | 보조 설명 | ‘왜 묻는지’ 1줄 | 꼭 필요할 때만. 회색 작은 글씨 |
| 6 | 입력 영역 | 패턴 Q1\~Q6 | 열리면 첫 입력에 자동 포커스 |
| 7 | 보조 링크 | “잘 모르겠어요” / “해당 없어요” / “없어요” | 화면당 0\~1개. 잘 모르겠어요 = 추정값 + 할 일 등록, 해당 없어요·없어요 = 빈 답 저장 |
| 8 | 주 버튼 | “다음” | 폭 가득. 입력 전·오류면 비활성. Q1에는 없음 |
| 9 | 자동 저장 표시 | “저장했어요” / 오프라인 “기기에 저장했어요” | 화면을 넘길 때마다 저장, 1.5초 표시. 오프라인은 연결 시 자동 동기화 |

키보드 (데스크톱)

| 키 | 동작 |
| --- | --- |
| Enter | 주 버튼(비활성이면 무시). 다른 버튼·링크에 포커스면 그 버튼 |
| Esc / Alt+← | 뒤로. 달력·드롭다운이 열려 있으면 그것만 닫음 |
| 1\~9 | Q1 n번째 선택, Q2 n번째 칩 켜기·끄기(입력 칸 포커스 없을 때) |
| 숫자 키 | Q3·Q4 칸에 바로 입력 |
| Tab / Shift+Tab | 입력 → 보조 링크 → 주 버튼. Q6은 행 안 칸 순서 |
| ↑ ↓ ← → | Q1 선택지, Q4 달력 날짜 이동 |

자동 저장·이어하기

- 화면을 넘길 때마다 저장. 다시 열면 “이어서 할까요?” 후 멈춘 화면부터
- 온보딩 밖 흐름은 첫 화면 Esc = 닫기 + “작성 중인 내용은 저장돼요”

입력 칸 상태 (화면 전체 상태는 → 공통 › 공통 상태)

| 상태 | 표시 |
| --- | --- |
| 빈 값 | 자리표시 회색, 주 버튼 비활성 |
| 입력 중 | 칸 테두리 진하게, 유효하면 주 버튼 활성 |
| 오류 | 칸 테두리 + 칸 아래 1줄 문구(빨강), 주 버튼 비활성. 입력을 멈춘 뒤 표시 |
| 비활성 | 주 버튼(빈 값·오류), 한도에 닿은 추가 버튼·칩만 |
| 이상값 | “입력한 값이 맞나요?” 1회 확인, 막지 않음(기준은 화면별) |

## Q1 단일 선택

카드 2\~5개 세로 나열. 고르면 0.3초 뒤 자동 다음(주 버튼 없음).

> 화면 그림: Q1 단일 선택, O-15 (그림은 기획서 페이지 사본에 있어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 질문 | “지금 어떤 집에 사세요?” | O-15 |
| 2 | 선택지 카드 | “전세” / “반전세·월세” / “자가” / “부모님 집” / “아직 안 구했어요” | 2\~5개, 세로 1열. 문구 12자 이내, 필요하면 카드 안 회색 1줄 |
| 3 | 선택됨 | 체크 + 굵은 테두리 | 0.3초 뒤 다음. 그 사이 다른 카드를 누르면 바꾸고 다시 셈 |

상태

- 빈 값: 선택 없음, 첫 카드에 포커스
- 입력 중: 같은 카드 연타는 1회로 처리
- 비활성: 조건에 안 맞는 선택지는 숨김

예외·오류

- 추가 입력이 붙는 선택지(O-52 ‘직접 정할게요’, O-19b ‘네’): 카드 아래 입력 펼침 + 주 버튼 표시
- 답을 바꿔 분기가 달라지면 “앞에서 적은 답 {n}개가 지워져요. 바꿀까요?” 확인

## Q2 다중 선택 칩

칩 여러 개를 고른 뒤 주 버튼 ‘다음’.

> 화면 그림: Q2 다중 선택 칩, O-36 (그림은 기획서 페이지 사본에 있어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 질문 | “매달 꼭 나가는 돈을 골라주세요” / 보조 “대출 상환은 다음에 따로 물어요” | O-36 |
| 2 | 칩 | “주거” “공과금” “통신” … “기타” | 누를 때마다 켜기·끄기. 한도는 화면별 |
| 3 | 선택된 칩 | 굵은 테두리 + 옅은 채움 | 순서가 우선순위인 화면(O-21)만 순번 표시 |
| 4 | 주 버튼 | “다음” | 1개 이상이면 활성 |

- 배타 칩 ‘없어요’(O-35b·O-44): 누르면 다른 칩 해제, 다른 칩을 누르면 ‘없어요’ 해제
- 그룹 칩(O-36·O-41·O-44): 다음 화면에서 고른 그룹의 세부 항목을 Q2로 물음
- 칩이 3줄을 넘으면 나머지는 ‘더 보기’
- 앞 답으로 정해지는 칩은 켜진 채 시작(O-41 보증금)

상태

- 빈 값: 모두 꺼짐, 주 버튼 비활성
- 비활성: 한도에 닿으면 꺼진 칩 비활성 + “{n}개까지 고를 수 있어요”

예외·오류

- 적은 내용이 있는 칩을 끄면 “{그룹}에 적은 내용도 지워져요” 확인

## Q3 금액 입력

큰 숫자 칸 하나, 아래에 만 원 단위로 읽어 줌.

> 화면 그림: Q3 금액 입력, O-38, 데스크톱과 좁은 창 웹 (그림은 기획서 페이지 사본에 있어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 질문 | “식비·생활용품 등에는 한 달에 얼마쯤 쓰세요?” | O-38 |
| 2 | 금액 칸 | 큰 숫자 + “원” | 3자리마다 쉼표. 자리표시 “0”(예시값이 있으면 “예: 50만 원”) |
| 3 | 만 원 단위 읽기 | “130만 원” | 입력할 때마다 갱신 |
| 4 | 빠른 금액 칩 | “+1만” “+10만” “+50만” “+100만” | 누를 때마다 현재 값에 더함. 큰 금액 4곳(O-19a 결혼 총예산·내 집 마련·전세 보증금·자동차 구입)은 “+1,000만” “+5,000만” “+1억” |
| 5 | 잘 모르겠어요 | “잘 모르겠어요” | 구간 칩 5개 → 중간값 채움 + ‘추정’ 배지·할 일 등록. 구간 → 핵심 규칙 › 데이터 항목 5장. O-19c·O-39는 ‘없어요’, O-31은 없음(O-16 ‘쉬는 중’이면 “지금은 수입이 없어요” = 0원) |
| 6 | 좁은 창 하단 고정 | 빠른 금액 칩 + 주 버튼 | 앱 숫자 키패드 바로 위, 금액 칸은 계속 보이게 |
| 7 | 좁은 창 숫자 키패드 | 3×4, 마지막 줄 “00” “0” 지우기 | OS 키패드 대신 앱 자체 키패드. 화면이 열리면 바로 펼침, 누른 숫자는 끝에 붙음 |

금액 입력 규칙

- 입력: 숫자만, 맨 앞 0 지움, 커서는 항상 끝. 저장은 정수(원)
- 읽기 형식: “5,000원” / “320만 원” / “320만 5,000원” / “1억 2,000만 원” / “2억 원”
- 최대 999억 원(99,999,999,999원, 입력 검증). 내부 저장과 계산은 정수 원 단위. 넘으면 칸 아래 “999억 원까지 넣을 수 있어요”
- 0원 불가: “0원보다 큰 금액을 넣어 주세요”. 0이 답이면 ‘없어요’ 링크(화면별)
- 붙여넣기: 숫자 외 문자 제거, “320만”·“1억 2천만” 단위 환산. 해석 불가면 “숫자만 붙여넣을 수 있어요”
- 단위 실수 힌트: 월 금액에 1\~9,999원이면 “{n}만 원인가요?” 링크(누르면 ×10,000)
- 비율·금리(O-46): 단위 ‘%’, 소수점 1자리, 읽기·빠른 칩 없음

상태

- 빈 값: 자리표시 “0” 회색, 주 버튼 비활성
- 입력 중: 읽기 표시 갱신, 1원 이상이면 주 버튼 활성
- 오류: 최대값 초과·0원 → 칸·문구 빨강, 주 버튼 비활성

예외·오류

- 배우자가 넣어 둔 값(P-05): 채워진 채 열림 + 보조 “{나}님이 적어 둔 값이에요”
- 뒤로 와서 금액을 바꾸면 그 금액을 쓰는 계산만 다시 함

## Q4 날짜·월 선택

연·월·일 칸 직접 입력 + 달력, 미정이면 대안 링크.

> 화면 그림: Q4 날짜·월 선택, O-12 (그림은 기획서 페이지 사본에 있어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 질문 | “결혼 예정일은 언제예요?” / 보조 “결혼기념일과 결혼 비용 기한에 써요” | O-12 |
| 2 | 날짜 칸 | 년 / 월 / 일 | 칸이 차면 다음 칸으로(연 4자리, 월·일 2자리). 연·월 피커는 2칸 |
| 3 | 달력 | 달력 버튼, 칸 포커스 시 펼침 | 고르면 칸 채움. 범위 밖 날짜 비활성, Esc = 달력만 닫기 |
| 4 | 대안 링크 | “아직 미정이에요” | 문구는 화면별. O-12는 연·월 피커 “언제쯤 예정이에요?”로 바뀜 + ‘추정’·할 일 등록 |

- 연도만 받는 화면(O-24): 4자리가 유효하면 자동 다음. 추천값 미리 채움
- 생년월일(O-13, P-04): 칸 대신 연, 월, 일 3열 휠(DateWheel). 가운데 회색 띠가 고른 줄, 위아래 줄은 흐리게. 터치, 마우스 휠로 굴리거나 ↑↓(PageUp/PageDown 10년). 휠 아래 “만 {n}세”. 처음부터 값이 있어 ‘다음’ 바로 누를 수 있음
- 월급날(O-32, P-05, 설정 월급날): 회색 판 위 1\~31을 7칸씩 놓은 숫자 판, 고른 날만 검정 동그라미. ‘말일’은 판 아래 한 줄. ←→ 하루, ↑↓ 일주일
- 범위는 화면별(O-13 1950\~올해 − 18, 결혼한 날은 오늘 이전, 예정일은 오늘 이후)
- 붙여넣기: “2027-05-15”·“2027.5.15”·“20270515” 해석
- 생일·제사(챙길 날): 양력/음력 토글

상태

- 빈 값: “YYYY” “MM” “DD” 회색, 주 버튼 비활성
- 입력 중: 칸 자동 이동, 달력도 같은 날짜로 이동
- 오류: “없는 날짜예요”, 범위 밖은 화면별 문구

예외·오류

- 월급날(O-32) 29\~31일: 없는 달은 말일로 계산, 보조 “짧은 달은 말일로 계산해요”

## Q5 짧은 텍스트

이름·별칭 등 한 칸.

> 화면 그림: Q5 짧은 텍스트, O-03 (그림은 기획서 페이지 사본에 있어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 질문 | “뭐라고 부르면 될까요?” | O-03 |
| 2 | 입력 칸 | 미리 채운 값 “찬우” + 지우기 × | O-03은 로그인 이름을 미리 채움. ×는 값이 있을 때만 |
| 3 | 글자 수 | “2/10” | 최대 글자 수는 화면별(O-03 10자), 한도에서 입력 멈춤 |
| 4 | 주 버튼 | “다음” | 앞뒤 공백 뺀 1자 이상이면 활성 |

- 앞뒤 공백 제거, 연속 공백 1칸, 줄바꿈·탭 지움. 이모지·특수문자 허용

상태

- 빈 값: 자리표시 “예: 찬우” 회색, 주 버튼 비활성
- 오류: 공백만 입력 → “이름을 넣어 주세요”

예외·오류

- 붙여넣기가 한도를 넘으면 한도까지만 넣고 “10자까지만 넣었어요”
- 배우자 호칭(O-05)이 내 호칭과 같으면 “두 분 호칭이 같아요. 그대로 쓸까요?” 확인

## Q6 목록 입력

한 화면에 여러 항목(한 화면 한 질문의 예외). 항목 추가·삭제, 합계 바로 표시.

> 화면 그림: Q6 목록 입력, O-35, 데스크톱과 좁은 창 웹 (그림은 기획서 페이지 사본에 있어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 질문 | “보통 몇 월에 얼마쯤 받아요?” / 보조 “여러 번 받으면 하나씩 추가해 주세요” | O-35 |
| 2 | 항목 앞 칸 | “3월 ▾” | 화면별(월·이름·통장 이름). 월은 1\~12월 드롭다운 |
| 3 | 금액 칸 | “2,000,000원” | Q3 금액 입력 규칙 그대로. 포커스 행만 만 원 단위 읽기 |
| 4 | 삭제 | × | 묻지 않고 바로 삭제 + Toast “삭제했어요”, “되돌리기” 6초. 행이 1개면 비우기 |
| 5 | 빈 항목 | 회색 “월 ▾” “0원” | 처음 열면 빈 행 1개 |
| 6 | 항목 추가 | “+ 항목 추가” | 빈 행 추가 후 첫 칸 포커스(빈 행이 있으면 그 행으로) |
| 7 | 합계 | “1년에 모두 700만 원” | 완성 행만 더해 바로 갱신, 없으면 “—”. 문구는 화면별 |
| 8 | 주 버튼 | “다음” | 완성 행 1개 이상, 미완성 행 없을 때 활성 |
| 9 | 좁은 창 하단 고정 | 합계 줄 + 주 버튼 | 목록만 스크롤, 키패드가 열리면 그 바로 위로 |

목록 규칙

- 항목 한도 기본 10개. 닿으면 ‘항목 추가’ 비활성 + “10개까지 넣을 수 있어요”
- 빈 행은 저장 안 함. 일부만 채운 행·0원 행은 빈 칸 빨강 + “금액을 넣어 주세요”
- 행이 정해진 화면(O-63·W-04b·W-04e)은 추가·삭제 없음
- 중복 허용. 저장 뒤 다시 열면 월 순 정렬
- 합계는 미완성 행 제외. 이상값 확인은 합계 기준
- 키보드: Tab = 행 안 칸 → 다음 행 → ‘항목 추가’. ‘항목 추가’에서 Enter = 추가, 그 외 Enter = 다음

상태

- 빈 값: 빈 행 1개, 합계 “—”, 주 버튼 비활성
- 입력 중: 포커스 행 강조, 합계 바로 갱신
- 오류: 미완성 행·금액 오류 칸만 빨강, 주 버튼 비활성

예외·오류

- 행이 많으면 목록만 스크롤, 질문·합계·주 버튼 고정
- 뒤로 갔다 오면 저장된 행만 열림
- 배우자가 같은 목록을 고치면 행 단위로 합침, 같은 행이면 충돌 선택(→ 공통 › 공통 상태)

## Q7 안내·확인

입력 없이 설명·요약 + 주 버튼. 아래는 O-20 예(세부 → 화면 설계 › 온보딩 ① O-20).

> 화면 그림: Q7 안내·확인, O-20 파트 시작 (그림은 기획서 페이지 사본에 있어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 제목·보조 | “이제 둘의 목표를 정해요” / 보조 “고른 목표마다 얼마를, 언제까지 모을지 물어볼게요” | O-20. 파트 시작 ID = O-{파트}0 |
| 2 | 지금까지 답 | “지금까지 알려준 내용” + 앞 파트 답 + ‘수정’ | 파트 끝 요약 화면 대신. ‘수정’ → 해당 질문 → 복귀. 첫 파트 시작(O-10)은 없음 |
| 3 | 주 버튼 | “목표 고르기” | 항상 활성. 문구는 화면별(O-10 “시작할게요”) |

- 파트 시작 = O-{파트}0(O-10·O-20, 필요 시 O-30·O-50). 파트 끝 요약 화면은 따로 두지 않음
- O-61 분석 중: 주 버튼 없이 1.5초 뒤 자동 다음
- 확인형(P-04·P-10): 항목마다 ‘맞아요’ / ‘수정’, P-10은 ‘좋아요’ / ‘다르게 해볼래요’

상태

- 오류: 요약을 못 불러오면 공통 서버 오류
