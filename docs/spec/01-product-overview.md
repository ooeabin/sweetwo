## 1. 개요

sweeTwo(2026-11-13 v2.2): 둘이 정한 월급 계획을 한 장으로 같이 보고, 같이 모으는 저금이 얼마나 찼는지 확인하는 커플 앱. 슬로건 “둘이 구워서 더 달콤한 자산파이”는 웹사이트·스토어에서만(앱 안에서는 안 씀, Q3, → 04).

앱이 답하는 질문 세 가지(순서도 이대로, 2026-11-13)

1. 우리가 같이 모으는 돈, 얼마나 찼지? → 홈 맨 위 ‘같이 모으기’(H-10)
2. 이번 달도 계획대로 됐지? → 월급날 확인 한 번(W-02), 자동 줄은 앱이 알아서
3. 경조사와 큰돈 나갈 날, 언제지? → 캘린더, 위젯, 알림

자산 관리(순자산)는 네 번째 메뉴로 가볍게 넣고 가끔 봄. 매달 할 일은 거의 없고 홈·위젯·알림으로 진행을 보는 앱(의도).

| 대상 유형 | 주는 가치 (한 줄) | 주로 닿는 화면 |
| --- | --- | --- |
| 예비부부 | 결혼 비용을 둘이 한 진행 막대로 모으고, 기한까지 얼마 더 필요한지 보며, 결혼식 D-day와 잔금 날짜를 챙기고, 다 모으면 다음 저금으로 이어 감 | H-10, H-12, W-15, W-14 |
| 한 사람이 관리하는 집 | 관리하는 쪽은 둘의 돈을 월급 계획 한 장으로, 관리하지 않는 쪽은 2분 합류 뒤 ‘보내기’와 ‘용돈’이 자동이라 위젯과 경조사 알림만 | O-30c, P-05c, W-01, 위젯 |
| 같이 사는 연애 커플 | 월급은 숨긴 채 같이 모으는 저금 합계와 같이 쓰는 통장 몫만 보여 주고, 분담은 제안 → ‘좋아요’ | S-13, W-01b, H-10 |
| 맞벌이 자동화족 | 자동 줄은 나가는 날 앱이 확인, 월급날은 예외만 한 번 | W-01 줄 설정, W-02 |
| 불규칙 소득 | 월급날 목록 없이 “돈 들어왔어요”로 그때그때 저금에 나눠 넣고, 기간 중간부터 들어온 돈과 필요한 돈을 막대로 | H-13, W-20 |

| 항목 | 내용 |
| --- | --- |
| 타깃 | 예비부부, 결혼한 커플, 같이 사는 커플, 연애 중인 커플(2026-11-13 O-11 4지선다). 혼자 시작할 수 있고 파트너는 첫 저금 뒤 언제든 초대 |
| 핵심 가치 | 같이 모으는 저금의 진행을 둘이 한 곳에서 봄. 월급 계획을 한 번 정해 두면 월급날 한 번 확인(자동 줄은 앱이), 상여·가족 지원은 “돈 들어왔어요”로 |
| 핵심 기능 | 같이 모으기(H-10, 묶음 W-15), 월급 계획(줄마다 체크리스트에 넣기·자동 줄), 월급날 확인 한 번, 돈 들어왔어요, 모은 금액 바로잡기·잔액 맞추기, 쓸 곳 메모(결혼 준비), 분담 도우미, 날짜를 정한 월급 변경, 순자산(평가금액 기준), 자산 순위(두 사람 동의), 캘린더(금융 일정 + 경조사), 위젯 |
| 데이터 입력 | 수기 입력, 월급날 확인 한 번. 결제 하나하나 기록, 은행 연동, 마이데이터, 스크래핑은 넣지 않음. 얼마를 썼는지 묻지 않음 |
| 돈 관리 원칙 | 월급을 저금(저금 항목마다) + 지출(고정지출, 생활비, 용돈)으로 나눔. 통장을 어떻게 나눠 쓰는지는 묻지 않음. 앱은 돈을 옮기지 않음 |
| 관리 형태 | 세 질문(같이 쓰는 생활비, 같이 모으는 저금, 누가 관리)을 엔진 각자/합쳐서 + 관리하는 사람으로(미리 고른 값 없음, 2026-11-13, → 08 2장). 저금은 각자면 사람마다 따로(같이 모으려면 묶음), 합쳐서면 공동 월급 계획에 |
| 두 사람 | 같이 쓰는 것은 누구나 바로 고치고, 상대에게 알림 + 활동 기록, 고친 사람에게 ‘되돌리기’. 예외 둘(관리 형태 합치기, 분담 제안)만 상대 답. 각자 계열에서 파트너 것은 공개 단계(모두 / 저금만(기본) / 했어요만)대로 보기만(2026-11-13) |
| 플랫폼 | 모바일 앱(iOS·Android, 태블릿 iPad·Galaxy Tab 포함) 하나. 같은 계정으로 여러 기기에서 같은 데이터. 웹 앱은 없음 (5장, ADR 0001). 데스크톱 앱(Windows·macOS)은 없앰 2026-11-10, ADR 0008 |
| 지원 언어·통화 | 한국어·원화·한국 시간만 |

탭: 홈 / 월급 / 자산 관리 / 캘린더(2026-11-08 ADR 0007). 설정은 아바타(넓은 창)·톱니(좁은 창)에서.

| 탭 | 보여 주는 것 |
| --- | --- |
| 홈 | 같이 모으기(H-10), 이번 달 한 줄(H-11/H-13), 할 일 띠, 월급 계획·캘린더 타일, 결혼 준비(H-12), 자산 관리·저금 타일(2026-11-13, → 19) |
| 월급 | 이번 달 월급 체크리스트, 월급 계획, 저금 항목 상세(모은 금액, 목표 금액·기한, 월 필요액, 달성 축하) |
| 자산 관리 | 직접 적은 통장, 투자, 부동산, 대출. 순자산 = 자산 − 부채 |
| 캘린더 | 금융 일정(월급날, 만기, 기한을 정한 저금 항목의 목표 기한) + 경조사(생일, 기념일, 사귄 날, 명절, 가족 행사를 한 종류로) + 쓸 곳 메모 날짜 |

## 2. 핵심 사용자 흐름

2026-11-13: 가입 → 온보딩(3분 이하: 이름, 두 사람 사이, 같이 쓰는 생활비, 같이 모으는 저금, (누가 관리), 월급 + 공개 고지, 월급날, 알림 허용 → 준비 끝) → 첫 저금 → (초대) → 앱 잠금 권장(건너뛸 수 있음) → 홈. 그림 → 03 3장. 아래는 예전 설명: 홈(저금 항목 추가를 권함). 매달은 월급날 체크리스트에 체크 → 저금이 저금 항목에 쌓임 → 다음 월급날 3일 전 빠진 줄만 확인(월급 전 확인). 월급 계획과 저금 항목은 언제든 바로 고침. 경로 → 유저 플로우, 시점 → 핵심 규칙 › 월 사이클.

## 5. 출시 순서

모바일 앱(휴대폰·태블릿)만 출시. React 화면·계산 로직을 Capacitor로 감쌈(ADR 0001). 웹 앱(브라우저에서 쓰는 앱)은 내지 않음. 데스크톱 앱은 없앰(2026-11-10, ADR 0008).

| --- | --- | --- |
| — | 데스크톱 (Windows, macOS) | 없앰 2026-11-10, ADR 0008 |

| 2 | 모바일 확장 | 잠금 화면 위젯, WG-02·03·05(WG-01·04는 1단계, 2026-11-13) |
