## 1. 개요

sweeTwo: 예비·신혼부부가 함께 목표를 정하고, 매달 월급을 정한 대로 나눠 목표에 모으는 앱. 슬로건 “함께 구워 더 달콤한 자산파이”.

앱이 답하는 질문 세 가지

1. 우리 목표, 얼마나 모았지? → 목표
2. 이번 달 월급, 정한 대로 나눴지? → 월급 체크리스트
3. 우리 자산, 지금 얼마지? → 우리 자산

| 항목 | 내용 |
| --- | --- |
| 타깃 | 결혼 준비 중인 예비부부 ~ 결혼 3년 차, 맞벌이 중심. 혼자 시작할 수 있고 배우자는 언제든 초대 |
| 핵심 가치 | 목표가 주인공. 월급을 한 번 나눠 두면 매달 체크만 하면 되고, 체크한 저금이 목표에 바로 쌓여 얼마나 왔는지 둘이 같이 봄 |
| 핵심 기능 | 목표(비상금 기본 + 템플릿), 월급 분배표, 이번 달 월급 체크리스트(체크하면 저금이 목표에 쌓임), 월말 확인, 한눈에 순자산, 캘린더(돈 일정 + 챙길 날) |
| 데이터 입력 | 수기 입력, 매달 체크만. 결제 하나하나 기록, 은행 연동, 마이데이터, 스크래핑은 넣지 않음. 얼마를 썼는지 묻지 않음 |
| 돈 관리 원칙 | 목표를 먼저 정하고 월급을 저금(목표마다) + 쓰는 돈(고정지출, 생활비, 용돈)으로 나눔. 통장을 어떻게 나눠 쓰는지는 묻지 않음. 앱은 돈을 옮기지 않음 |
| 월급 관리 방식 | 각자 따로(분배표와 체크리스트가 사람마다) / 합쳐서 같이(하나). 기본 각자, 설정에서 언제든 바꿈. 목표는 어느 방식이든 같이 씀 |
| 부부 | 누구나 바로 고치고, 상대에게 알림 + 활동 기록, 고친 사람에게 ‘되돌리기’ |
| 플랫폼 | 설치형 데스크톱 앱(Windows·macOS)과 모바일 앱(iOS·Android)을 같은 코드로 함께 출시, 같은 계정으로 두 앱에서 같은 데이터. 웹 앱은 없음 (5장, ADR 0001) |
| 지원 언어·통화 | 한국어·원화·한국 시간만 |

탭: 홈 / 목표 / 우리 자산 / 캘린더 [확인 필요]. 설정은 아바타(넓은 창)·톱니(좁은 창)에서.

| 탭 | 보여 주는 것 |
| --- | --- |
| 홈 | 인사, 목표(1순위 크게 + 나머지 작게), 이번 달 월급 체크리스트, 우리 자산(순자산), 다가오는 일정(최대 3개). 꼭 필요한 할 일은 맨 위 한 줄 |
| 목표 | 목표 목록과 상세, 모은 돈, 월 필요액, 예상 달성일, 넣기·빼기·꺼내 쓰기 |
| 우리 자산 | 직접 적은 통장, 투자, 부동산, 대출. 순자산 = 자산 − 부채 |
| 캘린더 | 돈 일정(월급날, 만기, 목표 기한) + 챙길 날(생일, 기념일, 명절, 양가 행사를 한 종류로) |

## 2. 핵심 사용자 흐름

가입 → 11화면 온보딩(약 2분 [확인 필요]: 이름, 초대, 결혼 상태, 결혼한 날·예정일, 출생연도, 목표, 1순위 목표 금액·기한, 월급 관리 방식, 월급, 월급 분배표, 결과 한 장) → 홈. 매달은 월급날 체크리스트에 체크 → 저금이 목표에 쌓임 → 다음 월급날 3일 전 빠진 줄만 확인(월말 확인). 분배표와 목표는 언제든 바로 고침. 경로 → 유저 플로우, 시점 → 핵심 규칙 › 월 사이클.

## 3. MVP 범위

| 기능 | MVP | 다음 단계 |
| --- | --- | --- |
| 온보딩 | 11화면 약 2분 [확인 필요](데스크톱·모바일 앱 어디서든 처음 시작 가능), 배우자 합류 짧은 흐름(이름, 출생연도, 월급, 분배표. 휴대폰으로 초대받으면 모바일 앱에서) | — |
| 목표 | 비상금(기본) + 템플릿 19개 + 직접 만들기, 월 필요액, 예상 달성일, 지연 표시, 넣기·빼기·꺼내 쓰기, 달성 축하 | 수익률 시뮬레이션(유료화 시점, 목표 프리미엄 기능, 목표 상세 G-02) |
| 월급 체크리스트 | 월급 분배표(W-01), 이번 달 월급 체크리스트(W-02, 대신 체크 포함), 월말 확인(W-05), 관리 방식 각자·합쳐서 | — |
| 우리 자산 | 자산·부채 직접 입력, 순자산, 예상 순자산(평가금액 기준), 순자산 그래프 | 엑셀 일괄 업로드 |
| 캘린더 | 돈 일정 + 챙길 날 직접 입력, 음력, 알림 | — |
| 양가 균형 리포트 | 제외 | 챙길 날을 한 종류로 합쳐 근거 데이터가 달라짐, 다시 검토 [확인 필요] |
| 비슷한 부부와 비교 | 제외 | 출시 후, 무료. 공공 통계로 시작 후 그룹별 100쌍이면 앱 데이터(→ 핵심 규칙 › 계산·배분 7장) |
| 14일 무료 체험·추천 보상 | 제외 | 유료화 시점(→ 사업 계획 6장) |
| 부부 계정 | 초대(온보딩에서 바로, 나중에도 홈 할 일·설정), 공개 범위 3단계, 누구나 바로 고침 + 알림·되돌리기, 연결 해제(S-12: 자산 정리 안, 14일 후 기본안 적용) | — |
| 다크 모드 | 기기 설정 따름 | 설정에서 라이트·다크·기기 설정 고정 선택 |
| 금액 가리기 | 포함(규칙 → 화면 설계 › 공통) | — |
| 위젯 | 데스크톱 트레이 위젯 창(→ 화면 설계 › 위젯) | OS 기본 위젯(macOS 알림 센터·Windows 11 위젯 보드)은 출시 뒤, 모바일 홈·잠금 화면 위젯은 모바일 앱 출시 뒤 |

## 4. 수익모델

| 모델 | 내용 |
| --- | --- |
| 무료 | 온보딩, 목표(개수 제한 없음), 월급 분배표·체크리스트·월말 확인, 우리 자산, 캘린더, 비슷한 부부와 비교(출시 후) |
| 프리미엄 구독 | 수익률 시뮬레이션(목표 프리미엄 기능, 유료화 시점), 양가 균형 리포트(다시 검토), 그 밖의 구성은 다시 정함 [확인 필요] |
| 전문가 연결 | 재무설계·대출 상담 예약 수수료 |

유료화 전에는 프리미엄 기능을 숨김(자물쇠·“프리미엄 살펴보기”·S-16 진입 없음), 유료화 시점에 기능·결제·체험을 함께 엶. 앱 안 광고 없음, 금융상품 수수료 없음 등 수익 원칙 → 사업 계획 6장.

## 5. 출시 순서

설치형 데스크톱 앱과 모바일 앱을 함께 먼저 출시. 모바일 앱은 데스크톱과 같은 React 화면·계산 로직을 Capacitor로 감쌈(ADR 0001). 웹 앱(브라우저에서 쓰는 앱)은 내지 않음.

| 단계 | 플랫폼 | 범위 |
| --- | --- | --- |
| 1 | 데스크톱 (Windows, macOS) | MVP 전체 |
| 1 (함께) | 모바일 (iOS, Android) | MVP 전체(좁은 창 화면). 휴대폰 초대 → 앱 설치 → 합류가 기본 길. 데스크톱 전용(트레이 위젯, 단축키, 명령 팔레트 Ctrl(⌘)+K)은 빼고 검색 화면으로. 앱 잠금은 PIN + Face ID·지문, 알림은 모바일 푸시 |
| 2 | 모바일 확장 | 홈·잠금 화면 위젯, OS 기본 위젯 |
