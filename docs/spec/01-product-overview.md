# sweeTwo 신혼부부 자산관리 앱 기획서

Oct 9, 2026 · @yun

> 2026-10-14부터 정본은 저장소 docs/ 폴더예요. 개발 중 바뀜 내용은 저장소 문서에 바로 반영돼요. 이 페이지는 그 시점의 사본이에요.

## 1. 개요

sweeTwo: 신혼부부가 가이드에 따라 목표 설정·재정 정리·월 저축·양가 경조사를 함께 관리하는 앱. 슬로건 “함께 구워 더 달콤한 자산파이”.

| 항목 | 내용 |
| --- | --- |
| 타깃 | 결혼 준비 중인 예비부부 \~ 결혼 3년 차, 맞벌이 중심 |
| 핵심 기능 | 가이드형 온보딩, 목표 세분화, 재정 진단, 월 저축 관리, 챙길 날(양가·우리 둘) |
| 데이터 입력 | 수기 입력, 월 1회 합계(결제 하나하나 기록과 은행 자동 연동, 마이데이터는 넣지 않음. 월 1회 합계 + 정산 + 둘이 함께가 차별점) |
| 돈 관리 원칙 | 공동자금과 용돈 분리, 공동 통장 3개(공동 생활비·목표자금·비상금) + 각자 개인 통장(예비부부는 결혼 준비 통장), 목표를 먼저 정하고 배분 |
| 차별점 | ‘다음에 무엇을 할지’ 알려주는 코칭, 부부 공동 사용, 양가 명절·생신·경조사의 예산화 |
| 플랫폼 | 설치형 데스크톱 앱(Windows·macOS)과 반응형 웹(처음 시작·합류·월말 정리·핵심 설정 등) 함께 출시, 같은 코드로 모바일 앱(iOS·Android) 확장 (5장) |
| 지원 언어·통화 | 한국어·원화·한국 시간만 |

## 2. 핵심 사용자 흐름

> 화면 그림: 핵심 사용자 흐름, 4단계 + 반복 루프 (그림은 기획서 페이지 사본에 있어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

온보딩은 최초 1회, 끝나면 ‘이번 달 남은 기간 플랜’으로 바로 시작. 이후 월 저축 관리(월급 플랜 → 월급 나누기 → 월말 정리)가 매달 반복되고, 분기마다 재진단·목표 조정.

## 3. MVP 범위

| 기능 | MVP | 다음 단계 |
| --- | --- | --- |
| 가이드형 온보딩 | 파트 0\~6 전체(웹에서도 처음 시작 가능), 배우자 짧은 온보딩(반응형 웹 포함) | 투자성향 퀴즈 고도화 |
| 목표 | 템플릿 21개, 계산식, 충돌 조정 | 수익률 시뮬레이션(유료화 시점, 목표 프리미엄 기능, 목표 상세 G-02) |
| 재정 진단 | 자산·부채 입력, 지표 5개, 리포트 | 엑셀 일괄 업로드 |
| 월 저축 관리 | 월급 플랜, 월급 나누기(배우자 합류 + 통장 역할을 나눈 부부), 월말 정리(W-04) 전체(기본 3단계: 지출 입력, 저축 확인, 월 정산 요약), 미달·초과 처리, 제안, 생활비 체크(선택) | 계획 다시 세우기 비교 시뮬레이션, 월말 정리 심화 |

## 4. 수익모델

| 모델 | 내용 |
| --- | --- |
| 무료 | 온보딩, 목표(개수 제한 없음), 진단, 월 저축 관리, 월말 정리 전체(월 정산 요약, 변동 항목별 보기, 지난달 대비 포함), 양가 캘린더, 계획 다시 세우기, 비슷한 부부와 비교(출시 후) |
| 프리미엄 구독 | 월말 정리 심화(여러 달 흐름, 항목별 분석 같은 깊은 분석), 수익률 시뮬레이션(목표 프리미엄 기능, 유료화 시점), 양가 균형 리포트(데이터 1년 누적 후), 계획 다시 세우기 비교(여러 안 나란히) |
| 전문가 연결 | 재무설계·대출 상담 예약 수수료 |

유료화 전에는 프리미엄 기능을 숨김(자물쇠·“프리미엄 살펴보기”·S-16 진입 없음), 유료화 시점에 기능·결제·체험을 함께 엶. 앱 안 광고 없음, 금융상품 수수료 없음 등 수익 원칙 → 사업 계획 6장.

## 5. 출시 순서

설치형 데스크톱 앱과 반응형 웹을 함께 먼저 출시, 화면·계산 로직을 재사용해 모바일 앱 후속 출시.

| 단계 | 플랫폼 | 범위 |
| --- | --- | --- |
| 1 | 데스크톱 (Windows, macOS) | MVP 전체 |
| 1 (함께) | 반응형 웹 (브라우저) | 처음 시작(온보딩 O 전체, 진입점 A-05, O-01, L-01), 합류(P-01\~11), 이번 달 보기, 월급 나누기(W-02), 생활비 체크, 월말 정리(W-04), 제안 확인·보내기(G-08), 목표 보기(G-01·G-02), 챙길 날 준비·기록(Y-05·Y-08), 내 수입·내 용돈·내 명의 항목 수정, 핵심 설정(S-10, S-11/S-11e, S-12, S-14, S-18, S-19, S-21). 데스크톱 React 화면 재사용. ‘대신 체크’ 유지. 웹 알림은 이메일 |
| 2 | 모바일 (iOS, Android) | 알림, 월급 나누기, 월말 정리, 양가 일정부터 시작 → 전체 기능 |

## 6. 문서 지도

문서는 5개 묶음. 한 내용은 한 곳에만 두고, 여러 화면에 걸치는 규칙의 정본은 핵심 규칙 묶음.

| 묶음 | 하위 탭 |
| --- | --- |
| 제품 개요 | 사업 계획, 유저 플로우, 브랜드 |
| 핵심 규칙 | 계산·배분, 월 사이클, 부부·제안·권한, 데이터 항목 |
| 화면 설계 | 공통(질문 화면 패턴, 공통 상태), 알림, 로그인·가입, 온보딩 ① 파트 0\~2, 온보딩 ② 파트 3\~6, 배우자 합류, 이번 달, 월급 플랜, 월말 정리, 목표, 우리 자산, 캘린더, 설정, 위젯, 어드민 화면, 웹사이트 |
| 기술·운영 | 동기화, 보안·개인정보, 성공 지표, 어드민 |
| 출시 준비 | 사용성 테스트, FAQ |
| 별도 문서 | 개발 가이드: 기술 스택, 폴더 구조, 코드 규칙, 테스트·배포 절차. 이 문서의 규칙을 구현하는 기준 |

읽는 순서

- 공통: 제품 개요 → 유저 플로우 → 핵심 규칙: 부부·제안·권한 → 월 사이클 → 계산·배분
- 디자이너: 화면 설계 공통 → 알림 → 온보딩부터 기능 순 → 브랜드
- 개발자: 데이터 항목 → 기술·운영 → 동기화 → 보안·개인정보 → 성공 지표 → 어드민 → 개발 가이드(별도 문서)
- 출시 전: 출시 준비
