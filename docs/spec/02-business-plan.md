# 사업 계획

## 1. 포지셔닝

**기록하는 가계부가 아니라, 부부가 월급 플랜과 월말 정리로 돈 계획을 같이 정하는 앱.** 타깃·차별점은 → 제품 개요 1장, 경쟁 대비 위치는 2장.

**수동 입력을 강점으로 보는 논리**

- 입력 단위가 거래가 아니라 월 합계·월급 나누기: 매일 기록 없음, 사이클당 월급 나누기(통장을 나눠 쓰는 부부만) 2분 + 월말 정리 5\~10분
- 항목별로 쓴 돈과 저축을 손으로 적는 월말 정리 자체가 부부의 월 1회 돈 대화 → 핵심 지표(월말 정리 완료 부부 수)와 일치
- 계좌 인증·마이데이터 동의 없음 → 가입 장벽·민감정보 보관 최소, 배우자에게 계좌 전체가 아닌 고른 항목만 공개
- 은행·카드사 무관: 어느 은행 모임통장을 써도 같은 구조, 특정 금융사 상품 판매 동기 없음(중립성)

## 3. 시장 규모

| 구분 | 정의 | 가정 | 규모 |
| --- | --- | --- | --- |
| TAM | 예비부부 + 결혼 0\~3년 차 부부 | 연 혼인 약 24만 건(2025)·최근 4년 혼인 합 약 85만 건(추정) + 다음 1년 예비부부 약 24만 쌍 | 약 110만 쌍 |
| SAM | 맞벌이 + 직접 계획 의향 | 맞벌이 비중 약 55%(가정), 앱으로 직접 돈 계획 의향 30%(가정) | 약 18만 쌍 |
| SOM | 정식 출시 3년 안 활성 부부 | SAM의 5%(가정) | 약 9천 쌍 |

- 결혼식 비용(예식장 + 스드메) 평균 약 2,000만\~2,150만 원(한국소비자원, 비수기·성수기): 예비부부 단계에서 돈 계획 수요가 가장 큼
- 구독만으로는 작음: 9천 쌍 × 유료 전환 5% × 연 3.9만 원 ≈ 연 1,800만 원 → 전문가 연결 예약 수수료 병행 필요(리스크 1, 수익원은 6장)

## 4. MVP 범위

기능 범위는 → 제품 개요 › MVP 범위. 아래는 사업 일정에 따른 추가 기준만.

- 출시 필수: 어드민 화면 요약 표의 ‘필수’ 화면
- 출시 후 3개월: 프리미엄 판매 시작(결제·구독 인프라 S-16·AD-08, 월말 정리 심화·수익률 시뮬레이션(목표 상세 G-02)·계획 다시 세우기 비교, 이때 기능·결제·체험을 함께 엶. 그 전에는 자물쇠·“프리미엄 살펴보기”·S-16 진입 없음), 온보딩 이탈 화면 상위 5개 문구 수정, 엑셀 일괄 업로드, AD-07 템플릿·AD-09 쿠폰·체험·AD-11 캠페인(첫 3사이클 코호트 확인 후)
- 이후: 전문가 연결 예약 수수료, AD-12·13 콘텐츠 관리, 양가 균형 리포트(데이터 1년 누적 후, 프리미엄), 모바일 앱(iOS·Android), 비슷한 부부와 비교(무료, 공공 통계로 시작 → 핵심 규칙 › 계산·배분 12장)

## 6. 가격·수익 모델

- 무료: 온보딩·목표·진단·월 저축·월말 정리·챙길 날·계획 다시 세우기. 핵심 습관 루프는 유료벽 없음. 출시 후 비슷한 부부와 비교도 무료
- 유료(프리미엄): 월말 정리 심화(여러 달 흐름, 항목별 분석 같은 깊은 분석. 월 정산 요약, 항목별 보기, 지난달 대비는 무료), 수익률 시뮬레이션(목표 › 목표 상세 G-02), 계획 다시 세우기 비교, 양가 균형 리포트(데이터 1년 누적 후)
- 경계 원칙: ‘이번 달을 하는 데’ 필요한 것은 무료, ‘여러 달을 돌아보고 비교하는 것’은 유료 → 3사이클 이상 쓴 부부만 가치 체감
- 부부 1구독: 한 명 결제 = 부부 공간 전체 적용, 결제 기록은 결제자만(설정 S-16)
- 수익원: 프리미엄 구독 + 전문가 연결 예약 수수료(4장 ‘이후’)만. 앱 안 제3자 광고 없음. 제휴는 청첩장·웨딩 플래너 등 가입 채널 제휴만, 금융상품 제휴·추천·판매 수수료 없음(등록 요건·중립성)

| 후보 | 금액 | 근거 |
| --- | --- | --- |
| A | 월 2,900원 / 연 24,000원 | 편한가계부와 같은 선, 저항 최소 |
| B | 월 4,900원 / 연 39,000원 | 2인 사용·코칭 가치 반영, 1인당 월 2,450원 |
| C | 연 49,000원 단일(월 요금 없음) | 연 단위 회고 기능 성격, 이탈 방지 |

- 검증: 내부 테스트에서 가격 질문(반 강제 선택형 설문 + 반 페이지 가짜 문 테스트) → 정식 후 첫 2개월 페이월 A/B(B vs C), 지표는 페이월 전환율(목표 8%)·30일 환불률
- 체험·추천 보상: 유료화 시점(4장 ‘출시 후 3개월’ 프리미엄 판매 시작)에 결제 화면(S-16)·AD-09와 함께 도입, 출시 범위 아님. 3번째 월말 정리 완료 시 14일 무료 체험, 추천 가입 시 두 부부 모두 프리미엄 1개월(7장)
