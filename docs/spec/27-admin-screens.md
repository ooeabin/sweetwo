- 검색도 감사 로그

예외·오류

- IP 허용 목록 밖: 로그인 화면 전에 차단
- 세션 만료·다른 곳에서 로그인: 로그인 화면, 재로그인 후 보던 화면. 30분 무활동은 브라우저를 닫았다 열어도 이어서 셈
- 로그인·인증 화면(AdminAuth, 2026-11-06): 워드마크 + ‘어드민’ 태그, 제목 “어드민 로그인” [확인 필요], 보낸 뒤 제목 “메일함에서 링크 열기” + “{이메일}로 링크 보냄” [확인 필요] + ‘다른 이메일로 받기’ [확인 필요]. 설명 글과 아래 작은 글은 없음(2026-11-06)
- 로그인 링크: 보낸 뒤 60초 동안 버튼을 막고 “{n}초 뒤 다시 받기 가능” [확인 필요]. 너무 자주 누름: “잠시 뒤 다시 시도” [확인 필요]. 보낼 수 없는 주소: “로그인할 수 없는 이메일” [확인 필요]. 메일 링크는 새 탭에서 열려도 로그인이 이어짐
- 권한 없는 화면 주소로 접근: “권한 없음” + 대시보드로
- 결과 없음: “일치하는 회원 없음”

> 화면 그림: AD-04 개인정보 열람 요청 (그림은 기획서 페이지 사본에 있어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

예외·오류

- 사용자 거절: 열람 불가, 문의는 스크린샷 등으로 진행
- 사용자가 ‘지금 그만 보게 하기’ 또는 24시간 경과: 즉시 닫힘, 사용자에게 “문의 처리를 위해 {범위}를 확인했어요” 알림
- 원값 승인 거절: 구간으로만 요청

- 이메일 문의: 이메일 정확히 일치로 회원 연결(auth 이메일, 대소문자 무시, 1명일 때만), 없으면 회원 없이 처리
- 이메일 문의 상세: 오른쪽 ‘이메일’ 묶음에 “제목”, “보낸 사람”(가린 주소, 예 cha***@example.com. 전체 주소는 보여 주지 않음), “회원”(연결되면 사용자 ID → AD-03, 없으면 “회원 연결 없음”), 첨부가 있었으면 “첨부 파일” “n개 미수신, 메일함에서 확인” [확인 필요]. 대화는 받은 순서대로(사용자/운영자). 자동 첨부와 동의 요청(4번)은 없음
- 이메일 문의 답변: 대화 위에 안내 띠 “메일 발송 연결 전까지 답장은 네이버웍스 help@에서 직접” [확인 필요](이메일 문의에만, 모든 역할). 메일 발송(SES)을 연결한 뒤에는 보내면 help@에서 답장 메일(제목 “Re: 원래 제목 [A-10001]”, 받은 메일에 이어지게). 연결 전에는 답변이 대화에만 남고 메일은 나가지 않음. 앱 알림 없음. 상태 규칙은 앱 문의와 같음
- 이메일 문의 이어짐: 답장(In-Reply-To·References) 또는 제목의 문의 번호로 같은 주소에서 온 메일은 그 문의에 덧붙음. 사용자 답변 대기 → 처리 중, 완료 7일 안 → 다시 열림(접수), 7일 넘으면 새 문의
- 이메일 문의는 앱 ‘내 문의’(S-19a)에 보이지 않음(보낸 주소는 꾸밀 수 있어서)
