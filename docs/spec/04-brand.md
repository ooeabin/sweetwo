# 브랜드

## 1. 브랜드 핵심

- **이름**: sweeTwo(스위투). sweet + two, 달콤한 둘. T는 늘 대문자
- **슬로건**: “함께 구워 더 달콤한 자산파이”. 둘이 함께 모은 돈(자산파이)을 둘이 함께 구워 키운 파이의 한 조각이라는 뜻, 상징(케이크 조각)과 짝
- 캐치프레이즈는 ‘함께 구워 더 달콤한 자산파이’ 하나만. 새 표어를 만들지 않음
- **상징**: 체리를 얹은 케이크 조각(3D). 앱 아이콘, 심볼, 파비콘이 모두 이 그림

**한 줄 정의**: 둘이 처음 함께 돈을 모으는 시기를, 다음 할 일 하나씩으로 가볍게 이끌어 주는 부부 돈 코치

**성격 키워드**: 다정함, 명료함, 함께

**하지 말 것**

- 금테크·금괴·왕관 같은 올드한 ‘황금’ 표현, 브랜드 색(체리) 범벅
- 압박·죄책감 주는 말(“실패”, “늦었어요”, 경고성 카운트다운)
- 배우자·양가를 비교·평가하는 표현(순위, ‘더 많이 썼어요’)
- 예외: 다른 부부와의 비교 통계는 10% 구간으로만, 배우자끼리나 양가는 비교하지 않음(→ 핵심 규칙 › 계산·배분 12장)

## 2. 톤

문구 톤과 좋은 예·나쁜 예는 → 화면 설계 › 공통.

## 3. 비주얼

- 화면 기본은 흰 바탕 + 검정 알약(ink) 주 버튼과 무채색. 브랜드 색(체리)은 작은 점과 글자에만
- 브랜드 색(체리) brand: 라이트 #C8102E, 다크 #FF5C74. 옅은 판 brand-soft: #FDE8EC / #3D1820, 그 위 글자 brand-ink: #9E0F2C / #FFB3BF. brand 바탕 위 글자는 라이트에서 흰 글자, 다크에서 어두운 글자
- 로고 색 logo: #E8344F(라이트, 다크 같음). 심볼 케이크 조각의 분홍빛. 워드마크에만
- brand 쓰는 곳: 달성 배지, 새 알림 점(순자산 차트 끝점은 없어짐)
- brand-soft 쓰는 곳: 달력의 오늘 날짜 칸만. 제안 카드 머리와 월말 정리 띠는 무채색(surface-alt)
- 브랜드 색을 쓰지 않는 곳: 카드, 띠, 패널 같은 넓은 면, 모든 버튼(오류 버튼과 헷갈림), 숫자 알약(이번 달 탭 옆 제안 수, 우선순위 순번은 ink), 변화 알약(기본 회색 surface-alt. 월별 저축과 순자산 차트의 변화 알약만 포인트색: 계획 100% 이상·증가 초록, 미만·감소 살구, 빨강 없음), 진행 막대, 본문 글자색, 순자산 차트 면(ink 옅은 면)
- 브랜드 버튼, 브랜드 카드는 없음. 축하 화면(목표 달성, 결혼일 전환 등) 버튼은 주 버튼(검정). 달성한 목표 카드는 기본 카드 + 작은 체리 ‘달성’ 배지
- 영역 틴트 5개는 뜻 고정: 우리 둘(together), 양가(family), 목표(goal), 비상금(safety), 투자·부동산(invest). 한 화면 2가지까지
- 목표(goal) 틴트는 따뜻한 모래색: goal 라이트 #F6EEE5 / 다크 #2E2620, 글자 goal-ink #6B4A2B / #E8CFB2. 목표 차트색은 살구 #E3A15F / 다크 #BE8838. 둘 다 브랜드 색과 별개
- 손실·미달은 경고색 없이. 오류색 danger는 체리와 구분되는 주황빛 빨강(라이트 #C2410C, 다크 #FF8A5C), 입력 오류·저장 실패에만, 항상 아이콘·문구와 같이
- 글꼴 SUIT. 작은 아이콘(메뉴, 버튼, 목록, 입력 칸)은 Phosphor 아이콘(MIT 라이선스)의 굵은 둥근 선, 크기 16·20·24. 채운 모양은 현재 선택된 자리에만(상단 메뉴 줄 현재 탭, 하단 독 현재 칸, 켜진 상태). 색은 글자색 그대로(검정, 회색), 체리나 영역색으로 칠하지 않음
- 큰 자리 그림(목표 카드 그림, 목표 달성 화면, 온보딩 결과, 빈 상태)은 앱 아이콘(케이크 조각)과 같은 3D 그림체: 부드러운 무광 3D, 단순한 둥근 모양, 은은한 그라데이션, 흰 바탕, 색 3\~4가지에 체리색 포인트. 물건 1개. 바탕 지운 PNG. 사람 얼굴, 글자, 로고 없음. 목표 그림 21장, 빈 상태 1장, 장면 그림 5장 모두 이 그림체(힙스필드에서 앱 아이콘 케이크를 그림체 참고로 넣어 생성). 빈 상태 그림은 부스러기만 남은 빈 디저트 접시와 포크 한 장(→ 화면 설계 › 공통 › 공통 상태). 목표 그림 21개(직접 만들기는 회색 기본 그림 goal-custom, 사용자가 사진으로 바꿀 수 있음 → 목표 G-02)는 디자인 시스템 Illustrations 묶음이 정본
- 사람 색(Avatar)은 → 화면 설계 › 공통

**그림 움직임 규칙**

- 움직이는 그림은 5곳만: W-04 끝, P-11, P-01, H-T1, A-02. 장면은 각 화면 요소 표 1번
- 장면 그림에 짧은 영상(약 6초, 소리 없음)을 씀. 영상 5개는 예전 실사 그대로, 3D로 다시 만들기는 보류. 화면에 들어올 때 한 번만 재생, 반복 재생 없음
- 형태가 화면 밖으로 잘리면 안 됨. 그림 전체가 항상 그림 자리 안에 있어야 함
- 영상 바탕은 흰색이라 라이트 모드 surface(#ffffff) 위에만 둠
- 다크 모드와 ‘동작 줄이기’ 설정에서는 영상 대신 배경을 지운 정지 그림을 보여줌
- 영상을 불러오기 전과 실패했을 때도 정지 그림을 보여줌
- 그 외 화면(목표 카드, 빈 상태)은 정지 그림만 씀

색 값·토큰·컴포넌트는 [sweeTwo 디자인 시스템](https://claude.ai/artifact/5KKC9HnqXVWEja5sif5JjF) 기준.

## 4. 로고·앱 아이콘 규격

워드마크, 상징 그림, 심볼, 앱 아이콘(체리를 얹은 케이크 조각, 최종) 모두 확정. 파일은 [sweeTwo 디자인 시스템](https://claude.ai/artifact/5KKC9HnqXVWEja5sif5JjF) Brand 묶음의 확정 파일만 사용.

**워드마크**

- 둥근 붓 필기체 “sweeTwo”. Damion 폰트를 바탕으로 글자 이음과 굵기를 다듬음. 폰트는 OFL로 상업 사용 가능
- 글꼴로 다시 치지 않고 확정 SVG 파일만 사용
- 기본 색은 케이크 분홍(logo #E8344F), 체리 바탕 위에서는 흰색, 한 가지 색 인쇄는 검정. 다른 색, 그림자, 외곽선 금지
- 앱 안 워드마크도 케이크 분홍, 한 화면 1개만
- T와 w는 붙여 씀(T 세로획 아래와 w 첫 획이 닿음)

**상징 그림**

- 미니 체리 타르트(3D 그림체): 주름진 쿠키 컵, 생크림, 꼭지 달린 체리 한 알, 흰 바탕
- 체리 타르트는 A-02 로그인 첫 화면 장면 그림 전용: Illustrations의 scene-tart.webp(영상 motion-a02-tart.mp4는 예전 실사, 3D 재제작 보류). 앱 아이콘, 심볼, SNS 공유 이미지, 랜딩(L-01)에는 케이크 조각을 씀
- 앱 아이콘은 아래 ‘앱 아이콘’(케이크 조각)
- 앱 화면 안에는 A-02 로그인 첫 화면에만 씀

**앱 아이콘**

- 체리를 얹은 케이크 조각(3D): 비스듬히 본 조각 하나. 앞은 뾰족, 뒤는 둥근 크러스트, 옆면에 연분홍 크림 층 두 줄, 윗면에서 흘러내린 크림 한 방울, 위에 꼭지 짧은 체리 한 알. 케이크는 체리 계열 그라데이션, 크림 연분홍. 흰 바탕, 그림자 없음, 케이크 정가운데, 케이크 긴 쪽이 아이콘의 약 78%, 말랑한 3D. 뜻: ‘함께 구워 더 달콤한 자산파이’의 한 조각
- 파일(디자인 시스템 Brand): app-icon.png(1024, 흰 바탕, 그림자 없음, 케이크 정가운데), app-icon-macos.png(Mac 독용), symbol.png(같은 케이크 조각, 바탕 없음 512), favicon-32/48.png(케이크 조각), apple-touch-icon.png(180)
- 상태: 최종 확정. 설치 파일용 .icns와 .ico, macOS 트레이 템플릿(한 색 실루엣)은 개발할 때 만듦

**심볼**

- symbol.png: 앱 아이콘과 같은 케이크 조각, 바탕 없음 512. 트레이 아이콘, SNS 공유 이미지, 랜딩(L-01) 그림에 씀
- 파비콘과 홈 화면에 추가용 아이콘은 앱 아이콘 파일(favicon-32/48.png, apple-touch-icon.png)을 씀

**여백·최소 크기**

- 여백: 로고 높이의 1/2 이상
- 최소 크기: 워드마크 높이 16px, 심볼 16px

**상표**: 이름·워드마크·심볼 확정, 출원 준비 중. 문자 상표 “sweeTwo”와 “스위투”, 워드마크·심볼 로고 상표(9류, 42류 우선). 일정 → 출시 준비 4장.
