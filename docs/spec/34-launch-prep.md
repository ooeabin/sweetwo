# 출시 준비

정식 출시 = 내부 테스트 종료 + 출시 승인 기준 통과 + 법적·행정·보안 체크리스트 완료 + 결정 필요 항목 확정(→ 사업 계획 › 결정 필요). 출시 시기는 → 사업 계획 5장. 지켜야 할 기준은 → 보안·개인정보, 구현은 → 기술·운영.

## 2. 내부 테스트

- 선행: 사용성 테스트 6쌍 완료와 수정 반영(→ 사용성 테스트 8장)
- 인원: 지인 20\~30쌍(→ 사업 계획 5장). 결혼 준비 중인 커플과 신혼부부 모두 포함, 월급 관리 방식 각자·합쳐서 모두 포함
- 조건: 결제 없음, 정식과 같은 앱. 운영 서버 그대로 사용(별도 테스트 서버 없음), 모두 보여 주기 출시 전에 내부 테스트 계정과 데이터 모두 삭제, 참여자에게 미리 안내
- 의견: 문의하기(S-19a), 끝날 때 설문(가격 질문 포함)
- 종료 조건: 온보딩 완료율 80% + 첫 체크 완료율 70% [확인 필요](→ 성공 지표 2장) + 아래 승인 기준 충족
