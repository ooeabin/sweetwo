# 알림

## 규칙

- 채널: 푸시 = 데스크톱 앱 OS 알림(앱이 꺼져 있거나 웹만 쓰면 메일로 대신. ‘앱이 꺼져 있음’ = 최근 10분 안에 데스크톱 앱 접속 신호(트레이 상주 포함)가 없음). 인앱 = 알림 센터(N-01·N-02) 기록. 메일 = 가입 때 받은 알림 이메일. 모바일 푸시는 2단계(모바일 앱)부터
- 시각은 기본값, S-14에서 바꿀 수 있음. 방해 금지 기본 밤 10시\~아침 8시, 그 사이 알림은 끝나는 시각에 푸시. 모든 날짜·알림 시각·방해 금지 시간은 한국 시간(KST) 기준, 기기 시간대는 무시
- 상한: 메일만 계정마다 월 6회. 사실값 주간 요약 메일은 상한에서 빼고 S-14에서 따로 끔. 웹만 쓰는 사용자(최근 30일 데스크톱 앱 접속 없음)는 핵심 알림(제안, 월말 정리, 연결 해제 관련) 메일을 상한에서 뺌. 푸시(OS 알림)·인앱 알림 센터는 상한 없음, 대신 S-14에서 종류별로 끔. 메일이 상한에 닿으면 우선순위 낮은 것부터 건너뜀: 리마인드·요약 → 정보 → 할 일 → 결정 기한(상한 밖). 광고성(마케팅) 메일·푸시는 별도 상한 월 1회, 마케팅 수신 동의자만, 밤 9시\~아침 8시 발송 안 함, 알림 센터에 남기지 않음. 건너뛴 메일도 알림 센터에는 남음
- 상한 밖(메일 상한에서 빠지고 S-14에서 끌 수 없음)은 아래만. 보안·계정에 바로 영향이 있거나, 기한 안에 결정해야 하는 알림
  - 보안·계정: 새 기기 로그인, 연결 해제 요청, 연결 해제 완료, 상대 계정 삭제, 계정 삭제 접수·완료·복구, 관리자 열람 요청과 배우자 열람 알림, 문의 답변 도착, 약관 개정과 마케팅 수신 동의 재확인(법정 고지)
  - 기한 있는 결정: 제안 적용 예정(적용 2일 전, 반대할 마지막 기회), 연결 해제 기본안 적용 예정(14일 기한 2일 전)
  - 서비스 고지: 1등급 장애 고지 메일(어드민에서 보냄, 서비스 메일이라 상한 밖)
- 배우자 미합류·혼자 쓰기면 상대에게 가는 알림 없음. 미합류 배우자가 담당인 알림(챙길 날 등)은 시작한 사람에게 감, 합류하면 담당자에게 넘어감
- 서프라이즈 챙길 날: 작성자에게만. 푸시 제목 “챙길 날 알림이 있어요”, 본문 숨김. 센터에는 문구 전체

## 센터와 푸시·메일

- 센터 = 받는 사람 기준 모든 알림 기록. 푸시·메일 발송 여부와 무관
- 상한·방해 금지로 보내지 않은 알림도 예정 시각에 센터에 쌓임
- 푸시 누름 → 앱 열림 + 대상 화면 + 센터 항목 읽음. 이메일 링크 → 웹 대상 화면 + 읽음(세션이 없으면 로그인 뒤 그 화면, 대상이 없거나 상대 비공개 항목이면 이번 달 + 토스트 → 로그인·가입 진입 표)
- S-14에서 받는 방법을 모두 꺼도 센터 기록은 계속
- 이번 달 할 일·배우자 활동 표시는 그대로, 센터는 별도 기록(예: 제안 도착 = 할 일 + 센터 둘 다)
