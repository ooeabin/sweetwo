# 알림

## 규칙

- 채널: 푸시 = 모바일 앱 푸시(APNs·FCM, 앱이 꺼져 있어도 옴). 데스크톱 앱 OS 알림은 없앰(2026-11-10, ADR 0008). 인앱 = 알림 센터(N-01·N-02) 기록. 메일 = 자동 예비로만(2026-11-04): 사용자 설정 없이 아래 ‘상한 밖’ 종류(보안·계정·결정 기한·법정 고지)와, 푸시를 받을 곳이 없는 사람의 월급 전 확인만 보냄(모바일 푸시를 받을 기기가 없고 데스크톱 앱도 꺼져 있음 = 최근 10분 안에 데스크톱 앱 접속 신호(트레이 상주 포함)가 없음). 그 밖의 종류별 알림 메일과 주간 요약 메일은 보내지 않음. 주소 = 소셜 계정 이메일(카카오가 이메일을 주지 않으면 가입 A-04에서 받은 주소), 고치는 곳 S-11b
- 시각은 기본값, S-14에서 바꿀 수 있음. 방해 금지 기본 밤 10시\~아침 8시, 그 사이 알림은 끝나는 시각에 푸시(방해 금지가 12시간을 넘어도 끝나면 보냄, 2026-11-12 QA 10구간 S10-04). 아래 ‘상한 밖’ 보안·계정 알림은 방해 금지 없이 바로 푸시(2026-11-12 S10-11). 모든 날짜·알림 시각·방해 금지 시간은 한국 시간(KST) 기준, 기기 시간대는 무시
- 상한(2026-11-04): 종류별 알림 메일을 보내지 않으니 메일 월 6회 상한은 없앰. 푸시(모바일 푸시, OS 알림)·인앱 알림 센터는 상한 없음, 대신 S-14에서 종류별로 끔. 광고성(마케팅) 메일·푸시는 별도 상한 월 1회, 마케팅 수신 동의자만, 밤 9시\~아침 8시 발송 안 함, 알림 센터에 남기지 않음
- 상한 밖(메일로 보내고 S-14에서 끌 수 없음)은 아래만. 보안·계정에 바로 영향이 있거나, 기한 안에 결정해야 하는 알림
  - 보안·계정: 새 기기 로그인, 연결 해제 요청, 연결 해제 완료, 상대 계정 삭제, 계정 삭제 접수·완료·복구, 관리자 열람 요청과 파트너 열람 알림, 문의 답변 도착, 약관 개정과 마케팅 수신 동의 재확인(법정 고지)
  - 서비스 고지: 1등급 장애 고지 메일(어드민에서 보냄, 서비스 메일이라 상한 밖)
- 알림 제목의 사람 이름은 그 사람 호칭, 호칭이 없으면 ‘파트너가’ / ‘파트너와’(“님이 …” 대신, 2026-11-11 S3-29). 파트너 변경(하나·여럿 묶음 “파트너가 3가지를 바꿨어요”), 활동 기록, 주간 요약 “이번 주 파트너가 바꾼 게 3개 있어요”, 파트너 열람 알림 “운영자가 파트너 문의를 확인하고 있어요” / “파트너가 동의한 범위만, 11월 7일까지 봐요” [확인 필요]도 같음(2026-11-12 S10-01). 서버 문구는 이 표와 같게(pgTAP `partner_noti_copy`)
- 파트너 미합류·혼자 쓰기면 상대에게 가는 알림 없음. 경조사 알림은 두 사람 모두에게, 파트너 미합류면 시작한 사람에게만 [확인 필요]
- 파트너 변경 알림(→ 핵심 규칙 › 커플·권한): 제안·승인 없이 누구나 바로 고치고, 상대에게 알림 + 알림 센터 활동 기록. 파트너 활동은 홈에 두지 않고 알림 센터에서만 봄
  - 바로 알림(푸시·인앱): 월급 계획 금액, 관리 방식, 저금 항목 목표 금액·기한·삭제, 목표 금액 달성(대신 체크 알림은 2026-11-03 없앰)
  - 주간 요약에만(푸시 없음, 센터 활동 기록 + 월요일 요약): 자산 금액 수정, 저금 항목 추가·이름·달성 뒤 선택, 경조사 추가·메모(제목 “예빈님이 경조사를 바꿨어요” [확인 필요], 2026-11-09 ‘챙길 날’에서 바꿈)
  - 두 목록에 없는 변경이 어느 쪽인지 → 핵심 규칙 › 커플·권한 4장 [확인 필요]
  - 묶기: 같은 사람이 바꾼 것은 첫 변경부터 10분 안의 것을 모아 푸시 1번, 센터에도 항목 1개. 하나면 그 문구, 여럿이면 “예빈님이 3가지를 바꿨어요” [확인 필요] + 누르면 바뀐 것 목록(목록 화면이 생기기 전까지는 첫 변경의 화면, 본문 “생활비 68만 원 → 70만 원 외 1개” [확인 필요])
  - 주간 요약에만 가는 변경은 푸시 없이 센터 활동 기록 1개(같은 묶기, 문구는 위 표 형식. 예: “예빈님이 자산을 바꿨어요” / “전세 보증금 2억 원 → 2억 2,000만 원”). 저금 항목 삭제 본문 “저금을 지웠어요” [확인 필요](넣기·빼기·꺼내 쓰기는 2026-11-08 없앰)
  - 10분 안에 ‘되돌리기’로 취소한 변경은 알리지 않음. 남은 게 없으면 보내지 않음
  - 주인이 있는 저금 항목(각자 모드) 변경은 알리지 않고 활동 기록에도 남기지 않음(달성만 알림). 변경 알림은 합쳐서 모드의 우리 둘 저금 항목만 [확인 필요]
  - 고친 사람에게는 알림 없이 Toast ‘되돌리기’만(→ 공통 › 공통 상태 14번)

- 대상이 이미 처리됨(체크리스트 사이클 끝남, 연결 해제 요청 취소 등): 처리 결과 화면으로 이동(지난 체크리스트는 읽기 전용으로 열림). 결과 화면이 없으면 Toast “이미 처리된 알림이에요”
- 대상 항목 삭제: 이동 없이 Toast “지워진 항목이에요”
- 대상 볼 권한 없음(연결 해제 뒤 상대 항목): 이동 없이 Toast “지금은 볼 수 없는 항목이에요”

## 센터와 푸시·메일

- 센터 = 받는 사람 기준 모든 알림 기록. 푸시·메일 발송 여부와 무관
- 상한·방해 금지로 보내지 않은 알림도 예정 시각에 센터에 쌓임
- 푸시 누름 → 앱 열림 + 대상 화면 + 센터 항목 읽음. 이메일 링크(sweetwo.kr 앱 링크) → 그 기기에 앱이 있으면 앱의 대상 화면 + 읽음, 없으면 웹사이트 안내 “sweeTwo 앱에서 열어 주세요” + 앱 받기(세션이 없으면 로그인 뒤 그 화면, 대상이 없거나 상대 비공개 항목이면 홈 + 토스트 → 로그인·가입 진입 표)
- S-14에서 받는 방법을 모두 꺼도 센터 기록은 계속
- 홈 할 일 한 줄(H-06)은 그대로, 센터는 별도 기록(예: 월급 전 확인 = 홈 할 일 + 센터 둘 다). 파트너 활동은 센터에만 있음
