# 월급 플랜

## 흐름 요약

기준일 0시에 플랜 생성 → 이번 달 맨 위 카드에서 W-02 월급 나누기(각자 월급일에) → 켠 경우 사이클 중간일에 W-03 생활비 체크 → 월말 정리. W-01은 이번 달의 월급 플랜 카드(H-03)에서 언제든 열림. 앱 틀 → 화면 설계 › 이번 달 › 앱 기본 틀, 여기서는 본문 영역만 그림. 플랜 생성 시점·사이클·첫 사이클 → 핵심 규칙 › 월 사이클. 사실값은 즉시 반영, 배분 결정은 제안 → 핵심 규칙 › 부부·제안·권한.

## W-01 월급 플랜

> 화면 그림: W-01 월급 플랜, 본문 영역(아래는 월급 나누기가 없거나 통장이 하나일 때 4칸 막대) (그림은 기획서 페이지 사본에 있어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 월 선택 | “‹ 10월 월급 플랜 ›”, 기간 “10.25 \~ 11.24” | 지난 달은 읽기 전용 |
| 2 | 임시 배지 | “임시” | 배우자 미합류 또는 추정값 있을 때만. 혼자 쓰기면 없음 |
| 3 | 진행 문구 | “7곳 중 2곳 나눴어요” | 두 사람 나누기 줄 전체 기준. 다 끝나면 “월급을 다 나눴어요”. 배우자가 합류하고 통장 역할을 나눈 부부만. 미합류 단계는 “예빈님이 합류하면 여기서 월급을 나눠요” 미리보기 한 줄만, 혼자 쓰기와 통장 하나는 없음 |
| 4 | 돈 흐름 막대 | 용돈, 공동 생활비, 목표자금, 비상금 | 월 수입 대비 비중, 보기만. 월급 나누기가 없거나 통장이 하나면 ‘용돈, 고정, 생활비, 저축’ 4칸 |
| 5 | 특이사항 | 예: “상여금 200만 원이 들어오는 달이에요” / “추석이 있어 양가 지출이 있어요” | 최대 3개. 들어오는 돈이면 탭 → W-07 |
| 6 | 계획액 | 통장별 금액, 통장 목록(ListRow: 역할 이름 + 잔액 + 이번 달 넣을 돈, → 우리 자산 F-01 16번)으로 보여 줌 | 탭 → W-01a. ⌄ 펼치면 목표자금은 목표별 배분, 공동 생활비는 고정지출 합계·생활비 예산(양가 비용은 목표자금 ‘양가 비용’ 목표로) |
| 7 | 담당·월급날 칩 | 이름표 “찬우”·날짜 “10.25”는 작고 흐리게, “156만”은 진하게 | 사람마다 1칩, 날짜 = 각자 월급날. 내 칩 체크 = 바로 완료, 배우자 칩은 보기만 |
| 8 | 자동 나누기 줄 | “목표자금 → 공동 생활비” | 아래 ‘자동 나누기 줄 표시’ |
| 9 | 주 버튼 | “월급 나누기” | W-02. 내 나누기가 다 끝나면 숨김. 월급 나누기가 없거나 통장이 하나면 주 버튼 “월급 플랜 저장” |

예외·오류

- 첫 사이클: 제목 “이번 달 남은 기간 플랜”, 금액 = 남은 일수 비례
- 배우자 미합류: 배우자 칩에 ‘추정’ 표시, 추정값 없으면 내 칩만
- 두 사람 다 수입 0원: 분담 50:50으로 담당 칩 계산 + 진행 문구 아래 “수입이 들어오면 다시 계산해요”. 한쪽만 0원이면 평소 분담 규칙(→ 핵심 규칙 › 계산·배분)
- 연결 해제 대기 중: 지난 플랜 그대로 연장, 금액 탭(W-01a) 비활성, 체크만 가능
- 사실값이 바뀐 직후: 아래 ‘사실값 바뀐 직후 표시’
- 금액 탭(W-01a ‘이번 달만 바꾸기’): 한 화면 입력, 빠지는 곳 금액을 바로 아래 미리보기. 제안 아님: 즉시 적용 + 상대 알림 + 토스트 ‘되돌리기’. 기본 배분 변경은 F-05·목표에서

## W-02 월급 나누기

월급 나누기: 앱은 돈을 옮기지 않음. 사용자가 은행 앱에서 각 통장으로 직접 옮긴 뒤 여기서 체크.

> 화면 그림: W-02 월급 나누기, 찬우 탭과 다른 금액 (그림은 기획서 페이지 사본에 있어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 사람 탭 | 이름표 “찬우” 작게 + “10.25” 진하게 / “예빈” + “11.10” 같은 방식 | 내 탭이 기본. 날짜 = 각자 월급일. 배우자 탭은 보기만 + ‘예빈님 대신 체크’ |
| 2 | 나누기 줄 | “공동 생활비 통장에 156만 원” | 공동 통장 나누기만(개인 통장 제외) |
| 3 | 옮겼어요 | ‘옮겼어요’ → 체크 표시 + ‘취소’ | 누르면 바로 완료, 체크한 사람 기록 |
| 4 | 다른 금액 | “다른 금액을 옮겼어요” | → W-02a |
| 5 | 자동 나누기 줄 | “공동 생활비 통장에 30만 원” + “목표자금 통장에서” | 일반 줄과 같은 체크 |
| 6 | 금액 입력 | “얼마를 옮겼어요?” / “계획보다 10만 원 적어요” | Q3, 계획액이 기본값. 차액은 미달·초과로 기록 |
| 7 | 주 버튼 | “확인” | 저장 → W-02 (줄은 완료 + 실제 금액 표시) |

- 월급 나누기(W-02)는 배우자가 합류하고 통장 역할을 나눠 쓸 때만 보임(“통장 하나로 써요”면 옮길 통장이 없어 숨김). 미합류, 혼자 쓰기, 통장 하나로 쓰는 부부는 월급 나누기 없이 월말 정리(W-04j 지출 입력, W-04k 저축 확인, 정산 요약)로 가계부를 끝까지 씀
- 월급일 전에도 체크 가능. 통장 잔액은 묻지 않음
- 내 나누기가 다 끝나면 W-02 끝 “월급을 다 나눴어요” + 배우자 진행(“예빈 0/3”). 배우자 활동(H-08)에만 표시, 알림 없음

예외·오류

- 대신 체크: 배우자 활동에 “찬우님이 대신 체크했어요”(앱 미설치 배우자용, 웹에서도 가능)
- 두 사람이 같은 줄을 거의 동시에 체크: 먼저 저장된 체크 유지, 나중 사람에게 “예빈님이 먼저 체크했어요”
