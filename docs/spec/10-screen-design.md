# 화면 설계

화면별 와이어프레임·요소·문구의 목차. 여러 화면에 걸친 규칙 → 화면 설계 › 공통, 알림 → 화면 설계 › 알림.

## 화면 ID

| 접두어 | 범위 | 화면 탭 |
| --- | --- | --- |
| A | 로그인·가입·앱 잠금·세션 | 로그인·가입 |
| O | 온보딩(11화면, O-10 첫 화면 \~ O-60 결과) | 온보딩 ①② |
| P | 배우자 합류 | 배우자 합류 |
| H | 홈(H-01\~H-06) | 홈 |
| W | 월급 분배표·이번 달 월급 체크리스트·월말 확인 | 월급 체크리스트 |
| G | 목표 | 목표 |
| F | 자산·부채·순자산 | 우리 자산 |
| Y | 챙길 날(생일, 기념일, 명절, 양가 행사 모두 같은 종류)·돈 날짜 보기(캘린더) | 캘린더 |
| S | 설정·가이드 모아보기 | 설정 |
| WG | 위젯(트레이 위젯 창, OS·모바일 홈·잠금 화면 위젯) | 위젯 |
| N | 알림 센터 | 알림 |
| AD | 어드민(웹 전용) | 어드민 화면 |
| L | 공개 웹사이트(랜딩, 설치 안내, 릴리스 노트, 약관, 고객센터) | 웹사이트 |
| Q1\~Q7 | 질문 화면 패턴(화면 ID 아님) | 공통 › 질문 화면 패턴 |

- 화면 ID = 접두어 + 두 자리 순번(예: A-03). 한 화면을 나눈 단계는 뒤에 소문자(예: F-04a, S-12d). 결번: L-04, S-11c, S-12b, S-12e, S-12f(없앤 화면, 번호 다시 쓰지 않음)
- 2026-10-25 재기획(→ `docs/adr/0003-replan-goal-checklist.md`)
  - 그대로 남는 ID: O-03, O-06, O-07, O-11, O-12, O-21, O-23, O-24, W-01, W-02
  - 새 뜻으로 다시 쓰는 ID: O-10 온보딩 첫 화면, O-13 출생연도(예전 생년월일, 2026-10-26 다시 넣음), O-30 월급 관리 방식, O-31 월급, O-50 월급 분배표, O-60 결과, W-01 월급 분배표, W-05 월말 확인, H-01\~H-06 새 홈 구성
  - 없앤 ID(번호 다시 쓰지 않음): O-14(배우자 출생연도는 합류 P-03a에서 본인이 답함), O-19a\~e, O-36\~O-67(O-60 빼고), W-01a, W-03, W-04a\~p, W-07, G-08, H-P1\~P7, H-T1\~T7
  - 예전 챕터 안내(O-20 등)와 11화면 밖의 다른 O 화면(O-14\~O-35 중)은 목표 추가(G-03) 같은 다른 화면이 틀을 빌려 쓰는지 확인한 뒤 결번으로 정리 [확인 필요]

## 와이어프레임 범례

| 표시 | 뜻 |
| --- | --- |
| 상단 띠 + 점 3개 창 | 데스크톱 앱 창 |
| 상단 띠에 주소 칸이 있는 창 | 웹사이트(브라우저) |
| 둥근 세로 틀 | 좁은 창 웹 |
| 실선 사각형 | 입력 칸, 보조 버튼 |
| 색 채운 버튼 (유일한 색) | 주 버튼 |
| 점선 + 옅은 채움 버튼 | 비활성 주 버튼 (입력 전) |
| 회색 밑줄 글자 | 링크 |
| X 친 상자 | 이미지·그림 자리 |
| 번호 원 | 아래 요소 표의 번호 |

- 와이어프레임은 데스크톱 창 기준. 좁은 창 배치가 다를 때만 오른쪽에 좁은 창을 함께 그림
