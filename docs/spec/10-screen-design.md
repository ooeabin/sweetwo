# 화면 설계

화면별 와이어프레임·요소·문구의 목차. 여러 화면에 걸친 규칙 → 화면 설계 › 공통, 알림 → 화면 설계 › 알림.

## 화면 ID

| 접두어 | 범위 | 화면 탭 |
| --- | --- | --- |
| A | 로그인·가입·앱 잠금·세션 | 로그인·가입 |
| O | 온보딩 (파트 시작 = O-{파트}0) | 온보딩 ①② |
| P | 배우자 합류 | 배우자 합류 |
| H | 이번 달 (예비부부·결혼일 전환 포함) | 이번 달 |
| W | 월급 플랜·월급 나누기·생활비 체크·월말 정리 | 월급 플랜, 월말 정리 |
| G | 목표 (G-08 = 단건 제안 응답) | 목표 |
| F | 자산·부채·월 수입·지출·재정 진단 | 우리 자산 |
| Y | 챙길 날·돈 날짜 보기(캘린더) | 캘린더 |
| S | 설정·가이드 모아보기 | 설정 |
| WG | 위젯(트레이 위젯 창, OS·모바일 홈·잠금 화면 위젯) | 위젯 |
| N | 알림 센터 | 알림 |
| AD | 어드민(웹 전용) | 어드민 화면 |
| L | 공개 웹사이트(랜딩, 설치 안내, 릴리스 노트, 약관, 고객센터) | 웹사이트 |
| Q1\~Q7 | 질문 화면 패턴(화면 ID 아님) | 공통 › 질문 화면 패턴 |

- 화면 ID = 접두어 + 두 자리 순번(예: A-03). 한 화면을 나눈 단계는 뒤에 소문자(예: F-04a, S-12d). 결번: L-04, S-11c(없앤 화면, 번호 다시 쓰지 않음)

## 와이어프레임 범례

| 표시 | 뜻 |
| --- | --- |
| 상단 띠 + 점 3개 창 | 데스크톱 앱 창 |
| 상단 띠에 주소 칸이 있는 창 | 웹사이트(브라우저) |
| 둥근 세로 틀 | 좁은 창 웹 |
| 실선 사각형 | 입력 칸, 보조 버튼 |
| 색 채운 버튼 (유일한 색) | 주 버튼 |
| 점선 + 옅은 채움 버튼 | 비활성 주 버튼 (입력 전) |
| 회색 밑줄 글자 | 링크 |
| X 친 상자 | 이미지·그림 자리 |
| 번호 원 | 아래 요소 표의 번호 |

- 와이어프레임은 데스크톱 창 기준. 좁은 창 배치가 다를 때만 오른쪽에 좁은 창을 함께 그림

## 화면 탭

| 화면 탭 | 범위 | 화면 ID |
| --- | --- | --- |
| 공통 (하위: 질문 화면 패턴, 공통 상태) | 모든 화면 공통 규칙, 질문 틀·입력 패턴, 빈 화면·오류·오프라인 등 상태 | Q1\~Q7 |
| 알림 | 알림 종류·문구·상한, 알림 센터 | N-01\~03 |
| 로그인·가입 | 실행, 시작 화면, 소셜 로그인·가입(카카오·구글·애플), 브라우저 로그인 대기, 알림 이메일 입력, 약관, 앱 잠금, 초대 링크 진입, 세션 만료 | A-01\~08, O-01 |
| 온보딩 ① 파트 0\~2 | 호칭·결혼 상태·목표(예비부부 분기 포함) | O-03\~O-25 |
| 온보딩 ② 파트 3\~6 | 소득·지출·자산·돈 나누는 규칙·결과·첫 미션 | O-31\~O-67 |
| 배우자 합류 | 합류 온보딩 | P-01\~11 |
| 이번 달 | 첫 화면(할 일·월급 플랜 카드·받은 제안)·예비부부·결혼일 전환, 앱 기본 틀·검색 | H- |
| 월급 플랜 | 플랜·월급 나누기·생활비 체크 | W-01\~03 |
| 월말 정리 | 월말 정리·제안 응답·놓친 달·들어오는 돈 | W-04\~, W-07 (묶음 제안 W-04p) |
| 목표 | 목표 목록·상세·추가·결혼 비용·단건 제안(G-08) | G- |
| 우리 자산 | 자산·부채·월 수입·지출·재정 진단 | F- |
| 캘린더 | 양가·우리 둘 챙길 날, 돈 날짜 읽기 전용 표시 | Y- |
| 설정 | 설정(메뉴 밖, 상단 두 사람 아바타·좁은 창 설정 버튼으로 진입)·휴지통·위젯 설정, 가이드 모아보기 | S-01\~22 |
| 위젯 | 데스크톱 트레이 위젯 창, OS 기본 위젯·모바일 홈·잠금 화면 위젯(출시 뒤) | WG-01\~05 |
| 어드민 화면 | 웹 전용 내부 도구 | AD- |
| 웹사이트 | 공개 웹사이트, 다운로드와 설치 안내, 초대 링크 이동 | L-01\~L-03, L-05, L-06 |
