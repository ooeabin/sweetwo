# 화면 설계

화면별 와이어프레임·요소·문구의 목차. 여러 화면에 걸친 규칙 → 화면 설계 › 공통, 알림 → 화면 설계 › 알림.

## 화면 ID

| 접두어 | 범위 | 화면 탭 |
| --- | --- | --- |
| A | 로그인·가입·앱 잠금·세션 | 로그인·가입 |
| O | 온보딩(질문 6~7화면 + O-60 준비 끝, O-03 이름 \~ O-60, 2026-11-10 O-10·O-12·O-13 뺌) | 온보딩 ①② |
| P | 파트너 합류 | 파트너 합류 |
| H | 홈(H-01\~H-09, 2026-11-09 홈 허브. H-01·H-05는 없앰) | 홈 |
| W | 월급 탭: 월급 계획·이번 달 월급 체크리스트·월급 전 확인·저금 항목(W-10\~W-12) | 월급 탭 |
| G | 목표(2026-11-08 없앰, ADR 0007. 번호 다시 쓰지 않음) | — |
| F | 자산·부채·순자산 | 자산 관리 |
| Y | 경조사(생일, 기념일, 명절, 양가 행사 모두 같은 종류)·금융 일정 보기(캘린더) | 캘린더 |
| S | 설정·가이드 모아보기 | 설정 |
| WG | 위젯(모바일 홈·잠금 화면 위젯. 트레이 위젯 창은 없앰 2026-11-10, ADR 0008) | 위젯 |
| N | 알림 센터 | 알림 |
| AD | 어드민(웹 전용) | 어드민 화면 |
| L | 공개 웹사이트(랜딩, 설치 안내, 릴리스 노트, 약관, 고객센터) | 웹사이트 |
| Q1\~Q7 | 질문 화면 패턴(화면 ID 아님) | 공통 › 질문 화면 패턴 |

- 화면 ID = 접두어 + 두 자리 순번(예: A-03). 한 화면을 나눈 단계는 뒤에 소문자(예: F-04a, S-12d). 결번: L-04, S-12b, S-12e, S-12f(없앤 화면, 번호 다시 쓰지 않음). S-11c는 ‘내 월급’ 화면으로 씀
- 2026-10-25 재기획(→ `docs/adr/0003-replan-goal-checklist.md`)
  - 그대로 남는 ID: O-03, O-06, O-07, O-11, O-21, O-23, O-24, W-01, W-02(O-12는 2026-11-10 없앰)
  - 새 뜻으로 다시 쓰는 ID: O-10 온보딩 첫 화면·O-13 출생연도(둘 다 2026-11-10 없앰, 번호 다시 쓰지 않음), O-30 월급 관리 방식, O-31 월급, O-50 월급 계획, O-60 결과, W-01 월급 계획, W-05 월급 전 확인, H-01\~H-06 새 홈 구성
  - 없앤 ID(번호 다시 쓰지 않음): O-14, P-03a 합류 출생연도(2026-11-11, 출생연도는 F-08 ‘출생연도 알려 주기’ → S-11i), O-19a\~e, O-36\~O-67(O-60 빼고), W-01a, W-03, W-04a\~p, W-07, G-08, H-P1\~P7, H-T1\~T7
  - 예전 챕터 안내(O-20 등)와 다른 O 화면(O-14\~O-35 중)은 결번
- 2026-11-09 홈 허브(GCOO 앱 홈처럼, 좁은 창 하단 탭 막대 대신 ☰ 메뉴 서랍): H-02 저금 상자, H-03 큰 상자(다음 월급날), H-04 자산 관리 타일로 뜻을 바꿔 다시 씀. 새 ID H-07 월급 계획 타일, H-08 캘린더 타일, H-09 저금 타일. 없앤 ID: H-05 일정(번호 다시 쓰지 않음)
- 2026-11-08 목표를 저금 항목으로(→ `docs/adr/0007-goal-into-saving-line.md`)
  - 새 ID: W-10 저금 항목 상세, W-10a 고치기, W-11a\~d 저금 항목 추가, W-12 달성 축하, W-12a 달성 뒤 선택
  - 없앤 ID(번호 다시 쓰지 않음): G-01\~G-08 전부(G-02a·b·p, G-03a\~g 포함), O-21, O-23, O-24, H-06 할 일 ‘목표 금액 정하기’

## 와이어프레임 범례

| 표시 | 뜻 |
| --- | --- |
| 상단 띠 + 점 3개 창 | 넓은 창(예전 데스크톱 앱 창 그림, 지금은 태블릿 넓은 창으로 읽음) |
| 상단 띠에 주소 칸이 있는 창 | 웹사이트(브라우저) |
| 둥근 세로 틀 | 좁은 창 웹 |
| 실선 사각형 | 입력 칸, 보조 버튼 |
| 색 채운 버튼 (유일한 색) | 주 버튼 |
| 점선 + 옅은 채움 버튼 | 비활성 주 버튼 (입력 전) |
| 회색 밑줄 글자 | 링크 |
| X 친 상자 | 이미지·그림 자리 |
| 번호 원 | 아래 요소 표의 번호 |

- 와이어프레임은 넓은 창 기준(예전 데스크톱 창 그림, 지금은 태블릿). 좁은 창 배치가 다를 때만 오른쪽에 좁은 창을 함께 그림

| 화면 탭 | 범위 | 화면 ID |
| --- | --- | --- |
| 공통 (하위: 질문 화면 패턴, 공통 상태) | 모든 화면 공통 규칙, 질문 틀·입력 패턴, 빈 화면·오류·오프라인 등 상태 | Q1\~Q7 |
| 알림 | 알림 종류·문구·상한, 알림 센터 | N-01\~03 |
| 로그인·가입 | 실행, 시작 화면, 소셜 로그인·가입(카카오·구글·애플), 브라우저 로그인 대기, 알림 이메일 입력, 약관, 앱 잠금, 초대 링크 진입, 세션 만료 | A-01\~08, O-01 |
| 온보딩 ① 흐름 | 이름·초대·결혼 상태(2026-11-10 첫 화면 O-10, 결혼한 날 O-12, 출생연도 O-13 뺌) | O-03, O-06, O-07, O-11 |
| 온보딩 ② 월급 | 월급 관리 방식·월급·월급날(월급 계획은 추천값으로 자동, 결과 화면 없음, ADR 0005) | O-30, O-31, O-32, (O-50 추천값) |
| 파트너 합류 | 합류 온보딩 | P-01\~11 |
| 홈 | 첫 화면 허브(2026-11-09: 다음 월급날 큰 상자, 할 일 띠, 월급 계획·캘린더 타일, 저금 상자, 자산 관리·저금 타일), 앱 기본 틀(넓은 창 사이드바, 좁은 창 머리·메뉴 서랍)·검색 | H-01\~09 |
| 월급 탭 | 월급 계획·이번 달 월급 체크리스트·월급 전 확인·저금 항목 상세·추가·달성 축하·저금 목록 | W-01, W-02, W-02a, W-05, W-10, W-10a, W-11a\~d, W-12, W-12a, W-13 |
| 월급 전 확인 | 예전 월말 정리를 없앤 안내와 바뀐 곳 표(화면은 월급 체크리스트 W-05) | — |
| 목표 | 없앰(2026-11-08), 바뀐 곳 표만 | — |

| 설정 | 설정(메뉴 밖, 상단 두 사람 아바타·좁은 창 설정 버튼으로 진입)·휴지통·위젯 설정, 가이드 모아보기 | S-01\~22 |
