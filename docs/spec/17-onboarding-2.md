# 온보딩 ② 파트 3\~6

## 흐름 요약

챕터 3(수입과 지출) = 파트 3, 챕터 4(나누기와 플랜) = 파트 5·6(챕터 → 온보딩 ① 흐름 요약). 파트 3(소득·지출)은 필수, 파트 4(자산·부채)는 전부 첫 주 할 일로 미룸. 파트 5에서 용돈·분담을 정하고 파트 6 결과(요약 → 통장 → 목표 → 진단 → 월급 플랜 → 첫 미션)를 거쳐 이번 달.

| 경우 | 첫 결과 전 경로 | 첫 주 할 일로 미룸 |
| --- | --- | --- |
| 신혼부부, ‘지금부터 합쳐서’ 예비부부 | O-30 → O-31 → O-32 → O-33 → O-36 → O-38 → O-39 → O-50 → O-51 → O-52 → O-61\~67 → 이번 달 | O-34\~35b, O-37, O-38b, O-41\~47, O-53 |
| ‘각자 관리’ 예비부부 (O-19e) | O-30 → O-31 → O-32 → O-33 → O-50 → O-52(결혼 비용) → O-61\~67(결혼 준비 통장 1개) → 이번 달(예비부부 모드) | **O-36\~39 건너뜀** → 결혼일 전환(H-T5). O-51·O-53도 결혼일 전환(H-T)에서 |
| 프리랜서·사업자 (O-16) | O-31 대신 O-31 분기(가장 적게 번 달) | O-35b 변동 수입도 같은 기준 |
| O-39 ‘없어요’ | — | 3일째 ‘대출 정리하기’ 없음 |
| 배우자 미합류 또는 추정값 있음 | 결과에 ‘임시 플랜’ 배지 | 결과 직후 ‘배우자 초대하기’(O-07) |

- 진행 표시: 챕터 진행(“3/4 수입과 지출”, “4/4 나누기와 플랜” + 챕터 안 막대, → 온보딩 ① 흐름 요약). 결과(O-61\~67)는 4/4 모두 채움
- ‘나중에 할게요’: 파트 5만 표시
- 첫 주 할 일 화면: 진행 막대 = 카드 안 화면 수, 오른쪽 ‘닫기’(답 저장, 카드는 이번 달에 남음). 끝나면 이번 달
- 반복 화면(O-37·O-42·O-45\~47): 질문 위 “{항목} 2/4”
- 예시값: 찬우 실수령 350만 원·월급날 25일, 예빈 추정 250만 원(미합류, 200\~300만 구간 중간값), 공동 고정지출 100만 + 대출 상환 30만, 생활비 130만, 용돈 각자 50만, 분담 ‘직접 정할게요’ 60 : 40(‘버는 만큼’ = 실수령 비율 350 : 250 → 찬우 292만, 예빈 208만), 9월 월급 플랜 남은 18일

| 합류 + 추정값 있음 | 임시 플랜 | “추정값을 정확히 채우면 다시 계산돼요” | 추정값이 들어간 값만 ‘추정’ |
| 합류 + 추정값 없음 | 없음 | — | 없음 |
| 혼자 쓰기 | 없음 | — | 추정값이 들어간 값만 ‘추정’ |

- 값을 채우거나 배우자가 합류하면 재계산(안 나눈 돈만), 배지·추정 사라짐
- 첫 플랜 이름 = 기준일의 월(25일 기준, 10월 7일 시작 → “9월 월급 플랜”)

예외·오류

- 남은 기간 15일 미만: 4번 아래 “이번 달은 기간이 짧아서 다음 달과 합쳐 정리해요”. 사이클 합치기 → 핵심 규칙 › 월 사이클
- 기준일 변경으로 남은 기간 0일: 새 기준일까지로 재계산
- 4번 0원: “이번 달은 옮기지 않고 시작할까요?” 1회 확인
- 저장 실패·오프라인: 기기에 먼저 저장, 연결되면 자동 저장
