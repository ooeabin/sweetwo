# 온보딩 ② 월급과 월급 계획

## 흐름 요약

2026-11-13부터 아래 ‘온보딩 ② v2.2’가 정본. 예전(2026-11-02, ADR 0005): O-30 월급 관리 방식 → O-31 월급 → O-32 월급날 → O-60 준비 끝 → 홈. O-32 다음에 월급 계획을 추천값으로 만들고(O-50 추천값 표) 첫 체크리스트를 연 뒤 홈으로. 월급 계획은 홈 H-03 ‘월급 계획 고치기’ → W-01에서 고침(2026-11-03 할 일 ‘월급 계획 확인’은 없앰). 온보딩 ①에 이어짐(→ 온보딩 ① 흐름 요약). 월급 계획과 체크리스트 규칙 → 월급 체크리스트, 계산 → 핵심 규칙 › 계산·배분.

- 예시: 찬우 실수령 350만 원, 월급날 25일, ‘각자’, 저금 항목 없음(온보딩 뒤 체크리스트 첫 저금 빈 줄에서 추가, ADR 0007·2026-11-09)
- 파트너 미합류여도 같은 흐름. 월급 계획은 내 월급으로만 만듦

O-50 추천값 고친 점(→ 06 3-1·3-2)

- ‘체크리스트에 넣기’ 기본: 저금·고정지출 켬, 생활비·용돈 끔. 자동 줄 기본 끔, 나가는 날 기본 = 월급날(날짜 없음은 1일)
- 합쳐서 추천 용돈: 같은 금액(합 × 10% ÷ 2, 1만 원 단위). 소득 비례는 W-01에서 직접
- 한 사람 관리형: 관리하지 않는 쪽 줄은 합류 때 ‘보내기’ + ‘용돈’(P-05c)
- 생활비 ‘네’ + 각자 관리: ‘같이 쓰는 통장’ 0원 줄(체크리스트에 넣기 켬, 자동 줄 켬, Q9)
