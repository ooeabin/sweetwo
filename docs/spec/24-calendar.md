# 캘린더

## 흐름 요약

캘린더 탭(첫 화면 = Y-04 달력, 2026-11-17부터. 예전 Y-01 일정 목록은 없앰) → 날 누르면 상세(Y-05) → ‘다녀왔어요’ → 기록(Y-08). 한 달력에 두 가지가 보임: 앱이 자동으로 넣는 금융 일정(월급날, 목표 기한(기한을 정한 저금 항목만), 만기, 월급날 확인 목록 안내)과 사용자가 직접 넣는 경조사. 경조사는 생일, 기념일, 명절, 양가 행사를 모두 같은 종류로, 같은 방법(Y-07)으로 넣음. 결정 이유 → `docs/adr/0003-replan-goal-checklist.md`.

- 예시값: 찬우(시작한 사람), 예빈(합류한 사람), 오늘 10월 2일, 월급날 25일
- 입력 흐름(Y-07·08)은 본문 위 레이어, 공통 틀(진행 막대 = 흐름 안 화면 수, 닫기 = 입력값 저장)
- 없앤 것: 양가 처음 등록(Y-02), 가족 목록(Y-03), 양가 비용 예산과 매년 목표(Y-06), 양가·우리 둘 구분과 색, 낸 곳 질문과 월급 나누기 줄, 결혼 준비 일정·결제, 파트너 생일 서프라이즈, 단계별 체크리스트, 제안 적용일

## 캘린더 범위

- 캘린더 탭(아이콘 calendar) = 금융 일정과 경조사를 한 달력·목록에서 보는 날짜 화면. 홈 = 한눈에, 월급 = 체크와 저금, 자산 관리 = 현황, 캘린더 = 날짜
- 경조사: 추가·수정·기록 모두 여기서(Y-04\~Y-09). 생일, 결혼기념일, 사귄 날, 명절, 어버이날, 가족 행사(2026-11-13 ‘양가 행사’에서), 그 밖의 날 모두 같은 종류. 따로 보는 화면, 따로 쓰는 색, 분류가 없음
- 금융 일정: 앱이 자동으로 넣고 캘린더에서는 고치지 않음(읽기 전용). 누르면 해당 화면으로 이동(아래 표)
- 보기 필터 “전체” “경조사·기념일” “금융 일정”(2026-11-23부터 밑줄 탭, 예전 작은 칩 줄) [확인 필요](2026-11-15 ‘경조사’에서 바꿈): 목록·달력 공통, 기본 “전체”, 마지막 선택 기억
- 표시 구분: 경조사 = 영역 색 점 한 가지(together), 금융 일정 = 검정 작은 점 + 작은 라벨
- 홈 캘린더 타일(H-08)에 가장 가까운 경조사 하나와 D-day(2026-11-09, 예전 홈 H-05 일정 최대 3개는 없앰, → 홈)

- 달성했거나 그만 모은 저금 항목의 기한은 표시하지 않음

## 규칙

- 경조사의 금액은 메모일 뿐. 저금 항목, 월급 계획, 체크리스트, 순자산 어디에도 더하거나 빼지 않음 [확인 필요]
- 경조사를 위해 미리 모으고 싶으면 저금 항목을 따로 만듦(예: ‘양가 행사’). 캘린더가 자동으로 저금 항목을 만들거나 빼지 않음(꺼내 쓰기는 2026-11-08 없앰)
- 누가 넣거나 고쳐도 바로 반영 + 상대 알림, 활동 기록(→ 핵심 규칙 › 커플·권한). 상대 화면도 바로 바뀜(Realtime, 2026-11-12 QA 9구간 S9-03). 고친 사람에게 Toast “고쳤어요” + ‘되돌리기’(6초, 고치기 전 값으로, Y-05 준비 상황·미리 알림·메모·금액 메모, Y-07 수정, S9-04)
- 미리 알림은 두 사람 모두에게 [확인 필요]. 파트너 미합류면 시작한 사람에게만
- 파트너에게 숨기는 경조사(서프라이즈)는 두지 않음. 모든 경조사는 두 사람이 같이 봄 [확인 필요]. 2026-11-12 QA 9구간 D2: 서버도 새 서프라이즈와 21자 넘는 이름을 거절(지금 있는 옛 행은 그대로)

### 경조사 그림 키 (2026-11-24 K안, 사용자 결정)

달력 칸(숫자 아래 20px)과 고른 날·다가오는 일정 줄 앞(40px)에 보이는 그림 이름. 그림 목록과 그림체는 `docs/design/assets/Illustrations.md` 10번, 코드 표는 core `rules/calendar-view.ts` 한 곳(`CARE_ART_KEYS`, `careArtDefault`, `moneyArtKey`). 그림 파일 이름 = 키. 파일이 아직 없으면 그림 칸을 그리지 않음(숨김 규칙).

- 경조사: DB `care_day.art_key`(글자, 비어 있을 수 있음). Y-07에서 이름 칩을 고르면 칩 기본 그림을 저장하고, 12개 중 다른 것을 고르면 그것. 비어 있거나 12개 밖 값이면 앱이 kind 기본값을 씀. 마이그레이션 `20261229090000_care_art_key`가 기존 행을 kind 기준으로 채움.
- 칩 기본값: 생일 `cake`, 결혼기념일 `diamond`, 사귄 날 `heart`, 설날·추석 `moon-stars`, 어버이날 `flower-tulip`, 행사 `gift`, 직접 쓰기와 그 밖 `gift`. 12개: `cake` `heart` `diamond` `gift` `flower-tulip` `confetti` `users-three` `house` `baby` `graduation-cap` `airplane-tilt` `moon-stars`.
- 금융 일정은 종류별 고정 4개(고르지 않음): 월급날 `wallet`, 자산·대출 만기 `vault`, 저축·투자 기한 `flag-pennant`, 쓸 곳 메모 날짜 `receipt`. 월급날 확인 목록 안내, 자동으로 나가는 날, 공휴일은 그림 없음.

### 자동으로 만드는 결혼기념일 [확인 필요]

- 설정 S-11h에서 결혼한 날을 처음 넣을 때(결혼 상태 ‘결혼했어요’) 경조사 하나를 만듦(2026-11-10 온보딩 O-12 없앰): 이름 “결혼기념일”, 날짜 = 결혼한 날(양력), 반복 매년, 금액 메모 없음, 미리 알림은 Y-07 기본값
- 다른 경조사와 같은 종류. 만든 뒤에는 Y-07에서 이름, 날짜, 알림을 고치거나 지울 수 있음. 지운 뒤에 결혼한 날을 바꿔도 다시 만들지 않음
- 이미 있으면 새로 만들지 않음. 설정에서 결혼한 날을 바꾸면 자동으로 만든 경조사의 날짜도 옮김(사용자가 날짜를 직접 고쳤으면 옮기지 않음)
- 준비 중(결혼 예정일)은 만들지 않음. 결혼 상태가 ‘결혼했어요’가 아니게 바뀌면 자동으로 만든 결혼기념일을 지움(사람이 날짜·이름을 고쳤거나 다녀온 기록이 있으면 그대로, 2026-11-10 잘못 고른 ‘결혼했어요’를 바로잡을 때 남지 않게). 다시 ‘결혼했어요’ + 날짜면 새로 만듦. 자동으로 만들 때는 따로 상대 알림을 보내지 않음(설정에서 결혼한 날을 바꾼 알림 하나로 충분)
