# 캘린더

## 흐름 요약

캘린더 탭(Y-01 목록 / Y-04 달력) → 날 누르면 상세(Y-05) → ‘다녀왔어요’ → 기록(Y-08). 한 달력에 두 가지가 보임: 앱이 자동으로 넣는 돈 일정(월급날, 목표 기한, 만기, 월말 확인)과 사용자가 직접 넣는 챙길 날. 챙길 날은 생일, 기념일, 명절, 양가 행사를 모두 같은 종류로, 같은 방법(Y-07)으로 넣음. 결정 이유 → `docs/adr/0003-replan-goal-checklist.md`.

- 예시값: 찬우(시작한 사람), 예빈(합류한 사람), 오늘 10월 2일, 월급날 25일
- 입력 흐름(Y-07·08)은 본문 위 레이어, 공통 틀(진행 막대 = 흐름 안 화면 수, 닫기 = 입력값 저장)
- 없앤 것: 양가 처음 등록(Y-02), 가족 목록(Y-03), 양가 비용 예산과 매년 목표(Y-06), 양가·우리 둘 구분과 색, 낸 곳 질문과 월급 나누기 줄, 결혼 준비 일정·결제, 배우자 생일 서프라이즈, 단계별 체크리스트, 제안 적용일

## 캘린더 범위

- 캘린더 탭(아이콘 calendar) = 돈 일정과 챙길 날을 한 달력·목록에서 보는 날짜 화면. 홈 = 한눈에, 목표 = 모으기, 우리 자산 = 현황, 캘린더 = 날짜
- 챙길 날: 추가·수정·기록 모두 여기서(Y-01\~Y-09). 생일, 결혼기념일, 명절, 어버이날, 양가 행사, 그 밖의 날 모두 같은 종류. 따로 보는 화면, 따로 쓰는 색, 분류가 없음
- 돈 일정: 앱이 자동으로 넣고 캘린더에서는 고치지 않음(읽기 전용). 누르면 해당 화면으로 이동(아래 표)
- 보기 필터 칩 “전체” “챙길 날” “돈 일정” [확인 필요]: 목록·달력 공통, 기본 “전체”, 마지막 선택 기억
- 표시 구분: 챙길 날 = 영역 색 점 한 가지(together), 돈 일정 = 검정 작은 점 + 작은 라벨
- 30일 안 일정 최대 3개는 홈 H-05 다가오는 일정에도 보임(→ 홈)

| 돈 일정 | 라벨 | 누르면 |
| --- | --- | --- |
| 월급날 | 각자 모드 “찬우 월급날” “예빈 월급날” / 합쳐서 모드는 체크리스트를 만드는 날 하나 “월급날” | W-02 그 달 체크리스트 |
| 목표 기한 | “{목표 이름} 기한”. 매년 목표는 “{목표 이름} 쓰는 달”(그 달 1일) | G-02 목표 상세 |
| 자산·대출 만기일 | “{항목 이름} 만기”. 배우자 비공개 항목은 표시 안 함 | F-04 항목 상세 |
| 월말 확인 | “월급 확인” [확인 필요] + 다음 월급날 3일 전\~전날 띠 | W-05 월말 확인(체크 안 한 줄이 없으면 W-02) |

- 월급날이 주말·공휴일이면 직전 영업일에 표시(설정 S-11에서 끔, → 핵심 규칙 › 월 사이클 1장)
- 달성·보류·사용 완료 목표의 기한은 표시하지 않음

## 규칙

- 챙길 날의 금액은 메모일 뿐. 목표, 월급 분배표, 체크리스트, 순자산 어디에도 더하거나 빼지 않음 [확인 필요]
- 챙길 날을 위해 미리 모으고 싶으면 목표를 따로 만듦(예: ‘양가 큰 행사’, ‘결혼기념일’ 목표). 목표 돈을 썼으면 목표 상세 ‘꺼내 쓰기’(G-02b)에서 기록. 캘린더가 자동으로 목표를 만들거나 빼지 않음
- 누가 넣거나 고쳐도 바로 반영 + 상대 알림, 활동 기록(→ 핵심 규칙 › 부부·권한)
- 미리 알림은 두 사람 모두에게 [확인 필요]. 배우자 미합류면 시작한 사람에게만
- 배우자에게 숨기는 챙길 날(서프라이즈)은 두지 않음. 모든 챙길 날은 두 사람이 같이 봄 [확인 필요]

예외·오류

- 챙길 날이 하나도 없음: 4·5번 자리에 빈 상태(틀 → 공통 › 공통 상태) “생일, 기념일, 명절을 적어 두면 미리 알려 드려요” [확인 필요] + “챙길 날 추가” → Y-07. 돈 일정은 그대로 보임
- 음력 날: 올해 양력 날짜로 표시, 상세에 음력 함께. 윤달 날짜가 그해 없으면 평달 같은 날, 음력 30일이 없는 달이면 그 달 말일(→ 핵심 규칙 › 데이터 항목 3장)
- 60일 안 챙길 날 없음: 5번 자리 “60일 안에는 챙길 날이 없어요”
- ‘돈 일정’ 필터에 이번 달 돈 일정 없음: “이번 달은 돈 일정이 없어요” [확인 필요]

### 자동으로 만드는 결혼기념일 [확인 필요]

- 온보딩 O-12 ‘했어요’(결혼한 날) 저장 때, 또는 설정 S-11h에서 결혼한 날을 처음 넣을 때 챙길 날 하나를 만듦: 이름 “결혼기념일”, 날짜 = 결혼한 날(양력), 반복 매년, 금액 메모 없음, 미리 알림은 Y-07 기본값
- 다른 챙길 날과 같은 종류. 만든 뒤에는 Y-07에서 이름, 날짜, 알림을 고치거나 지울 수 있음. 지운 뒤에 결혼한 날을 바꿔도 다시 만들지 않음
- 이미 있으면 새로 만들지 않음. 설정에서 결혼한 날을 바꾸면 자동으로 만든 챙길 날의 날짜도 옮김(사용자가 날짜를 직접 고쳤으면 옮기지 않음)
- 준비 중(결혼 예정일)은 만들지 않음. 자동으로 만들 때는 따로 상대 알림을 보내지 않음(설정에서 결혼한 날을 바꾼 알림 하나로 충분)
