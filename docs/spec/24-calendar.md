# 캘린더

## 흐름 요약

캘린더 메뉴(Y-01 목록 / Y-04 달력) → 날 누르면 상세(Y-05) → ‘다녀왔어요’ → 기록(Y-08, 낸 곳에 따라 양가 비용 차감·나누기 줄). 처음엔 Y-02로 양가 부모님과 양가 비용 예산을 만들고, 예산은 Y-06에서 바꿔 예빈에게 제안함.

- 예시값: 찬우(작성자), 예빈(배우자), 오늘 10월 2일, 기준일 25일, 결혼기념일 4월 18일

## 캘린더 범위

- 캘린더 메뉴(아이콘 calendar) = 챙길 날과 돈 날짜를 한 달력·목록에서 보는 날짜 화면. 이번 달 = 할 일, 우리 자산 = 현황 기록, 캘린더 = 날짜
- 챙길 날(양가·기념일·명절): 추가·수정·기록 모두 여기서(Y-01\~Y-09). ‘챙길 날’은 일정 종류 이름으로 씀
- 돈 날짜: 읽기 전용. 캘린더에서 수정하지 않고, 누르면 해당 화면으로 이동(아래 표)
- 보기 필터 칩 “전체” “챙길 날” “돈 날짜”: 목록·달력 공통, 기본 “전체”, 마지막 선택 기억
- 표시 구분: 챙길 날 = 영역 색 점(양가 family, 우리 둘 together), 돈 날짜 = 검정 작은 점 + 작은 라벨
- 서프라이즈 일정 숨김 규칙은 보기 필터와 상관없이 그대로(→ 서프라이즈 일정)
- ‘다가오는 챙길 날’은 이번 달 첫 화면에 그대로 둠(→ 화면 설계 › 이번 달)

| 돈 날짜 | 라벨 | 누르면 |
| --- | --- | --- |
| 각자 월급날 | “찬우 월급날” “예빈 월급날” | W-01 월급 플랜 |
| 자산·대출 만기일 | “{항목 이름} 만기”. 배우자 비공개 항목은 표시 안 함 | F-04 항목 상세 |

## 규칙

- 양가 비용 = 이번 회차(결혼기념일 기준 1년) 챙길 날 예산 합계. ‘양가 비용’ 매년 목표로 저축 가능 금액에서 매달 배분, 회차 바뀔 때 남은 돈 이월. 월 적립 계산 → 핵심 규칙 › 계산·배분
- 예비부부: 목표·월 적립 없이 예산만 저장, 결혼일 전환에서 저장된 예산으로 목표 생성 → 핵심 규칙 › 계산·배분
- 예산 변경 = 예빈에게 제안(G-08) → 핵심 규칙 › 부부·제안·권한
- 처음 등록(Y-02): 부모님 4분 미리 생성, 생신·금액만 차례로 질문(약 1분). 묻지 않은 날(어버이날·그 밖의 날) 금액 = 0원, 추천값 자동 입력 없음
- 생활비 통장·카드로 낸 돈 = 목표 사용 + ‘목표자금 → 공동 생활비’ 나누기 줄 → 핵심 규칙 › 계산·배분
- 알림은 담당자(챙길 사람)에게만, 준비 상황·기록 완료는 둘에게 공유. 담당자가 미합류 배우자면 시작한 사람에게 감(→ 화면 설계 › 알림)
- 양가 균형 리포트(데이터 1년 누적 후, 프리미엄) → 제품 개요

예외·오류

- 예비부부: 4번 위에 ‘결혼 준비 일정’ 목록 먼저. 7번은 “양가 비용 예산 288만 원 중 40만 원 썼어요”, 모아둔 돈 없음
- 음력 날: 올해 양력 날짜로 표시, 상세에 음력 함께. 윤달 날짜가 그해 없으면 평달 같은 날, 음력 30일이 없는 달이면 그 달 말일(→ 핵심 규칙 › 데이터 항목 3장)
- 60일 안 챙길 날 없음: 5번 자리 “60일 안에는 챙길 날이 없어요”
- ‘돈 날짜’ 필터에 이번 달 돈 날짜 없음: “이번 달은 돈 날짜가 없어요”
