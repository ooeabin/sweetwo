# 캘린더

## 흐름 요약

캘린더 탭(Y-01 목록, 2026-11-09 맨 위 이번 주 띠 + ‘달력 ›’ → Y-04 달력) → 날 누르면 상세(Y-05) → ‘다녀왔어요’ → 기록(Y-08). 한 달력에 두 가지가 보임: 앱이 자동으로 넣는 금융 일정(월급날, 목표 기한(기한을 정한 저금 항목만), 만기, 월급 전 확인)과 사용자가 직접 넣는 경조사. 경조사는 생일, 기념일, 명절, 양가 행사를 모두 같은 종류로, 같은 방법(Y-07)으로 넣음. 결정 이유 → `docs/adr/0003-replan-goal-checklist.md`.

- 예시값: 찬우(시작한 사람), 예빈(합류한 사람), 오늘 10월 2일, 월급날 25일
- 입력 흐름(Y-07·08)은 본문 위 레이어, 공통 틀(진행 막대 = 흐름 안 화면 수, 닫기 = 입력값 저장)
- 없앤 것: 양가 처음 등록(Y-02), 가족 목록(Y-03), 양가 비용 예산과 매년 목표(Y-06), 양가·우리 둘 구분과 색, 낸 곳 질문과 월급 나누기 줄, 결혼 준비 일정·결제, 파트너 생일 서프라이즈, 단계별 체크리스트, 제안 적용일

## 캘린더 범위

- 캘린더 탭(아이콘 calendar) = 금융 일정과 경조사를 한 달력·목록에서 보는 날짜 화면. 홈 = 한눈에, 월급 = 체크와 저금, 자산 관리 = 현황, 캘린더 = 날짜
- 경조사: 추가·수정·기록 모두 여기서(Y-01\~Y-09). 생일, 결혼기념일, 사귄 날, 명절, 어버이날, 가족 행사(2026-11-13 ‘양가 행사’에서), 그 밖의 날 모두 같은 종류. 따로 보는 화면, 따로 쓰는 색, 분류가 없음
- 금융 일정: 앱이 자동으로 넣고 캘린더에서는 고치지 않음(읽기 전용). 누르면 해당 화면으로 이동(아래 표)
- 보기 필터 칩 “전체” “경조사” “금융 일정” [확인 필요]: 목록·달력 공통, 기본 “전체”, 마지막 선택 기억
- 표시 구분: 경조사 = 영역 색 점 한 가지(together), 금융 일정 = 검정 작은 점 + 작은 라벨
- 홈 캘린더 타일(H-08)에 가장 가까운 경조사 하나와 D-day(2026-11-09, 예전 홈 H-05 일정 최대 3개는 없앰, → 홈)

## 규칙

- 경조사의 금액은 메모일 뿐. 저금 항목, 월급 계획, 체크리스트, 순자산 어디에도 더하거나 빼지 않음 [확인 필요]
- 경조사를 위해 미리 모으고 싶으면 저금 항목을 따로 만듦(예: ‘양가 행사’). 캘린더가 자동으로 저금 항목을 만들거나 빼지 않음(꺼내 쓰기는 2026-11-08 없앰)
- 누가 넣거나 고쳐도 바로 반영 + 상대 알림, 활동 기록(→ 핵심 규칙 › 커플·권한). 상대 화면도 바로 바뀜(Realtime, 2026-11-12 QA 9구간 S9-03). 고친 사람에게 Toast “고쳤어요” [확인 필요] + ‘되돌리기’(6초, 고치기 전 값으로, Y-05 준비 상황·미리 알림·메모·금액 메모, Y-07 수정, S9-04)
- 미리 알림은 두 사람 모두에게 [확인 필요]. 파트너 미합류면 시작한 사람에게만
- 파트너에게 숨기는 경조사(서프라이즈)는 두지 않음. 모든 경조사는 두 사람이 같이 봄 [확인 필요]. 2026-11-12 QA 9구간 D2: 서버도 새 서프라이즈와 21자 넘는 이름을 거절(지금 있는 옛 행은 그대로)

예외·오류

- 경조사가 하나도 없음: 4·5번 자리에 빈 상태(틀 → 공통 › 공통 상태) 그림 자리 + “경조사 추가”(2026-11-11 사용자 결정: 제목 문장 “생일, 기념일, 명절을 적어 두면 미리 알려 드려요”는 없앰) → Y-07(회색 보조 버튼, 2026-11-03). 금융 일정은 그대로 보임
- 음력 날: 올해 양력 날짜로 표시, 상세에 음력 함께. 윤달 날짜가 그해 없으면 평달 같은 날, 음력 30일이 없는 달이면 그 달 말일(→ 핵심 규칙 › 데이터 항목 3장)
- 60일 안 경조사 없음: 5번 자리 “60일 안에는 경조사가 없어요”
- ‘금융 일정’ 필터에 금융 일정 없음(2026-11-12 QA 9구간 D3 = A): Y-01 목록은 5번 자리 “60일 안에는 금융 일정이 없어요” [확인 필요], Y-04 달력은 그 달에 없을 때 “이번 달은 금융 일정이 없어요”(공통 상태 18번)
- 못 불러옴: 본문 자리에 공통 상태 7번 카드 “잠시 문제가 생겼어요” / “다시 시도해 주세요” + ‘다시 시도’(빈 상태를 보이지 않음, 2026-11-12 S9-02)

## Y-07 경조사 추가

모든 경조사를 같은 3화면으로 넣음. 이름 칩은 이름과 날짜, 반복 기본값만 채워 주고 종류를 나누지 않음.

> 화면 그림: Y-07c 날짜 (그림은 기획서 페이지 사본에 있어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 날짜 | 년 / 월 / 일 | Q4. 달력에서 열면 채워짐 |
| 2 | 양력·음력 | “양력” / “음력” | 음력이면 매년 양력 날짜 자동 계산 |
| 3 | 반복 | “매년 돌아와요” 켜기·끄기 [확인 필요] | 기본값은 이름 칩을 따름(아래 표), 직접 쓴 이름은 켜짐 |

예외·오류

- 지난 날짜 입력: “이미 지난 날이에요. 기록으로 남길까요?” → Y-08
- 같은 이름, 같은 날짜가 이미 있음: “같은 날이 있어요. 그래도 추가할까요?” [확인 필요] 한 번 확인(Y-07d ‘추가하기’와 ‘건너뛰기’ 모두, 2026-11-12 S9-09)

## Y-05 경조사 상세

> 화면 그림: Y-05 경조사 상세 (그림은 기획서 페이지 사본에 있어요. 재기획 전 그림이라 구분, 챙길 사람, 명절 할 일 목록은 없앴어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 제목 | 머리 ‘‹ 어머니 생신’, 맨 위 카드는 큰 “D-12”(26px) + “10월 14일”(2026-11-04 카드에서 이름을 뺌) | 음력이면 날짜 뒤 “(음력 8월 3일)”. “수정” → 이름·날짜(Y-07 화면) |
| 2 | 금액 메모 | “30만 원” | 수정 = Q3, 비워 둘 수 있음. 메모일 뿐 계산에 들어가지 않음 |
| 3 | 반복 | “한 번” / “매년” | Y-07 반복 값 |
| 4 | 준비 상황 | 칩 “아직” / “준비 중”, 그날부터는 아래 주 버튼 “다녀왔어요”(2026-11-04 칩에서 뺌: 칩인데 누르면 기록 화면으로 넘어가 헷갈려서) | 다녀왔어요 → Y-08. 그날이 된 경조사는 목록(다음 경조사 카드)·달력(고른 날 목록)에도 ‘다녀왔어요’ |
| 5 | 미리 알림 | 체크 목록 “30일 전” “14일 전” “7일 전” “당일”(2026-11-04 칩에서 바꿈, 줄을 누르면 켜고 끔) [확인 필요] | 기본 D-30 + D-7, 수정 = “D-30” “D-14” “D-7” “당일” 여러 개 선택. D-14·당일은 선택(기본 꺼짐) |
| 6 | 작년에는 | “작년엔 안마기를 드렸어요 (25만 원)” | 지난 회차 기록 있을 때만 |
| 7 | 메모 | 자리표시 “예: 무릎이 안 좋으시다고 하셨음” | 자유 메모, 두 사람이 같이 봄 |
| 8 | 지우기 | ⋯ → “지우기” | 묻지 않고 휴지통으로 + Toast “되돌리기”(→ 설정 S-21) |

예외·오류

- 기록 없이 날짜 7일 경과: 상태 ‘지남’, 4번 자리 “기록하기” → Y-08. 한 번인 날은 기록하면 더는 ‘지남’·‘기록하기’·목록 ‘기록할 날’ 띠에 나오지 않음(2026-11-12 S9-01)
- 못 불러옴: 목록으로 돌아가지 않고 머리 ‘‹’ + 공통 상태 7번 카드 + ‘다시 시도’(2026-11-12 S9-02)
- 같은 항목을 둘이 1분 안에 다르게 수정: 나중 사람에게 선택 화면(충돌 규칙 → 기술·운영 › 동기화)

## Y-09 선물 기록

- 무엇을·언제·얼마 드렸는지 목록, 경조사별·연도별 보기
- 최근 2년 안 같은 경조사에 같은 선물 기록 시 “작년에도 드렸어요”
- 사진은 서버에 암호화 저장, 두 사람만 봄(→ 보안·개인정보)
- 사진이 있는 기록은 행 앞에 첫 사진 미리보기(40px) + 보조 줄 “사진 3장” [확인 필요]

- 기록이 없음: “아직 선물 기록이 없어요” + “경조사에 ‘다녀왔어요’를 누르고 기록하면 여기에 모여요” [확인 필요] (2026-11-04)

## 참고

### 이름 칩 기본값

모두 같은 경조사. 칩은 입력을 줄여 주는 기본값만 정함.

| 칩 | 날짜 | 반복 | 비고 |
| --- | --- | --- | --- |
| 생일 | 직접 입력, 음력 가능 | 매년 | 부모님 생신, 서로의 생일 모두 이 칩 |
| 결혼기념일 | 직접 입력 | 매년 | 설정 S-11h에서 ‘결혼했어요’로 결혼한 날을 넣으면 자동으로 하나 만들어짐(아래 ‘자동으로 만드는 결혼기념일’, 2026-11-10 온보딩 O-12는 없앰). 결혼한 날을 적지 않았으면 여기서 ‘결혼기념일’ 칩으로 직접 넣음 |
| 설날 | 음력 1월 1일 (연휴 함께 표시) | 매년 | 날짜 자동 |
| 추석 | 음력 8월 15일 (연휴 함께 표시) | 매년 | 날짜 자동 |
| 어버이날 | 5월 8일 | 매년 | 날짜 자동 |
| 행사 | 직접 입력 | 한 번 | 결혼식, 돌잔치, 집들이, 가족 모임 등 |
| 사귄 날(2026-11-13) | 직접 입력 | 매년 | 연애 중이에요·같이 살아요에서 맨 앞 [확인 필요] |
| 직접 쓰기 | 직접 입력, 음력 가능 | 매년 | 제사 등 |

- 설날·추석 연휴와 공휴일은 경조사로 넣지 않아도 달력에 공휴일로 보임

### 자동으로 만드는 결혼기념일 [확인 필요]

- 설정 S-11h에서 결혼한 날을 처음 넣을 때(결혼 상태 ‘결혼했어요’) 경조사 하나를 만듦(2026-11-10 온보딩 O-12 없앰): 이름 “결혼기념일”, 날짜 = 결혼한 날(양력), 반복 매년, 금액 메모 없음, 미리 알림은 Y-07 기본값
- 다른 경조사와 같은 종류. 만든 뒤에는 Y-07에서 이름, 날짜, 알림을 고치거나 지울 수 있음. 지운 뒤에 결혼한 날을 바꿔도 다시 만들지 않음
- 이미 있으면 새로 만들지 않음. 설정에서 결혼한 날을 바꾸면 자동으로 만든 경조사의 날짜도 옮김(사용자가 날짜를 직접 고쳤으면 옮기지 않음)
- 준비 중(결혼 예정일)은 만들지 않음. 결혼 상태가 ‘결혼했어요’가 아니게 바뀌면 자동으로 만든 결혼기념일을 지움(사람이 날짜·이름을 고쳤거나 다녀온 기록이 있으면 그대로, 2026-11-10 잘못 고른 ‘결혼했어요’를 바로잡을 때 남지 않게). 다시 ‘결혼했어요’ + 날짜면 새로 만듦. 자동으로 만들 때는 따로 상대 알림을 보내지 않음(설정에서 결혼한 날을 바꾼 알림 하나로 충분)
