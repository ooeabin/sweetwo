# 목표

## 흐름 요약

목표 메뉴 = G-01 목록 → G-02 상세. 추가(G-03a\~f)는 한 화면 한 질문, 배분에 영향을 주는 변경(추가·삭제·금액·기한·순서·보류·다시 모으기·담당)은 저장 시 예빈에게 제안(G-08). 제안 규칙 → 핵심 규칙 › 부부·제안·권한. 템플릿·금액 계산·보유액 계산 → 핵심 규칙 › 계산·배분. 예비부부는 결혼 비용(G-07)이 맨 위.

- 예시값: 찬우(작성자), 예빈(배우자), 저축 가능 82만 원, 기준일 25일

- 열린 제안이 있는 목표: 카드에 “제안 중” 배지 추가, 누르면 G-08

예외·오류

- 매년 목표: 기한 대신 “다음 사용 2027년 8월” / “1회차”, 예상 달성 대신 이월액
- 달성 이후: 숫자 블록 위에 “400만 원 모았어요” + ‘이 돈을 썼나요?’(G-05 사용 기록)

**목표 사진(직접 만든 목표만)**

- 대상: G-03a ‘직접 만들기’로 만든 목표. 기본 목표 21종은 그림 고정, “사진 바꾸기” 없음
- 기본: 회색 기본 그림(디자인 시스템 goal-custom 자리, 회색 바탕 + 디자인 시스템 깃발(flag-pennant, hg-ico--flag-pennant) 아이콘). G-01 카드와 G-02 헤더에 같은 그림
- “사진 바꾸기”: G-02 헤더 그림 아래, 목표 수정에도 같은 동작. 고르기 → 정사각형 자르기(ImageCrop) → 저장
- 올리기 규칙은 프로필 사진(→ 설정 S-11e)과 같음: JPG/PNG/HEIC, 큰 사진은 줄여 저장, 실패 문구도 같음
- “사진 지우기”: 회색 기본 그림으로 돌아감
- 고지 한 줄: “올린 사진은 {배우자}님과 나만 볼 수 있어요”({배우자} = 보는 사람의 배우자 호칭. 예: 찬우가 볼 때 “예빈님과 나만”)
- 두 사람 중 누가 바꿔도 바로 반영(제안 아님). 배우자 활동(ActivityFeed)에 “찬우님이 목표 사진을 바꿨어요”, 알림은 보내지 않음
- 와이어프레임 상태: G-01, G-02, 목표 수정 그림은 기본 목표 기준. 회색 기본 그림과 “사진 바꾸기”는 아직 안 그림

## 목표 수정

> 화면 그림: 목표 수정, 제안 보내기 (그림은 기획서 페이지 사본에 있어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 질문 | 고친 값의 질문 그대로 “언제까지 모을까요?” | 목표 금액 Q3, 기한 Q4, 이름 Q5(바로 저장) |
| 2 | 입력 | 지금 값 채움 | 패턴 규칙 그대로 |
| 3 | 영향 미리보기 | 월 배분, 상태, 기한 전 → 후 | 다른 목표 배분이 바뀌면 그 목표 줄 추가 |
| 4 | 제안하기 | “예빈님께 제안하기” | 배분 결정이면 제안, 미합류·혼자 쓰기는 “저장”(바로 적용). 저축 가능 금액을 넘으면 G-04 |
| 5 | 제안 중 카드 | “제안 중” + “기한 2031년 12월 → 2033년 12월” + “좋아요면 바로, 반대 없으면 10월 25일부터 적용돼요” | G-02 헤더 아래. 예빈 화면은 같은 자리에 좋아요 / 다르게 해볼래요 / 반대 |
| 6 | 보내기 취소·철회 | “보내기 취소” / “철회” | 제안은 확인 없이 바로 보냄. 보내기 취소 = 예빈이 열기 전까지(없던 일로, 알림 없음). 철회 = 연 뒤 적용 전까지 |
| 7 | 숫자 블록 | 지금 값 유지 | 좋아요 또는 적용일에 바뀜 |
| 8 | 목표 사진(직접 만든 목표만) | 회색 기본 그림 또는 올린 사진 + “사진 바꾸기” / “사진 지우기” | 바로 저장(제안 아님). 규칙 → G-02 목표 사진 |
