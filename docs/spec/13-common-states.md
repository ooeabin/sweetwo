# 공통 상태

모든 화면이 함께 쓰는 빈 상태·로딩·오류·오프라인·충돌·업데이트·되돌리기·확인 Modal의 정본 18종. 화면 탭에는 여기와 다른 점만 적음. 알림 문구 → 화면 설계 › 알림.

> 화면 그림: 빈 상태, 목표·자산·챙길 날 없음, 배우자 미합류 (그림은 기획서 페이지 사본에 있어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

> 화면 그림: 로딩·오류, 스켈레톤, 연결 끊김, 서버 오류, 권한 없음 (그림은 기획서 페이지 사본에 있어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

> 화면 그림: 오프라인·충돌·업데이트, 토스트, 충돌 선택, 강제 업데이트, 점검 (그림은 기획서 페이지 사본에 있어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

**빈 상태 규칙**

- 모든 빈 상태(표 1\~4·16\~18, 알림 N-03, 휴지통 S-21, 캘린더 Y-01 등록 전 포함)는 같은 틀: 그림 → 제목 → 보조 문구 → 버튼. 행동을 이끄는 빈 상태 4곳(G-01, F-01·F-02, Y-01 등록 전, H-08)만 보조 문구 1줄, 나머지는 제목 1줄. 버튼이 있어도 ‘없어요’류(부채 없음 등)는 제목 1줄
- 그림은 모두 같은 한 장: 부스러기만 남은 빈 디저트 접시와 포크, 120px
- 화면 탭에는 문구와 버튼만 적음
