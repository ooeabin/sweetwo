# 계산·배분

월 수입에서 용돈과 공동 생활비를 뺀 저축 가능 금액을 우선순위대로 비상금과 목표에 나눔. 계좌 연동 없이 월말에 넣는 합계(지출 항목별 합계, 이번 달 넣은 저축)로 계산. 통장 ‘역할’과 잔액 맞추기는 선택.

## 1. 사실값과 배분 결정

| 구분 | 항목 | 바뀌는 방식 |
| --- | --- | --- |
| 사실값 | 내 수입, 월급날, 고정지출 금액, 자산·부채 금액·잔액 | 언제든 즉시 반영 + 이번 사이클 안 나눈 돈 재계산. 상대에게는 배우자 활동(H-08) + 주 1회 요약, 수입 변경만 즉시 알림. 미합류·혼자 쓰기면 알림 없음 |
| 배분 결정 | 용돈, 분담 방식, 공동 목표 추가·삭제·우선순위·금액·기한·보류·다시 모으기·담당, 기준일, 생활비 예산, 양가 비용 예산, 결혼 비용 예산. 담당 ‘나’ 목표도 공동 저축 가능 금액을 쓰면 포함 | 제안(→ 핵심 규칙 › 부부·제안·권한). 확정·적용되면 안 나눈 돈 재계산 |
| 즉시 적용(제안 아님) | ‘이번 달만 바꾸기’(W-01), 생활비 체크 W-03c ‘내 용돈에서’, ‘비상금 → 공동 생활비’ 보충 줄 | 즉시 적용 + 상대 알림. W-01은 되돌리기 가능 |

- 안 나눈 돈 재계산: 이미 옮긴 줄은 그대로, 그달 분담 비율 어긋남 허용. 차이는 월말 정리 미달·초과로 처리, 다음 사이클은 정상 비율
- 알림 종류·시점·상한 → 화면 설계 › 알림

## 2. 통장 구조

| 통장 | 용도 | 들어가는 돈 |
| --- | --- | --- |
| 공동 생활비 | 주거비·관리비·식비·공과금·대출 상환 | 고정지출 + 생활비 |
| 목표자금 | 목표별 저축·투자가 빠져나가는 통장(양가 비용 포함) | 목표별 월 배분액 합계 |
| 비상금 | 실직·질병 등 예상 못 한 지출에만 사용 | 비상금 목표의 월 배분액 |
| 개인(각자) | 용돈·취미·자기계발 | 각자 용돈 |
| 결혼 준비(예비부부만) | 결혼 비용 모으기·결제 | 결혼 비용 목표의 월 배분액 |

- 통장 역할 나누기는 선택. 온보딩 기본으로 “통장 하나로 써요”도 고를 수 있고, 이때는 역할 없이 금액만 계산. 나누면 공동 통장 3개 + 각자 개인 통장, 공동 생활비와 목표자금은 분리, 비상금 통장은 통합 불가. 역할 나누기는 나중에 권하는 기능
- 결혼 준비 통장은 목표자금 통장과 별개 역할
- 실제 계좌 연결 없음. 통장마다 자산 항목 1개와 연결, 월말 정리에서 입력한 잔액 = 자산 금액
- 시작 잔액: 결과 화면(O-63)에서 통장별 지금 잔액을 한 화면 목록으로 받음 = 첫 월말 정리 기준선. 생활비 통장은 “쓰던 통장이 있어요”(이름 + 지금 잔액) / “새로 만들 거예요”(0원). 입력한 통장은 첫 주 자산 입력 때 자산 목록에 자동 포함
- O-63에서 잔액 표를 건너뛰면 기준선 없이 시작, 첫 W-04k부터 납입액을 쌓음
- 통장 하나 모드: 나누기 줄 없음. 생활비 카드로 쓴 목표 돈은 W-04j 큰 지출(연간 목표에서 꺼내 쓰기), 비상금 보충은 정산 요약의 설명 한 줄로 처리. 통장 방식은 설정 S-10a에서 바꾸고 다음 사이클부터 적용

## 3. 월 수입과 저축 가능 금액

- 월 수입 = 두 사람 월 실수령 + 매달 부수입(월세·임대 등). 연간 이벤트 소득·이자·배당·매도 대금 제외
- 변동 수입자(프리랜서·사업자·부업) = 기준 수입 사용. 온보딩 ‘가장 적게 번 달’로 시작, 월말 정리 기록 6개월 쌓이면 ‘최근 6개월 중 낮은 3개월 평균’으로 갱신 제안(월말 정리 W-04a2 뒤 카드로만 표시, 알림 없음)
- 기간을 정한 수입 변경(휴직 등)이 있으면 그 기간엔 변경 금액 사용
- 고정지출에 대출 월 상환액(O-39) 포함
- 저축 가능 금액 = 월 수입 − 용돈 합계 − 고정지출 − 생활비 예산. 양가 비용은 ‘양가 비용’ 매년 목표로 배분
- 생활비 예산: 온보딩 추정치로 시작. 월말 정리 최근 3개월 실제 평균과 10% 넘게 차이 나면 보정 제안(월말 정리 W-04g 정산 요약 아래 보정 제안 카드 1장으로 기본 표시, 알림 없음, 늦게 정리한 달 제외, 생활비 체크 결과는 쓰지 않음, 큰 지출로 적은 돈은 모두 뺌)
- 생활비 실제(기본) = 월말 정리 W-04j에서 직접 넣은 변동 항목별 합계(큰 지출 제외). 잔액에서 거꾸로 계산하는 값은 꼼꼼 모드에서 잔액을 넣었을 때만 보조로 씀: 생활비 통장 입금액(‘목표자금 → 공동 생활비’ 나누기 줄 제외) − 고정지출 − 잔액 변화 − 생활비 통장·카드로 낸 목표 사용액 중 나누기 줄로 옮긴 금액. 따로 묻지 않음. 늦게 정리한 달은 계산 제외. 신용카드 주사용자(O-38b)는 ‘지난달 카드 사용분’ 라벨
- 이번 달 남은 생활비 = 생활비 예산 − 이번 달 변동 항목 입력 합계(고정, 큰 지출 제외). 음수면 홈 인사는 “생활비를 n만 원 넘게 썼어요”, 타일과 위젯 값은 “n만 원 넘었어요”. 예산이 0이면 % 숨김

## 4. 배분

1. 월 수입에서 용돈을 먼저 뺌
2. 공동 생활비 = 고정지출 + 생활비 예산
3. 남는 돈(저축 가능 금액)을 우선순위 순서대로 각 목표의 월 필요액만큼 배분
4. 각자 나눌 금액 = 공동자금 합계 × 분담 비율

- 기본 우선순위: 비상금 → 고금리 대출 → 결혼 비용(예비부부) → 사용자가 고른 순서. 숫자가 낮을수록 먼저
- 고금리 대출 = 연 8% 이상. 금리를 모르는 부채는 대출 유형별 평균 금리로 판단(어드민 설정값, 분기마다 갱신. 초기값 주택담보 4%·전세 4%·신용 6%·학자금 2%·카드론·현금서비스 15%)
- 비상금 충당률 50% 미만이면 비상금 1순위 고정
- 월 필요액·월 배분액은 1만 원 단위 올림(양가 비용 월 적립만 1천 원 단위 올림). 저축 가능 금액이 모자라면 마지막 순위 목표가 남은 금액만 받음
- 모든 목표를 채우고 남는 돈은 사용자가 고른 목표에 추가(기본: 주거 목표, 주거 목표가 없으면 1순위 목표). 설정 S-11 ‘남는 돈 넣을 목표’에서 변경, 배분 결정이라 제안
- 직접 조정(목표 › G-04): 손으로 정한 목표별 월 배분액은 고정값으로 저장, 다음 사이클에도 유지. 자동 배분은 고정값을 뺀 남은 금액만 우선순위대로 나눔. “자동으로 되돌리기”로 고정값 해제. 배분 결정이라 배우자와 연결된 상태면 제안
- 분담액: 반반 = ÷ 2 / 버는 만큼 = 각자 실수령 비율 / 직접 = 입력 비율. 1만 원 단위 반올림, 끝전 차이는 수입 많은 쪽. 두 사람 나눌 금액 합계가 공동자금 합계보다 적으면 모자란 만큼 수입 많은 쪽에 더함(배분은 필요액 이상)
- 두 사람 다 수입 0원: 분담 50:50, 안내 “수입이 들어오면 다시 계산해요”. 한쪽만 0원이면 고른 분담 방식 그대로
- 부족 상태(목표 월 필요액 합계 > 저축 가능 금액): 세 가지 안 제시, 적용은 제안
  - 기한 연장: 우선순위 낮은 목표부터 기한 늘리기
  - 금액 조정: 목표 금액 낮추기(양가 비용 포함)
  - 지출 줄이기: 생활비 예산·내 용돈 중 줄일 항목과 금액(상대 용돈은 대상 아님)

예시: 월 실수령 600만 원 부부

| 구분 | 금액 | 세부 |
| --- | --- | --- |
| 용돈 | 100만 원 | 각자 50만 원 |
| 공동 생활비 | 300만 원 | 고정지출·생활비 |
| 목표자금 | 150만 원 | 집 마련 100, 자녀 20, 노후 20, 여행 10 |
| 비상금 | 50만 원 | 목표 도달 후 목표자금으로 전환 제안 |

## 5. 목표

### 5-1. 템플릿

8개 분류(기본·갚기·주거·가족·즐거움·생활·미래·결혼), 21개 템플릿 + ‘직접 만들기’. 비상금·결혼 비용·양가 비용은 자동 생성이라 목표 추가(G-03a)에서 빠지고 분류 탭은 6개 + 맨 앞 ‘자주 고르는’ 탭(O-21 탭 7개). 같은 템플릿 여러 개 가능.

- 노후·연금은 중도 해지 손실을 막도록 납입액을 조절할 수 있는 소액으로 시작하게 안내

### 5-2. 형태

| 형태 | 규칙 |
| --- | --- |
| 한 번 | 달성 후 사용 확인 시 종료(사용 완료) |
| 매년 | 매년 같은 때 쓰는 돈을 나눠 모으는 반복 목표. 월 필요액 = (연간 금액 − 이월액) ÷ 다음 사용 월까지 남은 개월. 사용 월 월말 정리 W-04j 큰 지출 질문(‘연간 목표에서 꺼내 쓰기’)에서 사용 기록, 남은 돈은 다음 회차로 이월해 자동 재시작(회차 +1), 내년 금액 변경 여부 1회 질문(공동 목표면 제안). 나가는 연간 지출은 모두 매년 목표로 안내(연간 이벤트 W-07은 들어오는 돈 전용) |
| 매달 | 노후·아이 교육. 금액 목표 없이 월 납입액 그대로 배분, 누적액만 표시. 달성·지연 상태 없음 |

### 5-3. 계산식

- 부족액 = 목표 금액 − 보유액
- 월 필요액 = (목표 금액 − 보유액 − 기한 내 연간 이벤트 소득 배정액) ÷ 남은 개월(이번 달 포함), 1만 원 단위 올림
- 연 마일스톤 = 연도별 누적 목표액(월 필요액 × 경과 개월 + 현재 보유액)
- 예상 달성일 = 남은 금액 ÷ 현재 월 배분액을 올림한 개월 수 뒤의 달. 배분액 0이면 ‘미정’
- 수익률 기본 0%. 수익률 시뮬레이션 = 보유액과 월 배분액에 연 수익률 가정(월 복리)을 적용한 예상 달성일. 고를 수 있는 연 수익률 0\~10%, 기본 4%. 목표 화면의 프리미엄 기능, 유료화 시점부터(→ 화면 설계 › 목표 G-02)
- 기한 미입력 = 템플릿 기본 기한. 기본 기한 없는 목표에서 O-24 ‘잘 모르겠어요’ = 3년 뒤 + ‘추정’ + 할 일 등록
- O-18 출산 준비 기한: 1년 안 = 올해+1 / 1\~3년 = 올해+2 / 3년 뒤 = 올해+4 / 아직 모르겠어요 = 올해+3(‘추정’)

### 5-4. 보유액

- 보유액 = 연결 자산 금액(원금 기준, 원금 없으면 평가금액, 잔액을 안 맞춘 달은 아래 납입 추정 포함) + 목표자금 통장 중 이 목표 몫 + 기타 보유액(연결 자산 없는 돈만 직접 입력). 0 하한, 직접 수정 불가
- 이 목표 몫 = 이 목표로 나눈 누적액 − 이 목표에서 쓴 돈(목표 사용 기록). 잔액을 맞추지 않는 사람은 나눈 누적액 대신 W-04k 납입액 누적(7장)
- 통장 잔액과 몫의 합이 다르면 월말 정리에서 설명 안 된 차액만 어느 목표에서 썼는지 한 번 확인(달성한 목표도 선택지). 이자 등 작은 차이와 ‘목표에서 쓴 돈이 아니에요’는 나눈 비율대로 전 목표 몫에 배분
- 잔액 없는 달: W-04k 납입액을 연결 자산 금액에 더하고 ‘추정’으로 표시, 잔액을 맞추면 그 값으로 바꿈. 납입이 연결된 자산이 목표에 묶여 있으면 그 목표로 감(saving\_deposit.goal\_id). 목표 보유액, G-02 월별 막대, 달성 판정, 순자산 모두 이 규칙
- 목표자금 통장에서 연결 자산(적금·투자 등)으로 빠지는 월 납입액은 ‘통장 → 자산 이동’으로 예상 잔액에 미리 반영, 목표 사용으로 보지 않음

### 5-5. 상태

| 상태 | 조건 |
| --- | --- |
| 진행 중 | 예상 달성일 ≤ 기한 |
| 지연 | 예상 달성일 > 기한, 또는 2개월 연속 배분 미달(쉰 달 제외) |
| 달성 | 보유액 ≥ 목표 금액 → 달성 시점(연결 자산 금액을 고친 직후, 월말 정리 반영 직후 등)에 바로 축하 화면(G-05), 월 배분액을 다음 목표로 넘기기 제안. 이어서 “이 돈을 썼나요?” 아직이에요 / 썼어요(금액·낸 곳) / 다른 자산으로 옮겼어요. ‘아직이에요’면 달성 유지 |
| 사용 완료 | 달성 후 ‘썼어요’ 또는 ‘다른 자산으로 옮겼어요’. 남은 보유액은 자동으로 비상금 이동(자산 간 이동), ‘다른 목표로’ 선택 가능 |
| 마무리 중 | 결혼 비용 전용. 예식 후 남은 결제가 있을 때 |
| 보류 | 사용자가 직접 일시 중지, 배분에서 제외 |

- 매달 목표는 상태 없음. ‘결혼 후 목표’는 상태가 아닌 플래그(예비부부 각자 관리: 저장만, 배분 없음). 결혼일 전환 때 플래그를 풀고 진행 중으로 배분 시작

## 6. 목표 사용과 나누기 줄

낸 곳은 기록할 때 한 번만 정함: 챙길 날 기록(Y-08), 결혼 비용 ‘결제했어요’(G-07), 매년 목표 사용, 달성 후 ‘썼어요’(G-05). 월말 정리 W-04c는 기록 확인 + 설명 안 된 차액만 1질문. 매년 목표에서 꺼내 쓴 돈은 W-04j 큰 지출 질문이 맡고, W-04c는 달 중에 남긴 기록만 확인.

| 낸 곳 | 처리 |
| --- | --- |
| 목표자금 통장 | 그 목표 사용, 그 목표 보유액에서만 차감 |
| 생활비 통장·카드 | 그 목표 사용으로 즉시 차감 + ‘목표자금 → 공동 생활비 {금액}’ 나누기 줄 자동 추가 |
| 각자 돈 | 기록만 |
| 결혼 준비 통장 (예비부부) | 결혼 비용 사용, 그 목표 보유액에서만 차감 |
| 각자 돈·양가 지원 (예비부부) | 기록만 |

- ‘목표자금 → 공동 생활비’ 줄: 기록 즉시 이번 사이클 W-02에 추가(이번 사이클 월말 정리를 이미 마쳤으면 다음 사이클). 담당 = 기록한 사람. 자산 간 이동이라 실제 저축액·미달 계산에서 제외, 아직 안 옮긴 줄은 W-04b 예상 잔액·몫 대조에서 제외
- ‘비상금 → 공동 생활비’ 줄: 담당 = 같이(분담 비율), 비상금 잔액 한도. 변동 수입 부족(다음 사이클)·기간 수입 변경(저장 즉시 그 기간 플랜마다)에서 생김
- 사용액 > 보유액이어도 추가 질문 없음. 목표자금 통장(예비부부는 결혼 준비 통장) → 보유액 0에서 멈추고 넘친 금액은 W-04c(예비부부 H-P7) 차액 1질문에서 확인 / 생활비 통장·카드 → 보유액만큼만 나누기 줄, 넘친 금액은 생활비 실제에 포함 / 비상금에서 꺼냄 → W-04d가 비상금 잔액 감소로 감지
- 쓴 돈은 그 목표에서만 차감, 다른 목표 보유액은 그대로
- 서프라이즈 항목 지출은 ‘각자 돈’만
- 사용 월 = 사용 날짜가 속한 사이클
- 챙길 날 Y-08 기록은 W-04j 경조사·선물 항목에 미리 채우는 값으로만 쓰고, 쓴 돈에 따로 더하지 않음
- W-04j에서 연간 목표에서 꺼낸 큰 지출을 생활비 통장·카드로 냈으면 역할 모드에서는 위 ‘목표자금 → 공동 생활비’ 나누기 줄이 생김(통장 하나 모드는 줄 없음, 2장)

## 7. 실제 저축액과 미달·초과

- 자산 간 이동 = 만기금 이동, 매도 대금(‘팔았어요’), ‘목표자금·비상금 → 공동 생활비’ 줄, 사용 완료 뒤 비상금 이동. 실제 저축액·월 수입에서 제외
- 실제 저축액(기본) = W-04k에서 확인한 ‘이번 달 넣은 돈’ 합계, 자산 간 이동 제외. “더 꼼꼼히 정리하기”로 잔액을 맞춘 달은 통장별 (이번 정리 잔액 − 지난 정리 잔액)으로 대조. 잔액을 맞추지 않는 사람은 목표 진행률, 저축률 진단, F-08 비교를 W-04k 납입액을 쌓아서 계산하고, 잔액을 맞추면(W-04b, 분기 권유) 그 값으로 다시 맞춤. 생활비 통장은 남은 돈을 이월액으로 봄. 첫 정리는 O-63 기준선 대비

  **월 정산 요약**(월말 정리 W-04g 맨 위, 우리 자산 F-01, 무료)
  - 소득 = 그달 실제 받은 금액(W-04j에서 확인, 기본값은 월급 플랜 수입) + 들어온 돈(상여금, 다른 수입). 첫 사이클을 합칠 때도 실제 받은 금액만
  - 쓴 돈 = 고정지출 + 변동 항목 합계 + 용돈(각자 용돈은 한 줄씩) + 이번 달 큰 지출. 변동 항목은 공동 생활비(통장 하나 모드면 그 통장)에서 낸 돈만 적고, 각자 용돈으로 쓴 건 따로 적지 않음. 개인 부담 고정지출은 용돈 쪽에만. 큰 지출은 변동 항목 합계에 넣지 않고 ‘큰 지출’ 한 줄로, 연간 목표에서 꺼낸 것은 ‘연간 목표에서’로 표시
  - 저축 = W-04k의 이번 달 넣은 돈. 내 자산끼리 옮긴 돈(목표자금 통장 → 적금 등)은 W-04k에 적지 않음. W-04k 목록은 목표와 저축 상품 기준
  - 남은 돈 = 소득 − 쓴 돈 − 저축. 화면에는 저축과 남은 돈을 따로 보여 줌
  - 사용 비율 = 쓴 돈 ÷ 소득, 소수 첫째 자리. “소득의 59.3%를 썼어요”. 소득이 0이면 비율 대신 “소득을 넣으면 비율을 보여 드려요”
  - 지난달 대비 = 항목별 (이번 달 − 지난달), 1만 원 단위 반올림. 지난달 값이 없는 항목은 표시 없음
  - 배우자 미합류면 내 돈만 셈: “예빈님이 합류하기 전이라 찬우님 돈만 셌어요”
  - 예비부부도 같은 계산(W-04j, W-04k, W-04g), 문구는 결혼 자금 기준
- 수입 부족(변동 수입·기간 수입 변경)으로 생긴 차이와 쉰 달은 미달 판정에서 제외

| 상황 | 판정 | 처리 |
| --- | --- | --- |
| 미달 | W-04k 납입액 < 월급 플랜 계획 배분액(꼼꼼 모드로 잔액을 맞춘 달은 통장별 잔액 증가로 대조) | 부족분을 다음 3개월에 나눠 넣기 / 해당 목표 기한 연장 / ‘이번 달만 넘어가기’ |
| 초과 | W-04k 납입액 > 월급 플랜 계획 배분액(꼼꼼 모드로 잔액을 맞춘 달은 잔액 증가로 대조, 공동 생활비 통장에 남은 돈 포함) | 우선순위 높은 목표에 추가 배분 |
| 비상금 사용 | 비상금 잔액 감소 (W-04d) | 사유 기록, 다음 달부터 비상금 채우기를 1순위로 |
| 목표에서 쓴 돈 | 목표 사용 기록, 또는 목표자금·결혼 준비 통장 잔액에 설명 안 된 차액 | W-04c에서 기록 확인 + 차액만 1질문(달성한 목표·‘목표에서 쓴 돈이 아니에요’ 포함) |
| 비정기 소득 | 등록된 상여금·환급금 달 (연간 이벤트 W-07) | ‘추가 소득 나누기’: 목표 추가 배분과 용돈 보너스 비율 선택 |
| 변동 수입 차이 | W-04a2 실제 수입 ≠ 기준 수입 | 초과분 → 추가 소득 나누기 / 부족(0원 포함) → 항상 차액을 다음 사이클 ‘비상금 → 공동 생활비’ 줄로 보충, 즉시 적용 + 상대 알림 |

- 문구는 비난 대신 ‘회복 플랜’으로 표현

## 8. 순자산·재정 진단

- 순자산 = 자산 합계 − 부채 합계, 원금 기준(원금 없으면 평가금액). 예상 순자산 = 평가금액 기준, 차이 = 안 판 수익(손실이면 “−”, 표시만, 월급 플랜·목표 보유액·재정 진단 계산 제외). 배우자 화면은 비공개 항목 제외, ‘합계만’ 항목은 합계에 포함
- 평가 손익 = 평가금액 − 원금(% = ÷ 원금), 원금 있는 투자·부동산만
- 팔았어요: 받은 금액을 고른 통장 자산에 더함(자산 간 이동). 전부 매도 = 상태 ‘매도 완료’(목록에서 빠짐, 이력 유지) + 실현 손익 = 받은 금액 − 원금. 일부 매도 = 받은 금액 + 남은 평가금액 입력, 원금은 판 비율(받은 금액 ÷ (받은 금액 + 남은 평가금액))만큼 줄이고 그만큼 실현 손익 기록. 원금 없으면 실현 손익 없음
- 평가금액·시세는 자산 화면(F-04)에서 언제든 수정. 월말 정리 때 투자 평가액 분기 1회, 부동산 시세 6개월마다 리마인더(건너뛰기 가능)

| 지표 | 계산 | 양호 | 주의 | 위험 |
| --- | --- | --- | --- | --- |
| 저축률 | W-04k 저축 ÷ 소득(그달 실제, 7장 월 정산 요약과 같음) | 20% 이상 | 10\~20% | 10% 미만 |
| 비상금(몇 개월 생활) | 비상금 통장 잔액 ÷ 비상금 기준. ‘몇 개월 생활’ = 잔액 ÷ (고정지출 + 생활비 예산) | 100% 이상 | 50\~100% | 50% 미만 |
| 대출 상환 부담 | 월 원리금 합계 ÷ 월 수입 | 20% 이하 | 20\~35% | 35% 초과 |
| 고정지출 비율 | 고정지출 ÷ 월 수입 | 50% 이하 | 50\~60% | 60% 초과 |
| 투자 원칙 합의 | 공동자금 투자 허용 범위 설정 여부 | 둘 다 동의 | 한 명만 입력 | 미설정 |

- 비상금 기준 = (고정지출 + 생활비 예산) × 기준 개월. 둘 다 정규직이면 3, 한 명이라도 계약직·프리랜서·사업자·쉬는 중이면 6. 설정 S-11 ‘비상금 기준’에서 3 / 6을 직접 고르면 그 값(배분 결정이라 제안). 충당률·‘몇 개월 생활’ 모두 이 기준
- 진단은 ‘비공개’ 항목 제외 후 계산, 리포트에 그 사실 표시. 순자산·비율 지표는 원금 기준
- 투자 비중 = 투자 자산 합계 ÷ 총자산(부채를 빼기 전). 투자 원칙 허용 비중(→ 핵심 규칙 › 데이터 항목 6-7)과 비교
- 분기마다 진단 전체 재계산, 변경 사항 안내

## 9. 계획 다시 세우기 (F-07)

- 결혼 3년마다, 또는 이사·출산·이직·소득 20% 이상 변동 시 제안(이번 달 할 일 카드로만 표시, 알림 없음). 바뀐 부분만 다시 묻는 기본 흐름은 무료, 여러 안 비교 시뮬레이션은 프리미엄
- 기간을 정한 수입 변경(휴직 등): 폭과 무관하게 바로 F-07 비교·적용. ‘변경 후’에 그 기간 비상금 보충안 포함(보충액 = 월 수입 감소분 전액, 비상금 잔액 한도), 그 기간 플랜에 ‘비상금 → 공동 생활비’ 줄로 표시. 보충 줄은 사실값처럼 저장 즉시 반영(제안 아님) + 수입 변경 즉시 알림. 동시에 그 기간 분담을 ‘버는 만큼’으로 바꾸는 제안 자동 표시(일반 제안 규칙)
- 주거가 안정되면 용돈 비중 확대안 제안

## 10. 양가 비용

- 사용일이 여러 번인 매년 목표, 목표자금 통장에서 모음
- 회차 = 결혼기념일 기준 1년 하나로 통일. 표시 예 “이번 회차 288만 원 중 150만 원 썼어요”
- 목표 금액 = 이번 회차 챙길 날 예산 합계(자동, 챙길 날에서만 수정)
- 월 적립 = (회차 예산 − 이미 쓴 돈 − 모아둔 돈) ÷ 회차 남은 개월, 1천 원 단위 올림. 회차가 바뀌면 남은 돈 이월
- 예산 기본값: 앱이 금액을 제시하지 않고 부부가 정함. 다음 회차부터 지난 회차 실제 지출을 기본값으로 제안
- 예비부부: 챙길 날 예산은 저장만, 목표는 결혼일 전환에서 생성

## 11. 예비부부

| 구분 | 각자 관리 | 지금부터 합쳐서 |
| --- | --- | --- |
| 배분 목표 | 결혼 비용 하나. 비상금 목표 없음 | 신혼과 같음(비상금 포함) + 결혼 비용 |
| 다른 목표 | ‘결혼 후 목표’로 저장만(배분 없음), 결혼일 전환에서 생성·배분 시작 | 바로 배분 |
| 공동 고정지출 등(O-36\~39) | 온보딩에서 건너뜀 → 결혼일 전환 H-T5에서 질문 | 온보딩에서 질문 |

- 각자 관리 예비부부의 통장 = 결혼 준비 통장 1개 + 각자 매달 넣을 금액. 각자 금액은 결혼 비용 분담 방식(반반 / 버는 만큼 / 직접)대로
- 결혼 비용 월 필요액 = (총예산 − 양가 지원 − 모아둔 돈 − 각자 직접 낼 항목) ÷ 예식일까지 남은 개월
- 부족액(H-P4·G-07) = 위 분자 − 예식 전까지 남은 모으기 계획액(계획대로 모으면 0). 양가 지원 + 모아둔 돈 ≥ 총예산이면 월 필요액 0(H-P3 숨김, “여유 {n}만 원”), 목표 상태는 그대로
- ‘누가 내나요’(G-07d)는 계획으로만 씀(부족액·월별 막대). 실제는 ‘결제했어요’의 낸 곳
- 각자 가진 다른 돈(개인 예금 등)은 우리 자산 메뉴에 기록만, 배분에는 넣지 않음
- 양가 지원 ‘아직 몰라요’(O-19b) = 0원 + ‘추정’ + 할 일 ‘양가 지원 금액 알려주기’
- 예식일 미정(예정 연·월만) = 기한은 예정 월 말일 + ‘추정’ + 할 일 ‘예식일 정하기’. 확정·변경 시 결혼 비용 기한과 챙길 날 알림도 이동
- 예식 30일 이내 결혼 비용 예산 변경 예외 → 핵심 규칙 › 부부·제안·권한 6-6
- 결혼일 전환 때: 비상금 목표·결혼 후 목표·양가 비용 매년 목표(저장된 챙길 날 예산으로) 생성, 배분 시작. 전환 플랜(H-T6)이 그 사이클 예비 플랜을 대체, 이미 체크한 나누기는 승계·안 나눈 돈만 재계산
- 결혼 비용 마감: 전환(H-T2) 때 남은 결제가 있으면 ‘마무리 중’, 마지막 결제 기록 때 ‘달성’(없으면 바로 ‘달성’). 결혼 준비 통장에 남은 몫은 비상금 / 주거 목표 / 다른 목표 중 선택. 결혼 후 남은 목돈은 자산 ‘결혼 후 남은 목돈’으로 저장
- 전환 시점·상태 → 핵심 규칙 › 부부·제안·권한

## 12. 비슷한 부부와 비교 (출시 후, MVP 밖)

비슷한 부부 그룹 안에서 우리 위치를 10% 구간으로 보여 주는 무료 기능. 이 장이 정본. 화면은 → 화면 설계 › 우리 자산 F-08, 동의는 → 보안·개인정보 5-1, 저장은 → 기술·운영 2장, 이벤트는 → 성공 지표.

### 12-1. 비교 단위와 그룹

- 비교 단위는 부부. 배우자 미합류 부부, 혼자 쓰기 부부는 제외(F-08 진입 줄도 숨김). 결혼 3년이 넘은 가입자는 단계 ‘이후’로 포함
- 기본 그룹 = 연령대 × 결혼 단계
- 연령대: 두 사람 출생연도(O-13, O-14)로 계산한 평균 나이, 5세 단위. 20대 후반(25\~29, 24세 이하 포함), 30대 초반(30\~34), 30대 후반(35\~39), 40대 이상
- 결혼 단계: 기존 4단계(예비, 신혼 첫해, 2\~3년차, 이후) → 부부·제안·권한 8장
- 더 좁혀 보기(선택 필터, 한 번에 여러 개 가능)
  - 사는 집(O-15): 전세, 반전세·월세, 자가, 부모님 집, 아직 안 구했어요
  - 맞벌이 여부: 두 사람 고용 형태가 모두 ‘쉬는 중’이 아니고 월 실수령이 모두 0보다 크면 맞벌이
  - 월 수입 구간: 두 사람 월 실수령 합계, O-33 칩과 같은 구간(200 미만 / 200\~300 / 300\~400 / 400\~500 / 500 이상, 만 원)

### 12-2. 지표

| 지표 | 계산 | 기준 |
| --- | --- | --- |
| 순자산 | 자산 합계 − 부채 합계, 원금 기준 | 8장과 같음 |
| 월 저축률 | W-04k 저축 ÷ 소득(그달 실제, 8장과 같음) | 최근 정리한 달 기준(7장) |
| 월 저축액 | 실제 저축액 | 최근 정리한 달 기준(7장) |
| 비상금 개월 수 | 비상금 통장 잔액 ÷ (고정지출 + 생활비 예산) | 8장 ‘몇 개월 생활’과 같음 |
| 부채 비율 | 부채 합계 ÷ 자산 합계 | 자산 0원이면 계산 안 함 |

- ‘비공개’ 항목은 제외, ‘합계만’ 항목은 합계로 포함
- 월말 정리를 한 번도 안 한 부부는 저축률, 저축액에서 제외

### 12-3. 표시

- 정확한 순위 없이 10% 단위 구간만 표시
- 그룹 분포 그림 위에 우리 위치 점과 그룹 중앙값 선
- 상위 50% 안: “비슷한 부부 가운데 상위 30% 안이에요”
- 중앙 아래: 사실만 순하게. “중간보다 조금 아래예요”, “아직 시작 단계예요”
- 압박·죄책감 문구 금지(→ 브랜드 1장, 공통 6장). 배우자끼리, 양가는 비교하지 않음
- 부채 비율은 낮을수록 위로 셈

### 12-4. 안전장치

- 그룹당 100쌍 이상일 때만 표시
- 모자라면 넓은 그룹으로 합침: 필터 그룹 → 연령대 × 결혼 단계 → 연령대만 → 전체. 화면에 실제 그룹 표시. 전체도 100쌍 미만이면 ‘그룹 부족’ 상태: 그림 대신 “비슷한 부부가 더 모이면 보여 드려요”, 단계별로는 2단계에서 모자란 그룹은 1단계 공공 통계 표시로 되돌리고, 공공 통계에도 없는 지표만 ‘그룹 부족’
- 지표마다 위아래 끝 1% 제외 후 계산
- 월 1회 배치 계산(pg\_cron, 기준일 작업과 겹치지 않는 시간). 결과는 그룹별 백분위 표만 저장, 개별 부부 값은 통계 테이블에 넣지 않음

### 12-5. 참여

- 선택 동의 ‘통계 참여’: 내 데이터를 이름 없이 통계에 넣기
- 두 사람 모두 동의해야 부부가 통계에 들어감. ‘참여한 부부만 비교를 볼 수 있음’은 2단계(앱 데이터)부터. 1단계 공공 통계 비교는 동의 없이 볼 수 있음
- 언제든 끌 수 있음(설정 S-18). 끄면 다음 계산부터 빠짐
- 법률 검토 필요: 신용정보·민감정보 해당 여부와 함께 → 보안·개인정보 5-4

### 12-6. 시작 순서

1. 1단계(정식 출시 뒤): 공공 통계로 먼저 표시. 통계청 가계금융복지조사의 가구주 연령대별 수치(10세 구간), 화면에 “공공 통계 기준” 표시. 1단계는 연령대(10세 구간)만 비교, 결혼 단계 그룹과 필터는 2단계부터. 공공 통계에 없는 지표는 숨김
2. 2단계: 그룹별 100쌍이 모이면 앱 데이터로 전환, 모자란 그룹은 1단계 표시 유지

- 공공 통계는 해마다 갱신, 어드민 계산 설정값(AD-19)에서 입력
