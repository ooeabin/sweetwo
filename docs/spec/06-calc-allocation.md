# 계산·배분

월급을 월급 분배표대로 나누고, 체크한 저금이 목표의 모은 돈에 쌓이는 계산의 정본. 앱은 돈을 옮기지 않고, 얼마를 썼는지 묻지 않음. 화면 → 온보딩 ② O-50, 월급 체크리스트(W-01·W-02·W-05), 목표, 우리 자산. 시점 → 핵심 규칙 › 월 사이클. 결정 이유 → `docs/adr/0003-replan-goal-checklist.md`.

- 예시: 찬우 실수령 350만 원, 월급날 25일, 관리 방식 ‘각자’, 오늘 2026년 10월. 1순위 내 집 마련(목표 1억 5,000만 원, 기한 2031년 10월), 2순위 여행(금액 미정). 온보딩 ② 예시와 같음

## 1. 금액 단위와 반올림

- 모든 금액은 원 단위 정수로 저장하고 계산. 부동소수점 금지
- 입력 최대 999억 원(99,999,999,999원). 합계가 넘으면 “999억+”, 음수는 “−” 붙여 표시(→ 화면 설계 › 공통 6장)
- 반올림·올림

| 값 | 단위 | 방식 |
| --- | --- | --- |
| 분배표 추천값(고정지출, 생활비, 용돈, 비상금 목표 금액, 저금 줄) | 1만 원 | 반올림 |
| 목표 월 필요액 | 1만 원 | 올림 |
| 분배표 줄 금액(사용자 입력) | 1만 원 | 입력 단위가 1만 원(O-50 6번). 0원 가능 |
| 예상 달성 개월 수 | 1개월 | 올림 |
| 남는 돈, 모은 돈, 순자산 | 1원 | 계산 그대로(화면 표시는 만 원 단위 포맷) |

- 반올림은 마지막에 한 번. 비상금 목표 금액처럼 다른 추천값에서 나오는 값은 반올림한 고정지출·생활비로 계산
- 표시 형식(“350만 원”, “1억 5,000만 원”)은 core 포맷 함수로만

## 2. 수입

- 수입 = 분배표 맨 위 수입 줄. 월 실수령(세금 떼고 통장에 들어오는 돈)만. 상여금, 이자·배당, 부수입은 넣지 않음 [확인 필요]
- 관리 방식별 수입

| 관리 방식 | 분배표 | 수입 |
| --- | --- | --- |
| 각자 | 사람마다 하나 | 그 사람 실수령 |
| 합쳐서 | 부부 공간에 하나 | 두 사람 실수령 합 |
| 배우자 합류 전(어느 방식이든) | 내 것 하나 | 내 실수령 |

- 합쳐서: 배우자가 합류해 실수령을 넣으면 공동 분배표 수입이 바로 두 사람 합으로 바뀜. 배우자 용돈 줄이 더해지고 남는 돈이 다시 계산됨(이번 사이클 처리 → 핵심 규칙 › 월 사이클 3장)
- 매달 금액이 달라요(프리랜서·사업자, O-31 3번): 가장 적게 들어온 달 금액을 실수령으로 적음. 앱이 평균을 내거나 기준을 바꾸자고 하지 않음. 더 들어온 달의 돈은 목표 상세 ‘넣기’로 직접 넣을 수 있음 [확인 필요]
- 월급이 없음(‘지금은 월급이 없어요’): 수입 0원, 월급날 없음. 추천값은 모두 0원

## 3. 월급 분배표

### 3-1. 줄 종류

| 종류 | 줄 | 체크하면 |
| --- | --- | --- |
| 저금 | 목표마다 1줄(비상금 포함). 순서 비상금 → 우리 목표 → 내 목표, 묶음 안은 우선순위 순 [확인 필요] | 그 금액이 연결된 목표의 모은 돈에 더해짐(4-2) |
| 쓰는 돈 | 고정지출, 생활비, 용돈(합쳐서면 사람마다 1줄), 직접 추가한 줄(최대 10줄) | 체크만. 얼마를 썼는지 묻지 않고 계산에 안 씀 |
| 남는 돈 | 자동 1줄 | 체크 없음 |

- 고정지출 = 월세·관리비·보험·통신·대출 상환처럼 매달 정해진 돈, 생활비 = 식비·장보기처럼 쓰는 대로 나가는 돈. 항목별로 나눠 적지 않음
- 목표 종류별 저금 줄(→ 목표 ‘목표 종류’)

| 목표 종류 | 각자 | 합쳐서 |
| --- | --- | --- |
| 우리 목표 | 두 사람 분배표 모두에 1줄씩. 목표에는 두 사람이 체크한 저금이 모두 쌓임. 0원 줄은 체크리스트에 안 보임 | 공동 분배표에 1줄 |
| 내 목표 | 주인 분배표에만 1줄 | 공동 분배표에 주인 이름을 붙인 1줄(예: “찬우 자기계발”), 체크는 누구나 |

### 3-2. 추천값 [확인 필요]

O-50에서 처음 채우는 값. W-01 ‘추천값으로 다시 채우기’도 같은 계산.

| 순서 | 줄 | 추천값 |
| --- | --- | --- |
| 1 | 고정지출 | 수입 × 25% |
| 2 | 생활비 | 수입 × 25% |
| 3 | 용돈 | 사람마다 그 사람 실수령 × 10% |
| 4 | 저금: 비상금 | 비상금 월 필요액. 비상금 목표 금액 = (고정지출 + 생활비) × 3, 월 필요액 = 목표 금액 ÷ 12 |
| 5 | 저금: 나머지 목표 | 남은 금액을 우리 목표(우선순위대로) → 내 목표(우선순위대로) 순서로 [확인 필요] 각 목표의 월 필요액만큼. 남은 금액이 모자라면 그 목표는 남은 만큼만, 그다음 목표는 0원. 금액이 없는 목표는 0원 |
| 6 | 남는 돈 | 저금까지 채우고 남은 금액 |

- 남은 금액 = 수입 − 고정지출 − 생활비 − 용돈 합계. 비상금도 남은 금액 안에서만 채움(남은 금액이 비상금 월 필요액보다 적으면 비상금이 남은 만큼만)
- 비상금은 우선순위와 관계없이 저금 맨 먼저
- 모든 추천값은 1만 원 단위 반올림
- 직접 추가한 쓰는 돈 줄은 추천값 없음(0원으로 시작)

예시: 찬우, 350만 원

| 줄 | 계산 | 금액 |
| --- | --- | --- |
| 고정지출 | 350만 × 25% = 87.5만 → 반올림 | 88만 원 |
| 생활비 | 350만 × 25% = 87.5만 → 반올림 | 88만 원 |
| 용돈 | 350만 × 10% | 35만 원 |
| 남은 금액 | 350 − 88 − 88 − 35 | 139만 원 |
| 비상금 | 목표 금액 (88 + 88) × 3 = 528만, 월 필요액 528만 ÷ 12 | 44만 원 |
| 내 집 마련 | 월 필요액 250만 중 남은 139 − 44 = 95만 | 95만 원 |
| 여행 | 금액 미정 | 0원 |
| 남는 돈 | 139 − 44 − 95 | 0원 |

- 배우자가 합류할 때(각자 모드, 배우자 분배표, → 배우자 합류 P-06): 같은 표로 배우자 실수령 기준 추천값을 채움
  - 우리 목표: 목표 월 필요액 − 상대(찬우) 저금 줄 금액(0보다 작으면 0)만큼, 배우자 월급의 남은 금액 안에서
  - 내 목표: 주인 혼자 채움. 배우자 분배표에는 상대의 내 목표 줄이 없음
- 각자 모드 W-01 ‘추천값으로 다시 채우기’에서 우리 목표 줄도 상대 저금 줄을 빼고 채우는지 [확인 필요]
- 비상금 목표 금액은 O-50에서 처음 정한 값. 나중에 분배표의 고정지출·생활비를 바꾸면 비상금 목표 금액도 따라 바뀌는지 [확인 필요]. 각자 모드에서 두 사람 고정지출·생활비를 더해 계산하는지 [확인 필요]

### 3-3. 남는 돈

- 남는 돈 = 수입 − 모든 줄 합계(저금 + 쓰는 돈). 자동 계산, 사용자가 고치지 않음
- 0 이상: “남는 돈 20만 원”. 표시만 하고 어느 목표에도 자동으로 넣지 않음
- 음수: “30만 원이 모자라요” + 안내 “쓰는 돈이나 저금을 줄여 주세요”. 저장은 막지 않음
- 저금 줄 금액이 그 목표 월 필요액보다 적어도 막지 않음. 그 목표 예상 달성일이 늦어짐(5-3)

### 3-4. 다시 계산되는 때

| 바뀐 것 | 처리 |
| --- | --- |
| 월급 금액 | 남는 돈만 다시 계산. 다른 줄은 그대로 |
| 분배표 줄 금액 | 남는 돈 다시 계산. 이번 사이클 체크 안 한 줄만 새 금액(→ 월급 체크리스트 ‘다시 계산되는 때’) |
| 목표 추가 | 저금 묶음 맨 아래 0원 줄 |
| 목표 삭제·달성 | 그 저금 줄 빠짐. 이미 체크한 이번 사이클 줄은 기록으로 남음 |
| 관리 방식(각자 ↔ 합쳐서) | 각자 → 합쳐서: 두 분배표를 합침, 같은 목표 줄은 금액을 더함. 합쳐서 → 각자: 수입 비율로 나눔 [확인 필요] |

## 4. 목표 모은 돈

### 4-1. 공식

- 모은 돈 = 처음에 적은 이미 모은 돈 + 체크한 저금 + 직접 넣은 돈 − 직접 뺀 돈 − 꺼내 쓴 돈
- 0 아래로 내려가지 않음. 빼기·꺼내 쓰기는 모은 돈까지만 [확인 필요]
- 우리 목표는 두 사람의 체크한 저금, 직접 넣은 돈을 모두 셈. 내 목표는 주인 분배표 줄의 체크(배우자 ‘대신 체크’ 포함)와 주인이 넣은 돈만(넣기·빼기·꺼내 쓰기는 주인만, → 목표 ‘목표 종류’)
- 사용자가 모은 돈 숫자를 바로 고치지 않음. 바꾸려면 목표 상세(G-02) ‘넣기·빼기’ 기록을 남김
- 모은 돈은 앱 안의 기록. 실제 돈은 통장에 있고 통장 잔액은 우리 자산에서 따로 적음(6장)

### 4-2. 체크와 모은 돈

| 동작 | 모은 돈 |
| --- | --- |
| 저금 줄 체크 | + 그 줄 금액 |
| ‘다른 금액으로 보냈어요’(W-02a) | + 실제 보낸 금액. 0원이면 ‘못 함’과 같음 |
| 체크 풀기 | − 그 줄에 더했던 금액 |
| ‘이번 달은 못 했어요’, 기준일이 지나 ‘못 함’ | 변화 없음 |
| 지난 사이클 잘못 체크 | 지난 체크리스트는 읽기 전용. G-02 ‘넣기·빼기’로 고침 |

- 같은 우리 목표에 두 사람이 체크하면(각자 모드) 둘 다 더함. 내 목표는 주인 줄만 있음(배우자가 ‘대신 체크’해도 주인 줄). 같은 줄을 거의 동시에 체크하면 먼저 저장된 체크만(→ 월급 체크리스트)
- 각 체크는 목표 기록(넣기, 출처 = 체크리스트 줄) 1건으로 남김. 체크를 풀면 그 기록을 지움(→ 데이터 항목)

## 5. 목표 계산

### 5-1. 형태

| 형태 | 목표 금액 | 월 필요액 | 상태 |
| --- | --- | --- | --- |
| 한 번 | 정한 금액 | (목표 금액 − 모은 돈) ÷ 남은 개월 | 진행 중, 지연, 달성 |
| 매년 | 1년에 쓰는 금액 | (연간 금액 − 모은 돈) ÷ 다음 쓰는 달까지 남은 개월. 온보딩에서는 모은 돈 0이라 연간 금액 ÷ 남은 개월 | 진행 중, 지연 |
| 매달 | 없음(월 납입액만) | 월 납입액 그대로 | 없음. 모은 돈 누적만 표시 |

- 매년 목표: 쓰는 달을 O-23에서 받고 기한(O-24)은 묻지 않음. 쓰는 달이 지나면 다음 해 같은 달로 넘어가고 남은 모은 돈은 그대로 이어지는지 [확인 필요]
- 매달 목표: 아이 교육·양육, 노후·연금. 기한 없음

### 5-2. 월 필요액

- 월 필요액 = (목표 금액 − 모은 돈) ÷ 남은 개월, 1만 원 단위 올림. 0 아래면 0
- 남은 개월 = 이번 달부터 기한 달 전까지의 개월 수, 최소 1. 예: 2026년 10월 → 2031년 10월 = 60개월
- 기한을 연도만 받았으면 달은 이번 달과 같은 달로 봄 [확인 필요]
- 기한이 없는 목표(빈 칸, ‘잘 모르겠어요’): 기본 기한 = 3년 뒤 + ‘추정’(→ 온보딩 ① O-24)
- 금액이 없는 목표(2순위부터, ‘금액 정하기’ 전): 월 필요액 없음, 분배표 저금 줄 0원
- 예시: 내 집 마련 (1억 5,000만 원 − 0) ÷ 60개월 = 250만 원 → “매달 250만 원씩 모으면 돼요”

### 5-3. 예상 달성일

- 예상 달성일 = 이번 달 + (목표 금액 − 모은 돈) ÷ 그 목표 저금 줄 금액(개월, 올림)
- 저금 줄 금액 = 분배표에서 그 목표를 가리키는 저금 줄 합. 우리 목표는 각자 모드면 두 사람 것 합, 내 목표는 주인 줄만(합쳐서면 공동 분배표의 그 1줄)
- 저금 줄이 0원이면 ‘미정’. O-60 문구 “분배표에서 저금을 정하면 언제 이룰지 알려 드려요”
- 수익률은 0%로 계산. 수익률 시뮬레이션(프리미엄, 유료화 시점)은 목표 상세 G-02에서 보기만, 이 계산에 넣지 않음
- 체크하지 못한 달은 모은 돈이 덜 쌓이므로 다음 계산에서 예상 달성일이 자연히 늦어짐. 따로 벌점이나 보정 없음
- 예시: 내 집 마련 1억 5,000만 원 ÷ 95만 원 = 157.9 → 158개월. 2026년 10월 + 158개월 = 2039년 12월 → “매달 95만 원씩 모으면 2039년 12월에 내 집 마련을 이뤄요”. 기한 2031년 10월보다 늦음 → “목표 기한보다 8년 늦어요”

### 5-4. 상태

| 상태 | 조건 |
| --- | --- |
| 진행 중 | 예상 달성일 ≤ 기한, 또는 기한이 없음 |
| 지연 | 예상 달성일 > 기한, 또는 예상 달성일 ‘미정’이면서 기한이 있음 [확인 필요]. 목표 카드에 “지연” 배지 |
| 달성 | 모은 돈 ≥ 목표 금액. 그때 바로 축하 화면(G-05), 분배표 저금 줄 빠짐 |

- 매달 목표는 상태 없음, 매년 목표는 진행 중과 지연만
- 기한 비교 문구(O-60 3번): 늦으면 “목표 기한보다 n년 늦어요”(1년 미만이면 n개월) [확인 필요], 안이면 “목표 기한 안에 이뤄요”

### 5-5. 템플릿

7개 분류(기본, 갚기, 주거, 가족, 즐거움, 생활, 미래), 비상금 + 템플릿 19개 + ‘직접 만들기’. 비상금은 처음부터 있는 기본 목표라 목표 고르기(O-21)·목표 추가(G-03a)에 없음. 같은 템플릿 여러 개 가능. 질문 문구 → 온보딩 ① O-23·O-24.

- 목표 개수 제한 없음. 무료·프리미엄 차이는 개수가 아닌 기능
- 노후·연금은 중도 해지 손실을 막도록 납입액을 조절할 수 있는 소액으로 시작하게 안내

## 6. 순자산

- 순자산 = 자산 합계 − 부채 합계. 우리 자산 탭에 적은 값으로만 계산
- 목표의 모은 돈은 순자산에 더하지 않음. 실제 돈은 통장에 있고 통장 잔액을 자산으로 적기 때문(같은 돈을 두 번 세지 않음) [확인 필요]
- 자산 금액은 원금 기준(투자·부동산에 넣은 원금을 적었으면 원금, 없으면 평가금액)
- 예상 순자산 = 평가금액 기준. 차이 = 안 판 수익(손실이면 “−”). 표시만, 목표 계산에 안 씀
- 평가 손익 = 평가금액 − 원금(% = ÷ 원금), 원금 있는 투자·부동산만
- 팔았어요: 받은 금액을 고른 통장 자산에 더함. 전부 팔면 ‘매도 완료’(목록에서 빠짐, 과거 순자산 기록 유지) + 실현 손익 = 받은 금액 − 원금. 일부 팔면 받은 금액 + 남은 평가금액 입력, 원금은 판 비율(받은 금액 ÷ (받은 금액 + 남은 평가금액))만큼 줄이고 그만큼 실현 손익 기록. 원금 없으면 실현 손익 없음
- 평가금액·시세는 자산 상세(F-04)에서 언제든 고침
- 배우자 화면: ‘비공개’ 항목은 빼고, ‘합계만’ 항목은 합계에 포함
- 지난달보다(H-04): 금액 이력으로 구한 지난달 말 순자산과 비교 [확인 필요]
- 가진 돈을 하나도 안 적었으면 순자산을 계산하지 않음(H-04 빈 상태)
- 음수면 “−”, 그래프에 0선

## 7. 비슷한 부부와 비교 (출시 후, MVP 밖)

비슷한 부부 그룹 안에서 우리 위치를 10% 구간으로 보여 주는 무료 기능. 이 장이 정본. 화면 → 우리 자산 F-08, 동의 → 보안·개인정보 5-1, 저장 → 기술·운영 2장, 이벤트 → 성공 지표.

재기획으로 그룹 기준(출생연도, 사는 집, 고용 형태)과 저축 지표(월말 정리 저축 확인)를 더 이상 받지 않음. 그룹과 지표를 다시 정해야 함 [확인 필요]. 아래는 다시 정하기 전까지의 기준.

### 7-1. 비교 단위와 그룹

- 비교 단위는 부부. 배우자 미합류, 혼자 쓰기 부부는 제외(F-08 진입 줄도 숨김)
- 그룹 후보: 결혼 상태(했어요 / 준비 중이에요), 두 사람 월 실수령 합계 구간(200 미만 / 200~300 / 300~400 / 400~500 / 500 이상, 만 원) [확인 필요]

### 7-2. 지표

| 지표 | 계산 |
| --- | --- |
| 순자산 | 6장과 같음 |
| 월 저금액 | 지난 사이클 체크리스트에서 체크한 저금 줄 합(실제 보낸 금액) [확인 필요] |
| 저금 비율 | 월 저금액 ÷ 분배표 수입 [확인 필요] |
| 부채 비율 | 부채 합계 ÷ 자산 합계. 자산 0원이면 계산 안 함 |

- ‘비공개’ 항목은 제외, ‘합계만’ 항목은 합계로 포함
- 체크리스트를 한 번도 끝내지 않은 부부는 저금 지표에서 제외

### 7-3. 표시

- 정확한 순위 없이 10% 단위 구간만
- 그룹 분포 그림 위에 우리 위치 점과 그룹 중앙값 선
- 상위 50% 안: “비슷한 부부 가운데 상위 30% 안이에요”
- 중앙 아래: 사실만 순하게. “중간보다 조금 아래예요”, “아직 시작 단계예요”
- 압박·죄책감 문구 금지(→ 브랜드 1장, 공통 6장). 배우자끼리, 양가는 비교하지 않음
- 부채 비율은 낮을수록 위로 셈

### 7-4. 안전장치

- 그룹당 100쌍 이상일 때만 표시
- 모자라면 넓은 그룹으로 합침(필터 그룹 → 결혼 상태만 → 전체). 화면에 실제 그룹 표시. 전체도 100쌍 미만이면 그림 대신 “비슷한 부부가 더 모이면 보여 드려요”
- 지표마다 위아래 끝 1% 제외 후 계산
- 월 1회 배치 계산(pg\_cron, 기준일 작업과 겹치지 않는 시간). 결과는 그룹별 백분위 표만 저장, 개별 부부 값은 통계 테이블에 넣지 않음

### 7-5. 참여

- 선택 동의 ‘통계 참여’: 내 데이터를 이름 없이 통계에 넣기. 두 사람 모두 동의해야 부부가 통계에 들어감
- 언제든 끌 수 있음(설정 S-18). 끄면 다음 계산부터 빠짐
- 법률 검토 필요: 신용정보·민감정보 해당 여부와 함께 → 보안·개인정보 5-4

### 7-6. 시작 순서

1. 1단계(정식 출시 뒤): 공공 통계(통계청 가계금융복지조사)로 먼저 표시, 화면에 “공공 통계 기준”. 공공 통계에 없는 지표는 숨김. 출생연도를 받지 않아 연령대 구간을 쓸 수 없음 [확인 필요]
2. 2단계: 그룹별 100쌍이 모이면 앱 데이터로 전환, 모자란 그룹은 1단계 표시 유지

- 공공 통계는 해마다 갱신, 어드민 계산 설정값(AD-19)에서 입력
