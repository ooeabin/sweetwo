## 규칙

- 가이드는 별도 메뉴 없음: 설정 › 가이드 모아보기(S-01)와 각 화면 ‘알아보기’ 링크로 진입. 체크리스트 완료는 이번 달 ‘할 일’에서만, S-02는 할 일을 누르면 열리는 설명 화면
- 내 정보·내 답 수정: 사실값은 즉시 반영, 배분 결정은 제안 → 핵심 규칙 › 부부·제안·권한
- 연결 해제·계정 삭제 때 데이터가 누구에게 남는지·얼마나 보관하는지 → 보안·개인정보
- 웹에서도 쓰는 설정: S-10, S-11/S-11e, S-12, S-14, S-18, S-19, S-21(→ 제품 개요 5장). S-15는 웹에서 기기 목록만, S-22는 데스크톱만

## S-11e 프로필 사진

S-11 ‘프로필 사진’에서 사진을 고르거나 끌어 놓으면 열리는 자르기 화면. 사진이 보이는 곳과 사진 없을 때 모습 → 화면 설계 › 공통 Avatar.

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 올리기 | 파일 고르기 또는 끌어 놓기 + 고지 한 줄 “올린 사진은 {배우자}님과 나만 볼 수 있어요”({배우자} = 보는 사람의 배우자 호칭. 예: 찬우가 볼 때 “예빈님과 나만”) | JPG, PNG, HEIC, WebP만. 최대 10MB. 별도 동의 체크 없음(처리방침 선택 수집 항목 → 보안·개인정보 5-3) |
| 2 | 자르기 | 정사각 자르기 틀 + 원형 미리보기 | 확대, 끌어서 위치 이동 |
| 3 | 저장 | “저장할게요” | 저장 → S-11. 서버에는 정사각 512px로 줄이고 EXIF 위치 정보를 지운 뒤 저장(보관 → 보안·개인정보) |

- 저장하거나 지우면 배우자 화면에 실시간 반영
- 배우자 활동에 “프로필 사진을 바꿨어요” 남김. 알림은 보내지 않음
- 저장 위치: 저장소 `avatars/{공간}/{사람}.jpg`(비공개, 같은 공간 두 사람만 읽음), 보여 줄 때 1시간짜리 서명 주소

예외·오류

- 10MB 초과: “10MB 이하 사진만 올릴 수 있어요”, 자르기 화면으로 넘어가지 않음
