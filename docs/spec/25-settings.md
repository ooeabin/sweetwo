## 규칙

- 가이드는 별도 메뉴 없음: 설정 › 가이드 모아보기(S-01)와 각 화면 ‘알아보기’ 링크로 진입
- 설정에서 바꾼 값은 바로 적용. 부부 공통 값이나 상대도 보는 값이면 상대 알림 + 활동 기록, 고친 사람에게 Toast ‘되돌리기’ → 핵심 규칙 › 부부·권한 4장
- 온보딩 답은 따로 다시 보는 화면 없이 그 정보가 있는 곳에서 고침: 이름·월급·관리 방식·결혼 상태·결혼한 날·출생연도 → S-11, 목표 → 목표 탭, 분배표 → W-01(→ 온보딩 ① 예외)
- 연결 해제·계정 삭제 때 데이터가 누구에게 남는지·얼마나 보관하는지 → 보안·개인정보
- 데스크톱·모바일 앱 설정은 같음. S-22(위젯, 트레이)만 데스크톱

## S-21 휴지통

‘삭제’로 보낸 항목(자산·부채 F-04, 목표 G-02 등)을 30일 보관하는 화면. 보내기는 묻지 않고 바로 + Toast “되돌리기”, 영구 삭제만 Modal 확인.

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 안내 | “지운 항목은 30일 뒤 완전히 지워져요” | 목록 위 1줄 |
| 2 | 항목 줄 | “청약 통장” + 작은 이름표 ‘자산’ / “10월 3일에 지웠어요” + 작은 흐린 “22일 남음” + 지운 사람 Avatar | 최근 지운 순. 휴지통 항목은 합계·순자산·분배표 계산에서 빠짐 |
| 3 | 되살리기 | “되살리기” | 묻지 않고 원래 자리로 + Toast “되살렸어요”, “되돌리기”. 같이 지워진 항목도 함께, 연결 대상이 없으면 연결 없이 되살리고 “연결된 항목이 없어 따로 되살렸어요”(→ 데이터 항목 ‘삭제 연결 처리’). 목표를 되살리면 분배표 저금 줄도 다시 생김(금액은 지우기 전 금액인지 0원인지 [확인 필요]), 배우자와 연결된 상태면 상대 알림(→ 핵심 규칙 › 부부·권한 4장) |
| 4 | 영구 삭제 | ⋯ → “영구 삭제”(맨 아래 빨간 글자) | Modal “완전히 지울까요?” / “되돌릴 수 없어요” + “지울게요”, “취소” |
| 5 | 비우기 | “휴지통 비우기” | Modal “{n}개를 완전히 지울까요?” + “지울게요”, “취소” |

- 30일 지나면 자동 영구 삭제, 알림 없음
- 내 명의·공동 항목만 보임. 배우자 명의 항목은 배우자 휴지통에만
- 저장 필드(삭제 시각·지운 사람) → 핵심 규칙 › 데이터 항목

예외·오류

- 빈 상태: “휴지통이 비어 있어요”
- 오프라인: 영구 삭제·비우기 비활성

## S-22 위젯

위젯 설정. 진입: S-10 ‘위젯’ 줄, 트레이 아이콘 오른쪽 클릭 ‘위젯 설정’. 위젯 규칙·화면 → 화면 설계 › 위젯.

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 트레이 아이콘 | “트레이 아이콘” / “앱 창을 닫아도 트레이에 남아요”, 기본 켜짐 | 데스크톱만. 끄면 트레이 위젯 창도 없음 |
| 2 | 위젯에 금액 보이기 | “위젯에 금액 보이기”, 기본 꺼짐 | 기기마다 따로. 가림 규칙 → 화면 설계 › 위젯 |
| 3 | 목표 고르기 | “목표 위젯에 보일 목표” / 오른쪽 “제주 여행” | 누르면 목표 목록(좁은 창은 BottomSheet)에서 1개. 기본 = 우선순위 첫 목표. WG-02·WG-04에 반영 |

예외·오류

- 목표가 없으면 3번 오른쪽 회색 “목표 없음”, 누르면 → G-03a
- 고른 목표가 휴지통·보류로 가면 우선순위 첫 목표로 바뀜
