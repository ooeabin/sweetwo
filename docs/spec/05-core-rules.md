# 핵심 규칙

여러 화면에 걸치는 규칙의 정본. 화면 탭에는 그 화면에서 보이는 것·문구만 두고, 규칙은 여기로 한 줄 링크.

- 계산·배분: 통장 구조, 저축 가능 금액·배분·반올림, 목표 템플릿·계산식·상태, 사실값 vs 배분 결정, 목표 사용과 ‘목표자금 → 공동 생활비’ 나누기 줄, 미달·초과, 재정 진단, 양가 비용, 예비부부 계산
- 월 사이클: 기준일·사이클·플랜 생성, 첫 사이클, 생활비 체크, 월말 정리 기간·반영 순서, 함께/혼자 정리, 놓친 달·쉬어가기, 월 플랜 상태
- 부부·제안·권한: 부부 상태, 연결·해제·30일 재연결, 상대 명의 대신 입력, 공개 범위, 권한, 제안(72시간·함께 정하기·상태·예외), 규칙 확정 전 기본값, 예비부부 → 신혼 전환
- 데이터 항목: 엔티티·필드, 공통 저장 규칙, 금액 구간 칩, 항목 분류표(수입·고정지출·생활비·비정기 지출·자산·부채·투자 원칙)
