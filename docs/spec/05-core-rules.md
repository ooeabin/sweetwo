# 핵심 규칙

여러 화면에 걸치는 규칙의 정본. 화면 탭에는 그 화면에서 보이는 것·문구만 두고, 규칙은 여기로 한 줄 링크. 2026-10-25 재기획 결정 → `docs/adr/0003-replan-goal-checklist.md`, 목표를 저금 항목으로(2026-11-08) → `docs/adr/0007-goal-into-saving-line.md`.

- [계산·배분](06-calc-allocation.md): 금액 단위·반올림·999억 상한, 수입(각자·합쳐서, 매달 달라요), 월급 계획 줄 종류·추천값·여유 자금, 저금 항목 모은 금액(시작할 때 모은 금액 + 체크한 저금 합), 목표 금액이 있는 저금 항목의 진행·월 필요액·예상 달성일·달성, 순자산, 비슷한 커플과 비교(출시 후)
- [월 사이클](07-month-cycle.md): 월급날과 기준일, 사이클, 월급 체크리스트 생성, 첫 사이클, 월급 전 확인, 사이클 상태
- [커플·권한](08-couple-proposal-permission.md): 우리 둘 상태, 연결·해제·30일 재연결, 상대 명의 대신 입력, 공개 범위, 권한(같이 쓰는 것은 누구나 바로 고침 + 알림·되돌리기, 각자 모드 파트너 월급 계획·체크리스트·저금은 보기만 2026-11-09)
- [데이터 항목](09-data-items.md): 엔티티·필드(기획 수준), 월급 계획·체크리스트 필드, 공통 저장 규칙, 금액 구간 칩, 자산·부채 분류표
