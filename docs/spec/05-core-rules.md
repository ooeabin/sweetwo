# 핵심 규칙

여러 화면에 걸치는 규칙의 정본. 화면 탭에는 그 화면에서 보이는 것·문구만 두고, 규칙은 여기로 한 줄 링크. 2026-10-25 재기획 결정 → `docs/adr/0003-replan-goal-checklist.md`, 목표를 저금 항목으로(2026-11-08) → `docs/adr/0007-goal-into-saving-line.md`, 같이 모으기와 확인 한 번(2026-11-13) → `docs/adr/0009-save-together-plan.md`.

- [계산·배분](06-calc-allocation.md): 금액 단위·반올림·999억 상한, 수입(각자·합쳐서, 매달 달라요, 날짜 없는 사람의 기간), 월급 계획 줄 종류(+ 같이 쓰는 통장, 보내기)·줄 설정·추천값(합쳐서 용돈 같은 금액, 보내기 = 월급 − 용돈)·여유 자금, 분담 도우미, 저금 모은 금액(이미 모은 금액 + 확인 + 돈 들어왔어요 ± 바로잡기), 진행·월 필요액·예상 달성일·기한까지 남은 금액·달성, 같이 모으기 묶음, 순자산(평가금액 기준), 자산 순위(둘의 합 / 또래 중간값)
- [월 사이클](07-month-cycle.md): 월급날과 기준일, 사이클, 확인 목록 생성(체크리스트에 넣기, 자동 줄 나가는 날), 첫 사이클(소급 없음), 월급 전 확인과 늦은 확인, 월급 변경 적용, 날짜 없는 사람의 기간, 사이클 상태
- [커플·권한](08-couple-proposal-permission.md): 우리 둘 상태, 관리 형태(세 질문 → 엔진), 연결·해제(같이 쓰던 것만 지움)·다시 연결 요청, 상대 명의 대신 입력, 공개 범위(S-13 한 목록), 권한(같이 쓰는 것은 누구나 바로 고침 + 알림·되돌리기, 예외 둘: 관리 형태 합치기·분담 제안, 각자 계열 파트너 것은 공개 단계대로 보기만)
- [데이터 항목](09-data-items.md): 엔티티·필드(기획 수준), 월급 계획·체크리스트 필드, 공통 저장 규칙, 금액 구간 칩, 자산·부채 분류표, v2.2 새 테이블·열(7장)
