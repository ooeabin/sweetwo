# 공통

모든 화면 공통 규칙. 화면 탭에는 이 규칙과 다른 점만 적음. 하위 탭: 질문 화면 패턴(질문 틀·입력), 공통 상태(빈 화면·오류·오프라인 등). 알림 → 화면 설계 › 알림.

## 1. 화면 원칙

- 입력은 한 화면에 질문 하나, 입력 하나. 예외(한 화면 목록 허용): Q6 목록 입력 패턴 화면(O-35·연간 고정 지출 등), 행이 고정된 잔액 목록(W-04b·O-63·W-04e), 월말 정리 W-04j 지출 입력·W-04k 저축 확인, O-36 그룹 칩, 동의 체크(A-05)
- 질문은 해요체 한 줄 (예: “한 달에 얼마 받아요?”)
- 하나만 고르는 질문은 고르면 0.3초 뒤 자동으로 다음 화면
- 모르는 질문은 ‘잘 모르겠어요’로 넘기고, 앱이 추정값을 넣은 뒤 이번 달 ‘할 일’에 남김
- 답은 화면을 넘길 때마다 즉시 저장
- 앞의 답에 따라 필요 없는 질문은 건너뜀
- 숫자를 보여줄 때는 결론 문장을 먼저 (“이번 달 200만 원을 저축했어요”), 표·그래프는 그 아래

## 2. 레이아웃

앱 틀(상단 메뉴 줄·오늘 띠·두 단 본문·좁은 창 머리·하단 독) → 이번 달 › 앱 기본 틀

| 구분 | 기준 해상도 |
| --- | --- |
| 데스크톱 앱 | 창 최소 960×640. 사이드바 없음, 상단 메뉴 줄 + 본문 최대 1120px 가운데. 이번 달은 두 단, 창 1100px 미만이면 한 단 |
| 입력 흐름 | 본문 위 전체 화면 레이어, 가운데 480px 한 열. 로그인·가입 화면도 같은 한 열 |
| 데스크톱 앱, 좁은 창 | 768px 미만: 모바일 앱과 같은 좁은 창 레이아웃 |
| 모바일 앱 (iOS, Android) | 좁은 창 레이아웃(768px 미만 기준): 하단 독, 주 버튼 하단 고정, 상단·하단 안전 영역(노치, 홈 표시줄) 띄움. 태블릿 가로처럼 768px 이상이면 넓은 창 화면 |

- 메뉴 4개: 이번 달(첫 화면)·목표·우리 자산·캘린더. 설정은 메뉴 밖(넓은 창 상단 메뉴 줄 오른쪽 두 사람 아바타, 좁은 창 상단 아이콘 4개(검색·눈·알림·설정) 중 설정). 좁은 창 추가는 하단 독 같은 줄 오른쪽 + 버튼, 검색 화면은 ⌘K와 같음(→ 화면 설계 › 이번 달 › 앱 기본 틀). 넓은 창은 상단 메뉴 줄 + 이번 달 두 단(왼쪽 할 일·월급 플랜, 오른쪽 목표·다가오는 일정·배우자 활동). 이번 달 = 할 일, 우리 자산 = 현황 기록, 캘린더 = 날짜
- 결과·요약 화면은 본문 안 2열 허용(768px 미만 1열)
- 하위 탭: 본문 상단 가로 탭(좁은 창은 가로 스크롤), 마지막으로 본 탭 기억
- 사람 색: Avatar만 찬우 연한 코랄(person-1)·예빈 하늘(person-2), 보는 사람과 상관없이 고정. 양가 일정은 family 틴트 + 해당 쪽 사람의 Avatar로 구분(남편 쪽/아내 쪽 별도 색 없음)
- Avatar: 프로필 사진이 있으면 원으로 자른 사진, 없으면 이름 첫 글자 1자 + 사람 색(person-1/person-2). 사진은 Avatar가 쓰이는 모든 곳(나누기 줄 담당, 배우자 활동, 제안 보낸 사람, 상단 메뉴 줄 아바타, 설정)에 같이 보임. 올리기·자르기 → 설정 S-11e
  - 원 바탕: 시작한 사람 연한 코랄(person-1, 라이트 #FFE0D6 / 다크 #4A2620), 합류한 사람 하늘(person-2)
  - 글자 색: 시작한 사람 person-1-ink(라이트 #8F3A22 / 다크 #FFC2B3), 합류한 사람 person-2-ink
  - 쓰는 곳: 나누기 줄 담당, 배우자 활동, 제안 보낸 사람, 상단 메뉴 줄 두 사람 아바타, 설정 계정 정보

## 3. 질문 화면·입력

질문 화면 틀(진행 표시·뒤로·나중에 할게요·보조 링크·주 버튼), 입력 패턴 Q1\~Q7, 금액·목록·날짜 입력 규칙, 질문 화면 키 → 공통 › 질문 화면 패턴

## 4. 키보드 조작 (데스크톱)

| 키 | 동작 |
| --- | --- |
| Esc 또는 Alt+← | 뒤로, 입력 흐름·Modal·패널 닫기 |
| Ctrl(⌘)+1\~4 | 메뉴 이동(이번 달·목표·우리 자산·캘린더) |
| Ctrl(⌘)+N | 빠른 추가 (목표 / 자산·부채 / 챙길 날) |
| Ctrl(⌘)+K | 검색(목표·항목·가족 이름) + 바로 하기(월급 나누기, 자산 추가, 목표 추가, 금액 가리기, 잠그기. 월급 나누기가 없으면 지출 적기) → 이번 달 › 앱 기본 틀 11번 |
| Ctrl(⌘)+L | 앱 잠금 |
| Ctrl(⌘)+, | 설정(S-10) |
| Ctrl(⌘)+J | 알림 센터 열기 |
| Ctrl(⌘)+Shift+H | 금액 가리기 켜고 끄기 |

질문 화면의 Enter·숫자·1\~9·방향키 → 공통 › 질문 화면 패턴. 모바일 앱은 스와이프 뒤로가기.

모바일 앱은 단축키 없음. 외부 키보드를 연결하면 Esc(뒤로)와 질문 화면 키만. 앱 잠금은 데스크톱과 같음(PIN + Face ID·지문, → 로그인·가입 A-06)

## 5. 화면 용어

은행·가계부 앱에서 흔히 쓰는 말은 그대로, 일상에서 잘 안 쓰는 기획 용어만 풀어 씀.

| 기획서 용어 | 화면 표기 | 기준 |
| --- | --- | --- |
| 자산, 부채, 순자산 | 그대로 | 흔히 쓰는 말 |
| 비상금, 예산, 저축률, 금리, 만기일, 명의 | 그대로 | 흔히 쓰는 말 |
| 재정 진단, 양호 / 주의 / 위험 | 그대로 | 흔히 쓰는 말 |
| 공개 범위, 경조사 | 그대로 | 흔히 쓰는 말 |
| 고정비 | 고정지출 | 가계부 표현 |
| 변동비 | 생활비 | 가계부 표현 |
| 개인자금 | 용돈 | 일상 표현 |
| 합산 소득, 합산 월소득 | 월 수입 (부부 합계) | 일상 표현 |
| 현금흐름 | 월 수입·지출 | 풀어 씀 |
| 저축 여력 | 저축 가능 금액 | 풀어 씀 |
| 양가 적립 | 양가 비용 (매년 목표) | 풀어 씀 |
| 재설계 | 계획 다시 세우기 | 풀어 씀 |
| 구성원 | 가족 | 풀어 씀 |
| 경조사 일정 + 기념일 | 챙길 날 | 일정 종류 이름(캘린더 안). 메뉴 이름으로 쓰지 않음 |
| 홈, 첫 화면 | 이번 달 | 메뉴 이름. 할 일·월급 플랜·월말 정리·받은 제안을 담음, ‘홈’ 쓰지 않음 |
| 자산 메뉴 | 우리 자산 | 메뉴 이름. 데이터 ‘자산·부채’는 그대로 |
| 날짜 메뉴 | 캘린더 | 메뉴 이름. 챙길 날 + 돈 날짜(읽기 전용)를 담음 |
| 변동비 체크 | 생활비 체크 | 가계부 표현 |
| 결산, 머니데이 | ‘{월}월 월급 플랜 정리’ | 하나로 통합. ‘월말 정리’는 기획 용어로만, 화면에 ‘이번 달 월말 정리’ 쓰지 않음 |
| 동의 요청, 확인 요청, 다음 달 바뀔 것 | 제안 | 하나로 통합, 반대 없으면 적용 |
| 기준일, 월 플랜, 배분안 | ‘{기준일의 월}월 월급 플랜’, 정리는 ‘{같은 월}월 월급 플랜 정리’ | 기준일은 화면에 ‘월급 플랜’으로 표현 |
| 미달 처리 선택지 | 이번 달만 넘어가기 | ‘쉬어가기’는 놓친 달 전용 |

## 6. 문구 톤

| 원칙 | 이렇게 | 이렇게 하지 않기 |
| --- | --- | --- |
| 해요체, 짧게 | “이번 달 월급 나누기가 2곳 남았어요” | “금월 미완료 월급 나누기 건수: 2” |
| 비난하지 않기 | “계획보다 20만 원 덜 모았어요. 다음 달에 나눠 채워볼까요?” | “목표 달성에 실패했습니다” |
| 배우자를 탓하지 않기 | “생활비가 계획보다 많이 나갔어요” | “{배우자}님이 생활비를 초과했어요” |
| 권유는 질문형 | “비상금부터 채워볼까요?” | “비상금을 채우세요” |
| 양가는 균형으로만 | “올해 양가 비용을 나란히 보여드릴게요” | 순위·점수·‘더 많이 썼어요’ 강조 |
| 금융상품은 개념만 | “납입액을 조절할 수 있는 연금 계좌가 있어요” | 특정 상품·금융사 추천, 수익 보장 표현 |

- 화면 문구는 제목 1줄 + 필요할 때만 보조 1줄. 인사·부연·자명한 안내 금지
- 한 줄에 정보 여럿을 둘 때 가운데 점으로 잇지 않음: 이름표는 작고 흐리게, 값은 진하게, 묶음 사이 간격으로 구분
- 금액은 숫자가 주인공: 단위(억·만·원)는 작게, 흐린 회색으로(큰 숫자에서 약 0.6배, 목록에서 약 0.8배). 입력 칸 ‘원’도 회색
- 음수·큰 금액: 음수(예: 순자산)는 “−”를 붙여 표시(“−1,200만 원”), 그래프는 0선을 그림. 위젯은 음수가 나오면 % 대신 금액. 합계가 999억 원을 넘으면 “999억+”
- 생활비 초과 문구: 인사말은 문장(“생활비를 n만 원 넘게 썼어요”), 타일과 위젯은 짧게(“n만 원 넘었어요”)
- 순위·점수 금지의 예외: 다른 부부와의 비교 통계는 10% 구간으로만, 배우자끼리나 양가는 비교하지 않음(→ 우리 자산 F-08)

## 7. 상태 화면·메뉴

빈 화면·로딩·연결 끊김·서버 오류·권한 없음·오프라인·충돌·강제 업데이트·점검·되돌리기 토스트·확인 Modal → 공통 › 공통 상태

- ⋯ 메뉴: 동작 최대 4개. 되돌릴 수 없는 동작은 맨 아래 빨간 글자 → Modal 확인. 좁은 창은 BottomSheet
- 프리미엄 기능: 유료화 전에는 화면에 없음(자물쇠·구독 S-16 진입 없음). 유료화 시점에 기능·결제·체험을 함께 여고 보여 주는 방식도 그때 정함

## 8. 금액 가리기

상단 눈 아이콘으로 켜고 끔. 여럿이 함께 보는 자리에서 금액만 가리는 용도.

- 켜면 모든 금액을 “•••”로 표시. 비율·날짜·이름은 그대로
- 기기마다 기억(같은 계정도 기기별로 따로)
- 앱 잠금 화면·앱 전환 미리보기에서는 설정과 상관없이 자동으로 가림
- 입력 화면(금액 입력 칸)은 가리지 않음
- 눈 아이콘 라벨: 꺼져 있으면 “금액 가리기”, 켜져 있으면 “금액 보기”
- 위젯 금액 표시 → 화면 설계 › 위젯

## 9. 접근성

- 명도 대비: 글자 4.5:1 이상, 입력 칸 테두리·아이콘 등 UI 요소 3:1 이상. 라이트·다크 모두 적용
- 스크린리더 라벨: 글자 없는 아이콘 버튼은 모두 aria-label(예: “알림”, “추가”, “더보기”). 금액 가리기를 켠 동안 금액은 “가려진 금액”으로 읽음
- 키보드·포커스: Tab 순서 = 화면을 읽는 순서(위→아래, 왼쪽→오른쪽). 포커스는 focus 색 테두리로 항상 표시. ⌘K 검색, Esc 닫기·뒤로, Enter 다음·확인(4장). Modal·BottomSheet는 열린 동안 포커스를 안에 가둠
- 글자 확대: 기기 글자 크기 200%까지 잘림·겹침 없이 줄바꿈
- 색만으로 뜻을 전하지 않음: 오류는 빨강 + 도움말 글자, 사람 구분은 색 + Avatar, 차트는 색 + 범례·값 라벨
- 움직임 줄이기: 기기의 ‘동작 줄이기’ 설정이 켜져 있으면 화면 전환·숫자 올라가는 효과를 끔
- 달력 그리드(캘린더 Y-04): 그리드 전체가 Tab 멈춤 1개, 안에서 방향키로 날짜 이동(←→ 하루, ↑↓ 일주일, Home·End 주의 처음·끝, PageUp·PageDown 이전·다음 달), Enter로 그 날 열기. 날짜마다 “10월 14일 수요일, 일정 2개”처럼 날짜·요일·일정 수를 읽음. 오늘은 “오늘”을 붙여 읽음
- 차트(순자산·목표 진행·막대): 차트마다 요약 문장을 aria-label로(예: “최근 12개월 순자산, 1억 50만 원에서 1억 2,220만 원으로 늘었어요”). 차트 아래 “표로 보기”로 같은 값을 표로 보여 줌. 금액 가리기 중에는 표·요약 문장의 금액도 “가려진 금액”
