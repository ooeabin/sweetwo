# 온보딩 ① 흐름

## 흐름 요약

가입 직후 8~9화면, 약 2분 [확인 필요]이면 월급 계획이 생기고 바로 홈으로 감. 결정 이유 → `docs/adr/0003-replan-goal-checklist.md`, 목표 고르기를 뺀 것 → `docs/adr/0007-goal-into-saving-line.md`. 질문 화면 틀·패턴(Q1~Q7)은 공통 참조, O-01·O-02는 로그인·가입.

- 순서: (A-05·A-06) → O-10 → O-03 → O-06 → (O-07) → O-11 → (O-12) → O-13 → O-30 → O-31 → O-32 → O-60 → 홈
- 월급 계획(O-50)는 O-32 다음에 추천값으로 자동으로 만들고 홈 H-03 ‘월급 계획 고치기’ → W-01에서 고침(2026-11-03 할 일 ‘월급 계획 확인’은 없앰). 결과 화면은 없고 O-60 ‘준비 끝’ 한 장 뒤 홈(ADR 0005)
- 목표 고르기(O-21)는 없앰(2026-11-08, ADR 0007). 온보딩이 끝나면 저금 항목 없이 시작하고, 첫 체크리스트 저금 묶음의 빈 줄 ‘+ 저금 추가’로 권함(2026-11-09, → 월급 탭 ‘첫 저금’). 기본 항목 ‘비상금’도 만들지 않음
- O-30 이후(월급, 월급 계획, 결과)는 온보딩 ②
- 진행 표시: 질문 화면 맨 위 얇은 막대 하나(브랜드 오렌지). O-10, O-60에는 없음. 챕터 구분 없음
- ‘나중에 할게요’는 O-06(초대)에만. 모르는 값은 ‘잘 모르겠어요’
- 초대받아 들어온 사람은 이 흐름 대신 파트너 합류(P 화면)
- 연결 해제가 확정된 두 사람은 다음에 앱을 열 때 S-12h → O-11부터 다시(O-10, O-03 이름, O-06 초대 건너뜀). O-12 결혼한 날은 다시 묻고, O-13 출생연도는 사람마다 남아 있어 건너뜀(→ 핵심 규칙 › 커플·권한 7장)
- 예시: 찬우(시작한 사람), 실수령 350만 원, 월급날 25일

## 규칙

- 처음에는 꼭 필요한 것만 물음: 이름, 초대, 결혼 상태, 결혼한 날·예정일, 출생연도, 월급. 결혼한 날·예정일과 출생연도는 비슷한 커플과 비교(F-08)의 그룹(연령대 × 결혼 단계)에 씀(→ 핵심 규칙 › 계산·배분 7장, 2026-10-26 결정). 그 밖의 정보는 쓰는 자리에서 물음

| 정보 | 묻는 곳 |
| --- | --- |
| 생일, 명절 | 캘린더 챙길 날 추가. 결혼기념일은 O-12(했어요)에서 자동으로 만듦 |
| 통장, 투자, 부동산, 대출 | 우리 자산 탭 처음 열 때 “자산 추가하기” |
| 저금 항목, 목표 금액·기한, 이미 모은 돈 | 체크리스트·홈 H-03 첫 저금 빈 줄, 월급 탭 + 버튼(W-11) |
| 파트너 이름, 월급, 월급날 | 파트너가 합류할 때 직접 |

- 나이 확인은 가입 약관 동의(A-05)의 “만 18세 이상이에요” 필수 체크로 함. O-13 출생연도는 비교 통계용이고 나이 확인용이 아님
- 답은 화면마다 저장. 앱을 닫았다 열면 “이어서 할까요?” / “멈춘 화면부터 이어서 할 수 있어요” [확인 필요] + “이어서 하기” [확인 필요] 후 멈춘 화면부터. 첫 화면(O-10)에 멈췄으면 묻지 않음, 한 번 실행에 한 번만. 합류 중(P-)은 묻지 않고 그 화면부터(→ 파트너 합류)

## O-21·O-23·O-24 (없앰)

2026-11-08 목표 고르기(O-21)와 목표 금액·기한(O-23·O-24)을 온보딩과 앱에서 없앴어요(ADR 0007). 저금 항목은 첫 저금 빈 줄(체크리스트·홈 H-03, 2026-11-09)과 월급 탭에서 이름·매달 금액·(선택) 목표 금액·이미 모은 돈·기한만 물어요(→ 월급 탭 W-11). 예전 목표별 질문 표는 git 기록에 있어요.

## 예외

온보딩 전체(①·②)에 해당. 화면별 예외는 각 화면 아래.

| 상황 | 처리 |
| --- | --- |
| 중간에 앱을 닫음 | 마지막 화면까지 저장. 다시 열면 “이어서 할까요?” 후 그 화면부터 |
| 뒤로 가서 답 변경 | 뒤 화면 중 영향받는 답만 다시 물음 |
| 말이 안 되는 값 | “입력한 값이 맞나요?” 1회 확인, 막지 않음 |
| 파트너 미합류 | 내 월급만으로 월급 계획을 만듦. 파트너가 합류하면 파트너가 자기 월급과 월급 계획을 넣음(→ 파트너 합류) |
| 오프라인 | 저장하지 않음. 서버로 가는 동작(다음, 저장)을 누르면 Toast “인터넷에 연결되면 할 수 있어요”, 입력한 값은 화면에 그대로(2026-11-09 동기화 4장과 같게, → 공통 상태 9번) |
| 온보딩 뒤 답 수정 | 따로 ‘내 답 다시 보기’ 없이 그 정보가 있는 화면에서 바로 고침: 이름 → 설정, 저금 항목 → 월급 탭, 월급·관리 방식 → 설정, 월급 계획 → W-01 |
