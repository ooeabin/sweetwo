# 온보딩 ① 흐름

## 흐름 요약

2026-11-13 v2.2(ADR 0009 결정 3·6·12): 순서 (A-05) → O-03 → O-11 → O-30 → O-30b → (O-30c) → O-31 → O-32 → O-55 → O-60 → (첫 저금 W-11a~e) → (미합류면 O-07 초대 시트) → A-06(앱 잠금 권장, 건너뛸 수 있음) → 홈. O-06 초대 화면은 없앰(번호 다시 쓰지 않음). PIN(A-06)은 가입 직후가 아니라 O-60 흐름 뒤. 첫 확인 목록은 다음 월급날(소급 없음). 목표 시간 3분 이하(A-01부터 O-60 중앙값). 아래 2026-11-10 설명 중 O-06·A-06 순서는 기록.

가입 직후 질문 6~7화면 + 준비 끝 한 장(약 1분 [확인 필요])이면 월급 계획이 생기고 바로 홈으로 감. 2026-11-10 QA 2구간에서 짧게 줄임: 첫 화면 O-10, 결혼한 날·예정일 O-12, 출생연도 O-13, 이어하기 질문 화면을 뺌(쓰는 자리에서 물음). 결정 이유 → `docs/adr/0003-replan-goal-checklist.md`, 목표 고르기를 뺀 것 → `docs/adr/0007-goal-into-saving-line.md`. 질문 화면 틀·패턴(Q1~Q7)은 공통 참조, O-01·O-02는 로그인·가입.

- 순서(2026-11-10 기록, 2026-11-13 위로 바꿈): (A-05·A-06) → O-03 → O-06 → (O-07) → O-11 → O-30 → O-31 → O-32 → O-60 → 홈
- 월급 계획(O-50)는 O-32 다음에 추천값으로 자동으로 만들고 홈 월급 계획 타일(H-07, 2026-11-09) → W-01에서 고침(2026-11-03 할 일 ‘월급 계획 확인’은 없앰). 결과 화면은 없고 O-60 ‘준비 끝’ 한 장 뒤 홈(ADR 0005)
- 목표 고르기(O-21)는 없앰(2026-11-08, ADR 0007). 온보딩이 끝나면 저금 항목 없이 시작하고, 첫 체크리스트 저금 묶음의 빈 줄 ‘+ 저금 추가’로 권함(2026-11-09, → 월급 탭 ‘첫 저금’. 2026-11-13부터 O-60 “첫 저금 만들기”). 기본 항목 ‘비상금’도 만들지 않음
- O-30 이후(월급, 월급 계획, 결과)는 온보딩 ②
- 진행 표시: 질문 화면 맨 위 얇은 막대 하나(브랜드 오렌지). O-60에는 없음. 챕터 구분 없음. 첫 화면 O-03은 뒤로 없음
- ‘나중에 할게요’는 O-55(알림), O-60(첫 저금), A-06(앱 잠금)에(2026-11-13, O-06 없앰). 모르는 값은 ‘잘 모르겠어요’
- 초대받아 들어온 사람은 이 흐름 대신 파트너 합류(P 화면)
- 연결 해제가 확정된 두 사람(2026-11-13): S-12h → 홈(각자 계열, 내 월급 계획이 남음) 또는 O-30부터(같이 계열이라 내 월급 계획이 없을 때, O-03·O-11 건너뜀). 결혼한 날·예정일과 출생연도는 온보딩에서 묻지 않음(→ 08 7장)
- 예시: 찬우(시작한 사람), 실수령 350만 원, 월급날 25일

## 규칙

- 처음에는 꼭 필요한 것만 물음(2026-11-13): 이름, 두 사람 사이, 관리 형태 세 질문, 월급, 월급날, 알림 허용. 결혼한 날·예정일과 출생연도는 온보딩에서 묻지 않고 쓰는 자리에서 물음(2026-11-10): 출생연도는 자산 순위 F-08(또래 비교)을 처음 볼 때 ‘출생연도 알려 주기’ → S-11i, 결혼한 날은 설정 S-11h나 캘린더 경조사 ‘결혼기념일’. 비슷한 커플과 비교(F-08 2단계)의 그룹(연령대 × 결혼 단계)은 이 값이 있는 커플만(→ 핵심 규칙 › 계산·배분 7장)

| 정보 | 묻는 곳 |
| --- | --- |
| 생일, 명절, 결혼기념일 | 캘린더 경조사 추가. 설정 S-11h에서 결혼한 날을 넣으면 결혼기념일을 자동으로 만듦(→ 캘린더) |

| 통장, 투자, 부동산, 대출 | 자산 관리 탭 처음 열 때 “자산 추가하기” |
| 저금 항목, 목표 금액·기한, 이미 모은 금액 | O-60 주 버튼 “첫 저금 만들기”(2026-11-13), 홈 H-10 빈 상태·띠 7번, 월급 탭 ‘+ 저금 추가’(W-11) |

- 나이 확인은 가입 약관 동의(A-05)의 “만 18세 이상이에요” 필수 체크로 함. 출생연도(S-11i)는 비교 통계용이고 나이 확인용이 아님
- 답은 화면마다 저장. 앱을 닫았다 열면 묻지 않고 가장 멀리 간 화면부터(2026-11-10, “이어서 할까요?” 질문 화면은 없앰). 뒤로 가서 앞 화면을 봐도 기록은 가장 멀리 간 화면 그대로. 단 월급 계획에 쓰는 답(관리 방식, 월급)을 바꾸면 그다음 화면부터(O-32에서 월급 계획을 다시 만들게). 합류 중(P-)도 그 화면부터(→ 파트너 합류)

## 없앤 화면(2026-11-10 QA 2구간)

- O-10 온보딩 첫 화면(“2분이면 우리 월급 계획이 생겨요” + 3단계 안내): 없앰. 가입 뒤 바로 O-03. 대신 넣는 안내 줄 없음
- O-12 결혼한 날·예정일: 온보딩에서 묻지 않음. 설정 S-11h, 캘린더 경조사 ‘결혼기념일’에서
- O-13 출생연도: 온보딩에서 묻지 않음. 자산 순위 F-08 ‘출생연도 알려 주기’ → S-11i에서(처음 적을 때는 휠을 움직여야 저장)
- 이어하기 질문(“이어서 할까요?”): 없앰. 바로 가장 멀리 간 화면으로
- 예전에 이 화면에 멈춰 있던 사람: O-10 → O-03, O-12·O-13 → O-30(앱이 옮김)

## O-06 같이 쓸 사람 초대 (없앰 2026-11-13, ADR 0009)

> 2026-11-13 없앰. 초대는 첫 저금 직후 O-07 시트(“같이 모을 사람을 초대할까요?” [확인 필요]), 홈 할 일 띠 15번 “같이 모을 사람을 초대해 보세요” [확인 필요], 메뉴 서랍, S-12. ‘받은 초대 코드가 있어요’는 O-01과 첫 실행 코드 자동 입력(“받은 초대 코드로 합류할까요?” 시트, → 15 O-01)으로. 아래는 기록.

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 질문 | “같이 쓸 사람을 초대할까요?” / 보조 “월급과 저금을 둘이 같이 볼 수 있어요” [확인 필요](2026-11-08) | — |
| 2 | 지금 초대할게요 | “지금 초대할게요” [확인 필요](2026-11-10 대답이라 해요체, 예전 ‘초대하기’) | → O-07 시트(코드 발급) → 닫으면 O-11 |
| 3 | 나중에 | “나중에 할게요” | → O-11. 홈 할 일 맨 위 ‘초대하기’ 한 줄 |

- 파트너가 이미 합류했으면(이어하기 중 합류 등) 이 화면과 O-07은 건너뜀(2026-11-10)
- 받은 코드로 합류(2026-11-11 QA 3구간 D4): 선택지 아래 회색 글자 버튼 “받은 초대 코드가 있어요 ›” [확인 필요] → P-01 코드 입력(뒤로 = O-06). 합류하면 내 온보딩 대신 합류 흐름(P-03 …)으로

- 초대 코드 발급·만료·다시 발급 규칙 → 파트너 합류
- 혼자 쓰기로 정하는 선택지는 두지 않음(초대를 안 하면 혼자 쓰는 것과 같음)

## O-21·O-23·O-24 (없앰)

2026-11-08 목표 고르기(O-21)와 목표 금액·기한(O-23·O-24)을 온보딩과 앱에서 없앴어요(ADR 0007). 저금 항목은 첫 저금 빈 줄(체크리스트, 2026-11-09)과 월급 탭에서 이름·매달 금액·(선택) 목표 금액·이미 모은 금액·기한만 물어요(→ 월급 탭 W-11). 예전 목표별 질문 표는 git 기록에 있어요.
