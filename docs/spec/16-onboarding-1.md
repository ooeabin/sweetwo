# 온보딩 ① 흐름과 목표

## 흐름 요약

가입 직후 9화면, 약 2분이면 첫 목표와 월급 분배표가 생기고 바로 홈으로 감. 결정 이유 → `docs/adr/0003-replan-goal-checklist.md`. 질문 화면 틀·패턴(Q1~Q7)은 공통 참조, O-01·O-02는 로그인·가입.

- 순서: (A-05·A-06) → O-10 → O-03 → O-06 → (O-07) → O-11 → O-21 → O-23 → O-24 → O-30 → O-31 → O-50 → O-60 → 홈
- O-30 이후(월급, 분배표, 결과)는 온보딩 ②
- 진행 표시: 질문 화면 맨 위 얇은 막대 하나(브랜드 오렌지). O-10, O-60에는 없음. 챕터 구분 없음
- ‘나중에 할게요’는 O-06(초대)에만. 모르는 값은 ‘잘 모르겠어요’
- 초대받아 들어온 사람은 이 흐름 대신 배우자 합류(P 화면)
- 예시: 찬우(시작한 사람), 1순위 목표 내 집 마련, 실수령 350만 원, 월급날 25일

## 규칙

- 처음에는 꼭 필요한 것만 물음: 이름, 초대, 결혼 상태, 목표, 월급. 그 밖의 정보는 쓰는 자리에서 물음

| 정보 | 묻는 곳 |
| --- | --- |
| 결혼기념일, 생일, 명절 | 캘린더 챙길 날 추가 |
| 통장, 투자, 부동산, 대출 | 우리 자산 탭 처음 열 때 “가진 돈 추가하기” |
| 2순위부터 목표 금액·기한 | 목표 카드의 “금액 정하기” |
| 배우자 이름, 월급, 월급날 | 배우자가 합류할 때 직접 |
| 이미 모은 돈 | 목표 상세 “이미 모은 돈 넣기” |

- 나이 확인은 가입 약관 동의(A-05)의 “만 18세 이상이에요” 필수 체크로 함 [확인 필요]
- 답은 화면마다 저장. 앱을 닫았다 열면 “이어서 할까요?” 후 멈춘 화면부터

## O-21 목표 고르기

Q2 변형: 그림 카드, 분류 탭, 순서 배지.

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 질문 | “둘이 가장 먼저 이루고 싶은 건 뭐예요?” / 보조 “고른 순서가 우선순위가 돼요” [확인 필요] | — |
| 2 | 자동 목표 줄 | “비상금은 자동으로 들어가요” | 고정 줄, 해제 불가 |
| 3 | 분류 탭 | “자주 고르는” / 갚기 / 주거 / 가족 / 즐거움 / 생활 / 미래 | 기본 ‘자주 고르는’, 탭을 바꿔도 선택 유지 |
| 4 | 목표 카드 | 그림 + 이름, 3열 | 누르면 선택·해제, 개수 제한 없음. ‘자주 고르는’ = 내 집 마련·여행·출산 준비·자동차 구입·교체·고금리 대출 갚기·노후·연금(O-11 준비 중이면 결혼 비용이 맨 앞) |
| 5 | 순서 배지 | 1, 2, 3 | 고른 순서 = 우선순위, 해제하면 당겨짐. 순서는 나중에 목표 탭에서 바꿈 |
| 6 | 추천 배지 | “추천” | O-11 준비 중 → 결혼 비용. 미리 선택 안 함 |
| 7 | 직접 만들기 | “+ 직접 만들기” | 모든 탭 맨 아래. O-23에서 이름부터 |
| 8 | 선택 수·주 버튼 | “3개 골랐어요” + “다음” | 0개면 “비상금만 먼저 모을게요” → O-30 |

| 분류 탭 | 목표 카드 |
| --- | --- |
| 갚기 | 고금리 대출 갚기, 전세·주택대출 중도상환 |
| 주거 | 내 집 마련, 전세 만기·이사 대비, 가전·가구·인테리어 |
| 가족 | 결혼 비용, 출산 준비, 아이 교육·양육, 양가 큰 행사, 반려동물 |
| 즐거움 | 여행, 결혼기념일, 명품·큰 물건 구입, 취미·자기계발 |
| 생활 | 자동차 구입·교체, 자동차 유지비, 연간 고정 지출 |
| 미래 | 노후·연금, 투자 종잣돈 |

- 좁은 창: 카드 2열, 분류 탭 가로 스크롤, 주 버튼 하단 고정
- 같은 목표 2개는 목표 탭(G-03)에서 추가
- 여기서 고른 목표는 모두 ‘우리 목표’로 저장. ‘누구 목표예요?’(G-03e)는 온보딩에서 묻지 않음(화면을 늘리지 않음). 내 목표로 바꾸려면 나중에 목표 상세 ⋯ “내 목표로 바꾸기”(→ 목표 ‘목표 종류’)

## O-23·O-24 1순위 목표 금액과 기한

온보딩은 1순위 목표만. 2순위부터는 금액 없이 만들어지고 목표 카드에 “금액 정하기”가 붙음.

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 목표 칩 | 작은 이름표 ‘1순위’ + “내 집 마련” | — |
| 2 | 질문 | 목표별 표 문구 | — |
| 3 | 금액 칸 | “500,000,000원” + 읽기 “5억 원” | Q3 |
| 4 | 빠른 금액 칩 | “+1,000만” / “+5,000만” / “+1억” | 내 집 마련·전세 보증금·자동차 구입·결혼 비용만, 그 외 +1만/+10만/+50만/+100만 |
| 5 | 잘 모르겠어요 (금액) | “잘 모르겠어요” | 구간 칩 → 중간값을 ‘추정’으로 저장(첫 구간은 상한의 1/2, 끝 구간은 하한). 목표 금액 “1천만 미만 / 1~3천 / 3천~1억 / 1~3억 / 3억 이상”, 여행 1인 “50만 미만 / 50~100 / 100~200 / 200~300 / 300만 이상” |
| 6 | 주 버튼 | “다음” | 0보다 크면 활성 |
| 7 | 기한 칸 | “2031년” + “5년 뒤” | O-24. 기본 기한 미리 채움, 올해 이전 불가 |
| 8 | 월 필요액 | “매달 250만 원씩 모으면 돼요” / “1억 5,000만 원 ÷ 60개월” | 기한을 바꾸면 다시 계산 |
| 9 | 잘 모르겠어요 (기한) | “잘 모르겠어요” | 기본 기한으로 저장. 기본 기한이 빈 칸이면 ‘3년 뒤’ + ‘추정’ |
