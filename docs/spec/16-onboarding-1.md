# 온보딩 ① 파트 0\~2

## 흐름 요약

> 화면 그림: 온보딩 흐름, 파트 0~6 + 배우자 합류 (그림은 기획서 페이지 사본에 있어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

온보딩 첫 화면(O-10), 호칭(O-03)부터 1순위 목표 기한(O-24)까지. O-01·O-02는 로그인·가입, 질문 화면 틀·패턴은 공통 참조. 파트 3\~6은 온보딩 ②.

- 기본: (A-05·A-06) → O-10 → O-03 → O-04 → O-05 → O-06 → (O-07) → O-11 → O-12 → O-13 → O-15 → O-16 → O-18 → O-20 → O-21 → 1순위 O-23 → O-24 → 챕터 3(O-30)
- 예비부부: O-18 뒤 O-19a → O-19b → O-19c → O-19d → O-19e → O-20. 각자 관리면 O-21 뒤 O-23·O-24 없이 파트 3
- 챕터: 필수 화면을 챕터 4개로 묶어 보여 줌. 내부 파트 번호(0\~6)는 그대로
  - 1 우리 소개: O-03\~O-19e(파트 0·1). 시작 안내는 O-10 첫 화면이 겸함
  - 2 목표: O-20 시작 안내 → O-21\~O-24(파트 2)
  - 3 수입과 지출: O-30 시작 안내 → O-31\~O-39(파트 3, 온보딩 ②)
  - 4 나누기와 플랜: O-50 시작 안내 → O-51·O-52 → O-61\~O-67(파트 5·6, 온보딩 ②)
- 진행 표시: 챕터 진행(헤더 가운데 “목표” + 챕터 안에서만 차는 얇은 막대, 브랜드 오렌지). 챕터 시작 안내는 0%, 질문마다 늘고 다음 챕터에서 0부터. 결과(O-61\~67)는 막대 없이 “나누기와 플랜” 글자만(결과 7장 동안 꽉 찬 막대가 멈춰 보이지 않게). O-10은 진행 표시 없음
- 챕터 끝 요약 화면은 따로 두지 않음(다음 챕터 시작 안내의 챕터 목록이 넘어감을 알려 줌, O-20은 지금까지 답도 보여 줌)
- O-14·O-17은 배우자가 합류 때 입력
- ‘나중에 할게요’ 없음(모두 필수). 모르는 값은 ‘잘 모르겠어요’·‘아직 몰라요’

## 규칙

- 첫 결과까지 필수 화면만 물음: 파트 4 제외 6파트(챕터 4개), 약 8분, 30화면 안팎. 나머지는 첫 주 할 일로 하루 하나씩(→ 온보딩 ② O-67)
- 미룬 목표는 추천값으로 먼저 계산, ‘추정’ 표시
- 배우자 몫(O-14·O-17, 정확한 수입, 배우자 용돈 P-07)은 배우자가 합류 때 직접 입력. 먼저 시작한 사람은 배우자 수입을 구간으로 고르거나 정확히 알면 금액으로 답함(O-33). 배우자 합류 전에만 대신 입력 가능, 합류하면 배우자에게 넘어감(→ 화면 설계 › 설정 S-11 ‘배우자 정보’ “제가 대신 입력할게요”)
- 합류 전 임시 플랜의 가정값(분담·배우자 용돈) → 핵심 규칙 › 계산·배분
- 사실값은 바로 반영, 배분 결정은 제안 → 핵심 규칙 › 부부·제안·권한
- 예비부부 결혼 비용 계산·결혼일 전환 → 핵심 규칙 › 계산·배분

## O-10 온보딩 첫 화면

가입 직후 첫 화면(Q7). 챕터 4개와 걸리는 시간을 먼저 보여 주고, 챕터 1(우리 소개) 시작 안내를 겸함. 레퍼런스: MacroFactor 시작 화면(단계 목록 + 첫 단계로 가는 버튼).

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 진행 표시 | 없음, 뒤로 없음 | — |
| 2 | 제목·보조 | “몇 가지만 여쭤보고 우리의 첫 플랜을 만들어 드릴게요” / “약 8분이면 충분해요” [확인 필요] | 보조 시간은 규칙의 ‘약 8분’ |
| 3 | 챕터 목록 | 회색 판 위 번호 1\~4 + 이름 + 한 줄: “우리 소개” “호칭, 결혼, 집과 일, 아이 계획을 알려 주세요” / “목표” “함께 모을 목표를 고르고 얼마를 모을지 정해요” / “수입과 지출” “월급과 매달 나가는 돈을 알려 주세요” / “나누기와 플랜” “용돈과 분담을 정하면 첫 플랜이 나와요” [확인 필요] | 누를 수 없음(보기만). 화면 읽기 이름 “이렇게 4단계로 물어볼게요” |
| 4 | 안내 1줄 | “입력하신 내용은 나중에 언제든 자유롭게 수정할 수 있으니, 편하게 작성해 주세요!” | 챕터 목록 아래 회색 작은 글씨. 수정은 결과 화면 뒤 설정 S-17 ‘내 답 다시 보기’ |
