# FAQ

사용자용 자주 묻는 질문 24개(2026-10-25 재기획에 맞춰 고침, → `docs/adr/0003-replan-goal-checklist.md`). 노출 위치: 웹사이트 L-01(5개)과 L-06(전체, 묶음별), 앱 설정 › 도움말(S-20, 검색 가능)은 L-06을 앱 안 보기로 엶. 원본은 저장소 마크다운 하나(apps/site/src/content). 답은 1\~3줄 해요체, 금융 자문·상품 추천 표현 없음.

| # | 질문 | 답 |
| --- | --- | --- |
| 1 | 계좌를 연결하지 않나요? | 네, 계좌·카드 연동 없이 직접 입력해요. 계좌번호나 금융 비밀번호를 받지 않아 안전하고, 월급날 정한 대로 보냈는지 체크만 하면 돼요. [확인 필요] |
| 2 | 매일 기록해야 하나요? | 아니요. 월급날 분배표대로 보내고 줄마다 체크하면 돼요. 한 달에 1\~2분이면 충분해요. 빠진 게 있으면 다음 월급날 3일 전에 한 번 알려 드려요. [확인 필요] |
| 3 | 어떤 계정으로 가입하나요? | 카카오·구글·애플 계정으로 가입해요. 이메일·비밀번호 가입은 없어요. |
| 4 | 배우자는 어떻게 초대하나요? | 처음 시작할 때 바로 보내거나, 나중에 홈이나 설정 › 부부 정보에서 초대 코드를 보내 주세요. 배우자는 휴대폰 앱이나 컴퓨터 앱을 설치한 뒤 코드를 넣고 1\~2분이면 합류해요. 코드는 7일 동안 쓸 수 있어요. [확인 필요] |
| 5 | 한 사람만 써도 되나요? | 네. 내 월급으로 분배표를 먼저 만들어 목표를 모을 수 있어요. 배우자가 합류하면 자기 월급을 직접 넣어요. [확인 필요] |
| 6 | 결혼 전에도 쓸 수 있나요? | 네. 결혼을 준비 중이라고 알려 주시면 ‘결혼 비용’ 목표를 먼저 추천해 드려요. 결혼 비용도 다른 목표처럼 매달 모으고 체크해요. [확인 필요] |
| 7 | 배우자가 내 정보를 다 볼 수 있나요? | 항목마다 ‘모두 보여 주기·금액만 보여 주기·숨기기’를 고를 수 있어요. 내 명의 항목은 기본이 금액만 보여 주기이에요. |
| 8 | 배우자와 생각이 다르면요? | 두 사람 모두 목표와 분배표를 바로 고칠 수 있어요. 고치면 상대에게 알림이 가고, 고친 사람은 바로 되돌릴 수 있어요. 누가 언제 바꿨는지는 변경 기록에 남아요. [확인 필요] |
| 9 | 투자 평가 손익은 어떻게 계산하나요? | 직접 넣은 평가액에서 넣은 원금을 뺀 값이에요. 팔기 전까지는 ‘안 판 수익’으로 따로 보여 주고, 순자산은 원금 기준으로 계산해요. 투자 권유가 아닌 단순 계산이에요. |
| 10 | 데이터는 어디에 보관되나요? | 국내(서울) 서버에 암호화해 보관해요. 운영자는 금액을 볼 수 없어요. 문의 해결에 필요할 때만, 문의한 분이 동의한 범위만 봐요. 배우자에게도 확인한 사실을 알려요. |
| 11 | 데이터를 내보낼 수 있나요? | 설정 › 데이터에서 엑셀(CSV)과 PDF 요약으로 내보낼 수 있어요. 배우자 개인 항목은 공개 범위대로만 담겨요. |
| 12 | 금액을 가릴 수 있나요? | 상단 눈 아이콘을 누르면 모든 금액이 “•••”로 바뀌어요. |
| 13 | 다크 모드가 있나요? | 기기 설정을 따라 라이트·다크가 바뀌어요. 앱 안에서 고르는 기능은 출시 뒤에 더해요. |
| 14 | 여러 기기에서 쓸 수 있나요? | 네. 같은 계정으로 로그인하면 휴대폰 앱과 컴퓨터 앱 어디서든 같은 내용이 보여요. 로그인된 기기는 설정 › 보안에서 확인해요. |
| 15 | 인터넷이 없어도 되나요? | 휴대폰 앱과 컴퓨터 앱 모두 마지막 내용을 볼 수 있고, 입력과 체크는 저장해 두었다가 연결되면 보내요. 초대와 연결 해제는 연결된 뒤에 할 수 있어요. [확인 필요] |
| 16 | 앱 잠금이 있나요? | 휴대폰 앱과 컴퓨터 앱 모두 PIN 6자리로 잠글 수 있고, Face ID나 지문, Mac의 Touch ID로도 풀 수 있어요. Windows Hello는 출시 뒤에 더해요. 기본은 5분 동안 쓰지 않으면 잠겨요. |
| 17 | 계정을 삭제하면 데이터는 어떻게 되나요? | 설정 › 데이터에서 계정을 삭제해요. 30일 안에 다시 로그인하면 되돌릴 수 있고, 그 뒤 완전히 지워져요. 배우자와 연결돼 있으면 공동 항목은 배우자에게 남아요. 삭제를 취소하면 혼자 쓰기로 돌아오고, 30일 안에 다시 연결할 수 있어요. |
| 18 | 이용 요금은 얼마인가요? | 핵심 기능은 무료예요. |
| 19 | 문의는 어디로 하나요? | 설정 › 도움말 › 문의하기에 남겨 주세요. 답변은 ‘내 문의’에서 확인해요. |
| 20 | 지운 항목을 되살릴 수 있나요? | 설정 › 데이터 › 휴지통에서 30일 안에 되살릴 수 있어요. 그 뒤엔 완전히 지워져요. |
| 21 | 광고가 나오나요? | 앱 안에 광고는 없어요. |
| 22 | 앱이 돈을 옮겨 주나요? | 아니요. 은행 앱에서 직접 보내고, sweeTwo에서는 보냈다고 체크만 해요. 저금 줄을 체크하면 그만큼 목표에 모은 돈이 쌓여요. [확인 필요] |
| 23 | 월급을 각자 관리해도 되나요? | 네. 각자 따로 관리하거나 합쳐서 같이 관리할 수 있어요. 각자 관리하면 분배표와 체크리스트가 사람마다 있고, 목표는 같이 모으거나(우리 목표) 혼자 모을 수 있어요(내 목표). 설정에서 언제든 바꿀 수 있어요. [확인 필요] |
| 24 | 순자산은 어떻게 계산하나요? | 우리 자산에 직접 적은 통장, 투자, 부동산에서 대출 잔액을 뺀 값이에요. 목표에 모은 돈은 실제로 통장에 있어서 순자산에 따로 더하지 않아요. [확인 필요] |
| 25 | 배우자와 연결을 끊으면 데이터는 어떻게 되나요? | 설정 › 부부 정보에서 연결 해제를 요청하면 배우자가 확인하거나 14일이 지난 뒤 해제돼요. 해제되면 두 분이 같이 쓰던 목표, 분배표, 체크리스트, 자산, 챙길 날, 기록이 모두 지워지고 각자 혼자 쓰기로 처음부터 시작해요. 필요하면 해제 전에 설정 › 데이터에서 내보내 두세요. 30일 안에 두 분이 다시 연결하면 되돌릴 수 있어요. [확인 필요] |
