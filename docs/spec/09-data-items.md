# 데이터 항목

개발 기준 데이터 정의. 저장하는 항목과 필드, 공통 저장 규칙, 화면 선택지의 분류 기준을 정함. 계산 규칙은 계산·배분과 월 사이클, 부부 상태와 권한은 부부·권한을 따름. 결정 이유 → `docs/adr/0003-replan-goal-checklist.md`.

- 이 문서의 이름과 필드는 기획 수준. 테이블·열 이름, 타입, 나누는 방식은 구현에서 정함(→ 기술·운영). DB 타입은 `supabase gen types` 결과만 씀
- 없앤 기능의 테이블은 스키마 규칙(추가만, 지우기는 2단계)대로 정리

## 1. 엔티티

| 사용자 | 로그인한 사람 | 로그인 수단(카카오/구글/애플)·소셜 계정 식별자, 알림 이메일(소셜 계정에서 받음 / 직접 입력, 다른 계정과 중복 허용·식별에 안 씀), 이름(최대 10자, O-03), 프로필 사진(정사각 512px 1장, 없으면 빈 값, → 설정 S-11e), 결혼 상태(했어요/준비 중이에요, O-11), 출생연도(O-13, 배우자는 P-03a. 1950~올해 − 18, 비슷한 부부와 비교의 연령대에만 씀 → 계산·배분 7장), 월 실수령(O-31, 0원 가능 = 월급 없음), 매달 달라요(켜면 가장 적게 들어온 달 금액), 월급날(1~31, 말일. 월급 없음이면 빈 값), 만 18세 이상 확인(A-05), 알림 설정, 분석 수집 꺼짐(설정 ‘사용 분석’, 계정 단위라 모든 기기에 적용), 통계 참여(선택 동의, 기본 꺼짐, 출시 후 → 계산·배분 7장), 온보딩 진행(멈춘 화면 ID·완료 시각), 계정 상태(사용 중/삭제 요청 30일 유예/삭제), 알림 메일 반송 여부, 내부 테스트 계정 표시(기본 꺼짐, 공개 출시 직전 삭제 대상) | 부부 공간 1개 |

## 2. 목표 필드

| 항목 | 형식 | 설명 |
| --- | --- | --- |
| 이름 | 텍스트 | 템플릿 이름 기본, 최대 20자, 수정 가능 |
| 템플릿 | 템플릿 코드 | 비상금 + 템플릿 19개 + 직접 만들기(→ 계산·배분 5-5). 분류는 템플릿에서 정해짐 |
| 형태 | 선택 | 한 번 / 매년 / 매달 |
| 목표 금액 | 금액, 빈 값 가능 | 매달형은 월 납입액, 매년형은 1년 금액. 2순위부터 온보딩에서는 빈 값(‘금액 정하기’) |
| 기한 | 년·월, 빈 값 가능 | 매년형은 다음 쓰는 달, 매달형은 없음 |
| 이미 모은 돈 | 금액 | 처음 적은 값. 목표 기록 ‘처음 이미 모은 돈’ 1건으로 저장 [확인 필요] |
| 모은 돈 | 계산값 | 저장하지 않음. 목표 기록으로 계산(→ 계산·배분 4장). 0 미만 불가 |
| 주인 | 우리(공동) 또는 사람 | 우리 = 우리 목표, 사람 = 그 사람의 내 목표. G-03e에서 정함, 온보딩 O-21 목표와 비상금은 우리. 혼자 쓰기에서 만든 목표는 사람. G-02 ⋯에서 바꿈(→ 목표 ‘목표 종류’) |
| 우선순위 | 정수 | 낮을수록 먼저. 주인 묶음(우리 / 사람)마다 따로. O-21 고른 순서, 목표 탭에서 바꿈. 비상금은 분배표 저금 맨 먼저 |
| 추정 여부 | 금액·기한 각각 | ‘잘 모르겠어요’로 넣은 값 |
| 공개 범위 | 선택 | 내 목표만. 전체 공개(기본) / 합계만 두 가지, 비공개 없음(→ 부부·권한 6장). 우리 목표는 늘 전체 공개 |
| 사진 | 이미지, 빈 값 가능 | 직접 만든 목표만, 정사각 512px 1장. 없으면 회색 기본 그림(→ 목표 G-02) |
| 상태 | 계산값 | 진행 중 / 지연 / 달성(→ 계산·배분 5-4). 달성 시각은 저장(축하 화면 1회) |

- 비상금 목표는 부부 공간마다 1개, 처음부터 있음. 지울 수 없음. 주인은 늘 우리
- 연결 해제가 확정되면 우리 목표, 내 목표 모두 지워짐(공동 공간 데이터 전부 삭제)

## 3. 분배표와 체크리스트 필드

**분배표 줄**

| 항목 | 설명 |
| --- | --- |
| 종류 | 저금 / 쓰는 돈. 남는 돈은 저장하지 않고 계산 |
| 쓰는 돈 구분 | 고정지출 / 생활비 / 용돈 / 직접 추가. 고정지출·생활비·용돈은 지우지 못함(0원) |
| 목표 id | 저금 줄만. 목표 1개 |
| 사람 | 용돈 줄만(합쳐서면 사람마다 1줄) |
| 이름 | 직접 추가한 줄만(예: “부모님 용돈”). 나머지는 종류·목표에서 정해짐 |
| 금액 | 원 단위 정수, 1만 원 단위 입력, 0원 가능 |
| 순서 | 묶음 안 순서. 저금 묶음은 목표 우선순위를 따름 |

**월급 체크리스트**

| 항목 | 설명 |
| --- | --- |
| 주인 | 사람(각자) / 부부 공간(합쳐서). 분배표와 같음 |
| 이름 | ‘{기준일의 월}월 월급’ |
| 기간 | 기준일 0시 ~ 다음 기준일 전날 자정(→ 핵심 규칙 › 월 사이클) |
| 상태 | 진행 중 / 다 했어요 / 끝남(→ 핵심 규칙 › 월 사이클 5장) |
| 첫 사이클 여부 | 온보딩 결과 직후 만든 것 |

**체크리스트 줄**

| 항목 | 설명 |
| --- | --- |
| 분배표 줄 id | 복사해 온 줄 |
| 종류·목표 id·사람·이름 | 만든 시점 분배표 줄을 복사 |
| 금액 | 만든 시점 분배표 금액. 분배표가 바뀌면 체크 안 한 줄만 새 금액 |
| 실제 금액 | ‘다른 금액으로 보냈어요’(W-02a)에서 넣은 값. 없으면 금액과 같음 |
| 상태 | 열림 / 체크 / 못 함. 못 함 = ‘이번 달은 못 했어요’ 또는 기준일이 지나 닫힘 |
| 체크한 사람 | 대신 체크면 대신 한 사람 |
| 체크한 시각 | KST |

- 저금 줄을 체크하면 목표 기록(넣기, 실제 금액, 출처 = 이 줄) 1건, 체크를 풀면 그 기록을 지움
- 지난 사이클 체크리스트는 읽기 전용

## 4. 공통 규칙

- 모든 엔티티: id, 부부 공간 id, 만든 사람·시각, 고친 사람·시각, 삭제 시각·삭제한 사람(휴지통). 휴지통 30일 보관 뒤 자동 영구 삭제(→ 화면 설계 › 설정 ‘휴지통’)
- 금액: 원 단위 정수 저장, 화면에서만 만 원 단위 표시. 입력 최대 999억 원(99,999,999,999원). 합계가 넘으면 “999억+”, 음수는 “−”(→ 화면 설계 › 공통 6장)
- 날짜·시각: 한국 시간(KST) 기준, 기기 시간대는 무시(알림 시각·방해 금지 시간 포함). 음력은 원본(월·일·윤달) + 해당 연도 양력 날짜 함께 저장
- 음력 변환: korean-lunar-calendar(npm, MIT, 한국천문연구원 기준표)로 core 패키지에서 클라이언트와 서버가 같은 계산(설·추석 포함). 천문연구원 자료와 대조 테스트. 양력 2050년 12월 31일까지 지원, 그 뒤 연도는 입력 불가. 윤달이 끼는 해에는 평달·윤달 중 사용자 선택. 윤달 날짜가 그해 없으면 평달 같은 날, 음력 30일이 그 달에 없으면(작은달) 그 달 말일
- 공휴일: 공공데이터포털 ‘한국천문연구원 특일 정보’ API. 서버가 매년 12월에 다음 해를 받고 매주 1회 다시 받아 임시공휴일 반영, 공휴일 테이블에 저장. 앱은 테이블만 읽음. 어드민 AD-19에서 직접 추가·수정(→ 기술·운영 1장). 쓰임: 캘린더 공휴일 표시, 월급날이 주말·공휴일이면 직전 영업일로 앞당겨 표시(→ 핵심 규칙 › 월 사이클 1장)
- ‘잘 모르겠어요’로 넣은 값은 ‘추정’ 표시 저장
- 자산·부채 금액 변경 시 이력(값, 시각, 고친 사람) 저장, 순자산 그래프와 ‘지난달보다’에 사용
- 자산·부채 모든 항목에 명의(나/배우자/공동)·공개 범위·마지막 갱신일 저장. 만기일 있는 항목은 D-60 미리 알림
- 목표 모은 돈과 자산은 따로 셈. 목표 모은 돈은 순자산에 더하지 않음(→ 계산·배분 6장) [확인 필요]
- 바로 고친 값은 활동 기록에 전·후 값을 남겨 ‘되돌리기’에 씀(→ 핵심 규칙 › 부부·권한)

**삭제 연결 처리**

| 지우는 항목 | 처리 | 연결된 것 |
| --- | --- | --- |
| 비상금 목표 | 차단: “이 항목은 지울 수 없어요” | — |
| 고정지출·생활비·용돈 줄 | 지우기 없음, 0원으로 | — |
| 목표 | 휴지통 | 분배표 저금 줄 빠짐. 이번 사이클 체크한 줄과 목표 기록은 기록으로 남고 같이 휴지통 |
| 직접 추가한 쓰는 돈 줄 | 바로 지움 + ‘되돌리기’ | 이번 사이클 체크 안 한 줄은 빠지고, 체크한 줄은 기록으로 남음 [확인 필요] |
| 자산 | 휴지통 | 과거 순자산 기록 유지 |
| 부채 | 휴지통 | 과거 순자산 기록 유지 |
| 챙길 날 | 휴지통 | — |

- 연결 해제 확정: 부부 공간의 모든 항목(목표, 목표 기록, 분배표·줄, 체크리스트·줄, 자산·부채와 금액 이력, 챙길 날, 활동 기록, 알림, 닫은 할 일, 휴지통)을 한 번에 지움. 휴지통을 거치지 않고 복구용 보관본으로 옮겨 30일 뒤 영구 삭제. 사용자·로그인 기기·동의 기록은 남음(→ 부부·권한 7장, 보안·개인정보 4장)
- ‘같이 휴지통’은 부모 항목을 되살리면 함께 되살아남. 목표를 되살리면 분배표에 0원 저금 줄이 다시 생김 [확인 필요]
- 되살릴 때 연결 대상이 없으면(이미 영구 삭제) 연결 없이 되살리고 Toast “연결된 항목이 없어 따로 되살렸어요”

## 5. 기타 상태

| 대상 | 상태 | 바뀌는 조건 |
| --- | --- | --- |
| 체크리스트 줄 | 열림 → 체크 / 못 함 | 체크, 체크 풀기(체크 → 열림), ‘이번 달은 못 했어요’, 다음 기준일 0시 |
| 배우자 초대 | 발급 → 사용됨 / 만료 | 7일 뒤 만료, 다시 발급 가능 |

- 체크리스트 상태 → 핵심 규칙 › 월 사이클 5장 / 목표 상태 → 계산·배분 5-4 / 부부 상태 → 핵심 규칙 › 부부·권한

## 6. 선택지 기준

### 6-1. 금액 구간 칩

‘잘 모르겠어요’ 입력용 구간 칩 5개. 저장값 = 구간 중간값(첫 구간 = 상한의 1/2, 끝 구간 = 하한) + ‘추정’.

| 금액 종류 | 구간 (만 원) | 저장값 (만 원) |
| --- | --- | --- |
| 목표 금액 공통 | 1,000 미만 / 1,000~3,000 / 3,000~1억 / 1억~3억 / 3억 이상 | 500 / 2,000 / 6,500 / 2억 / 3억 |
| 여행 1인 경비 | 50 미만 / 50~100 / 100~200 / 200~300 / 300 이상 | 25 / 75 / 150 / 250 / 300 |

- 분석 이벤트의 월 수입 구간(입력 칩 아님): 200 미만 / 200~300 / 300~400 / 400~500 / 500 이상(만 원)

### 6-2. 자산

그룹 칩 먼저, 그룹을 고르면 세부 항목. 모든 그룹에 ‘기타(직접 입력)’. 정책 상품 이름은 바뀌므로 앱에 고정하지 않고 어드민에서 고치는 데이터로(→ 화면 설계 › 어드민 화면 AD-19).

| 그룹 | 항목 | 추가로 묻는 것 |
| --- | --- | --- |
| 현금성 | 입출금 통장, 파킹통장·CMA, 현금, 외화 예금 | 외화는 통화·금액(원화 환산은 직접 입력) |
| 예금·적금 | 정기예금, 적금, 정책형 적금 | 만기일, 월 납입액, 금리(선택) |
| 청약 | 주택청약종합저축 | 월 납입액(선택) |
| 투자 | 국내 주식, 해외 주식, ETF, 펀드, 채권, ISA 계좌, 금·실물, 가상자산 | 평가금액, 넣은 원금(선택) |
| 연금 | 연금저축(펀드·보험), IRP, 퇴직연금(DC형), 개인연금보험 | 적립금, 월 납입액(선택) |
| 저축성 보험 | 저축보험, 변액보험 | 해지환급금(모르면 납입 총액), 만기 |
| 부동산 | 전·월세 보증금, 보유 주택, 분양권(납부한 계약금·중도금) | 계약 만기일 / 시세(직접 입력), 넣은 원금(보유 주택·분양권, 선택) |
| 기타 | 자동차(시세), 빌려준 돈, 기타 | 돌려받을 날(빌려준 돈) |

- 특정 종목·상품 추천 없음

### 6-3. 부채

| 그룹 | 항목 | 추가로 묻는 것 |
| --- | --- | --- |
| 주택 | 전세자금대출, 주택담보대출, 중도금·잔금 대출 | 금리, 월 상환액, 만기일 (모두 선택) |
| 신용 | 신용대출, 마이너스통장, 카드론·현금서비스, 리볼빙 | 금리, 월 상환액. 마이너스통장은 사용액 |
| 할부 | 자동차 할부, 큰 금액 카드 할부 | 남은 회차, 월 납부액 |
