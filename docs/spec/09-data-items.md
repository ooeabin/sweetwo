# 데이터 항목

개발 기준 데이터 정의. 저장하는 항목·필드, 공통 저장 규칙, 화면 선택지의 분류 기준을 정함. 계산 규칙은 계산·배분·월 사이클, 상태 규칙은 부부·제안·권한을 따름. 테이블·타입 → 기술·운영.

## 3. 공통 규칙

- 모든 엔티티: id, 부부 공간 id, 만든 사람·시각, 고친 사람·시각, 삭제 시각·삭제한 사람(휴지통). 휴지통 30일 보관 뒤 자동 영구 삭제(→ 화면 설계 › 설정 ‘휴지통’)
- 금액: 원 단위 정수 저장, 화면에서만 만 원 단위 표시. 입력 최대 999억 원(99,999,999,999원). 합계가 이를 넘으면 “999억+”, 음수는 “−”(→ 화면 설계 › 공통 6장)
- 날짜·시각: 한국 시간(KST) 기준, 기기 시간대는 무시(알림 시각·방해 금지 시간 포함). 음력은 원본(월·일·윤달) + 해당 연도 양력 날짜 함께 저장
- 음력 변환: korean-lunar-calendar(npm, MIT, 한국천문연구원 기준표)로 core 패키지에서 클라이언트와 서버가 같은 계산(설·추석 포함). 천문연구원 자료와 대조 테스트. 양력 2050년 12월 31일까지 지원, 그 뒤 연도는 지원 범위 밖이라 입력 불가. 윤달이 끼는 해에는 평달·윤달 중 사용자 선택. 예외: 윤달 날짜가 그해 없으면 평달 같은 날, 음력 30일이 그해 그 달에 없으면(작은달) 그 달 말일
- 공휴일: 공공데이터포털 ‘한국천문연구원 특일 정보’ API. 서버가 매년 12월에 다음 해를 받고 매주 1회 다시 받아 임시공휴일 반영, 공휴일 테이블에 저장. 앱은 테이블만 읽음. 어드민 AD-19에서 직접 추가·수정(→ 기술·운영 1장). 쓰임: 캘린더 공휴일 표시, 월급날이 주말·공휴일이면 직전 영업일로 앞당겨 표시(설정에서 끔 → 월 사이클 1장)
- 환갑 = 태어난 해 + 60년. 칠순·팔순은 세는 나이 기준 + 69·79년, 만 나이 기준 + 70·80년
- ‘잘 모르겠어요’로 넣은 값은 ‘추정’ 표시 저장
- 금액 변경 시 이력(값, 시각, 월말 정리/직접 수정 구분) 저장, 그래프에 사용
- 자산·부채 모든 항목에 명의(나/배우자/공동)·공개 범위·마지막 갱신일 저장. 만기일 있는 항목은 D-60 미리 알림
- 돈의 원천은 자산 하나: 통장은 자산에 붙은 ‘역할’, 목표 보유액은 자산에서 계산. 같은 돈을 두 곳에 입력하는 화면 없음

## 6. 항목 분류표

온보딩·자산·부채·월 수입·지출 화면 선택지는 모두 이 표 기준. 그룹 칩 먼저 표시, 그룹 선택 시 세부 항목 노출. 모든 그룹에 ‘기타(직접 입력)’ 포함. 사용자는 기본 칩을 고르고, 이름을 바꾸고, 직접 추가할 수 있음. 정책 상품과 구독 서비스 이름은 바뀌므로 앱에 고정하지 않고 어드민에서 고치는 데이터로 관리(→ 화면 설계 › 어드민 화면 AD-19).

### 6-3. 변동 지출 항목

생활비 한 칸을 항목으로 나눔. 결제 하나하나 기록이 아니라 월말에 카드 명세서를 보며 항목별 합계만 넣음(월말 정리 W-04j). 항목 합계 = 생활비 실제.

- 기본 칩: 장보기(식재료), 외식·배달, 카페·간식, 생활용품, 대중교통·택시, 주유·충전, 쇼핑(옷·잡화), 미용, 병원·약, 경조사, 선물, 여행, 문화·취미, 운동, 자기계발, 육아용품, 반려동물, 기타
- 항목 켜기·끄기, 이름 바꾸기, 직접 추가는 부부 단위. 항목별 예산은 선택(우리 자산 F-05)
- 항목별 보기와 지난달 대비는 무료, 여러 달 흐름과 항목별 분석은 유료 ‘월말 정리 심화’

* 지인 경조사 많은 시기(결혼식 시즌 등) 대비 ‘경조사 적립’ 매년 목표 생성 가능

### 6-4. 연 1회 큰 지출(비정기 지출)

연 1회 큰 지출 기본 칩(월말 정리 W-04j “이번 달 큰 지출이 있었나요?”): 자동차보험(연납), 자동차세, 재산세, 보험 연납, 명절 비용, 기타. 고르면 아래 매년 목표에서 꺼내 쓰거나 이번 달 예외로 표시. 예외 금액은 생활비 예산 보정(3개월 평균)에서 뺌.

| 항목 | 기본 월 (수정 가능) | 처리 |
| --- | --- | --- |
| 자동차세 | 6월·12월 (연납이면 1월) | 매년 목표 ‘자동차 유지비’에 포함 |
| 자동차 보험(연납) | 갱신 월 | 매년 목표 ‘자동차 유지비’ |
| 재산세 | 7월·9월 | 매년 목표 ‘연간 고정 지출’ |
| 종합소득세 (프리랜서·사업) | 5월 | 매년 목표 ‘연간 고정 지출’ |
| 연말정산 추가 납부 | 2월 | 매년 목표 ‘연간 고정 지출’ |
