# 월말 정리

## 흐름 요약

이번 달 ‘10월 월급 플랜 정리할 때예요’ 카드(다음 기준일 3일 전\~전날) → W-04a 시작 → a2(기준 초과면 W-07) → j 지출 입력 → k 저축 확인 → (h 다음 달 조정, 조건) → g 정산 요약 → 끝(기본 3단계). 선택 “더 꼼꼼히 정리하기”를 고르면 b 잔액 → c 목표에서 쓴 돈 → d 비상금 → e 투자 → f 대출 → i 대화 카드. 함께 모드(두 계정 동시 진행)는 바뀐 값을 바로 확정, 혼자 정리는 끝에서 ‘월말 정리 제안’ 1건으로 배우자에게 보냄(W-04p). 화면 문구는 ‘{월}월 월급 플랜 정리’로 통일. 제안 적용·함께 정하기 → 핵심 규칙 › 부부·제안·권한, 놓친 달·쉬어가기 → 핵심 규칙 › 월 사이클, 저축액·미달 계산 → 핵심 규칙 › 계산·배분.

- 상단 바: 진행 막대(이번 정리에 나오는 단계 수, 시작·끝 제외) + 닫기(Esc, 입력값 저장). 조건 단계는 해당 없으면 건너뜀. ‘나중에 할게요’ 없음(W-04e·i는 건너뛰기)
- 넓은 창은 본문 가운데 한 열(W-04h만 넓게)
- 예시값: 찬우(정리 시작), 예빈(배우자), 10월 월급 플랜, 다음 기준일 11월 25일
- 무료: W-04a\~k 전체, 월 정산 요약, 변동 항목별 보기, 지난달 대비. 유료화 시점 프리미엄: ‘월말 정리 심화’(여러 달 흐름, 항목별 분석 같은 깊은 분석). 수익률 시뮬레이션 → 화면 설계 › 목표 › G-02

### 기본 3단계와 월 정산 요약

- 기본 흐름(무료): W-04a 시작 → W-04j 지출 입력 → W-04k 저축 확인 → (W-04h 다음 달 조정) → W-04g 정산 요약 → 끝. W-04h는 조건 단계: 받은 제안, 보류 제안, 함께 정하기 항목이 하나라도 있으면 자동으로 들어가고, 없으면 빠짐
- 선택 “더 꼼꼼히 정리하기”: W-04g 아래 버튼. W-04b 잔액 맞추기, W-04c 목표에서 쓴 돈, W-04d 비상금, W-04e 투자, W-04f 대출, W-04i 대화 카드. 이 단계들은 화면 목록에 ‘필수(꼼꼼 모드에서)’로 표시
- 제안(W-04 끝 제안 보내기, W-04p)과 함께 모드는 배우자가 합류했을 때만 기본으로 보임. 미합류와 혼자 쓰기는 바로 저장, 혼자 써도 가계부로 끝까지 씀
- 결제 하나하나 기록과 은행 자동 연동(마이데이터)은 넣지 않음. 월 1회 합계 + 정산 + 둘이 함께가 차별점(→ 제품 개요)
- 와이어프레임은 옛 9단계 흐름 기준, W-04j와 W-04k, 정산 요약은 아직 안 그림

**W-04j 지출 입력**

> 화면 그림: W-04j 지출 입력, SpendItems(hg-spend)와 BigExpense(hg-big) (그림은 기획서 페이지 사본에 있어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

- 컴포넌트: 디자인 시스템 SpendItems(hg-spend), 맨 아래 BigExpense(hg-big). 소득 확인은 SpendItems 위
- 소득 확인: 그달 실제 받은 금액, 기본값은 월급 플랜 수입 + “맞아요” / “수정”. 첫 사이클을 합칠 때도 실제 받은 금액만
- 고정 확인: 공동 고정지출 확인 묶음(목록과 금액), 항목별 ‘이번 달만 고치기’. 개인 부담 고정지출은 용돈 쪽에만 둠
- 변동 항목별 합계: “카드 명세서를 보며 항목별로 이번 달 합계만 넣어요”. 켜진 변동 항목마다 금액(Q3), 금액 칸 아래 보조 줄(“지난달 41만”, 미리 채운 항목은 “챙길 날에서 채웠어요”). 공동 생활비(통장 하나 모드면 그 통장)에서 낸 돈만 적고, 각자 용돈으로 쓴 건 적지 않음. 경조사·선물 항목에는 챙길 날 Y-08 기록을 미리 채움(따로 더하지 않음). 항목 합계 = 생활비 실제(→ 핵심 규칙 › 계산·배분 3장)
- 항목 관리: 켜기·끄기, 이름 바꾸기, “+ 항목 추가”. 기본 항목 → 핵심 규칙 › 데이터 항목 6-3
- 합계 줄: “이번 달 쓴 돈(용돈, 큰 지출 빼고)” = 고정 + 변동 항목 합계
- 큰 지출: “이번 달 큰 지출이 있었나요?” 칩(“자동차보험 연납”, “자동차세”, “재산세”, “보험 연납”, “직접 쓰기”, “없어요”) → 고른 칩마다 금액 + “모아 둔 돈에서 냈어요”(연결된 매년 목표 보유액에서 차감, 연결된 매년 목표가 없으면 이 선택지 숨김) / “이번 달만 예외예요”
- 큰 지출로 적은 돈은 변동 항목 합계와 생활비 실제, 생활비 예산 보정 제안(3개월 평균)에서 빼고, 정산 요약에 ‘큰 지출’ 한 줄로 보여 줌. 생활비 통장·카드로 낸 연간 목표 돈은 역할 모드에서 ‘목표자금 → 공동 생활비’ 나누기 줄이 생김(→ 핵심 규칙 › 계산·배분 6장)
- 잔액에서 거꾸로 계산하는 생활비 실제는 꼼꼼 모드에서 잔액을 넣었을 때만 보조로 씀
- 월급 나누기가 없는 사람(혼자 쓰기, 배우자 합류 전, “통장 하나로 써요”)은 월말 정리 기간 전에도 이번 달 오늘 띠 ‘지출 적기’로 W-04j를 앞당겨 열어 적어 둠. 적은 값은 칸을 벗어날 때 같은 month\_close에 draft로 자동 저장돼 월말 정리 W-04j에 그대로 채워짐. 둘이 동시에 적으면 항목 단위로 나중 저장이 이기고 Toast로 알림(→ 기술·운영 › 동기화)

**W-04k 저축 확인**

> 화면 그림: W-04k 저축 확인, 상품별 이번 달 넣은 돈 (그림은 기획서 페이지 사본에 있어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

- “이번 달 넣은 돈”을 상품별로: 청약, 적금, 정책 적금 등은 월 납입액을 채워 두고 “맞아요” / “수정”. 비상금과 목표자금에 넣은 돈도 여기서. 목록은 목표와 저축 상품 기준, 내 자산끼리 옮긴 돈(목표자금 통장 → 적금 등)은 적지 않음. 연결 자산이 없으면 목표나 ‘기타 저축’으로 기록
- 상품 이름 기본 칩 → 핵심 규칙 › 데이터 항목 6-5
- 잔액은 분기 1회 “잔액도 맞춰 볼까요?” 권유, 건너뛰기 가능. 넣은 돈은 연결 자산 금액에 ‘추정’으로 더해 두고, 잔액을 맞추면 그 값으로 바꿈(→ 핵심 규칙 › 계산·배분 5-4)

**W-04g 정산 요약**(맨 위, 무료, 디자인 시스템 MonthSummary(hg-sum), 우리 자산 F-01 17번에도 같은 컴포넌트)

> 화면 그림: W-04g 정산 요약, MonthSummary(hg-sum)와 보정 제안 카드 (그림은 기획서 페이지 사본에 있어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

- 구성 순서(MonthSummary): 머리 “10월 정산” + “소득의 59.3%를 썼어요” → 막대(쓴 돈 ink, 저축 chart-goal, 남은 돈 hairline) → 숫자 4칸(소득, 쓴 돈, 저축, 남은 돈) → 쓴 돈 나눠 보기(고정, 변동, 용돈, 큰 지출, 저축 한 줄) → 지난달보다 칩 최대 4개 → 보정 제안 카드
- 소득 / 쓴 돈(고정, 변동, 용돈, 큰 지출) / 저축(이번 달 넣은 돈) / 남은 돈(저축을 뺀 뒤) / “소득의 59.3%를 썼어요”. 저축과 남은 돈은 따로 보여 줌
- 예: 소득 7,642,680 / 쓴 돈 4,534,929(고정 1,387,540, 변동 1,838,389(자동차보험 제외), 용돈 600,000(찬우 300,000, 예빈 300,000), 큰 지출 자동차보험 709,000) / 저축 900,000 / 남은 돈 2,207,751 / 사용 비율 59.3%
- 지난달보다 칩(최대 4개): “외식·배달 +8만 원”, “쇼핑(옷·잡화) −3만 원”
- 예외 문구: 소득 0이면 비율 대신 “소득을 넣으면 비율을 보여 드려요”, 배우자 미합류면 월급 플랜과 같은 기준(배우자 수입 추정값이 있으면 “예빈님 수입은 추정값으로 셌어요”, 모르면 “예빈님이 합류하기 전이라 찬우님 돈만 셌어요”, → 핵심 규칙 › 계산·배분 7장), 예비부부는 결혼 자금 기준 문구. MonthSummary 아래에 기존 모은 돈 문장(계획의 n%), 계획 대비 표(W-04k 납입액 vs 월급 플랜 계획 배분액), 목표 진행, 순자산 변화, 미달·초과 처리
- MonthSummary 맨 끝(지난달보다 칩 다음)에 생활비 예산 보정 제안 카드 1장(기본): “최근 3개월 평균 138만 원을 썼어요. 예산을 맞출까요?” + ‘맞추기’ / ‘그대로 두기’(우리 자산 F-05 생활비 카드와 같은 문구). 최근 3개월 평균이 생활비 예산과 10% 넘게 다를 때만. 맞추기 = 다음 달 생활비 예산(혼자 정리는 월말 정리 제안 묶음에, 함께 모드·미합류·혼자 쓰기는 바로 확정). 계산 → 핵심 규칙 › 계산·배분 2장
- 계산식 → 핵심 규칙 › 계산·배분 7장

## W-07 들어오는 돈

상여금·연말정산 환급 등 들어오는 돈 전용. 나가는 돈(자동차세·재산세·보험 연납 등)은 매년 목표로 안내(→ 목표).

| 항목 | 내용 |
| --- | --- |
| 진입 | W-01 특이사항, 우리 자산 > 월 수입·지출(F-05), W-04a2 변동 수입 초과분 |
| 목록 | 월별로 묶은 들어오는 돈 |
| 추가 흐름 | 이름 → 금액 → 몇 월에(매년 반복 여부) |
| 플랜 반영 | 들어오는 달 W-01에 ‘추가 소득 나누기’ 카드(목표 / 용돈 비율). W-04a2 기준 수입 초과분도 같은 카드 |

## 예외

- 월말 정리 없이 기준일이 지남: 새 플랜은 그대로 생성, 지난달은 위 놓친 달 화면(→ 핵심 규칙 › 월 사이클)
- 월급날(기준일) 변경: 현재 사이클 길이 조정(→ 핵심 규칙 › 월 사이클)
- 배우자 사이클 중간 합류: 이번 플랜 유지, 안 나눈 돈만 재계산. 미합류 동안 적용된 변경은 P-10에서 목록으로만(→ 배우자 합류). 기본값 플랜 → 핵심 규칙 › 부부·제안·권한
- 결혼일 전환 직후: → 이번 달 H-T, 핵심 규칙 › 계산·배분
- 기간을 정한 수입 변경(휴직·육아휴직 등): 그 기간 플랜마다 ‘비상금 → 공동 생활비’ 보충 줄, 계획 다시 세우기(F-07) ‘변경 후’에 보충안, 분담 ‘버는 만큼’ 제안 자동 표시(→ 핵심 규칙 › 계산·배분 / 부부·제안·권한)
- 연결 해제 대기 중: 월말 정리는 하되 다음 달 조정(W-04h)은 건너뜀 → 핵심 규칙 › 부부·제안·권한 1장
- 연결 해제 후 혼자 쓰기: 제안 없이 바로 적용(W-04 끝 예외와 같음)
