# 월급 전 확인

월말 정리(지출 입력, 저축 확인, 정산 요약, 꼼꼼 모드, 다음 달 조정, 놓친 달·쉬어가기)는 없앴어요(2026-10-25, `docs/adr/0003-replan-goal-checklist.md`). 한 달은 월급 체크리스트로 끝나요.

- 2026-11-13(ADR 0009): 월급날 확인은 한 번(“모두 계획대로 됐어요”), 자동 줄은 나가는 날 앱이 확인. 남은 일은 월급 전 확인(W-05) 하나: 다음 월급날 3일 전에 **손 줄**(자동이 아닌 확인할 줄)이 남았을 때만 알림 1회, 남은 줄을 확인하거나 “이번 달은 건너뛸게요”로 닫음. 자동 줄만 있는 사람에게는 없음. 다음 사이클이 끝날 때까지 늦게 확인할 수 있음. 아래 예전 설명: 줄이 모두 체크 또는 ‘못 함’이면 그 달이 끝남(“…체크를 다 했어요”, ‘못 함’이 섞이면 “…마쳤어요”, 2026-11-12 D4). 끝내는 화면(W-02 끝)은 없고 W-02 막대 아래 한 줄(2026-11-12)
