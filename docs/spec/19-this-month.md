# 이번 달

## 흐름 요약

앱을 열면 보이는 첫 화면 = 이번 달(온보딩·로그인 후 포함, 예비부부도 같음). 결혼 예정일 전엔 예비부부 이번 달(H-P), 이후엔 신혼 이번 달(H-01\~08)을 보여 주고, 예식 뒤 첫 기준일에 결혼일 전환(H-T1\~T7)을 거쳐 신혼 이번 달로 바뀜. 카드는 월급 플랜(W-01·02·03)·월말 정리(W-04)와 목표·우리 자산·캘린더로 이어짐.

월급 나누기가 없는 사람의 오늘 띠(위 표 7번, 10번): 첫 타일 “이번 달 남은 생활비”, 주 버튼 ‘지출 적기’ → W-04j(SpendItems).

예외·오류

- 오프라인: 데스크톱은 조회 + 입력 대기열 저장, 일부 동작 비활성(→ 동기화) / 웹은 오프라인 미지원
- 불러오는 중: 0.3초 넘으면 카드 모양 스켈레톤

## 신혼 이번 달 기본 상태 (H-01\~H-08)

> 화면 그림: 신혼 이번 달 기본 상태, 월급 나누기 전(옛 사이드바 틀, 시안: sweeTwo 앱 틀 시안 캔버스의 ‘고른 안’) (그림은 기획서 페이지 사본에 있어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 인사 문구 (H-01) | “찬우님, 10월 월급 나누기가 2곳 남았어요” / 월급 나누기가 없으면 “찬우님, 이번 달 생활비가 32만 원 남았어요”(음수면 “찬우님, 생활비를 n만 원 넘게 썼어요”) | 지금 할 일을 한 문장으로. 맨 위 카드 내용을 따라 바뀜 |
| 2 | 맨 위 카드 (H-02) | “이번 달 돈, 이렇게 옮겨요” / “2곳, 240만 원이 남았어요” + “월급 나누기” | 따로 카드로 그리지 않고 오늘 띠로 흡수: 행동은 오늘 띠 주 버튼(평소 “월급 나누기”, 월급 나누기가 없으면 “지출 적기”, 월말 정리 기간 “정리 시작”), 금액·개수는 숫자 타일과 인사 제목으로. 항상 1개. 우선순위: 결혼 후 설정 마무리 > 지난달 정리 남음 > 월말 정리 > 월급 나누기(W-02)·지출 적기(W-04j, 월급 나누기가 없을 때)·생활비 체크(W-03) > 첫 주 할 일. 나머지는 할 일로 내려감. 그 외 시기엔 플랜 요약 → W-01. 월말 정리를 끝낸 뒤 7일 동안 플랜 요약 카드 아래 ‘정리 고치기’ → W-04 다시 열기(→ 월말 정리 › W-04 끝) |

| 9 | 배우자 활동 (H-08) | “예빈님이 공동 생활비 나누기를 끝냈어요” 등 | 최근 5건 → 관련 화면. 사실값 변경은 건마다 1건 + 주 1회 요약 “이번 주 예빈님이 고정지출 등 3개 값을 바꿨어요”. 배우자 미합류면 없음. 최근 90일 안 활동이 없으면 “아직 활동이 없어요”. 출처 = 상대가 일으킨 알림, 상대가 끝낸 월급 나누기 줄, 상대가 추가하거나 바꾼 자산·부채(DB `partner_activity`). 알림 규칙 → 화면 설계 › 알림 |

- 배우자가 혼자 월말 정리 중이면 변동 수입 당사자 맨 위 카드: “10월 수입, 얼마 들어왔나요?”(W-04a2 1문항). 기준일 전날까지 답 없으면 기준 수입으로 처리
- 첫 진입: 월급 나누기 전이면 월급 나누기 카드, 월급 나누기를 마치면 첫 주 할 일. 첫 사이클이 15일 미만이면 월말 정리 카드 없음(→ 핵심 규칙 › 월 사이클)
- 배우자 미합류·추정값 보완·지출 점검은 상단 배너 없이 할 일(H-04) 항목으로만

예외·오류

- 저축 가능 금액 0 이하: 할 일에 ‘지출 점검’(받은 제안 다음) → F-05
- 추정값 3개 이상: 할 일에 ‘정확한 값 입력’
- 연결 해제 후 혼자 쓰기: ‘임시’ 배지·초대 할 일·배우자 활동 없음, 플랜에 내 용돈만. 배분 결정은 제안 없이 바로 적용(→ 핵심 규칙 › 부부·제안·권한)

## 예비부부 이번 달 (H-P1\~H-P7)

결혼 예정일 전 이번 달. 통장 3개·생활비 체크·월말 정리는 숨기고 결혼 비용 결제와 모으기만 표시. 월 사이클은 ‘결혼 자금 모으기 → 월말 확인(H-P7)’ 2단계. 예비부부 배분·목표·결혼 준비 통장 계산 → 핵심 규칙 › 계산·배분.

> 화면 그림: 예비부부 이번 달, 아래는 H-P1 다른 상태 (그림은 기획서 페이지 사본에 있어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | D-day 헤더 (H-P1) | “결혼까지 D-87” / “2027년 1월 9일” | 누르면 예식일 수정. 바꾸면 결혼 비용 목표 기한·챙길 날 알림도 함께 이동 |
| 2 | 이번 달 결혼 비용 결제 (H-P2) | “이번 달 나갈 결혼 비용 2건, 1,050만 원” + 항목·결제일·금액 | 체크 = ‘결제했어요’ → 결제 기록(G-07) |
| 3 | 이번 달 모으기 (H-P3) | “찬우 150만 원” “예빈 120만 원” | 각자 결혼 준비 통장으로 결혼 자금 모으기 체크, W-02 방식. 양가 지원 + 모아둔 돈 ≥ 총예산이면 카드 숨김 |
| 4 | 결혼 비용 현황 (H-P4) | 결제 완료, 남은 결제, 총예산, 양가 지원, 모아둔 돈, 예식 전까지 모을 돈(예: 3,000 − 1,000 − 900 − 800 = 부족 300만 원) | 부족액(→ 핵심 규칙 › 계산·배분)이 0 초과면 “예식 전까지 300만 원이 부족해요” + “조정하기” → G-07, 0 이하면 “여유 {n}만 원” |
| 5 | 결혼 준비 할 일 (H-P5) | 예비부부 체크리스트 미완료 3개 | D-30부터 ‘결혼 후 규칙 미리 정하기’ → H-T3\~T5 미리 열기 |
| 6 | 다가오는 일정 (H-P6) | 상견례·결제일·신혼집 잔금일·양가 생신 | → Y-05 |
| 7 | 예식일 미정 | “2027년 1월 예정” + “추정” | 할 일에 ‘예식일 정하기’. 결혼일 전환 알림 없음 |
| 8 | 예식을 올렸나요? | “예식을 올렸나요?” + “결혼했어요” / “미뤄졌어요” | 예정 월 말일이 지나면 헤더 자리에. 결혼했어요 → H-T1, 미뤄졌어요 → 새 예정 월(Q4) |

- 월말 확인(H-P7): 월말 정리 기간에 헤더 아래 맨 위 카드 “이번 달 결혼 준비 돈을 확인할 차례예요” → 지출 입력(W-04j) → 저축 확인(W-04k, 결혼 자금으로 넣은 돈) → 받은 제안(G-08) → 정산 요약(W-04g, 결혼 자금 기준 문구). 결혼 준비 통장 잔액(W-04b 방식)과 결혼 비용 사용 확인(W-04c 방식, 미리 채운 결제 기록 확인 + 설명 안 된 차액만 질문)은 꼼꼼 모드에서. 부제 “1\~2분이면 돼요”, 알림은 월말 정리와 같은 때(기준일 3일 전·전날 오후 8시)
- ‘지금부터 합쳐서’ 예비부부: 신혼 이번 달 + H-P1·H-P2·H-P4 추가
- 카드 순서: H-P1 → (월말 정리 기간 H-P7) → H-P2 → H-P3 → H-P4 → H-P5. 맨 위 카드 우선순위: 결혼 후 설정 마무리 > 예식을 올렸나요 > 월말 확인(H-P7)
- 결혼 비용·챙길 날 기록의 “어디서 냈어요?” 선택지 ‘결혼 준비 통장’ / ‘각자 돈·양가 지원’ → 목표 G-07

## H-T1 축하, H-T2 결혼 비용 마무리

예식 후 첫 기준일(최소 예식 + 7일)에 알림과 함께 시작, 약 5분. 두 사람 중 한 명이 진행.

> 화면 그림: H-T1 축하, H-T2 남은 돈 보낼 곳 (그림은 기획서 페이지 사본에 있어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 그림 | 초 하나를 올린 웨딩 케이크(체리 없음), 1:1. 초에 불이 붙었다가 후 불어 꺼지듯 꺼지고 연기가 사라짐 | 한 번 재생, 처음과 끝 장면이 같음. 규칙 → 제품 개요 › 브랜드 3장 그림 움직임 규칙 |
| 2 | 제목 | “결혼을 축하해요!” / “약 5분이면 돼요” | H-T1 |
| 3 | 할 일 3가지 | “결혼 비용 마무리” “돈 나누는 규칙” “월급 플랜” | 순서대로 진행. 월급 플랜 = H-T4\~T6 |
| 4 | 확인만 | “확인만” 배지 | 예비부부 이번 달에서 미리 정했거나 ‘지금부터 합쳐서’ 부부인 단계 |
| 5 | 주 버튼 | “시작할게요” | → H-T2 |
| 6 | 나중에 | “나중에 할게요” | 예비부부 이번 달 유지, 맨 위 카드 “결혼 후 설정을 마무리해 주세요” |
| 7 | 진행 표시 | 3칸 막대 | 할 일 3가지 기준. H-T7에서 숨김 |

다른 H-T 화면

- H-T2 남은 목돈: “축의금 등 결혼 후 남은 목돈이 있나요?” → 금액(자산 ‘결혼 후 남은 목돈’으로 저장)
- H-T4 통장 구조: 공동 생활비·목표자금·비상금 통장 안내 + 결혼 준비 통장을 목표자금 통장으로 바꿀지 Q1. “통장 하나로 써요” 선택지도 있음(고르면 통장 역할 없이 월 금액만, → 핵심 규칙 › 계산·배분 2장)
- H-T5 월 수입·지출: 고정지출·생활비가 결혼 후 바뀌었는지(신혼집 주거비 등) 항목마다 “맞아요” / “수정”
- H-T7 첫 미션: 결혼기념일 등록 확인, 양가 등록(안 했다면), 신혼 첫해 체크리스트 시작

예외·오류

- H-T3 규칙은 배우자에게 제안(G-08)으로 감. 확정 전 기본값 플랜·좋아요 처리 → 핵심 규칙 › 부부·제안·권한
- H-T6 목표 생성(비상금·결혼 후 목표·양가 비용), 예비 플랜 대체·안 나눈 돈 재계산 → 핵심 규칙 › 계산·배분
- 예식일이 ‘추정’이면 시작 알림 없음, H-P1 ‘결혼했어요’로만 시작
