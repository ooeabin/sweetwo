# 홈

## 흐름 요약

앱을 열면 보이는 첫 화면 = 홈(온보딩·로그인 후 포함). 세 가지 질문에 답함: 이번 달 월급 정한 대로 나눴지(H-03), 저금이 얼마나 모였지(H-02), 우리 자산 지금 얼마지(H-04). 카드는 월급 탭(W-01·W-02·W-05, 저금 항목 W-10), 우리 자산 탭, 캘린더로 이어짐. 결정 이유 → `docs/adr/0003-replan-goal-checklist.md`, 목표를 저금 항목으로 → `docs/adr/0007-goal-into-saving-line.md`.

| ID | 화면 | 형태 | 진입 |
| --- | --- | --- | --- |
| — | 앱 기본 틀 | 왼쪽 사이드바, 화면 제목 줄, 두 단 본문 / 좁은 창은 머리, 하단 탭 막대 | 모든 메뉴 |
| H-01 | 인사 | 없앰(2026-11-03, 번호 다시 쓰지 않음) | — |
| H-02 | 저금 | 목표 금액이 있는 저금 항목 줄(최대 4개), 없으면 없음(2026-11-09 제안 한 줄 대신 H-03 첫 저금 빈 줄) | 홈 → W-10 |
| H-03 | 이번 달 월급 | 체크 목록 카드 | 홈 → W-02, 줄 바로 체크 |
| H-04 | 우리 자산 | 카드 | 홈 → F-01 |
| H-05 | 다가오는 일정 | 카드(최대 3개) | 홈 → 캘린더 Y-01 |
| H-06 | 할 일 한 줄 | 본문 맨 위 Banner(있을 때만, 1개) | 항목별 화면 |

Esc·뒤로 닫기 |

예외·오류

- 오프라인: 볼 수만 있음. 체크·입력을 누르면 Toast “인터넷에 연결되면 할 수 있어요”(입력 대기열 없음, 2026-11-09 확정, → 동기화 4장)
- 불러오는 중: 0.3초 넘으면 카드 모양 스켈레톤
