# 홈

## 흐름 요약

앱을 열면 보이는 첫 화면 = 홈(온보딩·로그인 후 포함). 세 가지 질문에 답함: 우리 목표 얼마나 모았지(H-02), 이번 달 월급 정한 대로 나눴지(H-03), 우리 자산 지금 얼마지(H-04). 카드는 목표 탭, 월급 체크리스트(W-01·W-02·W-05), 우리 자산 탭, 캘린더로 이어짐. 결정 이유 → `docs/adr/0003-replan-goal-checklist.md`.

| ID | 화면 | 형태 | 진입 |
| --- | --- | --- | --- |
| — | 앱 기본 틀 | 왼쪽 사이드바, 인사 카드(홈), 두 단 본문 / 좁은 창은 머리, 하단 탭 막대 | 모든 메뉴 |
| H-01 | 인사 | 인사 카드의 인사 문장과 큰 숫자 | 홈 |
| H-02 | 목표 | 1순위 큰 카드 + 나머지 작은 줄 | 홈 → G-02, 더보기 → G-01 |
| H-03 | 이번 달 월급 | 체크 목록 카드 | 홈 → W-02, 줄 바로 체크 |
| H-04 | 우리 자산 | 카드 | 홈 → F-01 |
| H-05 | 다가오는 일정 | 카드(최대 3개) | 홈 → 캘린더 Y-01 |
| H-06 | 할 일 한 줄 | 본문 맨 위 Banner(있을 때만, 1개) | 항목별 화면 |

## 앱 기본 틀

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 바탕·본문 | 흰 바탕 + 왼쪽 사이드바 + 본문(옅은 테두리·그림자의 둥근 흰 카드) | 넓은 창. 본문 최대 폭 1120px 가운데. 입력 흐름은 본문 위 레이어(가운데 480px) |
| 2 | 사이드바 | 위에서부터 워드마크 → 검색 칸 “검색” “⌘K” → 탭 4개 → 아래 끝 두 사람 아바타 + “설정” → 눈 → 알림 | 넓은 창의 모든 메뉴 화면 왼쪽, 화면 높이에 고정 |
| 3 | 탭 | “홈” “목표” “우리 자산” “캘린더” [확인 필요] | 앱을 열면 홈. 현재 탭은 회색 바탕 + 굵은 글자. Ctrl(⌘)+1~4. 설정은 탭에 없음(아바타 줄로 진입) |
| 4 | 검색 칸 | “⌘K” | 누르면 검색 화면(12번). Windows는 Ctrl+K |
| 5 | 눈·알림 | 눈 아이콘, 알림 버튼 | 눈 = 금액 가리기(켜면 금액 “•••”, 기기마다 기억). 알림 = 알림 센터(배우자 활동 포함, → 알림), 새 알림 있으면 brand 점 |
| 6 | 두 사람 아바타 | Avatar 2개 | 누르면 설정(S-10). 마우스를 올리면 툴팁 “모두 저장됨” / “저장 중”. 오프라인은 Banner. Avatar 색은 찬우 person-1, 예빈 person-2 고정. 배우자 미합류면 빈 원 |
| 7 | 인사 카드 | 날짜(“10월 26일 월요일”) + 인사(H-01) + 오른쪽 큰 숫자 하나 + 진행 막대 + 아래 ‘추가’(보조 버튼), ‘월급 체크하기’(주 버튼) | 홈에만, 본문 위 흰 카드. 큰 숫자 = 체크가 남았으면 한 개수/전체(“2/5”), 다 했으면 1순위 목표 %(“18%”), 막대도 같은 비율. 주 버튼은 이번 달 체크 안 한 줄이 있을 때만 → W-02. 추가 = 목표 / 가진 돈·대출 / 챙길 날(Ctrl(⌘)+N) |
| 8 | 본문 두 단 | 왼쪽 목표(H-02), 이번 달 월급(H-03) / 오른쪽 우리 자산(H-04), 다가오는 일정(H-05) | 창 1100px 미만이면 한 단(H-02 → H-03 → H-04 → H-05). 할 일 한 줄(H-06)은 두 단 위 |
| 9 | 화면 제목 줄 | 제목 + 오른쪽 ‘추가’ | 홈 밖의 메뉴 화면. 본문 맨 위, 인사 카드 없음 |
| 10 | 좁은 창 머리 | 홈은 워드마크, 다른 메뉴는 큰 제목(메뉴 이름) + 오른쪽 아이콘 4개(검색, 눈, 알림, 설정) | 768px 미만만. 홈은 그 아래 인사 카드(버튼 꽉 차게). 설정 → S-10 |
| 11 | 하단 탭 막대와 + 버튼 | 화면 아래 가운데 떠 있는 흰 알약 탭 막대 “홈” “목표” “우리 자산” “캘린더”(아이콘 + 이름) + 막대 위 오른쪽 검정 원형 + 버튼 | 좁은 창만. 현재 탭은 회색 알약 + 진한 글자 + 채운 아이콘. + 버튼 = 그 화면에 맞는 추가: 홈·목표 = 목표, 우리 자산 = 가진 돈·대출(F-03), 캘린더 = 챙길 날. 설정에서는 숨김 |
| 12 | 검색 화면 | 입력창 “찾거나 바로 할 일을 입력해요” + ‘바로 하기’ 묶음(“월급 체크하기” “목표 추가” “가진 돈 추가” “금액 가리기” “잠그기”) + 결과 목록 / 빈 상태 “찾는 게 없어요” | 데스크톱 ⌘K와 좁은 창 검색 버튼이 같은 화면(CommandPalette). 월급 체크하기 → W-02, 목표 추가 → G-03a, 가진 돈 추가 → F-03, 금액 가리기 켜고 끄기, 잠그기 → A-06(데스크톱만). 결과는 종류별 묶음(목표, 가진 돈·대출, 챙길 날) 최대 5개씩. 금액 가리기 켜져 있으면 결과 금액도 “•••”. 배우자 비공개 항목은 결과에 없음. Esc·뒤로 닫기 |

예외·오류

- 오프라인: 조회 + 입력 대기열 저장, 일부 동작 비활성(→ 동기화)
- 불러오는 중: 0.3초 넘으면 카드 모양 스켈레톤

## 홈 기본 상태 (H-01~H-06)

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 인사 (H-01) | 체크 안 한 줄이 있으면 “찬우님, 이번 달 월급 체크가 3개 남았어요” / 다 했으면 “찬우님, 내 집 마련까지 18% 왔어요” [확인 필요] | 한 문장. 1순위 목표가 비상금뿐이면 “비상금까지” |
| 2 | 목표 (H-02) 1순위 | 그림 + “내 집 마련” + “2,700만 / 1억 5,000만 원” + Meter + “예상 2037년 8월” + 이번 달 줄 “이번 달 95만 원 넣을 차례예요” / 체크했으면 “이번 달 95만 원 넣었어요” | 1순위 = 우리 목표 1순위(비상금 다음 첫 우리 목표). 배우자 미합류·혼자 쓰기면 전체 1순위(비상금 → 우리 목표 → 내 목표 순서의 첫 목표, 혼자 쓰기는 모두 내 목표). 카드 → G-02. 이번 달 줄은 체크리스트 저금 줄과 같은 체크 칸(바로 체크 가능). 기한보다 늦으면 “지연” 배지 |
| 3 | 목표 (H-02) 나머지 | 큰 카드 다음 목표 3개까지 작은 줄(그림, 이름, % ) + “목표 더보기”. 내 목표 줄에는 작은 “나” 표시 [확인 필요] | 순서 = 우리 목표 → 내 목표(묶음마다 우선순위 순). 배우자의 내 목표는 홈에 안 나옴(목표 탭에서 봄). 혼자 쓰기는 “나” 표시 없음. 줄 → G-02, 더보기 → G-01. 금액 없는 목표는 % 대신 “금액 정하기” → G-03 금액 화면 |
| 4 | 이번 달 월급 (H-03) | “10월 월급” + “5개 중 2개 했어요” + 줄 목록(저금 먼저, 쓰는 돈 다음) + “분배표 고치기” | 줄 체크 = W-02와 같은 동작. 각자 모드 + 배우자 합류면 카드 아래 “예빈님 3개 중 1개”(누르면 W-02 예빈 탭). 카드 제목 → W-02 |
| 5 | 우리 자산 (H-04) | “순자산 8,420만 원” + “지난달보다 +210만 원” + 6개월 작은 선 그래프 | → F-01. 계산 → 우리 자산. 가진 돈을 하나도 안 적었으면 “가진 돈을 적으면 순자산을 보여 드려요” + “가진 돈 추가하기” → F-03 |
| 6 | 다가오는 일정 (H-05) | 30일 안 월급날, 챙길 날, 만기, 목표 기한, 날짜순 최대 3개 | 줄 → 캘린더 Y-05, 제목 → Y-01 |
| 7 | 할 일 한 줄 (H-06) | 아래 순서 중 맨 앞 1개만 | 있을 때만. 닫기 없는 것과 있는 것이 정해져 있음(아래 표) |

할 일 한 줄 순서

| 순서 | 할 일 | 문구 | 이동 | 닫기 |
| --- | --- | --- | --- | --- |
| 1 | 연결 해제 요청 받음 | “예빈님이 연결 해제를 요청했어요” | S-12d | 없음 |
| 2 | 다시 연결 요청 받음 | “예빈님이 다시 연결하자고 했어요” | S-12g | 없음 |
| 3 | 월말 확인 | “10월 월급에서 체크 안 한 게 2개 있어요” | W-05 | 있음(이번 달만) |
| 4 | 배우자 초대 | “같이 쓸 사람을 초대해 주세요” + “코드 복사” | ‘코드 복사’ = 코드를 만들어(있으면 그대로) 복사 + Toast “코드를 복사했어요” [확인 필요]. 못 만들면 S-12 | 있음(7일 동안 안 보임) |
| 5 | 목표 금액 정하기 | “여행 목표 금액을 정해 주세요” | G-03 금액 화면 | 있음 |
| 6 | 만기·챙길 날 | 만기: “청년 적금이 만기됐어요” [확인 필요] / 챙길 날: “11월 2일 어머니 생신이에요” | 만기 F-04a(만기일부터 정리할 때까지), 챙길 날 Y-05(7일 안 [확인 필요]) | 있음(그 항목·날짜만) |

- 한 번에 하나만. 닫거나 끝내면 다음 순서가 올라옴
- 배우자 활동은 홈에 두지 않고 알림 센터에서 봄

## 홈 상태 변형

| 번호 | 상태 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 이번 달 다 했어요 | H-03 “10월 월급을 다 나눴어요” + 저금 합계 “목표에 140만 원 모았어요” | 줄 목록 접힘(펼치기 가능). 주 버튼 ‘월급 체크하기’ 숨김 |
| 2 | 월급이 없어요 | H-03 “월급이 생기면 분배표를 만들어 드려요” + “월급 알려 주기” | O-31에서 ‘지금은 월급이 없어요’를 고른 경우 → S-11 |
| 3 | 해제 대기 띠 | “연결 해제를 기다리고 있어요” / “11월 7일에 해제돼요” [확인 필요] + “확인하기” | 연결 해제 대기 중 두 사람 모두, 본문 맨 위 띠(닫기 없음). 확인하기 → 요청한 사람 S-12, 받은 사람 S-12d |
| 4 | 시작한 사람을 기다림 | 인사 “{나}님이 시작하고 있어요” / 카드 “{나}님이 첫 목표를 정하면 알려 드릴게요” | 합류한 사람인데 시작한 사람이 아직 온보딩 중일 때. {나} = 시작한 사람 이름. 이 카드 + 다가오는 일정만(→ 배우자 합류) |
| 5 | 목표가 비상금뿐 | H-02 비상금 큰 카드 + “다른 목표 추가하기” | → G-03a |

예외·오류

- 연결 해제 후 혼자 쓰기: 초대 할 일, 배우자 진행 줄 없음. 해제 확정 뒤 처음 열면 홈 대신 S-12h → 온보딩 O-11(같이 쓰던 데이터는 지워져 홈은 새 온보딩 뒤 다시 채워짐, → 핵심 규칙 › 부부·권한 7장)
