# 사용성 테스트

MVP 개발 전, 클릭형 프로토타입으로 결혼 준비 중인 커플과 신혼부부 6쌍이 9화면 온보딩 → 첫 월급 체크 → 합류 → 목표 확인 → 자산 추가까지 막힘없이 가는지와 매달 체크를 이어갈 의향을 확인함.

## 1. 목적·핵심 가설

- 목적: 출시 전 가장 큰 위험(분배표를 이해하고 매달 체크를 이어갈지, 목표가 주인공으로 읽히는지, 둘이 같이 쓰는지) 검증, 치명 이슈를 MVP 전에 수정. 2026-10-25 재기획(`docs/adr/0003-replan-goal-checklist.md`) 흐름 기준
- 기준 인원: 6쌍 12명 (온보딩은 주도자 6명, 합류는 상대 6명)

| # | 가설 | 성공 기준 |
| --- | --- | --- |
| H1 | 수동 체크여도 매달 쓸 만함 | “다음 달에도 월급날 체크해 쓸까요” 5점 척도 4점 이상 9/12명 |
| H2 | 9화면 온보딩을 3분 안에 끝냄 | 도움 없이 O-60 ‘시작할게요’ 5/6명, 소요 중앙값 2분 이하 (상한 3분) [확인 필요] |
| H3 | 분배표와 체크의 관계를 이해함 | 체크해도 돈이 옮겨지지 않고 은행 앱에서 직접 보낸다는 것, 저금 줄을 체크하면 목표에 더해진다는 것을 자기 말로 설명 10/12명 [확인 필요] |
| H4 | 목표 진행을 바로 읽음 | 홈에서 1순위 목표의 모은 돈, 예상 달성일, ‘지연’ 여부를 10초 안에 말함 10/12명 [확인 필요] |
| H5 | 배우자가 초대 링크로 혼자 합류함 | 도움 없이 합류 완료 5/6명, 3분 이하. “실제로도 합류할 것” 4점 이상 9/12명 |
| H6 | 순자산과 목표에 모은 돈의 차이를 앎 | 목표에 모은 돈이 순자산에 따로 더해지지 않는 이유를 자기 말로 설명 8/12명 [확인 필요] |

## 2. 프로토타입 범위

- 도구: Figma 프로토타입 (데스크톱 창 1100px 기준), 합류(P-)만 좁은 창 웹 프레임 추가
- 가짜 데이터: 찬우·예빈 맞벌이 신혼 1년 차, 찬우 실수령 350만 원·월급날 25일, 1순위 목표 내 집 마련. 참가자는 실제 금액 대신 이 데이터로 진행 (주도자 = 찬우 역, 상대 = 예빈 역)
- 금액·텍스트 입력: 칸을 누르면 정해진 값 채움. 실제 입력 부담은 사후 질문으로 보완

| 묶음 | 클릭 가능 화면 | 시작 상태 |
| --- | --- | --- |
| 1. 로그인·가입 | A-01·A-02·A-05 (소셜 로그인은 클릭 1번으로 통과, A-05 “만 18세 이상이에요” 체크 포함) | 신규 |
| 2. 온보딩 | O-10 → O-03 → O-06(·O-07) → O-11 → O-21 → O-23 → O-24 → O-30 → O-31 → O-50 → O-60 | 신규 |
| 3. 홈·월급 체크리스트 | 홈 H-01\~H-06, W-01·W-02·W-02a·W-02 끝·W-05 | 첫 체크리스트 직후 / 다음 월급날 3일 전 |
| 4. 목표·우리 자산 | G-01·G-02·G-03a\~f, F-01·F-03 | 한 달 뒤 |
| 5. 배우자 합류 | A-07(P-01)\~합류 완료 P 화면 | 초대 링크 받은 상태 |

- 제외: 설정·어드민·캘린더·연결 해제 (위험 낮음 또는 2차 테스트)

## 3. 참가자

| 구성 | 쌍 | 기준 |
| --- | --- | --- |
| 맞벌이 신혼 (결혼 1\~3년 차) | 2 | 월급을 합쳐서 관리 1쌍, 각자 관리 1쌍 |
| 결혼 준비 중 커플 | 2 | 예식 6개월\~1년 이내, 결혼 비용을 모으는 중 |
| 한쪽 프리랜서·변동 수입 | 1 | 월 수입 편차 큰 쪽 포함 |
| 신혼 첫해, 돈 관리 시작 전 | 1 | 가계부·자산 앱 사용 경험 없음 |

- 공통: 둘이 함께 90분 참여, 데스크톱(Windows·macOS) 사용 가능, 돈 관리 주도자·덜 적극적인 쪽이 섞이게
- 제외: UX·핀테크 종사자, 최근 6개월 내 유사 테스트 참여자
- 앱 경험: 자산·가계부 앱 사용 중 3쌍 이하
- 모집 채널: 결혼 준비 온라인 카페·웨딩 커뮤니티, 지인 추천, 리서치 패널 (스크리너 설문)
- 사례비: 커플당 10만 원 (1인 5만 원 상품권), 예비 1쌍 추가 모집

## 4. 세션 구성 (90분)

- 진행자 1 + 관찰자 1, 대면 우선(방 2개), 화면·음성 녹화 동의
- 따로 과제 중 상대는 옆방에서 사전 설문(지금 돈 관리 방식)

| 시간 | 단계 | 참여 | 내용 |
| --- | --- | --- | --- |
| 0\~5분 | 안내·동의 | 같이 | 녹화·가짜 데이터·소리 내어 생각하기 안내 |
| 5\~15분 | 사전 인터뷰 | 같이 | 지금 돈 관리 방식, 누가 주도, 앱·엑셀 사용 경험과 그만둔 이유 |
| 15\~35분 | 과제 T1·T2 | 따로 (주도자) | 온보딩과 초대, 결과 이해 |
| 35\~50분 | 과제 T3 | 따로 (상대) | 합류 |
| 50\~77분 | 과제 T4\~T7 | 같이 | 월급 체크, 목표 확인, 월말 확인, 자산 추가 |
| 77\~90분 | 사후 질문 | 각자 설문 → 같이 인터뷰 | SUS, 지속 의향, 이해도 3문항, 가장 헷갈린 화면 |

## 5. 과제

| # | 과제 | 참여 | 시작 화면 | 성공 조건 | 관찰 포인트 |
| --- | --- | --- | --- | --- | --- |
| T1 | 처음 설치하고 첫 목표와 월급 분배표 만들기(배우자 초대 포함) | 주도자 | A-01 | O-07에서 초대 코드를 보낸 뒤 O-60 ‘시작할게요’ 도달 | 멈춘 화면, O-06 ‘초대하기’ / ‘나중에 할게요’ 선택 이유, ‘잘 모르겠어요’ 사용, 금액 질문(O-23·O-31) 망설임, O-30 각자·합쳐서 이해, O-50 추천값을 고치는지와 ‘모자라요’ 반응 |
| T2 | “매달 얼마씩 모으면 언제 내 집 마련을 이뤄요?” 답하기 | 주도자 | O-60 | O-60 문장대로 금액과 예상 달성일, 기한보다 늦은지 맞게 말함 | 예상 달성일과 기한 혼동, ‘분배표에서 저금을 늘리면 앞당길 수 있어요’ 이해 |
| T3 | 초대 링크로 합류하기 | 상대 | A-07(P-01) | 합류 완료(자기 월급과 분배표 넣기) | 찬우가 정한 관리 방식 확인 반응, 자기 분배표 만들기 망설임 |
| T4 | 월급날, 분배표대로 보냈다고 체크하기 | 같이 | 홈(월급날 알림) | W-02에서 줄 모두 체크(한 줄은 W-02a 다른 금액), 각자 관리면 배우자 줄 ‘대신 체크’ 1번 | 체크와 은행 앱에서 실제로 보내는 일의 관계, 저금 줄 체크 뒤 목표 금액이 늘어난 것을 알아채는지, Toast ‘되돌리기’ |
| T5 | 우리 목표가 얼마나 모였는지 확인하고 2순위 목표 금액 정하기 | 같이 | 홈 | H-02에서 1순위 진행률·예상 달성일을 말하고, ‘금액 정하기’로 여행 목표 금액을 넣음 → 분배표에 0원 줄이 생긴 것을 W-01에서 찾음 | 목표가 주인공으로 읽히는지, ‘지연’ 배지 이해, 목표와 분배표 저금 줄의 연결 이해 |
| T6 | 다음 월급날 3일 전, 빠진 줄 정리하기 | 같이 | 홈 H-06 월말 확인 한 줄 | W-05에서 한 줄 체크, 한 줄 ‘이번 달은 못 했어요’ | ‘못 함’ 저금 줄이 목표에 더해지지 않고 예상 달성일이 늦어진다는 이해, 누가 조작하는지 |
| T7 | 우리 자산에 통장과 대출을 하나씩 추가하고 순자산 설명하기 | 같이 | 홈 H-04 ‘가진 돈 추가하기’ | F-03에서 2개 추가 → F-01 순자산을 말하고, 목표에 모은 돈이 순자산에 따로 더해지지 않는 이유를 설명 | 목표에 모은 돈과 통장 잔액 혼동, 공개 범위 선택 |
