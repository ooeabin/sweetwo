# 사용성 테스트

> 2026-11-09 과제를 지금 흐름(ADR 0007 저금 항목, 월급 탭)으로 다시 씀. 목표 탭(G-)·목표 고르기(O-21)·우선순위·‘지연’ 배지는 없앤 화면이라 과제에 없음.

MVP 개발 전, 클릭형 프로토타입으로 결혼 준비 중인 커플과 신혼부부 6쌍이 온보딩 → 첫 저금 추가 → 첫 월급 체크 → 합류 → 저금 확인 → 자산 추가까지 막힘없이 가는지와 매달 체크를 이어갈 의향을 확인함.

## 1. 목적·핵심 가설

- 목적: 출시 전 가장 큰 위험(월급 계획을 이해하고 매달 체크를 이어갈지, 저금 줄 체크로 모은 금액이 쌓이는 걸 알아보는지, 둘이 같이 쓰는지) 검증, 치명 이슈를 MVP 전에 수정. 2026-10-25 재기획(`docs/adr/0003-replan-goal-checklist.md`) 흐름 기준
- 기준 인원: 6쌍 12명 (온보딩은 주도자 6명, 합류는 상대 6명)

| # | 가설 | 성공 기준 |
| --- | --- | --- |
| H1 | 수동 체크여도 매달 쓸 만함 | “다음 달에도 월급날 체크해 쓸까요” 5점 척도 4점 이상 9/12명 |
| H2 | 온보딩을 3분 안에 끝냄 | 도움 없이 O-60 ‘홈으로 가기’ 5/6명, 소요 중앙값 2분 이하 (상한 3분) [확인 필요] |
| H3 | 월급 계획과 체크의 관계를 이해함 | 체크해도 돈이 옮겨지지 않고 은행 앱에서 직접 보낸다는 것, 저금 줄을 체크하면 그 저금의 모은 금액에 더해진다는 것을 자기 말로 설명 10/12명 [확인 필요] |
| H4 | 저금 진행을 바로 읽음 | 홈 H-02에서 ‘내 집 마련’의 모은 금액과 목표 금액 대비 %, W-10에서 예상 달성일과 ‘기한보다 늦어요’ 한 줄을 10초 안에 말함 10/12명 [확인 필요] |
| H5 | 파트너가 초대 링크로 혼자 합류함 | 도움 없이 합류 완료 5/6명, 3분 이하. “실제로도 합류할 것” 4점 이상 9/12명 |
| H6 | 순자산과 저금의 모은 금액 차이를 앎 | 저금의 모은 금액이 순자산에 따로 더해지지 않는 이유를 자기 말로 설명 8/12명 [확인 필요] |

## 2. 프로토타입 범위

- 도구: Figma 프로토타입 (넓은 창 1100px 기준, 2026-11-10 데스크톱 앱을 없애 태블릿으로 읽음), 합류(P-)만 좁은 창 프레임 추가
- 가짜 데이터: 찬우·예빈 맞벌이 신혼 1년 차, 찬우 실수령 350만 원·월급날 25일, 저금 ‘내 집 마련’(이미 모은 금액 2,000만 원, 목표 금액 1억 5,000만 원). 참가자는 실제 금액 대신 이 데이터로 진행 (주도자 = 찬우 역, 상대 = 예빈 역)
- 금액·텍스트 입력: 칸을 누르면 정해진 값 채움. 실제 입력 부담은 사후 질문으로 보완

| 묶음 | 클릭 가능 화면 | 시작 상태 |
| --- | --- | --- |
| 1. 로그인·가입 | A-01·A-02·A-05 (소셜 로그인은 클릭 1번으로 통과, A-05 “만 18세 이상이에요” 체크 포함) | 신규 |
| 2. 온보딩·첫 저금 | O-10 → O-03 → O-06(·O-07) → O-11 → (O-12) → O-13 → O-30 → O-31 → O-32 → O-60 → 홈(체크리스트 저금 묶음 빈 줄 ‘+ 저금 추가’ → W-11a\~d) | 신규 |
| 3. 홈·월급 체크리스트 | 홈 H-02\~H-06, W-01·W-02·W-02a·W-02 끝·W-05 | 첫 체크리스트 직후 / 다음 월급날 3일 전 |
| 4. 저금·자산 관리 | W-10·W-10a·W-12·W-12a, F-01·F-03 | 한 달 뒤 |
| 5. 파트너 합류 | A-07(P-01)\~합류 완료 P 화면 | 초대 링크 받은 상태 |

- 제외: 설정·어드민·캘린더·연결 해제 (위험 낮음 또는 2차 테스트)

## 5. 과제

| # | 과제 | 참여 | 시작 화면 | 성공 조건 | 관찰 포인트 |
| --- | --- | --- | --- | --- | --- |
| T1 | 처음 설치하고 월급 계획 만들기(파트너 초대 포함) | 주도자 | A-01 | O-07에서 초대 코드를 보낸 뒤 O-60 ‘홈으로 가기’ 도달 | 멈춘 화면, O-06 ‘초대하기’ / ‘나중에 할게요’ 선택 이유, 금액 질문(O-31) 망설임, O-30 각자·합쳐서 이해 |
| T2 | 첫 저금 ‘내 집 마련’ 만들기(이미 모은 금액 2,000만 원 넣기) | 주도자 | 첫 홈 | 체크리스트 저금 묶음 빈 줄 ‘+ 저금 추가’ → W-11a\~d를 끝내고 W-10에서 모은 금액 2,000만 원, 매달 금액, 예상 달성일과 ‘기한보다 늦어요’ 여부를 맞게 말함 | 빈 줄을 찾는지, W-11b 빈 칸·빠른 칩 사용, ‘이미 모은 금액이 있어요’ 발견, 예상 달성일과 기한 혼동, ‘매달 금액 바꾸기’ / ‘기한 바꾸기’ 이해 |
| T3 | 초대 링크로 합류하기 | 상대 | A-07(P-01) | 합류 완료(자기 월급 넣기) 뒤 홈에서 “찬우님처럼 나도 모을 곳을 만들어 볼까요?” 줄을 찾음 | 찬우가 정한 관리 방식 확인 반응, 찬우 저금에 내 돈도 들어간다고 오해하는지 |
| T4 | 월급날, 월급 계획대로 보냈다고 체크하기 | 같이 | 홈(월급날 알림) | W-02에서 줄 모두 체크(한 줄은 W-02a 다른 금액), 각자 관리면 파트너 탭은 보기만(맨 위 ‘보기만 할 수 있어요’ 줄) | 체크와 은행 앱에서 실제로 보내는 일의 관계, 저금 줄 체크 뒤 모은 금액이 늘어난 것을 알아채는지, Toast ‘되돌리기’, 파트너 탭이 왜 잠겼는지 이해 |
| T5 | 저금이 얼마나 모였는지 확인하고 ‘적금’에 목표 금액 정하기 | 같이 | 홈 | H-02에서 ‘내 집 마련’ 진행률을 말하고, W-02 저금 줄 시트 ‘저금 보기’ → W-10에서 ‘적금’ 목표 금액을 정함(W-10a) → W-01 저금 묶음에서 같은 줄을 찾음 | 저금 하나가 월급 계획 한 줄이라는 연결 이해, ‘기한보다 늦어요’ 한 줄 이해 |
