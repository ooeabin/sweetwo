# 위젯

앱을 열지 않아도 홈의 세 질문(목표 얼마나 모았지, 이번 달 월급 정한 대로 나눴지, 우리 자산 지금 얼마지)과 다가오는 날을 한눈에 보는 작은 창(→ 홈). 숫자 하나가 주인공이고, 누르면 해당 화면으로 바로 이동(딥링크). 위젯 설정 → 설정 S-22. 위젯 화면·문구·상태·이동 화면의 정본은 이 탭(디자인 시스템 위젯 컴포넌트가 이 탭에 맞춤).

## 규칙

### 목적

- 위젯 하나 = 큰 숫자 하나(1순위 목표 %, 이번 달 월급 체크 진행 개수, 순자산 또는 지난달 대비 %, D-n) + 보조 1줄. 입력·수정·체크는 하지 않고 보기와 이동만 [확인 필요]
- 모든 플랫폼에서 위젯 종류와 내용은 같음(WG-01\~05). 플랫폼마다 놓이는 자리만 다름

### 플랫폼별 범위

| 플랫폼 | 위젯 | 시점 |
| --- | --- | --- |
| 데스크톱 (macOS·Windows) | 트레이 아이콘 + 트레이 위젯 창(폭 340px). 앱 창을 닫아도 트레이에 남음(S-22에서 끔) | 출시 포함 |
| macOS 알림 센터, Windows 11 위젯 보드 | WG-01\~04 | 출시 뒤(네이티브 확장 필요) |
| iOS·Android 홈 화면 | WG-01\~04 (소·중·대) | 모바일 앱 출시 뒤(네이티브 위젯 확장 필요) |
| iOS 잠금 화면 | WG-05 | 모바일 앱 출시 뒤 |

### 금액 표시

- 위젯은 남이 볼 수 있는 곳이라 기본은 금액 가림: 금액 자리에 같은 크기로 비율·건수·날짜를 보여 줌(“•••” 쓰지 않음). 라벨 옆에 작은 눈 끔 아이콘(Phosphor eye-slash). 이름·D-n은 그대로
- 설정 S-22 “위젯에 금액 보이기”를 켜면 금액 표시. 기기마다 따로
- 앱의 금액 가리기(→ 화면 설계 › 공통)가 켜져 있으면 S-22 설정과 상관없이 위젯도 가림
- 잠금 화면 위젯(WG-05)은 항상 금액 없음
- 앱이 잠겨 있으면(PIN) 위젯은 값 없이 “잠겨 있어요” + “앱 열기”만. 앱에서 금액 가리기를 켜고 끄면 위젯도 바로 같이
- 위젯에는 보는 사람이 앱에서 볼 수 있는 값만 보임(공개 범위 그대로 적용)

### 갱신

- 앱에서 값이 바뀌면 바로, 그 밖에는 30분마다
- 오프라인이면 마지막 값 + 작은 마지막 저장 시각
- 위젯 데이터는 기기에 암호화 캐시, 로그아웃 시 삭제(→ 보안·개인정보 2장)

### 디자인

- 흰 카드(다크는 기기 설정), radius-2xl, 글꼴 SUIT, 아이콘 Phosphor(굵은 둥근 선)
- 영역 틴트는 위젯 뜻에 맞게: 목표 = goal 틴트, 나머지는 흰 카드
- 진행 막대·단계 표시(stepper) 쓰지 않음. 진행은 숫자로만(목표는 %, 월급 체크는 개수), 원형 게이지는 잠금 화면 WG-05에만
- 브랜드 색(오렌지)은 목표 달성 배지에만. 가운데 점(·) 구분 없음

## 홈 화면·잠금 화면 위젯 (WG-01\~05)

> 화면 그림: WG-01\~05, 소·중·대 홈 화면 위젯(금액 가림 포함)과 잠금 화면 (그림은 기획서 페이지 사본에 있어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

### WG-01 이번 달 월급 (소)

금액이 없는 위젯이라 금액 가림과 상관없이 같은 모습.

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 진행 | “10월 월급” / “2개”(큰 숫자) / “5개 중 2개 했어요” [확인 필요] | 이번 달 체크리스트에서 체크한 줄 수(남는 돈 줄 제외, → 월급 체크리스트 W-02 진행). 각자 모드는 내 체크리스트, 합쳐서는 공동 체크리스트. 다 하면 “10월 월급을 다 나눴어요”. 누르면 → W-02 |
| 2 | 다음 월급날 | “다음 월급날 25일” | 내 다음 기준일(합쳐서면 공동 기준일, → 핵심 규칙 › 월 사이클). 월말 확인 기간(다음 월급날 3일 전 \~ 전날)에 체크 안 한 줄이 있으면 이 줄 대신 “체크 안 한 게 2개 있어요” [확인 필요], 누르면 → W-05 |
| 3 | 월급이 없을 때 | “월급이 생기면 분배표를 만들어 드려요” | O-31에서 ‘지금은 월급이 없어요’를 고른 경우(→ 홈 상태 변형 2번). 누르면 → S-11 |

## 트레이 위젯 창

> 화면 그림: 트레이 위젯 창, 로그인 전·오프라인·잠금 해제 전 (그림은 기획서 페이지 사본에 있어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

트레이 위젯 창 = WG-01(이번 달 월급) + WG-03 + 다음 할 일 1개 + “앱 열기”. 진행 막대 없음. 아이콘 아래에 붙어 열리고, 바깥을 누르거나 Esc로 닫힘.

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 트레이 아이콘 | sweeTwo 아이콘 | 누르면 창 열기·닫기. macOS 메뉴 막대는 단색 템플릿 아이콘(확정 전 → 사업 계획 9장). 오른쪽 클릭 메뉴 “sweeTwo 열기” “위젯 설정” “sweeTwo 끝내기”, 위젯 설정 → S-22 |
| 2 | 이번 달 월급 | WG-01과 같음 | → W-02, 월말 확인 기간 → W-05 |
| 3 | 다가오는 날 | WG-03과 같음 | → Y-05 / Y-01 |
| 4 | 다음 할 일 | “다음 할 일” / “여행 목표 금액을 정해 주세요” | 홈 할 일 한 줄(H-06)과 같은 것. 없으면 줄 숨김. 누르면 → 그 할 일 화면 |
| 5 | 앱 열기 | “앱 열기” | 앱 창을 앞으로 → 홈 |

## 예외

- 고른 목표가 휴지통·보류·달성으로 가면 1순위 목표로 바뀌고 S-22 선택도 그 목표로
- 앱이 꺼진 상태에서 위젯을 누르면 앱 실행 → 앱 잠금 해제 → 해당 화면. 대상이 지워졌으면 그 목록(G-01·Y-01)
- 세션 만료·다른 계정 로그인이면 위젯 캐시를 지우고 로그인 전 상태
- 트레이 아이콘을 끈 상태에서 앱 창을 닫으면 앱 종료(트레이에 남지 않음)
- 트레이 위젯 값은 앱 창이 열려 있을 때 홈 값이 바뀌면 갱신하고, 기기에 마지막 값을 남겨 앱을 다시 켜도 보여 줌. 다가오는 날은 2줄
- 없앤 위젯 내용(2026-10-25 재기획): 안 나눈 돈, 월급 나누기 진행, 이번 달 남은 생활비, 월말 정리 D-n, 받은 제안, 예비부부 결혼 자금 모으기
