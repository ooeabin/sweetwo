# 위젯

앱을 열지 않아도 이번 달 상황·다음 할 일·다가오는 날을 한눈에 보는 작은 창. 숫자 하나가 주인공이고, 누르면 해당 화면으로 바로 이동(딥링크). 위젯 설정 → 설정 S-22. 위젯 화면·문구·상태·이동 화면의 정본은 이 탭(디자인 시스템 위젯 컴포넌트가 이 탭에 맞춤).

## 규칙

### 목적

- 위젯 하나 = 큰 숫자 하나(안 나눈 돈 또는 월급 나누기 진행 %, 목표 %, 순자산 또는 지난달 대비 %, D-n) + 보조 1줄. 입력·수정은 하지 않고 보기와 이동만
- 모든 플랫폼에서 위젯 종류와 내용은 같음(WG-01\~05). 플랫폼마다 놓이는 자리만 다름

### 플랫폼별 범위

| 플랫폼 | 위젯 | 시점 |
| --- | --- | --- |
| 데스크톱 (macOS·Windows) | 트레이 아이콘 + 트레이 위젯 창(폭 340px). 앱 창을 닫아도 트레이에 남음(S-22에서 끔) | 출시 포함 |
| macOS 알림 센터, Windows 11 위젯 보드 | WG-01\~04 | 출시 뒤(네이티브 확장 필요) |
| iOS·Android 홈 화면 | WG-01\~04 (소·중·대) | 모바일 앱 출시 뒤(네이티브 위젯 확장 필요) |
| iOS 잠금 화면 | WG-05 | 모바일 앱 출시 뒤 |

### 금액 표시

- 위젯은 남이 볼 수 있는 곳이라 기본은 금액 가림: 금액 자리에 같은 크기로 비율·건수·날짜를 보여 줌(“•••” 쓰지 않음). 라벨 옆에 작은 눈 끔 아이콘(Phosphor eye-slash). 이름·D-n은 그대로
- 설정 S-22 “위젯에 금액 보이기”를 켜면 금액 표시. 기기마다 따로
- 앱의 금액 가리기(→ 화면 설계 › 공통)가 켜져 있으면 S-22 설정과 상관없이 위젯도 가림
- 잠금 화면 위젯(WG-05)은 항상 금액 없음
- 앱이 잠겨 있으면(PIN) 위젯은 값 없이 “잠겨 있어요” + “앱 열기”만. 앱에서 금액 가리기를 켜고 끄면 위젯도 바로 같이
- 위젯에는 보는 사람이 앱에서 볼 수 있는 값만 보임(공개 범위·서프라이즈 일정 그대로 적용)

### 갱신

- 앱에서 값이 바뀌면 바로, 그 밖에는 30분마다
- 오프라인이면 마지막 값 + 작은 마지막 저장 시각
- 위젯 데이터는 기기에 암호화 캐시, 로그아웃 시 삭제(→ 보안·개인정보 2장)

### 디자인

- 흰 카드(다크는 기기 설정), radius-2xl, 글꼴 SUIT, 아이콘 Phosphor(굵은 둥근 선)
- 영역 틴트는 위젯 뜻에 맞게: 목표 = goal 틴트, 나머지는 흰 카드
- 진행 막대·단계 표시(stepper) 쓰지 않음. 진행은 % 숫자로만, 원형 게이지는 잠금 화면 WG-05에만
- 브랜드 색(분홍)은 목표 달성 배지에만. 가운데 점(·) 구분 없음

## 홈 화면·잠금 화면 위젯 (WG-01\~05)

> 화면 그림: WG-01~05, 소·중·대 홈 화면 위젯(금액 가림 포함)과 잠금 화면 (그림은 기획서 페이지 사본에 있어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

### WG-01 이번 달 (소)

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 안 나눈 돈 | “이번 달 안 나눈 돈” / “210만 원” | 이번 달 월급 플랜에서 아직 체크 안 한 나누기 줄 합계. 다 하면 “월급을 다 나눴어요”. 누르면 → W-02 |
| 2 | 다음 월급날 | “다음 월급날 25일” | 체크 안 한 나누기 줄 중 가장 가까운 날. 월말 정리 기간에는 이 줄 대신 “월말 정리 D-2”, 누르면 → W-04 |
| 3 | 금액 가림 | “월급 나누기” + 눈 끔 아이콘 / “67%”(큰 숫자) / “3곳 중 2곳 나눴어요” | 큰 숫자 = 이번 달 체크한 나누기 줄 수 ÷ 전체 나누기 줄 수(정수 반올림). 다음 월급날 자리에 곳 수 줄. 다 하면 “월급을 다 나눴어요”, 월말 정리 기간에는 “월말 정리 D-2”. 누르면 → W-02 |
| 4 | 월급 나누기가 없을 때 | “이번 달 남은 생활비” / “32만 원” / “다음 월급날 25일”(월말 정리 기간에는 “월말 정리 D-2”). 금액 가림이면 “생활비 n% 남았어요” | 혼자 쓰기, 배우자 합류 전, “통장 하나로 써요”일 때 1\~3번 대신. 남은 생활비 = 생활비 예산 − 이번 달 변동 항목 입력 합계(고정, 큰 지출 제외), 이번 달 오늘 띠와 같은 규칙(→ 핵심 규칙 › 계산·배분 3장). n% = 남은 생활비 ÷ 생활비 예산(정수 반올림). 음수면 “n만 원 넘었어요”, 예산이 0이면 % 숨김. WG-04 3·4번, WG-05 사각형, 트레이도 이 규칙. 누르면 → W-04j, 월말 정리 기간에는 → W-04 |

## 예외

- 고른 목표가 휴지통·보류로 가면 우선순위 첫 목표로 바뀌고 S-22 선택도 그 목표로
- 앱이 꺼진 상태에서 위젯을 누르면 앱 실행 → 앱 잠금 해제 → 해당 화면. 대상이 지워졌으면 그 목록(G-01·Y-01)
- 세션 만료·다른 계정 로그인이면 위젯 캐시를 지우고 로그인 전 상태
- 트레이 아이콘을 끈 상태에서 앱 창을 닫으면 앱 종료(트레이에 남지 않음)
- 트레이 위젯 값은 앱 창이 열려 있을 때 이번 달 값이 바뀌면 갱신하고, 기기에 마지막 값을 남겨 앱을 다시 켜도 보여 줌. 다가오는 날은 2줄
