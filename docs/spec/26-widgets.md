# 위젯

앱을 열지 않아도 홈의 세 질문(이번 달 월급 정한 대로 나눴지, 저금 얼마나 모았지, 자산 지금 얼마지)과 다가오는 날을 한눈에 보는 작은 창(→ 홈). 숫자 하나가 주인공이고, 누르면 해당 화면으로 바로 이동(딥링크). 위젯 설정 → 설정 S-22. 위젯 화면·문구·상태·이동 화면의 정본은 이 탭(디자인 시스템 위젯 컴포넌트가 이 탭에 맞춤).

## 위젯 v2.2 (2026-11-13, ADR 0009 결정 13)

이 장이 2026-11-13부터 정본. v1(출시)에 모바일 홈 화면 위젯 두 개를 넣음. 위젯 번호 WG-01·WG-04는 출시 전이라 뜻을 바꿔 씀(예전 WG-01 ‘이번 달 월급’, WG-04 ‘우리 한눈에’는 출시 후 목록에서 빠짐, 아래 예전 장은 기록). WG-02·03·05와 잠금 화면 위젯은 출시 후.

| ID | 위젯 | 크기 | 내용 | 누르면 |
| --- | --- | --- | --- | --- |
| WG-01 | 같이 모으기 | 소·중 | 대표 저금(H-10과 같은 core `pickHero`) 이름 + 큰 숫자 진행률 % + 중은 얇은 막대와 “2027년 5월까지” 한 줄 [확인 필요]. 금액은 기본 가림(S-22에서 켜면 모은 금액). 묶음은 합계 기준, 묶음이 ‘퍼센트만 보여 주기’면 금액을 켜도 %만. 목표 금액이 없으면 모은 금액(가림이면 “모으는 중” [확인 필요]) | H-10의 그 저금(W-10) |
| WG-04 | 다가오는 날 | 소 | 가장 가까운 경조사 또는 쓸 곳 메모 날짜 “어머니 생신” + “D-13” [확인 필요]. 메모 금액은 보이지 않음 | Y-05 / W-14 |

- 플랫폼: iOS WidgetKit 확장, Android 홈 화면 위젯(RemoteViews, 2026-11-13 PR 13. Glance 대신, 태블릿 포함). `apps/mobile`만 알고 `packages/app`은 모름(브리지)
- 데이터(2026-11-13 PR 13, 예전 Edge Function `widget-feed` 대신): 앱이 홈 값을 받을 때마다 보여 줄 글만 기기 공유 저장소(iOS App Group, Android 앱 전용 저장소)에 씀. 위젯은 서버를 부르지 않고 토큰·세션을 두지 않음. 그래서 값은 앱을 마지막으로 연 때 것(공개 필터는 앱이 받은 값 그대로). 위젯은 30분마다와 자정에 다시 그려 D-n과 “잠겨 있어요”, 오래된 값 시각만 바꿈
- 금액은 넘기지 않음: S-22 화면이 생길 때까지 늘 가림(라벨 옆 눈 끔 아이콘). 묶음 ‘퍼센트만’과 공개 ‘했어요만’도 같은 %
- 설정 S-22(다시 씀): “위젯에 금액 보이기”(기기마다, 기본 끔) + “위젯에 보일 저금”(기본 = 대표 저금, 계정마다) [확인 필요]. 화면은 아직 없음(위젯은 기본값으로 동작)
- 분석 `widget_added`, `widget_tapped`(아직 없음, PR 14)
- 앱이 잠겨 있으면 “잠겨 있어요” + “앱 열기”만(아래 규칙 그대로). 잠금 시각 = 앱이 잠근 때, 또는 앱이 뒤로 간 뒤 자동 잠금 분(S-15)이 지난 때
- 빈 상태(2026-11-13 PR 13): WG-01 저금이 없으면 라벨 + “무엇을 같이 모을까요?” [확인 필요](H-10 빈 상태 질문), 누르면 → 홈. WG-04 날이 없거나 지났으면 라벨 + “다가오는 날이 없어요”, 누르면 → Y-01. 다 모은 저금은 오렌지 “다 모았어요” 배지(H-10과 같은 말)
- 위젯 고르기 설명(OS 위젯 목록): WG-01 “같이 모으는 저금이 얼마나 모였는지 봐요” [확인 필요], WG-04 “가장 가까운 경조사나 쓸 곳 메모 날짜를 봐요” [확인 필요]
- 글꼴은 기기 기본 글꼴(SUIT는 위젯에 넣지 않음) [확인 필요]

## 규칙

### 목적

- 위젯 하나 = 큰 숫자 하나(저금 항목 목표 금액 %, 이번 달 월급 체크 진행 개수, 순자산 또는 지난달 대비 %, D-n) + 보조 1줄. 입력·수정·체크는 하지 않고 보기와 이동만 [확인 필요]
- 모든 플랫폼에서 위젯 종류와 내용은 같음(WG-01\~05). 플랫폼마다 놓이는 자리만 다름

### 플랫폼별 범위

| 플랫폼 | 위젯 | 시점 |
| --- | --- | --- |
| 데스크톱 (macOS·Windows) | 트레이 아이콘 + 트레이 위젯 창(폭 340px). 앱 창을 닫아도 트레이에 남음(S-22에서 끔) | 없앰 2026-11-10, ADR 0008 |
| macOS 알림 센터, Windows 11 위젯 보드 | WG-01\~04 | 없앰 2026-11-10, ADR 0008 |

| iOS 잠금 화면 | WG-05 | 모바일 앱 출시 뒤 |

### 금액 표시

- 위젯은 남이 볼 수 있는 곳이라 기본은 금액 가림: 금액 자리에 같은 크기로 비율·건수·날짜를 보여 줌(“•••” 쓰지 않음). 라벨 옆에 작은 눈 끔 아이콘(Phosphor eye-slash). 이름·D-n은 그대로
- 설정 S-22 “위젯에 금액 보이기”를 켜면 금액 표시. 기기마다 따로
- 앱의 금액 가리기(→ 화면 설계 › 공통)가 켜져 있으면 S-22 설정과 상관없이 위젯도 가림
- 잠금 화면 위젯(WG-05)은 항상 금액 없음
- 앱이 잠겨 있으면(PIN) 위젯은 값 없이 “잠겨 있어요” + “앱 열기”만. 앱에서 금액 가리기를 켜고 끄면 위젯도 바로 같이
- 위젯에는 보는 사람이 앱에서 볼 수 있는 값만 보임(공개 범위 그대로 적용)

### 갱신

- 앱에서 값이 바뀌면 바로, 그 밖에는 30분마다
- 오프라인이면 마지막 값 + 작은 마지막 저장 시각
- 위젯 데이터는 기기 캐시(금액 없는 글만, OS 파일 보호, 백업 제외), 로그아웃 시 삭제(→ 보안·개인정보 2장). 2026-11-13 v2.2: 앱이 따로 암호화하지 않음(위젯 확장·런처가 읽어야 하고 금액·토큰이 없음)

### 디자인

- 흰 카드(다크는 기기 설정), radius-2xl, 글꼴 SUIT, 아이콘 Phosphor(굵은 둥근 선)
- 영역 틴트는 위젯 뜻에 맞게: 저금 항목 = goal 틴트, 나머지는 흰 카드
- 진행 막대·단계 표시(stepper) 쓰지 않음. 진행은 숫자로만(저금 항목은 %, 월급 체크는 개수), 원형 게이지는 잠금 화면 WG-05에만
- 브랜드 색(오렌지)은 목표 금액 달성 배지에만. 가운데 점(·) 구분 없음

## 홈 화면·잠금 화면 위젯 (WG-01\~05)

> 화면 그림: WG-01\~05, 소·중·대 홈 화면 위젯(금액 가림 포함)과 잠금 화면 (그림은 기획서 페이지 사본에 있어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

### WG-01 이번 달 월급 (소)

금액이 없는 위젯이라 금액 가림과 상관없이 같은 모습.

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 진행 | “10월 월급” / “2개”(큰 숫자) / “5개 중 2개 완료” [확인 필요] | 이번 달 체크리스트에서 체크한 줄 수(여유 자금 줄 제외, → 월급 체크리스트 W-02 진행). 각자 모드는 내 체크리스트, 합쳐서는 공동 체크리스트. 다 하면 “10월 월급 체크를 다 했어요”. 누르면 → W-02 |
| 2 | 다음 월급날 | “다음 월급날 25일” | 내 다음 기준일(합쳐서면 공동 기준일, → 핵심 규칙 › 월 사이클). 월급 전 확인 기간(다음 월급날 3일 전 \~ 전날)에 체크 안 한 줄이 있으면 이 줄 대신 “체크 안 한 게 2개 있어요” [확인 필요], 누르면 → W-05 |
| 3 | 월급이 없을 때 | “월급이 생기면 월급 계획을 만들어 드려요” | O-31에서 ‘지금은 월급이 없어요’를 고른 경우(→ 홈 상태 변형 2번). 누르면 → S-11 |

### WG-04 우리 한눈에 (대)

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 순자산 | “순자산” / “1억 2,220만 원”(큰 숫자) | 금액 가림이면 “순자산” + 눈 끔 아이콘 / 큰 숫자 “지난달보다 +2%”(지난달 말 순자산 대비 증감, 정수 반올림). 순자산이 음수면 “−1,200만 원”, 지난달 순자산이 0 이하면 % 대신 증감 금액(가림이면 “지난달보다 늘었어요”/“줄었어요”). 999억 원을 넘으면 “999억+”. → F-01 |

| 4 | 다음 월급날 | “다음 월급날” / “예빈 10일” | 각자 모드 + 파트너 합류면 두 사람 다음 월급날 중 가까운 날 + 그 사람 이름. 합쳐서·혼자 쓰기·파트너 합류 전이면 “다음 월급날” / “25일”(이름 없음). → W-02 |
| 5 | 저금 항목 2개 | “내 집 마련” / “31%”, “여행” / “58%” | WG-02에서 고른 저금 항목 + 저금 목록 W-13 순서 다음 1개(목표 금액이 있는 것만). 누르면 → W-10 |

### WG-05 잠금 화면 (한 줄·원형·사각형)

OS가 배경화면 위에 단색으로 그림(틴트·브랜드 색 없음). 금액은 어떤 설정에서도 없음.

| 번호 | 요소 | 내용·문구 | 동작·규칙 |

## 예외

- 고른 저금 항목이 휴지통·그만 모음으로 가거나 목표 금액을 지우면 저금 목록 W-13 순서 첫 항목으로 바뀌고 S-22 선택도 그 항목으로
- 앱이 꺼진 상태에서 위젯을 누르면 앱 실행 → 앱 잠금 해제 → 해당 화면. 대상이 지워졌으면 그 목록(W-02·Y-01)
- 세션 만료·다른 계정 로그인이면 위젯 캐시를 지우고 로그인 전 상태
- (없앰 2026-11-10, ADR 0008) 트레이 아이콘을 끈 상태에서 앱 창을 닫으면 앱 종료(트레이에 남지 않음)
- (없앰 2026-11-10, ADR 0008) 트레이 위젯 값은 앱 창이 열려 있을 때 홈 값이 바뀌면 갱신하고, 기기에 마지막 값을 남겨 앱을 다시 켜도 보여 줌. 다가오는 날은 2줄
- 없앤 위젯 내용(2026-10-25 재기획): 안 나눈 돈, 월급 나누기 진행, 이번 달 남은 생활비, 월말 정리 D-n, 받은 제안, 예비부부 결혼 자금 모으기
