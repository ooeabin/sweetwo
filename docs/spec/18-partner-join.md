# 파트너 합류

## 흐름 요약

휴대폰으로 초대 링크를 받은 예빈이 모바일 앱으로(앱이 없으면 스토어 → 설치 → P-01 코드 입력) 들어와 로그인한 뒤 이름, 출생연도, 관리 방식 확인, 내 월급, 월급날만 답하고 홈으로 감. 월급 계획은 추천값으로 만들어 두고 홈 H-03 ‘월급 계획 고치기’에서 고침(할 일 ‘월급 계획 확인’은 2026-11-03 없앰)(2026-11-03, 온보딩 ADR 0005와 같게)(설치 뒤 약 1~2분, 모바일 앱이나 데스크톱 앱에서 끝까지). 결정 이유 → `docs/adr/0003-replan-goal-checklist.md`, 관리 방식·권한 → 핵심 규칙 › 커플·권한.

| 경우 | 경로 |
| --- | --- |
| 기본 | P-01 → P-02 로그인(A-02 → (A-04) → A-05) → (P-02b) → P-03 → P-03a → P-04 → P-05 → P-05b → 홈 |
| 로그인됨, 우리 둘 공간 없음 | P-01 → (P-02b) → P-03 … |
| 혼자 쓰던 기록 있음 (A-07 6번) | P-01 → P-02a → (P-02b: 겹치는 항목 고르기) → P-03 … |
| 찬우가 대신 입력한 예빈 명의 자산·부채 없음 | P-02b 생략 |
| 찬우가 아직 온보딩 중 (월급 계획이 없음) | P-03 → P-03a → P-05 → P-05b → 홈 대기(→ 홈 상태 변형 4). 찬우가 온보딩을 마치면 P-04 → 홈(아래 ‘시작한 사람이 아직 온보딩 중’) |
| 월급이 없음 | P-05 ‘지금은 월급이 없어요’ → P-05b 없이 합류 완료 → 홈 |

- 진행 막대: P-03~P-05b(P-03, P-03a, P-04, P-05, P-05b), 온보딩과 같은 얇은 브랜드 오렌지 막대 하나(ChapterBar, 2026-11-03, 칸 막대에서 바꿈). P-01·P-02는 없음
- ‘나중에 할게요’ 없음
- 결혼 상태, 결혼한 날·예정일(O-11, O-12)은 우리 둘 공간에 하나라 다시 묻지 않음. 출생연도는 사람마다라 P-03a에서 물음
- 합류 완료(P-11)는 따로 화면이 없음: P-05b 저장 순간(월급 없음이면 P-05 저장 순간). 이때 월급 계획을 P-06 추천값 규칙대로 저장하고 첫 체크리스트를 만듦(월급 계획 확인 할 일은 2026-11-03 없앰. 내 저금이 없으면 홈·체크리스트 저금 묶음에 빈 줄 ‘+ 저금 추가’, → 월급 탭 ‘첫 저금’). 이때 초대 코드 ‘사용됨’, 찬우에게 알림 “예빈님이 합류했어요”(→ 화면 설계 › 알림)
- 좁은 창(768px 미만): 1열, 주 버튼 화면 아래 고정(→ 화면 설계 › 공통). 모바일 앱이면 합류 완료 직후 푸시 알림 허용을 1회 물음(P-11 “알림을 받을까요?” / “파트너가 체크하거나 바꾸면 바로 알려 드려요” + ‘알림 받기’(OS 허용 창) / ‘나중에 할게요’ → 홈) [확인 필요]
- 예시값: 찬우 실수령 350만 원, 월급날 25일, ‘각자’, 찬우 저금 항목 내 집 마련(목표 1억 5,000만 원, 기한 2031년 10월 → 월 필요액 246만 원, 찬우 월급 계획 95만) → 예빈 실수령 270만 원, 월급날 10일

## P-01 합류 시작

A-07(로그인·가입)의 진입 화면. 링크 분기·합류 불가 안내는 A-07 그대로.

- 배치(2026-11-03): 다른 질문 화면처럼 제목이 위, 코드는 제목 바로 아래 회색 상자(O-07 코드 상자와 같은 모양), 주 버튼은 아래 끝. 그림(1번)은 제목 위 주인공 자리의 3D 열린 봉투(`scene-invite`, 2026-11-05, 들어올 때 편지가 봉투에서 올라오는 움직임 한 번, 동작 줄이기면 정지). 코드 직접 입력도 제목 위 + 코드 칸 바로 아래. ‘이미 시작한 기록이 있어요’도 제목 위, 아래 바에 회색 보조 ‘취소’ + 주 버튼 ‘합류하기’ 반씩

> 화면 그림: P-01 합류 시작, 데스크톱 앱과 모바일 앱 (그림은 기획서 페이지 사본에 있어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 그림 | 제목 위 주인공 자리 열린 봉투(`scene-invite`, 위 ‘배치’와 같음. 2026-11-08 그림을 지워 2D로 다시 만들 때까지 빈 자리) | 들어올 때 한 번 재생 후 멈춤, 동작 줄이기면 정지. 규칙 → 제품 개요 › 브랜드 3장 그림 움직임 규칙 |

## P-02b 사전 입력 확인·동의

> 화면 그림: P-02b 사전 입력 확인·동의, 데스크톱 앱과 모바일 앱 (그림은 기획서 페이지 사본에 있어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 제목 | “찬우님이 미리 적어 둔 내 정보가 있어요” | — |
| 2 | 항목 목록 | 항목명 + 금액, 추정값은 ‘추정’ | 대상 = 예빈 명의 자산·부채만. 혼자 쓰던 기록과 겹치는 항목은 “내 기록 1,200만 원 / 찬우님 값 1,000만 원” 중 고름 |

| 4 | 보조 링크 | “지우고 새로 입력할게요” | 목록 항목 삭제. 필요하면 나중에 우리 자산 탭에서 직접 추가 |

- 동의 전에 이탈: 항목은 ‘대신 입력’ 그대로, 다음 접속 때 이 화면부터

## P-02a 혼자 쓰던 기록 옮기기

A-07 6번(혼자 시작한 기록 있음)에서 ‘합류하기’를 누른 사람만. 내 명의 사실값만 옮기고 공개 범위를 한 번 정함.

> 화면 그림: P-02a 혼자 쓰던 기록 옮기기 (그림은 기획서 페이지 사본에 있어요. 구현할 때 이 문서의 요소 표가 기준이에요.)

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 제목 | “내 정보만 옮겨요” | — |
| 2 | 옮길 항목 | “옮겨요” [확인 필요] + 목록: “월급” + 보조 “월급날 10일” + 금액, 내 명의 자산·부채 줄(이름 금액) + 오른쪽 공개 범위 “모두 보여 주기” / “금액만 보여 주기”(기본 금액만). 줄을 누르면 시트 “{이름} 공개 범위”에서 고름(2026-11-03, 기본 드롭다운 대신) | 월급은 공개 범위 없음(월급 계획에 씀, → 핵심 규칙 › 커플·권한 6장). 자산·부채 기본 ‘금액만 보여 주기’ |
| 3 | 안 옮기는 기록 | “안 옮겨요” + 목록 “저금 항목” [확인 필요] “월급 계획” “체크리스트” 줄마다 “1개” + 아래 “30일 보관 후 지워져요” 옆 ‘사본 내려받기’ | 원래 공간은 30일 보관 후 삭제, 그동안 사본(S-18 ‘내 데이터’ 엑셀) 내려받기 가능 |
| 4 | 주 버튼 | “다음” | 옮긴 월급·월급날은 P-05 초기값. 찬우가 대신 입력한 값과 겹치면 P-02b로 |

- 옮길 내 명의 값이 없으면 2번 대신 “옮길 정보가 없어요”, 3번만 표시

## P-06 월급 계획

2026-11-03부터 합류 흐름에서 이 화면은 보이지 않음(온보딩 O-50과 같게). 아래 추천값과 다시 채우는 규칙으로 합류 완료 때 자동 저장하고, 예빈은 홈 H-03 ‘월급 계획 고치기’ → W-01에서 고침(2026-11-03 할 일 ‘월급 계획 확인’은 없앰). 합쳐서면 찬우 알림은 그대로. 저장하는 사이 찬우가 공동 월급 계획을 고쳤으면 새 값으로 다시 계산해 저장. 아래 표는 예전 화면(이 화면에서 멈춘 사람만 봄)과 추천값 기준.

O-50과 같은 틀(수입 줄, 저금 묶음, 쓰는 돈 묶음, 줄 추가, 남는 돈). 관리 방식에 따라 내용이 다름. 금액은 모두 1만 원 단위 반올림, 남는 돈이 음수일 때 표시는 O-50과 같음.

### 각자: 예빈 월급 계획 만들기

추천값(처음 채우는 값) [확인 필요]

| 줄 | 추천값 |
| --- | --- |
| 고정지출 | 예빈 실수령 × 25% (O-50과 같음). 각자 방식에서 고정지출을 한 사람이 다 내는 두 사람도 있어 이 값이 맞는지 [확인 필요] |
| 생활비 | 예빈 실수령 × 25% |

### 합쳐서: 공동 월급 계획 확인

| 번호 | 요소 | 내용·문구 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 진행 표시 | 막대 끝까지 | — |
| 2 | 제목·보조 | “같이 쓰는 월급 계획이에요” [확인 필요] / “예빈님 월급을 더해 다시 채웠어요” [확인 필요] | — |
| 3 | 수입 줄 | “월급 620만 원” + 아래 회색 “찬우 350만 원, 예빈 270만 원” [확인 필요] | 두 사람 실수령 합 |
| 4 | 저금 묶음 | 줄마다 새 금액 + 바뀐 줄은 회색 이전 값(“95만 원 → 246만 원”) | 아래 다시 채우는 규칙 |
| 5 | 쓰는 돈 묶음 | 찬우가 정한 고정지출·생활비·찬우 용돈 그대로 + “예빈 용돈” 줄 추가 | 예빈 용돈 추천값 = 예빈 실수령 × 10% |
| 6 | 줄 추가, 금액 | O-50과 같음 | 예빈도 모든 줄을 고칠 수 있음 |
| 7 | 남는 돈 | “남는 돈 88만 원” | 자동 |
| 8 | 주 버튼 | “이대로 저장하기” | 저장 = 합류 완료 → 홈. 공동 월급 계획이 바뀜, 찬우 알림. 이번 사이클 체크리스트에 예빈 용돈 줄과 늘어난 저금 금액을 바로 더함(체크한 줄은 그대로, → 핵심 규칙 › 월 사이클 3장) |

다시 채우는 규칙 [확인 필요]

- 찬우가 정한 줄(고정지출, 생활비, 찬우 용돈, 저금 금액)은 줄이지 않음
- 늘어난 수입에서 예빈 용돈을 빼고 남은 금액을 저금 묶음 순서대로, 목표 금액과 기한이 있는 저금 항목의 월 필요액까지 저금 줄에 더함. 그래도 남으면 남는 돈
- 찬우가 각자일 때 만든 저금 항목 줄은 “찬우 {이름}”으로 공동 월급 계획에 그대로 있음(→ 월급 탭 ‘저금 항목’)
- 예시(620만 원): 고정지출 88만, 생활비 88만, 찬우 용돈 35만, 예빈 용돈 27만, 내 집 마련 95만 → 246만, 남는 돈 136만

## 시작한 사람이 아직 온보딩 중

찬우가 초대만 보내고 온보딩을 마치기 전(월급 계획이 없음)에 예빈이 합류한 경우.

| 번호 | 단계 | 내용 | 동작·규칙 |
| --- | --- | --- | --- |
| 1 | 합류 | P-03 → P-03a → P-05 → P-05b | P-04는 건너뜀. P-05b 저장 = 합류 완료(초대 코드 ‘사용됨’, 찬우 알림) |
| 2 | 홈 대기 | 인사 “{나}님이 시작하고 있어요” / 카드 “{나}님이 월급 계획을 만들면 알려 드릴게요” [확인 필요] | → 홈 상태 변형 4. {나} = 찬우 이름 |
| 3 | 찬우 온보딩 | 찬우 O-30·O-31·O-50 | 합쳐서면 O-50 수입 = 두 사람 합, 예빈 용돈 줄 포함(→ 온보딩 ② O-50 2번, 4번). 각자면 찬우 월급만 |
| 4 | 알림 | 찬우가 O-60을 마치면 예빈에게 “찬우님이 월급 계획을 만들었어요” [확인 필요] | 알림 종류 → 화면 설계 › 알림 |
| 5 | 이어서 | 예빈이 다음에 앱을 열면 P-04 → 홈 [확인 필요] | P-04 저장 때 월급 계획 저장. 각자: 예빈 월급 계획을 추천값으로 만듦(홈 H-03 ‘월급 계획 고치기’에서 고침). 합쳐서: 찬우가 이미 두 사람 합으로 만든 공동 월급 계획 그대로 |

- 예빈이 답한 이름, 출생연도, 월급, 월급날, 내 명의 항목은 바로 저장
- 찬우 온보딩에는 예빈 월급을 묻는 화면이 없음(합쳐서면 예빈이 넣은 값을 씀)

## 합류 뒤

- 찬우에게 알림 “예빈님이 합류했어요”(→ 화면 설계 › 알림)
- 찬우가 대신 입력한 예빈 명의 자산·부채는 P-02b 확인 뒤 소유가 예빈으로 넘어가 예빈이 수정·삭제(→ 핵심 규칙 › 커플·권한 3장)
- 홈: 각자 방식이면 찬우 홈 체크리스트 카드 아래 “예빈님 3개 중 0개”(→ 홈 H-03)
- 모바일 앱이면 첫 홈 상단에 1회 “PC에서도 같은 계정으로 쓸 수 있어요” + ‘데스크톱 앱 받기 링크 보내기’(알림 이메일로 L-02 주소) / 닫기 [확인 필요]. 보내면 Toast “알림 이메일로 링크를 보냈어요” [확인 필요]. 메일은 본인이 눌러 받는 안내라 알림 메일 설정·상한과 상관없이, 하루 한 번(`send_desktop_link`)

예외·오류

- 합류 도중 찬우가 월급 계획을 고침: 합쳐서면 P-06을 열 때의 공동 월급 계획 기준으로 다시 채움. 저장 직전 바뀌었으면 “찬우님이 방금 월급 계획을 바꿨어요” [확인 필요] 후 다시 계산한 값으로 보여 줌
- 남는 돈이 음수: O-50과 같이 “{n}만 원이 모자라요” + 안내, 주 버튼은 막지 않음
