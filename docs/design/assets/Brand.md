# Brand

브랜드 이름은 sweeTwo(스위투). 워드마크는 둥근 붓 필기체 “sweeTwo”. 앱 아이콘과 파비콘은 브랜드 오렌지 바탕에 흰 워드마크 ‘Two’(2026-11-06). 심볼도 같은 그림(파이 차트는 없앰). 어드민 안에서는 워드마크를 잉크로(밝은 화면 검정, 다크 화면 흰색, `Wordmark ink`, 2026-11-06).

- `logo-cherry.svg`: 워드마크 기본(`brand` #FF7716, 심볼 원 고리 색). 흰 바탕과 다크 바탕 모두. T와 w 사이는 다른 글자 사이와 같은 간격.
- `logo-white.svg`: 오렌지 바탕이나 사진 위.
- `logo-black.svg`: 한 가지 색만 되는 인쇄물.
- 앱 아이콘 그림(2026-11-06 바꿈): 브랜드 오렌지(`brand` #FF7716) 꽉 찬 바탕 위에 흰 워드마크 ‘Two’(logo-cherry.svg의 뒤 세 글자 T·w·o, 그대로 흰색). 컬리처럼 워드마크 글자를 아이콘으로 씀. Two 폭은 아이콘 폭의 74%, 가운데. Android 적응형 전경은 안전 영역 때문에 폭 48%(바탕은 `ic_launcher_background` #FF7716), 원형 아이콘 66%, 파비콘·트레이는 앱 아이콘과 같은 비율(74%)에 둥근 사각. 모두 `scripts/brand-icons/two.py`가 워드마크 벡터에서 만듦(AI로 다시 그리지 않음). 뜻: 둘(Two)이 함께. 예전 파이 차트 아이콘은 작게 줄이면 알아보기 어려워서 버림(레퍼런스 비교 후, 빗썸·토스·카카오 등 한국 앱 65개)
- `app-icon.png`: 앱 아이콘 원본(1024px, 꽉 찬 정사각형, 오렌지 바탕 흰 Two). iOS·Android는 이 파일을 줄여서 씀. 모서리는 각 OS가 깎음.
- `app-icon-macos.png`: Mac 독용(1024px). Mac은 모서리를 깎아 주지 않아 둥근 사각형(824px), 여백, 그림자를 파일에 넣음.
- `symbol.svg`, `symbol.png`: 심볼(2026-11-06): 앱 아이콘과 같은 오렌지 둥근 사각 + 흰 ‘Two’. symbol.png(512, 모서리 투명), symbol.svg(같은 그림 벡터, 둥근 사각 rx 230/1024). 랜딩(L-01) 첫 화면, 공유 이미지에 씀. 파이 차트는 모두 없앰.
- `favicon-32.png`, `favicon-48.png`: 브라우저 탭 아이콘(오렌지 둥근 사각 + 흰 Two, 2026-11-06). `apple-touch-icon.png`: 홈 화면에 추가할 때(180px, 앱 아이콘과 같음).
- 체리 타르트 그림(장면 그림·영상)은 모두 없앰(2026-10-19). O-01 시작·A-02 로그인 첫 화면 장면 자리에는 영어 워드마크(`Wordmark`, 높이 40px) + 캐치프레이즈 한 줄(20px 700) + 회색 보조 2줄을 세로 가운데에 둔다(2026-11-02, 당근 시작 화면처럼).
- 화면 안 로고는 `hg-wordmark`(마스크, `brand` 칠, 기본 높이 24px, 큰 자리와 로그인 첫 화면 히어로 40px, 트레이 20px).
- 금지: 다시 그리기, 늘이기, 기울이기, 색 바꾸기(워드마크는 브랜드 오렌지, 흰색, 검정만), 워드마크와 평면 심볼에 그림자, 외곽선. Two 글자 모양 바꾸기(워드마크 그대로). 브랜드 색 말고 다른 색 넣기.
- 여백: 로고 높이의 1/2 이상. 최소 높이 워드마크 16px, 심볼 16px.
- 상태: 앱 아이콘 2026-11-06 ‘Two’로 바꿈(이전: 2026-10-13 확정, 2026-10-25 브랜드 오렌지 한 색, 틈 2배·크러스트 1.4배, 앱 아이콘 계열은 무광 3D로 바꿈). 설치 파일용 .icns/.ico와 macOS 트레이 템플릿(한 색 실루엣)은 개발할 때 만듦.
