# Brand

브랜드 이름은 sweeTwo(스위투). 워드마크는 둥근 붓 필기체 “sweeTwo”. 브랜드 상징은 파이 차트(원 고리 + 빠져나온 파이 조각, 평면). 앱 아이콘과 심볼이 같은 그림.

- `logo-cherry.svg`: 워드마크 기본(`brand` #FF6F0F, 심볼 원 고리 색). 흰 바탕과 다크 바탕 모두. T와 w 사이는 다른 글자 사이와 같은 간격.
- `logo-white.svg`: 오렌지 바탕이나 사진 위.
- `logo-black.svg`: 한 가지 색만 되는 인쇄물.
- 앱 아이콘 그림: 평면 파이 차트: 두꺼운 원 고리(`brand` #FF6F0F)와 오른쪽 아래로 빠져나온 파이 조각 하나. 조각은 끝이 원 가운데를 향한 삼각형 몸통(연주황 #FFB380)과 얇은 틈 뒤 둥근 크러스트 띠(진주황 #C2410C). 그라데이션, 그림자, 입체감, 글자 없음. 바탕 흰색, 그림은 아이콘 정가운데, 긴 쪽이 아이콘의 약 78%.
- `app-icon.png`: 앱 아이콘 원본(1024px, 꽉 찬 정사각형, 흰 바탕). iOS·Android는 이 파일을 줄여서 씀. 모서리는 각 OS가 깎음.
- `app-icon-macos.png`: Mac 독용(1024px). Mac은 모서리를 깎아 주지 않아 둥근 사각형(824px), 여백, 그림자를 파일에 넣음.
- `symbol.svg`: 심볼 원본(벡터, 세 색 #FF6F0F, #FFB380, #C2410C). 아래 PNG는 모두 이 SVG에서 만듦.
- `symbol.png`: 심볼. 앱 아이콘과 같은 파이 차트, 바탕 없음(512px). 작은 자리(알림, 프로필 자리, 트레이, SNS 공유 이미지, 랜딩).
- `favicon-32.png`, `favicon-48.png`: 브라우저 탭 아이콘(파이 차트, 바탕 없음). `apple-touch-icon.png`: 홈 화면에 추가할 때(180px, 앱 아이콘과 같음).
- 체리 타르트 그림(장면 그림·영상)은 모두 없앰(2026-10-19). O-01 시작·A-02 로그인 첫 화면 장면 자리에는 영어 워드마크(`Wordmark`, 높이 56px 히어로) + 캐치프레이즈를 크게 넣어 당당한 첫인상을 준다.
- 화면 안 로고는 `hg-wordmark`(마스크, `brand` 칠, 기본 높이 24px, 큰 자리 40px, 로그인 첫 화면 히어로 56px, 트레이 20px).
- 금지: 다시 그리기, 늘이기, 기울이기, 색 바꾸기(워드마크는 브랜드 오렌지, 흰색, 검정만), 그림자, 외곽선. 앱 아이콘에 글자 넣기. 파이 조각에 장식(점, 구멍, 별) 더하기. 세 부분의 색 바꾸기.
- 여백: 로고 높이의 1/2 이상. 최소 높이 워드마크 16px, 심볼 16px.
- 상태: 앱 아이콘 확정(2026-10-13), 2026-10-25 색만 오렌지 계열로 바꿈(모양 그대로, PNG는 기존 파일의 세 색을 바꿔 다시 만듦). 설치 파일용 .icns/.ico와 macOS 트레이 템플릿(한 색 실루엣)은 개발할 때 만듦.
