# Brand

브랜드 이름은 sweeTwo(스위투). 워드마크는 둥근 붓 필기체 “sweeTwo”. 브랜드 상징은 체리를 얹은 케이크 조각(3D). 앱 아이콘과 심볼이 같은 그림.

- `logo-cherry.svg`: 워드마크 기본(`logo` #E8344F, 심볼 케이크 조각의 분홍빛). 흰 바탕과 다크 바탕 모두. T와 w는 붙여 씀.
- `logo-white.svg`: 체리 바탕이나 사진 위.
- `logo-black.svg`: 한 가지 색만 되는 인쇄물.
- 앱 아이콘 그림: 비스듬히 본 케이크 조각 하나. 앞은 뾰족, 뒤는 둥근 크러스트, 옆면에 연분홍 크림 층 두 줄, 윗면에서 흘러내린 크림 한 방울, 위에 꼭지 짧은 체리 한 알. 케이크는 체리 계열 그라데이션(밝은 체리 → `brand` → 짙은 체리), 크림은 연분홍, 바탕 흰색, 그림자 없음. 케이크는 아이콘 정가운데, 긴 쪽이 아이콘의 약 78%. 말랑한 3D.
- `app-icon.png`: 앱 아이콘 원본(1024px, 꽉 찬 정사각형, 흰 바탕). iOS·Android는 이 파일을 줄여서 씀. 모서리는 각 OS가 깎음.
- `app-icon-macos.png`: Mac 독용(1024px). Mac은 모서리를 깎아 주지 않아 둥근 사각형(824px), 여백, 그림자를 파일에 넣음.
- `symbol.png`: 심볼. 앱 아이콘과 같은 케이크 조각, 바탕 없음(512px). 작은 자리(알림, 프로필 자리, 트레이, SNS 공유 이미지, 랜딩).
- `favicon-32.png`, `favicon-48.png`: 브라우저 탭 아이콘(케이크 조각, 바탕 없음). `apple-touch-icon.png`: 홈 화면에 추가할 때(180px, 앱 아이콘과 같음).
- 체리 타르트 실사는 A-02 로그인 첫 화면 장면 그림으로만 남음(Illustrations `scene-tart`).
- 화면 안 로고는 `hg-wordmark`(마스크, `logo` 칠, 기본 높이 24px, 큰 자리 40px, 트레이 20px).
- 금지: 다시 그리기, 늘이기, 기울이기, 색 바꾸기(워드마크는 케이크 분홍, 흰색, 검정만), 그림자, 외곽선. 앱 아이콘에 글자 넣기. 케이크 조각에 장식(점, 별) 더하기.
- 여백: 로고 높이의 1/2 이상. 최소 높이 워드마크 16px, 심볼 16px.
- 상태: 앱 아이콘 확정(2026-10-13). 설치 파일용 .icns/.ico와 macOS 트레이 템플릿(한 색 실루엣)은 개발할 때 만듦.
