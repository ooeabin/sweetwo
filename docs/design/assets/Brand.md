# Brand

브랜드 이름은 sweeTwo(스위투). 워드마크는 둥근 붓 필기체 “sweeTwo”. 브랜드 상징은 파이 차트(원 고리 + 빠져나온 파이 조각). 앱 아이콘은 무광 3D, 작은 자리는 평면. 앱 아이콘과 심볼이 같은 그림.

- `logo-cherry.svg`: 워드마크 기본(`brand` #FF6F0F, 심볼 원 고리 색). 흰 바탕과 다크 바탕 모두. T와 w 사이는 다른 글자 사이와 같은 간격.
- `logo-white.svg`: 오렌지 바탕이나 사진 위.
- `logo-black.svg`: 한 가지 색만 되는 인쇄물.
- 앱 아이콘 그림: 파이 차트: 두꺼운 원 고리(`brand` #FF6F0F)와 오른쪽 아래로 빠져나온 파이 조각 하나. 조각은 끝이 원 가운데를 향한 삼각형 몸통과 틈 뒤 둥근 크러스트 띠. 고리, 몸통, 크러스트 모두 `brand` 한 색이고 흰 틈으로만 나뉨. 틈은 작게 줄여도 보이게 넓게(심볼 좌표 80, 고리 바깥 반지름 694 기준), 크러스트 두께 170. 앱 아이콘 계열(app-icon, app-icon-macos, apple-touch, symbol.png, og)은 말랑 점토 3D(Blender 렌더): 둥근 모서리와 둥근 단면, 반무광. 그늘은 브랜드 색(#FF6F0F) 그대로이고 왼쪽 위 빛을 받는 곳만 밝은 살구빛으로 올라감(검정·갈색 음영과 바닥 그림자 없음). 흰 바탕. 심볼은 아이콘 폭의 72%, 바운딩 박스 가운데. Android 적응형 아이콘은 가운데 66%만 안전해서 전경을 따로 폭 62%로 만듦(모바일 앱 아이콘 작업 때). 파비콘(16~48px)과 symbol.svg는 같은 형상의 평면 한 색. 모두 `scripts/brand-icons/build.py`가 형상 수치에서 만듦(3D는 `blender_scene.py`, AI로 다시 그리지 않음). 글자 없음.
- `app-icon.png`: 앱 아이콘 원본(1024px, 꽉 찬 정사각형, 흰 바탕). iOS·Android는 이 파일을 줄여서 씀. 모서리는 각 OS가 깎음.
- `app-icon-macos.png`: Mac 독용(1024px). Mac은 모서리를 깎아 주지 않아 둥근 사각형(824px), 여백, 그림자를 파일에 넣음.
- `symbol.svg`: 평면 심볼 벡터(한 색 #FF6F0F, 호 3개). 형상 원본은 `scripts/brand-icons/geom.py`의 수치.
- `symbol.png`: 3D 심볼. 앱 아이콘과 같은 파이 차트, 바탕 없음(512px, 그림자 없음). 작은 자리(알림, 프로필 자리, 트레이, SNS 공유 이미지, 랜딩).
- `favicon-32.png`, `favicon-48.png`: 브라우저 탭 아이콘(평면 파이 차트, 바탕 없음). `apple-touch-icon.png`: 홈 화면에 추가할 때(180px, 앱 아이콘과 같음).
- 체리 타르트 그림(장면 그림·영상)은 모두 없앰(2026-10-19). O-01 시작·A-02 로그인 첫 화면 장면 자리에는 영어 워드마크(`Wordmark`, 높이 56px 히어로) + 캐치프레이즈를 크게 넣어 당당한 첫인상을 준다.
- 화면 안 로고는 `hg-wordmark`(마스크, `brand` 칠, 기본 높이 24px, 큰 자리 40px, 로그인 첫 화면 히어로 56px, 트레이 20px).
- 금지: 다시 그리기, 늘이기, 기울이기, 색 바꾸기(워드마크는 브랜드 오렌지, 흰색, 검정만), 워드마크와 평면 심볼에 그림자, 외곽선. 앱 아이콘에 글자 넣기. 파이 조각에 장식(점, 구멍, 별) 더하기. 브랜드 색 말고 다른 색 넣기.
- 여백: 로고 높이의 1/2 이상. 최소 높이 워드마크 16px, 심볼 16px.
- 상태: 앱 아이콘 확정(2026-10-13), 2026-10-25 브랜드 오렌지 한 색, 틈 2배·크러스트 1.4배, 앱 아이콘 계열은 무광 3D로 바꿈. 설치 파일용 .icns/.ico와 macOS 트레이 템플릿(한 색 실루엣)은 개발할 때 만듦.
