# Tooltip

용어·아이콘 짧은 설명. 마우스를 올리거나 포커스하면 200ms 뒤에 뜸.

- 소비자가 주는 것: 설명 1~2줄(최대 240px).
- `ink` 바탕 + `on-ink` 글자, 꼬리 하나. 버튼·링크는 넣지 않음(필요하면 Modal).
- 좁은 창에서는 누르면 열리고 바깥 누르면 닫힘. 설명이 필요한 용어 옆에 `circle-help` 아이콘.

## 차트 툴팁(`hg-tip`)

- 차트 위 마우스·포커스 지점 옆. 작은 월(`i`) → 굵은 값(`b`, 15px) → 작은 비교 값(`i`), 줄 바꿈으로 구분. 가운데 점 금지.
- 꼬리 없음, `ink` 바탕, `pointer-events: none`. 차트 영역 밖으로 나가면 왼쪽으로 뒤집음.
- 키보드: 차트에 포커스 후 ←/→로 점 이동, 같은 툴팁.
