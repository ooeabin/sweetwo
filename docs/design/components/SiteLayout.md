# SiteLayout

웹사이트 틀(L 화면). 사이트 상단 바, 본문 구획, 하단으로 된 공개 페이지 틀. 앱 메뉴 줄 없이 같은 토큰과 컴포넌트를 씀.

- 소비자가 주는 것: 접속 OS(Mac, Windows, 휴대폰, 모름, 지원 안 함), 페이지 내용(구획 목록), 릴리스 노트 버전 목록, 약관 시행일 목록, 사업자 정보.
- 너비: 본문 최대 `site-max` 1200px(`hg-site__wrap`), 좌우 여백 `space-6`(좁은 창 `space-4`). 넓은 창 2단(`hg-site__hero`, `hg-site__two`), 768px 미만 1단. 3열 기능, 4칸 안심도 좁은 창에서 1열.
- 상단 바(`hg-site__bar`, 64px): 왼쪽 워드마크(`hg-wordmark`, 누르면 맨 위) → 오른쪽 “자주 묻는 질문”(`hg-btn--ghost`, L-06) + “웹에서 시작하기”(`hg-btn--secondary hg-btn--sm`, 웹 앱 A-01). 좁은 창은 워드마크와 “웹에서 시작하기”만.
- 첫 화면(`hg-site__hero`): 왼쪽 큰 제목(`hg-site__h1`, 40px, 좁은 창 28px)에 캐치프레이즈 “함께 구워 더 달콤한 자산파이” → (보조 1줄 `hg-site__lead`는 필요할 때만, 기능 설명 문장) → 다운로드 주 버튼 1개 → 글자 링크 “다른 OS용 받기” + “macOS 12 이상, Windows 10 64비트 이상에서 쓸 수 있어요”(`hg-site__os`). 오른쪽(좁은 창은 아래) 앱 화면 이미지(라이트 캡처, 흰 카드 위).
- 다운로드 버튼은 OS를 알아서 하나만: Mac “Mac용 다운로드”(`apple-logo`), Windows “Windows용 다운로드”(`windows-logo`), 휴대폰, 모름 “웹에서 시작하기”. 지원하지 않는 OS는 버튼 대신 “이 기기에서는 앱을 쓸 수 없어요. 웹에서 시작할 수 있어요” + “웹에서 시작하기”. “다른 OS용 받기”를 누르면 두 OS 버튼(보조)을 펼침.
- 한 페이지에 주 버튼(`ink`)은 첫 화면 하나와 같은 내용의 마지막 다운로드 하나. 나머지는 보조나 글자 링크.
- 구획(`hg-site__sec`): 제목(`hg-site__h2`, 28px) → 내용. 구획 사이 `space-16`(좁은 창 `space-10`) + `hairline-soft` 선.
  - 기능 3개(`hg-site__cols` + `hg-site__feature`): 제목 1줄 + 설명 1줄.
  - 둘이 쓰는 법(`hg-site__steps`): 번호 원(32px, `ink` 테두리) + 1줄. 진행 막대 없음.
  - 안심 4가지(`hg-site__safe`): 아이콘 24px + 1줄.
- 설치 안내(L-02): “다운로드를 시작했어요” → 설치 3단계(`hg-site__steps--col`) → 접기 1개 “보안 경고가 뜨나요?”(Accordion, 기본 접힘, OS에 맞는 안내만) → “설치 없이 웹에서 계속하기”.
- 릴리스 노트(L-03, `hg-release`): 버전마다 바로가기 주소(`id="1.2.0"`, `/releases#1.2.0`), 버전(18px 600 링크) + 날짜 → 묶음 “새 기능”, “고친 것” → 해요체 1줄씩. 최신순.
- 약관(L-05): 제목 + “시행일 {날짜}” → 본문 → “이전 버전” 목록(ListRow 링크, 시행일). 이전 버전을 보면 위에 글자 링크 “지금 버전 보기”.
- 하단(`hg-site__foot`): 링크 “이용약관”, “개인정보처리방침”(굵게, `is-strong`), “고객센터”, “상태 페이지” → 고객센터 메일 help@sweetwo.kr → 사업자 정보(상호, 대표, 사업자등록번호, 주소를 `hg-meta` 이름표 줄로, 값은 출시 준비 문서) → “sweeTwo는 입력한 숫자로 계산한 참고 정보를 보여드려요. 투자·금융 자문이 아니에요”.
- 브랜드 색은 워드마크에만. 분홍 버튼, 분홍 띠, 분홍 카드 없음. 다크 모드는 기기 설정, 앱 화면 이미지와 실사 그림은 다크에서도 흰 카드 위.
- 페이지 제목은 “{페이지 이름} - sweeTwo”(기획서 28 공통), 랜딩만 “sweeTwo | 함께 구워 더 달콤한 자산파이”. 캐치프레이즈는 이 문구 하나만 씀(다른 표어를 만들지 않음).

쓰는 곳: 웹사이트 L-01 랜딩, L-02 설치 안내, L-03 릴리스 노트, L-05 약관과 개인정보처리방침, L-06 고객센터.
