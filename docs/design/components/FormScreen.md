# FormScreen

온보딩 밖에서 쓰는 입력을 한 화면에 쌓는 틀(2026-11-23 사용자 결정). 예전 단계형(진행 막대 + 한 화면 한 질문, QuestionLayout)을 대신함. 레퍼런스: 카카오페이 주식 모으기(맨 위 문장이 고르는 대로 바뀜), PocketCU 예약 충전(질문마다 칩 + 입력을 한 화면에 쌓음). **온보딩(O-xx)과 파트너 합류(P-xx)의 단계형은 QuestionLayout 그대로.**

- 쓰는 곳: W-11 저축·투자 추가, W-01e 지출 추가, F-03 자산·부채 추가, F-04b 팔았어요, F-04a 만기 정리(2026-11-24). 다음에 같은 틀로 옮길 입력: W-20 수입 적기, W-10b 바로잡기, W-10c 잔액 맞추기, W-14a 쓸 곳 메모, W-01b 낼 몫 정하기.
- 앱 틀(탭, 사이드바) 없이 `hg-qmain` 한 열(최대 480px)에 `hg-form`. 안전 영역은 `hg-qmain`이 처리.
- 머리: `PageHeader`(‹ 왼쪽 + 가운데 제목 17px 700, 넓은 창은 ‘‹ 이전’ + 제목). 제목은 “저축·투자 추가”처럼 하는 일. Esc = ‹(시트가 열려 있으면 시트만 닫음).
- 요약 문장(`FormHero`, `hg-form__hero`): `title-1` 22px 700, 줄마다 `hg-form__heroline`. 이름 자리는 `ink`(오렌지 아님, 사용자 결정), 금액 자리만 `accent-app-text`(`hg-form__val`, 대비 예외: 14px 이상 700 짧은 말). 아직 안 고른 자리는 자리표시 문장. `aria-live="polite"`.
- 날짜(2026-11-24, 2026-11-26 휠은 앱에서 모두 없앰, PickSheet.md): 폼에는 연·월·일 휠을 펼쳐 두지 않고 한 줄 `DateField`(회색 판 “2026년 11월 26일 (목)” + ›) → 누르면 달력 시트 `DateSheet`(`DateSheet.md`). 접힌 줄(FormFold)의 만기일 시트도 같은 달력 시트.
- 질문 섹션(`FormSection`): 제목 15px 700 + 오른쪽 보조 글자(`body-sm` `slate`, 예 “미계획 금액 90만 원”) + 칩 묶음(`hg-form__chips`, 작은 칩 `Chip small`, 고르면 옅은 오렌지 판) 또는 입력. 섹션 사이 32px, 제목과 내용 사이 12px(2026-11-24 ‘영역 간격’, DESIGN.md).
- 금액(`FormAmount`): 좁은 창(768px 미만)은 칸(`hg-form__amountbtn`, 32px 700 + 원)을 누르면 기존 키패드(AmountInput)가 `BottomSheet`로 올라오고 ‘확인’으로 반영(화면 안에 키패드를 두면 요약 문장과 주 버튼이 가려지고, 한 화면에 입력이 여럿이라 OS 자판도 같은 문제라서 시트). 첫 숫자가 미리 채운 값을 덮어쓰고 999억 상한 흔들림은 AmountInput 규칙 그대로. 넓은 창은 칸에 바로 입력(`AmountInput embedded`). 빠른 칩은 두 경우 모두 칸 아래(고른 표시 없이 늘 회색).
- 글자 칸(`ShortText`, 2026-11-24 사용자 결정): FormScreen 안에서는 테두리 상자 없이 금액 칸처럼 아래 2px `ink` 밑줄 한 줄(`.hg-form input.hg-input`, 높이 48, 오류는 `danger` 밑줄, 포커스는 사각 박스 없이 같은 밑줄 그대로, 2026-11-24 구역 4). 이름 칸(F-03, Y-07, W-14a 등) 모두 같음.
- 빠른 금액 칩(`+10만`, `10만 원`, 2026-11-24): 누르면 더하거나 바꾸기만 하는 버튼이라 고른 표시(`is-selected`, 오렌지) 없이 늘 회색, `aria-pressed` 없음.
- 구간 선택(`SegChoice`, Tabs.md): 2~3개 중 하나(‘어떻게 챙겨요?’). 너비 꽉 참, `role="radiogroup"`.
- 선택 항목(`FormFolds` + `FormFold`): 회색(`surface-alt`) 8px 구분 띠(창 너비 꽉 참, 띠 위는 앞 섹션의 32, 띠 아래 첫 줄까지 12) 아래 접힌 줄 56px(이름 + 오른쪽 값 또는 “정하기 ›”). 누르면 기존 금액·칸 시트(`BottomSheet`, 연·월은 `PickSheet`). 값이 있으면 ink 600.
- 아래 고정 주 버튼: `StickyBar`(토스트가 가리지 않게 `--hg-bottom-bar-h` 연동). 필수가 안 채워지면 비활성. Enter(입력 칸 안)로도 제출. 버튼 윗변 위 32px(`--gap-area`)는 바탕색으로 채워 스크롤 중에도 입력·칩이 버튼에 붙어 보이지 않고, 그 위 16px은 투명 → 바탕 그라데이션(`.hg-stickybar::before`). 스크롤 끝에서도 마지막 내용과 버튼 사이 32 이상. 같은 규칙이 `.hg-page > .hg-stickybar`(W-02 등)에도 적용(2026-11-24).
- 지키는 것: 다크 모드(토큰), 좁은 창, ‘동작 줄이기’(요약 색 전환만 `dur-fast`), 키보드만으로 쓰기(구간·칩·접힌 줄 모두 버튼), 누르는 칸 44px 이상(터치에서 구간 44px, 접힌 줄 56px), 안전 영역.

- 자산 입력(2026-11-24, 시안 `work/w02-design/f03form2.html`): F-03은 요약 문장 + 자산/부채 밑줄 탭(`LineTabs`) + 종류 칩 두 줄 + 이름 + 지금 금액(오른쪽 보조 “잘 모르겠어요” → 시트) + 명의 고르기 + (처음이면 펼친 공개 범위 카드 줄, 아니면 접힌 줄) + 종류별 접힌 줄. F-04b 팔았어요·F-04a 만기 정리는 요약 문장 + 고르기 + 금액·통장 칩(고르면 “통장 n원 > m원” 한 줄 `hg-form__hint`). 고르기는 `SegChoice`(2~3개 짧은 것은 회색 판 안 칸, 설명·4개 이상은 카드 줄, F 모양, Tabs.md).

## 스테퍼 (2026-11-24 사용자 결정 “온보딩 제외하곤 되도록 한 화면, 힘들면 스텝퍼”)

한 화면으로 못 합치는 흐름(앞 답이 뒤 질문을 정하는 분기, 확인·동의 단계)만 같은 FormScreen에 `step={{ index, total, done }}`을 줘서 스테퍼로 만든다. 진행 막대(`hg-steps`, 챕터 막대)는 쓰지 않는다.

- 머리(‹ + 제목) 아래 “1/3”(`hg-form__step`, 13px slate 400, 화면 읽기 “3단계 중 1단계”) → 앞에서 답한 줄(`hg-form__done`, 높이 56, 이름 17/400 `ink-2` + 답 17/700, 줄 사이 hairline-soft, `onClick`이 있으면 그 단계로 돌아가는 줄) → 이번 질문 섹션 하나 → 아래 주 버튼(“다음”, 마지막은 저장·보내기). 건너뛰기류는 `later`(조용한 글자 버튼, 주 버튼 위).
- 한 단계에 질문 하나(관련 둘은 한 단계: 새 저금의 이름 + 매달 금액, 목표 금액 + 기한). 총 개수는 지금 고른 길 기준(분기로 늘면 같이 늘어남).
- 지금 쓰는 곳: S-11f 관리 형태(3), S-12a·c 연결 해제(2), W-15 같이 모으기(최대 5). 코드 `FormStepHead`, `StepDone`.
