# LineChart

시간에 따른 금액 변화(순자산 추이). 큰 값 아래로 카드 끝까지 꽉 찬 면, 눈금 없이 말풍선으로 값을 읽고, 기간 탭은 맨 아래.

- 소비자가 주는 것: 이름, 현재 값, 기간 변화, 월 목록, 값, 비교 계열(선택: 예상 순자산), 기간(6개월, 1년, 3년, 전체).
- 틀 `hg-chart--bleed`: 안쪽 여백 없이 위 머리(`hg-chart__kpi`, 여백 24px) → 그림(`hg-chart__plot`, 높이 200px, 카드 좌우 끝까지) → 범례 → 기간 탭(`hg-chart__tabs`, 위 `hairline-soft` 선).
- 머리: 라벨(`slate`) → 큰 값 34px(`hg-chart__value--lg`) → 변화 알약. 늘었으면 `invest` 바탕 `invest-ink` 글자(`is-up`), 줄었으면 `goal` 바탕 `goal-ink`(`is-down`, 빨강 금지). 그래프 자체는 무채색 유지, 색은 알약에만.
- 선: `ink` 2.5px 곡선, 첫 달은 왼쪽 20px, 마지막 달은 오른쪽 28px 안쪽에 둠(점이 잘리지 않게). 첫 달 왼쪽은 같은 높이 흐린 선과 면으로 카드 끝까지 이음. 아래 `ink` 12%→1% 그라디언트 면이 카드 바닥까지. 예상 순자산은 `stone` 1.5px 점선, 면 없음.
- 눈금, 격자, x축 글자 없음. 값은 말풍선(`hg-chart__bubble`, `ink` 바탕, 월 + 값 + 예상 값)으로만 읽음. 처음엔 마지막 달, 마우스(좁은 창은 끌기)로 달을 옮기면 세로 점선과 점이 따라감. 말풍선은 점 위 가운데에 두되, 카드 좌우 8px 안으로 들어오게 위치를 맞춤(잘리지 않게).
- 기간 탭: 4칸 고르게, 고른 칸만 `ink` 알약 + `on-ink` 글자.
- 끝점 브랜드 점은 쓰지 않음(말풍선이 그 역할). y축은 하나만, 다른 단위는 차트를 나눔.
- 키보드: 그림에 포커스가 오면 ←→로 달 이동, 말풍선 내용은 `aria-live="polite"`.
