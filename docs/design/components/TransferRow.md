# TransferRow

이번 달 월급 체크리스트 줄 한 행(W-02, 홈 H-03, W-05, 재기획 ADR 0003). 은행 앱에서 보낸 뒤 체크하면 한 것으로 기록. 앱이 돈을 옮기지는 않음.

- 소비자가 주는 것: 줄 이름(저금 줄은 목표 이름, 쓰는 돈 줄은 고정지출·생활비·용돈·직접 추가 이름), 보조 줄, 금액, 체크 상태, 줄 아래 글자 링크.
- 보조 줄: “예빈님이 10월 26일에 체크했어요” / “이번 달은 못 했어요” / 다른 금액이면 실제 금액.
- 배치(2026-10-27, 카카오뱅크 체크리스트 느낌): 왼쪽 이름(16px 600) 아래 보조 줄 → 오른쪽 금액 → 맨 오른쪽 체크 원(28px). 줄 위아래 12px(2026-11-09 밀도, 16px에서), 한 줄 줄 56px. 줄 사이 선 없음(2026-11-09, 간격만).
- 누르는 칸(2026-11-09): 체크 원은 보이는 28px, 누르는 칸 44px(`::before`로 `space-2`씩 넓힘). 줄 시트 버튼(`hg-transfer__open`)은 줄 높이만큼(위아래 `space-3` 음수 margin + padding).
- 체크는 `success` 원 + 흰 체크. 체크한 줄은 이름에 취소선, 이름과 금액을 `stone`으로 낮춤. ‘못 함’ 줄도 체크된 모양 + 보조 줄로 구분.
- 보기만 하는 줄(`viewOnly`, `is-view`, 각자 모드 파트너 체크리스트): 체크 칸 대신 상태만(체크했으면 `success` 체크 표시). 체크한 줄은 취소선 없이 이름과 금액만 `stone`으로 흐리게(2026-11-09, 취소선이 ‘지운 줄’처럼 보여서).
- 체크는 `button role="checkbox"` + `aria-checked`, `aria-label`은 “{줄 이름} 체크”.
- 저장 중(2026-11-06): `busy`면 체크 원에 `aria-busy`, 다시 누르기 막음. 부르는 쪽(CheckLine)은 누른 쪽 모양(체크·풀기)을 바로 보여 주고 실패하면 원래대로 + 토스트. 누르면 원이 92%로 작아짐, 색 바뀜 `dur-fast`.
- 체크 안 한 원(2026-11-03): 테두리와 안 체크를 같이 아주 흐리게(둘 다 `hairline`, 카카오뱅크 체크리스트처럼). 마우스를 올리면 테두리만 `border-control`. 빈 원이 비어 보이지 않게. 모든 `hg-check`에 같음.
- 줄 시트(2026-11-03): `onOpen`을 주면 이름·금액 부분이 버튼(`hg-transfer__open`, `aria-haspopup="dialog"`)이 되고, 누르면 소비자가 BottomSheet를 엶. W-02 ‘보냈어요’ + ‘다른 금액으로 보냈어요’(W-02a), W-05 ‘보냈어요’ + ‘이번 달은 못 했어요’. 줄 아래 링크를 줄마다 반복하지 않음.
- 줄 아래 글자 링크(`actions`): 지금은 쓰지 않음(남겨 둠).
- React 래퍼 `TransferRow`(packages/ui): `label`, `meta`(보조 줄), `amount`, `done`, `checkLabel`, `onToggle`, `disabled`(볼 수만), `badge`, `actions`(줄 아래 글자 링크), `onOpen`(줄을 누르면 시트), `lead`(줄 앞 아이콘 칸, `hg-transfer--lead`: 32px Lead(2026-11-09 밀도) + 이름·금액 + 체크 원. 홈 H-03, W-02, W-05).
- 줄 앞 칸(2026-11-09, 앱 `LineLead`): 종류 아이콘 + 영역 색 원(ListRow ‘Lead 종류 표’ `line`). 목표 금액이 있는 저금 줄은 아이콘 대신 진행 원(ListRow ‘진행 원’)이고, 보조 줄은 “2,700만 / 1억 5,000만 원” 글자만(이름 아래 얇은 막대 없음, 모든 줄 높이가 같음).
- 체크한 사람 칩(2026-11-03): 보조 줄 앞 `hg-transfer__who`(높이 20px, `surface-alt` 알약, 12px 600 `ink`) + “08.26 체크”. 내가 체크한 줄은 칩 없이 날짜만.
- `viewOnly`(2026-11-03 대신 체크 없앰): 파트너 줄 보기만. 체크 칸 대신 상태 칸 `hg-transfer__state`(한 줄은 `success` 체크 아이콘, 안 한 줄은 비움). 화면 읽기 “예빈 체크했어요 / 아직 체크 안 했어요” [확인 필요].
