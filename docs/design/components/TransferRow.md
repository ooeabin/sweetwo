# TransferRow

이번 달 월급 체크리스트 줄 한 행(W-02, 재기획 ADR 0003. 홈 H-03 줄은 2026-11-09 없앰). 은행 앱에서 보낸 뒤 체크하면 한 것으로 기록. 앱이 돈을 옮기지는 않음.

- 소비자가 주는 것: 줄 이름(저금 줄은 목표 이름, 지출 줄은 고정지출·생활비·용돈·직접 추가 이름), 보조 줄, 금액, 체크 상태, 줄 아래 글자 링크.
- 보조 줄: “예빈님이 10월 26일에 확인했어요” / “이번 달은 건너뛰었어요” / 다른 금액이면 실제 금액.
- 배치(2026-10-27, 카카오뱅크 체크리스트 느낌): 왼쪽 이름(15px 600) 아래 보조 줄 → 오른쪽 금액 → 맨 오른쪽 체크 원(28px). 줄 위아래 12px(2026-11-09 밀도, 16px에서), 한 줄 줄 56px. 줄 사이 선 없음(2026-11-09, 간격만).
- 누르는 칸(2026-11-09): 체크 원은 보이는 28px, 누르는 칸 44px(`::before`로 `space-2`씩 넓힘). 줄 시트 버튼(`hg-transfer__open`)은 줄 높이만큼(위아래 `space-3` 음수 margin + padding).
- 체크는 `accent-app` 브랜드 오렌지 원 + `on-accent-app` 체크(2026-11-09 파랑에서 바꿈. 2026-11-15부터 주 버튼 글자는 진한 `on-accent-app-text`라 체크 표시와 다름). 체크 표시 모양으로도 알아봄. 체크한 줄은 이름에 취소선, 이름과 금액을 `stone`으로 낮춤. ‘못 함’ 줄(2026-11-12 D2)은 체크 안 한 줄처럼 빈 원·취소선 없음(`done=false`) + 보조 줄 “이번 달은 건너뛰었어요”, 체크 칸 이름 “{줄 이름} 건너뜀”(체크 안 됨). 누르면 체크(보냈어요). 예전 ‘체크된 모양 + 보조 줄’은 체크한 줄과 헷갈려 바꿈.
- 보기만 하는 줄(`viewOnly`, `is-view`, 각자 모드 파트너 체크리스트): 체크 칸 대신 상태만(체크했으면 `accent-app` 오렌지 체크 표시). 체크한 줄은 취소선 없이 이름과 금액만 `stone`으로 흐리게(2026-11-09, 취소선이 ‘지운 줄’처럼 보여서).
- 체크는 `button role="checkbox"` + `aria-checked`, `aria-label`은 “{줄 이름} 확인”(‘못 함’ 줄은 “{줄 이름} 건너뜀”).
- 상대가 방금 바꾼 줄(`changed`, `is-changed`, 2026-11-12, 30 동기화 ‘바뀐 칸 2초 강조’): 줄 뒤 옅은 `surface-alt` 판(좌우 `space-2` 밖으로, `radius-md`)이 2초에 걸쳐 사라짐. ‘동작 줄이기’면 판만 있다가 부르는 쪽이 2초 뒤 끔. W-02.
- 저장 중(2026-11-06): `busy`면 체크 원에 `aria-busy`, 다시 누르기 막음. 부르는 쪽(CheckLine)은 누른 쪽 모양(체크·풀기)을 바로 보여 주고 실패하면 원래대로 + 토스트. 누르면 원이 92%로 작아짐, 색 바뀜 `dur-fast`.
- 체크 안 한 원(2026-11-03): 테두리와 안 체크를 같이 아주 흐리게(둘 다 `hairline`, 카카오뱅크 체크리스트처럼). 마우스를 올리면 테두리만 `border-control`. 빈 원이 비어 보이지 않게. 모든 `hg-check`에 같음.
- 줄 시트(2026-11-03): `onOpen`을 주면 이름·금액 부분이 버튼(`hg-transfer__open`, `aria-haspopup="dialog"`)이 되고, 누르면 소비자가 BottomSheet를 엶. W-02 ‘보냈어요’ + ‘다른 금액으로 했어요’(W-02a) + ‘이번 달은 건너뛸게요’(2026-11-23부터 채움 버튼이 아닌 글자 버튼 `hg-btn--link hg-btn--quiet`, slate 500, 아래 가운데)(W-05 화면은 2026-11-15 없앰). 저금 줄은 맨 아래 글자 버튼 ‘저축·투자 보기’(`hg-btn--link`, 2026-11-12). 줄 아래 링크를 줄마다 반복하지 않음.
- 줄 아래 글자 링크(`actions`): 지금은 쓰지 않음(남겨 둠).
- React 래퍼 `TransferRow`(packages/ui): `label`, `meta`(보조 줄), `amount`, `done`, `checkLabel`, `onToggle`, `disabled`(볼 수만), `badge`, `actions`(줄 아래 글자 링크), `onOpen`(줄을 누르면 시트), `changed`(2초 강조), `lead`(줄 앞 아이콘 칸, `hg-transfer--lead`: 32px Lead(2026-11-09 밀도) + 이름·금액 + 체크 원. 홈 H-03, W-02).
- 줄 앞 칸(2026-11-09, 앱 `LineLead`): 종류 아이콘 + 영역 색 원(ListRow ‘Lead 종류 표’ `line`). 목표 금액이 있는 저금 줄은 아이콘 대신 진행 원(ListRow ‘진행 원’)이고, 보조 줄은 “2,700만 / 1억 5,000만 원” 글자만(이름 아래 얇은 막대 없음, 모든 줄 높이가 같음).
- 체크한 사람 칩(2026-11-03): 보조 줄 앞 `hg-transfer__who`(높이 20px, `surface-alt` 알약, 12px 600 `ink`) + “08.26 확인”. 내가 체크한 줄은 칩 없이 날짜만.
- `viewOnly`(2026-11-03 대신 체크 없앰): 파트너 줄 보기만. 체크 칸 대신 상태 칸 `hg-transfer__state`(한 줄은 `accent-app` 오렌지 체크 아이콘, 안 한 줄은 비움). 화면 읽기 “생활비 확인했어요 / 생활비 건너뜀 / 생활비 아직 확인 안 했어요” [확인 필요]. ‘못 함’ 줄은 체크 표시 없이 보조 줄 “이번 달은 건너뛰었어요”(2026-11-12 D2).
- 2026-11-15 3차 검토: 줄 앞 칸(`lead`)은 W-02에서 쓰지 않음(한 줄에 원 하나 = 체크 원). `lead`에 그림이 없는 종류 자리 `Lead`를 주면 칸 없이 그림(`shownLead`, `hg-transfer--lead`도 안 붙음). W-10 매달 카드(`hg-goalbox`) 안 끝낸 달 줄은 취소선 없음.
- 2026-11-19 W-02 새 구조: W-02 줄은 체크 원 대신 상태를 보이는 줄(`status` prop, `hg-transfer--act`, 최소 68px). 왼쪽 이름(16px 600) + 보조 줄 하나, 금액(16px 700). 이름·금액을 누르면 줄 시트(`onOpen`). 오른쪽 상태 버튼(“확인”·“완료”·“건너뜀”·날짜)은 2026-11-23에 없애고 점·✓·–로 바뀜(맨 아래 항목). 선택 모양 규칙(체크 원)은 W-10 매달 카드·홈 등 다른 곳에서 그대로.

- **2026-11-23 W-02 상태 줄(사용자 결정 C안, 위 2026-11-19 ‘상태 버튼’을 대신함)**: 상태 버튼(`hg-transfer__action`, go·done·skipped·wait 변형)과 보기만 회색 글자(`hg-transfer__status`)를 없앰. `status` prop(`tone`: `go` / `done` / `skipped` / `wait`, `ariaLabel`, `busy`)을 주면 한 줄 전체가 버튼(`onOpen`, `hg-transfer__open`, 최소 68px로 누르는 칸 44px 이상, 포커스 링, Enter로 시트)이고, 안은 `[점 칸][이름 16px 600 + 보조 줄][금액 16px 700][오른쪽 모양 20px]`(`hg-transfer--act`, 줄 클래스 `is-go` / `is-done` / `is-skipped` / `is-wait`).
  - 할 일(`go`, 확인할 손 항목·확인 가능 시점): 이름 앞 8px `brand` 점(`hg-transfer__dot.is-on`) + 금액 + `›`(chevron-right, `stone`). 누르면 항목 시트(계획대로 했어요 / 다른 금액으로 했어요 / 이번 달은 건너뛸게요 글자 버튼). 화면 읽기 “{이름} {금액}, 확인할 것”.
  - 끝남(`done`, 자동 완료 포함): 점 없이 이름·금액·보조 줄 `stone` 500(취소선 없음, 2026-11-23 사용자 결정: `slate`는 `ink`와 거의 같아 보여 한 단계 옅게, 4.5:1 이상) + ✓(check, `stone`). 보기만 줄의 완료도 같음. 보조 줄은 종류, 자동 줄이 나가는 날 자동 확인되면 “자동으로 나갔어요” [확인 필요]. 누르면 시트에서 ‘체크 풀기’. 화면 읽기 “{이름} {금액}, 완료, 고치기”.
  - 건너뜀(`skipped`): 이름·금액 취소선 + `slate`, 보조 줄 “건너뜀” [확인 필요], 오른쪽 – (minus, `slate`). 누르면 시트(계획대로 했어요 / 다른 금액으로 했어요). 화면 읽기 “{이름} {금액}, 건너뜀, 고치기”.
  - 아직 때가 아님(`wait`: 월급날 전 미리 보기, 자동 줄의 나가는 날 전): 점·모양 없이 보통 글자, 보조 줄에 날짜 “25일에 확인해요” [확인 필요](미리 보기 손 줄) / “25일 자동으로 나가요” [확인 필요](자동 줄), 오른쪽은 금액만. 미리 보기는 누를 수 없음(`role="group"`), 나가는 날 전 자동 줄은 누르면 시트.
  - 보기만(`viewOnly`, 파트너 보기·“{이름}님이 확인해요” 묶음): 점과 ›를 그리지 않고 상태만. 확인한 줄은 흐린 글자 + ✓, 건너뜀은 취소선, 대기 줄은 보통 글자 + 보조 줄 “대기”. 지난 달 읽기 전용 줄도 점을 그리지 않음. 늦게 확인(지난 달)과 지난 달 모아보기에서 연 화면도 같은 규칙.
  - 점 자리는 같은 목록(`hg-checklist__list`)에 점이 하나라도 있을 때만 비워 이름 줄이 맞음(점 없는 목록은 들여쓰지 않음, `:has`). 점은 그래픽이라 뜻은 늘 화면 읽기 이름으로도 전함.
  - 오렌지 글자 버튼 규칙(옅은 오렌지 판 위 버튼, W-01 ‘월급 적기’, 카드 안 보조 버튼)은 그대로. W-02 ‘확인’ 상태 버튼의 `brand-soft` 규칙(`.hg-transfer__action--go`)은 지움.
- 바탕 기준 2026-11-23(W-02 상태 줄 `hg-transfer--act`, W-10 이번 달 줄): 줄 높이 56 이상·위아래 12, 이름 17px 400 + 보조 13px 400 `stone`(**종류 글자는 없앰**, 상태·날짜만), 금액 17px 700, 금액과 오른쪽 표시(› ✓ –) 사이 12px, 표시는 12px 칸. 점(할 일)은 왼쪽 24 여백 안에 절대 위치라 이름이 줄마다 같은 자리. 끝남·건너뜀 이름·금액은 `stone` 400(건너뜀만 취소선). W-10 이번 달 줄은 취소선 없음. `sub`가 빈 문자열이면 보조 줄 없이 상태 모양 줄(`CheckLine`)로 그림.
