# TransferRow

이번 달 월급 체크리스트 줄 한 행(W-02, 홈 H-03, W-05, 재기획 ADR 0003). 은행 앱에서 보낸 뒤 체크하면 한 것으로 기록. 앱이 돈을 옮기지는 않음.

- 재기획 쓰임: 이름(저금 줄은 목표 이름, 쓰는 돈 줄은 고정지출·생활비·용돈·직접 추가 이름), 금액, 체크 이름 “{줄 이름} 체크”, 보조 줄 “예빈님이 10월 26일에 체크했어요” / “이번 달은 못 했어요”, 줄 아래 글자 링크(‘다른 금액으로 보냈어요’, W-05 ‘이번 달은 못 했어요’). 못 함 줄도 체크된 모양 + 보조 줄로 구분. 아래 옛 설명(통장 나누기)은 재기획 전.

- 소비자가 주는 것: 받는 곳, 담당·월급일, 금액, 체크 상태, 자동 줄이면 영역 배지.
- 체크는 `success` 원 + 흰 체크. 옮긴 줄은 글자를 `stone`으로 낮춤.
- 체크는 `button role="checkbox"` + `aria-checked`, `aria-label`은 “{받는 곳} 옮겼어요”.
- 자동 나누기 줄(‘목표자금 → 공동 생활비’, ‘비상금 → 공동 생활비’)은 영역 배지를 붙이고 직접 지울 수 없음.
- React 래퍼 `TransferRow`(packages/ui): 받는 곳(“공동 생활비 통장에”), 보조 줄(자동 줄이면 “목표자금 통장에서”, 다른 금액이면 실제 금액), 금액, 체크, 줄 아래 글자 링크(취소, 다른 금액을 옮겼어요). 배우자 몫은 `disabled`로 보기만.
