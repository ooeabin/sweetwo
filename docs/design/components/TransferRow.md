# TransferRow

월급 플랜의 나누기 줄 한 행. 은행 앱에서 그 통장으로 옮긴 뒤 체크하면 나눈 것으로 기록. 앱이 돈을 옮기지는 않음.

- 소비자가 주는 것: 받는 곳, 담당·월급일, 금액, 체크 상태, 자동 줄이면 영역 배지.
- 체크는 `success` 원 + 흰 체크. 옮긴 줄은 글자를 `stone`으로 낮춤.
- 체크는 `button role="checkbox"` + `aria-checked`, `aria-label`은 “{받는 곳} 옮겼어요”.
- 자동 나누기 줄(‘목표자금 → 공동 생활비’, ‘비상금 → 공동 생활비’)은 영역 배지를 붙이고 직접 지울 수 없음.
