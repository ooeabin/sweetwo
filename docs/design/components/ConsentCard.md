# ConsentCard

동의 받기. 가입 때 약관 동의 묶음(전체 동의 + [필수], [선택] 줄)과, 한 가지를 묻는 동의 카드(F-08 참여, 관리자 열람 요청).

- 소비자가 주는 것: 동의 항목(이름, 필수 여부, 본문 주소), 체크 상태, 한 건 카드의 제목, 설명 줄, 버튼 글자, 남은 시간(열람 요청).

## 동의 묶음(`hg-consent`)

- 맨 위 “전체 동의”(`hg-consent__row--all`, 16px 600)는 회색 판(`plate`) 위 한 줄. 누르면 모든 줄을 켜고 끔. 줄을 하나라도 끄면 전체 동의도 꺼짐.
- 체크는 동그라미(24px, 켜지면 `ink` 채움 + 흰 체크).
- 필수 묶음(`requiredLabel`을 주면): 필수 항목을 묶음 줄 하나(동그라미 체크 + 펼치기 `chevron-down`, `aria-expanded`)로. 처음엔 펼쳐 둠. 하위 약관은 들여 쓰고 테두리 없는 작은 체크 표시(꺼지면 `border-control`, 켜지면 `ink`) + 13px `slate` 이름 + ‘보기’. 선택 항목은 묶음 아래 따로.
- 줄마다 Checkbox(`hg-checkbox`) + 이름 앞 “[필수]”(`slate` 600) 또는 “[선택]”(`stone` 400) + 오른쪽 글자 링크 “보기”. 줄 전체가 체크 영역(`button role="checkbox"` + `aria-checked`), “보기”는 따로.
- “보기”는 앱 안에서 L-05 약관 페이지를 엶(좁은 창 BottomSheet, 데스크톱 Modal 안 웹 보기). 브라우저로 나가지 않음. 닫으면 같은 자리로.
- 필수를 다 켜야 아래 주 버튼(“동의하고 계속하기”)이 켜짐. 선택은 안 켜도 됨, 나중에 설정 S-14에서 바꿈.
- 줄 순서(기획서 A-05): [필수] 이용약관 → [필수] 개인정보 수집·이용 → [필수] 배우자와 부부 공간 공유 → [선택] 마케팅 정보 받기. 나이 확인 줄은 없음(O-13 태어난 해로 확인).

## 한 건 동의 카드(`hg-consent-card`)

- 위 → 아래: 아이콘 + 제목(`title-3`) → 설명 1줄 → 알아 둘 것 2~3줄(`check` 아이콘 목록) 또는 `hg-meta` 이름표 줄 → 버튼 2개(오른쪽 끝, 보조 + 주).
- F-08 참여 안내: “우리 숫자를 비교에 보탤까요?” / 알아 둘 것 “이름 없이 나이대와 금액 구간만 써요”, “언제든 설정에서 끌 수 있어요”, “참여하면 같은 나이대 부부와 비교해 볼 수 있어요” / 버튼 “나중에 할게요”, “참여할게요”.
- 관리자 열람 요청(어드민 AD-04 L2): “고객센터가 문의 확인을 위해 보려고 해요” / 이름표 줄 “문의” 번호, “볼 수 있는 것” 범위, “기간” 동의하면 24시간 / 버튼 “보지 않아요”(보조), “볼 수 있어요”(주). 메모, 양가 가족 정보, 사진은 범위에 넣을 수 없음.
- 동의한 뒤 같은 카드는 “남은 시간 23시간 12분”(`hg-pair`) + 글자 링크 “지금 그만 보게 할게요”로 바뀜. 시간이 끝나면 카드가 사라지고 알림 “문의 처리를 위해 {범위}를 확인했어요”.
- 버튼은 둘 다 같은 크기, 어느 쪽도 `danger`나 `brand`로 칠하지 않음. 거절해도 불이익 문구 없음.
- 브랜드 색 쓰지 않음, 카드 바탕은 `surface` + `hairline` 테두리.

쓰는 곳: 가입 A-05 약관 동의, F-01 F-08 참여 안내, 설정 S-19 문의하기 아래 열람 요청.
