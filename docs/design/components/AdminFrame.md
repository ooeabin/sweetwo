# AdminFrame

어드민 틀. 왼쪽 메뉴 + 흰 본문 패널, 가린 개인정보, 열람 요청(L1, L2)과 2인 승인 상태.

- 소비자가 주는 것: 메뉴 목록과 지금 메뉴, 보는 관리자(이름, 역할, 접속 시각), 화면 제목, 본문(DataTable, Card), 열람 단계(L0, L1, L2)와 요청 상태.
- 다크 모드: 앱과 같이 시스템 설정을 따라 `data-theme`만 붙임(2026-11-06), 색은 토큰이 처리.
- 너비: 기준 1440px, 최소 1280px(`hg-admin`, 더 좁으면 가로 스크롤). 좁은 창, 터치 대응 없음. 웹 전용.
- 틀(2026-11-06 업무 도구답게 바꿈, 레퍼런스 Google Workspace Admin, Klaviyo, Square, Clerk, Vanta): `surface-alt` 사이드바(224px) + 흰 본문 한 판(`hg-admin__main`, 왼쪽 1px 선, 둥근 떠 있는 판 아님).
  - 사이드바: 워드마크 + 태그 “어드민”, 메뉴 묶음 이름(`hg-admin__group`) “운영”(대시보드, 회원, 문의) / “발송과 콘텐츠”(발송, 콘텐츠) / “관리”(시스템, 문서). 메뉴 줄 34px, 지금 메뉴는 흰 판 + 얇은 선, 개수는 작은 회색 배지(지금 메뉴면 검정).
  - 상단 바(`hg-admin__bar`, 56px, 위에 붙음): 왼쪽 통합 검색(`hg-search`, 440px, 27 기본 틀 2번, 찾으면 AD-02로), 오른쪽 보는 관리자(`hg-admin__me`: 이름 + 역할 `hg-tag` + 작은 접속 시각 + ‘로그아웃’).
  - 본문(`hg-admin__body`, 최대 1216px): 제목 20px + 오른쪽 버튼 → 아래 내용.
- 메뉴 머리: 워드마크 + 태그 “어드민”(`hg-tag`). 메뉴: 대시보드, 회원, 문의, 구독과 결제, 발송, 콘텐츠, 시스템. 보는 관리자는 상단 바 오른쪽(2026-11-06, 전에는 메뉴 아래 끝 칸).
- 개인정보가 나오는 화면(회원 상세 등)은 글자 선택, 복사 막음. 워터마크는 넣지 않음.
- 가린 값(`hg-mask-text`): L0에서 이메일 “ch***@g***.com”, 전화 “010-****-1234”. 금액은 L2에서도 구간(“1억~2억”)만.
- 열람 요청 폼(카드 안): 단계 고르기(Selection 카드형 Radio) “L1 이메일 전체, 접속 기록, 결제 내역” / “L2 사용자 동의 후 자산 항목, 금액 구간” → 문의 번호(필수, Input) → 사유(Select) → L2면 볼 범위(Checkbox) → 주 버튼 “열람 요청 보내기”. L1은 30분 뒤 다시 가림, L2는 사용자 동의 뒤 24시간.
- 2인 승인 상태(`hg-approve`): 줄마다 표시 원 + 단계 이름 + 오른쪽 사람과 시각. 끝낸 단계 `success` 원 + `check`, 기다리는 단계 빈 원 + “기다리는 중”. 순서: 요청(CS) → 승인(최고 관리자) → 사용자 동의(L2만) → 열람 중(남은 시간).
- 밀도(어드민 안에서만, 클래스 이름 그대로): 본문 글자 14px, 보조 13px. 버튼·입력 36px(작은 버튼 30px), 칩 30px, 카드는 그림자 없이 1px 선 + `radius-lg`, 안쪽 16·20px. 탭은 밑줄 탭(`hg-tab`, 지금 탭은 아래 2px 검정 선).
- 항목-값 줄(`hg-admin__kv`): 이름 132px 왼쪽 고정(13px `stone`) + 값은 바로 옆 왼쪽 정렬. 오른쪽 끝 정렬은 쓰지 않음.
- 대시보드 숫자(`hg-admin__stats`, `hg-admin__stat`): 이름 13px + 숫자 28px.
- 표는 DataTable(`hg-table`): 머리 32px 12px, 줄 36px 13px. 색으로 좋고 나쁨을 칠하지 않음.
- 되돌릴 수 없는 실행(세션 강제 종료 등)은 Modal + `danger` 버튼, 직전에 다시 인증.
- 브랜드 색은 워드마크와 주 버튼에만.

React 래퍼: `AdminFrame`(packages/ui, 메뉴·지금 메뉴·보는 관리자·제목·오른쪽 버튼). 표는 `DataTable`.
