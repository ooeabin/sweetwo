# AdminFrame

어드민 틀. 왼쪽 메뉴 + 흰 본문 패널, 가린 개인정보, 열람 요청(L1, L2)과 2인 승인 상태.

- 소비자가 주는 것: 메뉴 목록과 지금 메뉴, 보는 관리자(이름, 역할, 접속 시각), 화면 제목, 본문(DataTable, Card), 열람 단계(L0, L1, L2)와 요청 상태.
- 다크 모드: 앱과 같이 시스템 설정을 따라 `data-theme`만 붙임(2026-11-06), 색은 토큰이 처리.
- 너비: 기준 1440px, 최소 1280px(`hg-admin`, 더 좁으면 가로 스크롤). 좁은 창, 터치 대응 없음. 웹 전용.
- 틀(2026-11-06 업무 도구답게 바꿈, 레퍼런스 Google Workspace Admin, Klaviyo, Square, Clerk, Vanta, 사이드바는 Base44, Square, Shopify, Gumloop): `surface-alt` 사이드바(224px) + 흰 본문 한 판(`hg-admin__main`, 왼쪽 1px 선, 둥근 떠 있는 판 아님).
- 어드민 주 색(2026-11-06): 브랜드 오렌지 대신 잉크(`--brand`를 `ink`로, 밝은 화면 검정, 다크 화면 흰색). 워드마크도 잉크(`Wordmark ink`, `hg-wordmark--ink`, 2026-11-06). 어드민에는 브랜드 오렌지가 없다.
  - 사이드바: 워드마크(24px) + 태그 “어드민”, 메뉴 묶음 이름(`hg-admin__group`, 12px `stone`) “운영”(대시보드, 회원, 문의) / “발송과 콘텐츠”(발송, 콘텐츠) / “관리”(시스템, 문서). 메뉴 줄 32px, 아이콘 16px `slate`, 글자 14px `ink-2`. 사이드바 바탕은 흰색(본문과 1px 선으로 나눔, 2026-11-06 회색 판 없앰). 마우스는 `surface-sunk`, 지금 메뉴는 `accent-soft` 판 + `accent-ink` 글자·아이콘 600(2026-11-06 어드민 포인트 색 인디고). 개수는 오른쪽 작은 알약(`surface-alt` + `slate`, 지금 메뉴에서는 흰 바탕 + `accent-ink`).
  - 사이드바 아래 끝(`hg-admin__account`, 위 1px 선): 이니셜 원(28px, 잉크) + 이름 600 + 역할, 접속 시각을 따로 줄로(12px, 자르지 않고 줄바꿈, 2026-11-06 역할이 잘리던 것 고침) + 그 아래 줄에 ‘로그아웃’ 작은 글자 버튼(2026-11-06, 글 칸을 넓게).
  - 상단 바(`hg-admin__bar`, 56px, 위에 붙음): 왼쪽 통합 검색(`hg-search`, 440px, 흰 바탕 + 1px `hairline`, 포커스 `focus`, 27 기본 틀 2번, 찾으면 AD-02로).
  - 본문(`hg-admin__body`, 최대 1216px): 제목 20px + 오른쪽 버튼 → 아래 내용.
- 메뉴 머리: 워드마크 + 태그 “어드민”(`hg-tag`). 메뉴: 대시보드, 회원, 문의, 구독과 결제, 발송, 콘텐츠, 시스템. 보는 관리자는 사이드바 아래 끝(2026-11-06).
- 개인정보가 나오는 화면(회원 상세 등)은 글자 선택, 복사 막음. 워터마크는 넣지 않음.
- 가린 값(`hg-mask-text`): L0에서 이메일 “ch***@g***.com”, 전화 “010-****-1234”. 금액은 L2에서도 구간(“1억~2억”)만.
- 열람 요청 폼(카드 안): 단계 고르기(Selection 카드형 Radio) “L1 이메일 전체, 접속 기록, 결제 내역” / “L2 사용자 동의 후 자산 항목, 금액 구간” → 문의 번호(필수, Input) → 사유(Select) → L2면 볼 범위(Checkbox) → 주 버튼 “열람 요청 보내기”. L1은 30분 뒤 다시 가림, L2는 사용자 동의 뒤 24시간.
- 2인 승인 상태(`hg-approve`): 줄마다 표시 원 + 단계 이름 + 오른쪽 사람과 시각. 끝낸 단계 `success` 원 + `check`, 기다리는 단계 빈 원 + “기다리는 중”. 순서: 요청(CS) → 승인(최고 관리자) → 사용자 동의(L2만) → 열람 중(남은 시간).
- 밀도(어드민 안에서만, 클래스 이름 그대로): 본문 글자 14px, 보조 13px. 버튼·입력 36px(작은 버튼 30px), 칩 30px, 카드는 그림자 없이 1px 선 + `radius-lg`, 안쪽 16·20px. 탭은 밑줄 탭(`hg-tab`, 지금 탭은 아래 2px `accent-ink` 선 + `ink` 글자 600). 고른 칩은 `accent-soft` + `accent-ink` + 1px `accent-ink` 테두리. 보조 버튼은 흰 바탕 + 1px `hairline`(회색 판 아님), 꺼진 주 버튼은 잉크 30% 투명(회색 위 회색 대신). 표 줄 마우스는 `surface-sunk`.
- 어드민 색(2026-11-06, 단정하게): 포인트 색은 인디고 하나(`accent-soft`, `accent-ink`)를 지금 메뉴, 지금 탭, 고른 칩에만. 나머지 색은 상태에만: 경보 띠(`hg-admin__alert`, 노랑 `warning-soft` + `warning-ink`, 실패는 `is-bad`로 `danger-soft` + `danger`, 앞 `circle-alert` 아이콘, 끝 `chevron-right`), 0이 아닌 실패 숫자(`hg-admin__stat.is-bad`, `danger`), 표 상태 값([Status](Status.md) 점). 숫자 칸에 색 아이콘 칸, 색 판 배지는 두지 않음.
- 대시보드(AD-01, 2026-11-06): 경보 띠 → ‘회원 현황’ 카드(숫자 넷, 아래 작은 글 `hg-admin__stat small`) → 실패 건수 | 미처리 문의 → ‘최근 7일’ 카드(`hg-admin__trend` 세 칸, 칸마다 `hg-admin__bars`: 제목 + 오늘 값, 막대 7개 한 색 `accent-ink` 35%, 오늘만 100%, 위 모서리 4px, 아래 1px `hairline` 기준선, 첫날·오늘 날짜만. 값은 막대 title과 `hg-admin__more` 접기 안 표) → 앱 버전 | 최근 활동(‘승인 대기’ 바로 가기 줄 `hg-admin__alert is-quiet`, 최근 문의 표, 최근 감사 로그 `hg-admin__log` 3칸 줄).
- 항목-값 줄(`hg-admin__kv`): 이름 132px 왼쪽 고정(13px `stone`) + 값은 바로 옆 왼쪽 정렬. 오른쪽 끝 정렬은 쓰지 않음.
- 대시보드 숫자(`hg-admin__stats`, `hg-admin__stat`): 이름 13px + 숫자 28px.
- 표는 DataTable(`hg-table`): 머리 32px 12px, 줄 36px 13px. 색으로 좋고 나쁨을 칠하지 않음.
- 되돌릴 수 없는 실행(세션 강제 종료 등)은 Modal + `danger` 버튼, 직전에 다시 인증.
- 브랜드 오렌지는 쓰지 않음(워드마크, 주 버튼 모두 잉크). 로그인·인증은 AdminAuth.
- 공지 편집(AD-10, 2026-11-06): 오른쪽 칸(340px)에 카드 세 장. 입력 카드 → ‘대상’ 카드(조건 칩·입력 + 대상 수 `hg-admin__grid2` 안 `hg-admin__stat` 두 개 “대상” “제외”, 메일이면 아래 `hg-admin__kv` “반송·수신 거부”) → ‘미리보기’ 카드(앱 공지 띠 `hg-banner hg-banner--line`을 앱과 같은 마크업으로, 접힌 모양 + 펼친 모양, 메일을 켜면 안쪽 카드로 메일 모양). 미리보기 띠는 화면 읽기에서 숨기고 버튼은 탭으로 가지 않음. 새 클래스 없음.

React 래퍼: `AdminFrame`(packages/ui, 메뉴·지금 메뉴·보는 관리자·제목·오른쪽 버튼). 표는 `DataTable`.

쓰는 곳: 어드민 AD-01~AD-17 모든 화면.
- 긴 값(2026-11-06 검수): 표 칸, `hg-admin__kv` 값, 글자 링크(사용자 ID 등)는 칸을 넘지 않고 줄바꿈(`overflow-wrap: anywhere`, 한글은 낱말 단위). 숫자 칸(`is-num`)만 한 줄. 오른쪽 좁은 칸(340px)의 `hg-admin__kv` 이름표 칸은 88px. 검수는 1280px 창에서 모든 칸에 긴 ID·이메일·문장을 넣어 칸 밖으로 나가는 것이 없는지 확인.
- 빈 칸과 빈 표(2026-11-06 검수): 오른쪽 칸(`hg-admin__grid` 두 번째 칸)이 비면 왼쪽이 화면 폭을 꽉 채움. 표는 행이 없어도 머리만 남기지 않고 “아직 기록이 없어요” [확인 필요] 줄을 보임. 한 칸에 표가 둘이면 두 번째 표 위에 이름(`hg-card__label`).
