# BigExpense

이번 달 큰 지출. 1년에 한두 번 내는 큰돈(자동차보험 연납, 자동차세, 재산세 등)을 생활비와 섞이지 않게 따로 적는 질문. 월말 정리 지출 입력(W-04j) 맨 아래에 씀.

- 소비자가 주는 것: 큰 지출 칩 목록(기획서 데이터 항목 6-4), 고른 항목, 금액, 연결된 연간 목표(있으면), 처리 방식.
- 질문 “이번 달 큰 지출이 있었나요?” → 칩(여러 개 고를 수 있음, Chip 선택형) + “직접 쓰기” + “없어요”. “없어요”를 고르면 다른 칩이 풀림.
- 고른 칩마다 카드 1장(`hg-big__item`): 이름 + 금액 칸(SpendItems와 같은 칸) → 처리 방식 세그먼트 2개.
  - “모아 둔 돈에서 냈어요”: 연결된 매년 목표(자동차 유지비, 연간 고정 지출)에서 꺼내 쓴 것으로 기록. 아래 설명 “자동차 유지비 목표에서 70만 9천 원을 꺼내 썼다고 기록해요”. 연결된 목표가 없으면 이 선택지를 숨김.
  - “이번 달만 예외예요”: 목표와 상관없이 이번 달 지출로만 기록.
  - 어느 쪽이든 생활비 평균과 예산 보정에서 뺌. 정산 요약에는 ‘큰 지출’ 한 줄로 들어감.
- 역할을 나눈 부부가 생활비 카드로 냈다면 다음 달 월급 나누기에 ‘목표자금 → 공동 생활비’ 줄이 생김(기획서 계산·배분 6장).
- 같은 돈을 변동 지출(SpendItems)에 또 적지 않음. ‘명절 비용’은 칩에 없음(경조사·선물, 챙길 날).
- 접근성: 칩 묶음 `role="group"` + 질문 `aria-labelledby`, 세그먼트는 `role="radiogroup"`.
