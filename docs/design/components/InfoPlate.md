# InfoPlate

조건 요약 판(`hg-kv`, 카카오뱅크 상품 개설 확인 화면의 회색 판 방식). 결론 문장 아래에 조건이나 요약을 이름–값 두 열로.

- 소비자가 주는 것: 제목(선택, 14px 600 `slate`), 줄 목록(이름, 값, 하위 줄 여부), 아래 안내 한 줄(선택).
- `plate` 바탕, `radius-xl`, 안쪽 20px, 줄 사이 12px. 줄 사이 선 없음. 이름 15px `slate`, 값 15px 600 `ink` 오른쪽 맞춤(표 숫자). 하위 줄은 한 단계 들여 14px.
- 마크업은 `dl`(이름 `dt`, 값 `dd`).
- 쓰는 곳: O-66 조건 요약, W-04 끝 이번 달 요약, P-11 대기 내가 답한 것. W-04g 정산 요약(MonthSummary)의 나눠 보기 줄도 같은 판.

## DoneMark

완료 표시(`hg-donemark`). 완료 화면 제목 아래 가운데 72px 원(`brand-soft`) + 36px 체크(`brand`). ‘동작 줄이기’가 아니면 한 번 톡 커짐. 꾸밈이라 화면 읽기에서 숨김. 쓰는 곳: W-04 끝, P-11 대기.
