# InfoPlate

조건 요약 판(`hg-kv`, 카카오뱅크 상품 개설 확인 화면의 회색 판 방식). 결론 문장 아래에 조건이나 요약을 이름–값 두 열로.

- 소비자가 주는 것: 제목(선택, 14px 600 `slate`), 줄 목록(이름, 값, 하위 줄 여부), 아래 안내 한 줄(선택).
- `plate` 바탕, `radius-xl`, 안쪽 20px, 줄 사이 12px. 줄 사이 선 없음. 이름 15px `slate`, 값 15px 600 `ink` 오른쪽 맞춤(표 숫자). 하위 줄은 한 단계 들여 13px.
- 마크업은 `dl`(이름 `dt`, 값 `dd`).
- 쓰는 곳: P-11 대기 내가 답한 것(W-02 끝 저금 요약은 2026-11-12 W-02 끝과 함께 없앰).
