# Tabs

같은 화면 안에서 묶음을 바꾸는 알약 탭(`hg-tabs`)과, 보기 방식을 바꾸는 세그먼트(`hg-seg`).

- 소비자가 주는 것: 탭 이름들, 현재 탭.
- 알약 탭: 목표 분류(목표 고르기·목표 추가), 자산 묶음. 현재 탭은 `ink` 바탕. 넓은 창은 줄바꿈 허용, 좁은 창(768px 미만)은 한 줄로 두고 가로로 밀기(스크롤 막대 숨김, 화면 끝까지 닿게 좌우 16px 넓힘, 누른 탭이 보이게 따라감. 2026-11-02, 기획서 O-21 좁은 창).
- 세그먼트: 2~3개의 보기 전환(월·연, 목록·달력). 바탕 `surface-alt`, 현재 항목은 흰 바탕 + `shadow-1` + 1px `hairline` 테두리(2026-11-09 `surface-alt`를 연하게 하며 더함. 어드민·웹사이트는 `shadow-1`만).
- 탭 이름은 명사 1~2단어.
- `role="tablist"` + `button role="tab"` + `aria-selected`. 세그먼트 칸 높이 36px 이상, 터치 좁은 창 44px.

- 항목 앞 칸(`lead`, 선택): 사람 탭은 이름 앞에 작은 Avatar(22px).
