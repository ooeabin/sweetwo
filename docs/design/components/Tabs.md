# Tabs

같은 화면 안에서 묶음을 바꾸는 알약 탭(`hg-tabs`)과, 보기 방식을 바꾸는 세그먼트(`hg-seg`).

- 소비자가 주는 것: 탭 이름들, 현재 탭.
- 알약 탭: 목표 분류(목표 고르기·목표 추가), 자산 묶음. 현재 탭은 `ink` 바탕. 넓은 창은 줄바꿈 허용, 좁은 창(768px 미만)은 한 줄로 두고 가로로 밀기(스크롤 막대 숨김, 화면 끝까지 닿게 좌우 16px 넓힘, 누른 탭이 보이게 따라감. 2026-11-02, 기획서 O-21 좁은 창).
- 세그먼트: 2~3개의 보기 전환(월·연, 목록·달력). 바탕 `surface-alt`, 현재 항목은 흰 바탕 + `shadow-1` + 1px `hairline` 테두리(2026-11-09 `surface-alt`를 연하게 하며 더함. 어드민·웹사이트는 `shadow-1`만).
- 고르기(`SegChoice`, 2026-11-24 사용자 결정, 예전 ‘구간 선택’): 입력에서 꼭 하나를 고름(W-11·W-01e·W-01 줄 시트 ‘어떻게 챙겨요?’, F-03 명의, F-04b 얼마나 팔았어요?, F-04a 등). 모양은 짧은 2~3개 버튼과 카드 줄이 다르다(2026-11-24 14:40 사용자 결정 “토글 버튼은 이전 버전이 낫다”: 버튼만 #419의 A 테두리 버튼으로 되돌림, 카드 줄은 F ‘떠 있는 흰 알약’ 그대로). 짧은 2~3개는 버튼(`hg-choice`): 칸마다 떨어진 버튼(칸 사이 8, 높이 48, radius 12, 흰 바탕 `surface`), 안 고른 칸은 `hairline` 1px 테두리 + 15/400 `ink-2`, 고른 칸은 `ink` 1.5px 테두리 + 15/700 `ink`, 그림자·오렌지 없음(판 없음). 4개 이상·긴 글자(2개는 9자, 3개는 5자 넘음)·설명(`sub`)이 있으면 카드 줄(`hg-choice--rows`, ChoiceCards `hg-option--card`와 같은 모양): 높이 56 이상, radius 16, 칸 사이 8, 안 고른 카드는 판 색 + 15/400 `ink-2` + 오른쪽 빈 원(2px `border-control`), 고른 카드는 `choice-on` + 그림자 + 15/700 `ink` + 오른쪽 오렌지 체크 원, 설명은 이름 아래 13 `stone`. 회색 바탕 화면(홈만, `hg-frame--alt`)은 카드 줄 판 색을 `hairline-soft`로 한 단계 진하게. `hg-seg`(회색 판 + 흰 알약 `Tabs variant=seg`)는 월·연, 목록·달력처럼 보기 전환에만. 코드 `choiceVariant`가 기준을 정하고 `variant`로 고를 수 있음. `role="radiogroup"` + `role="radio"`(탭이 아니라 선택). 누르는 칸 44px 이상.
- 탭 이름은 명사 1~2단어.
- `role="tablist"` + `button role="tab"` + `aria-selected`. 세그먼트 칸 높이 36px 이상, 터치 좁은 창 44px.

- 항목 앞 칸(`lead`, 선택): 사람 탭은 이름 앞에 작은 Avatar(22px).
- 밑줄 탭(`LineTabs`, `hg-linetabs`, 바탕 기준 2026-11-23 사용자 결정): 목록 위 거르기. 15px, 고른 탭 700 `ink` + 아래 2px `ink` 밑줄, 나머지 `stone` 400, 숫자는 글자 옆 같은 굵기(`hg-linetab__n`), 전체 폭 `hairline` 한 줄이 아래. 탭 높이 44. `role="tablist"` + `role="tab"` + `aria-selected`, 소비자가 `label`(묶음 화면 읽기 이름)을 줌. 쓰는 곳: W-02 전체·남음·완료, 자산 관리 하위 탭(요약·자산·부채, 2026-11-23 ‘바탕 정리 2’), Y-09 경조사별/연도별. 탭이 많으면 옆으로 밀기(스크롤 막대 숨김), 회색 바탕 화면은 줄이 화면 끝까지. **쓰는 기준**: 목록을 거르거나 보기를 바꾸는 탭은 `LineTabs`, 알약 `Tabs`는 사람 바꾸기(내 것/파트너/합계, 앞 칸에 Avatar)에만, 꼭 하나를 고르는 입력은 `SegChoice`나 `Chip`.
