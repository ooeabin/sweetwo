# Tabs

같은 화면 안에서 묶음을 바꾸는 알약 탭(`hg-tabs`)과, 보기 방식을 바꾸는 세그먼트(`hg-seg`).

- 소비자가 주는 것: 탭 이름들, 현재 탭.
- 알약 탭: 목표 분류(목표 고르기·목표 추가), 자산 묶음. 현재 탭은 `ink` 바탕. 넓은 창은 줄바꿈 허용, 좁은 창(768px 미만)은 한 줄로 두고 가로로 밀기(스크롤 막대 숨김, 화면 끝까지 닿게 좌우 16px 넓힘, 누른 탭이 보이게 따라감. 2026-11-02, 기획서 O-21 좁은 창).
- 세그먼트: 2~3개의 보기 전환(월·연, 목록·달력). 바탕 `surface-alt`, 현재 항목은 흰 바탕 + `shadow-1` + 1px `hairline` 테두리(2026-11-09 `surface-alt`를 연하게 하며 더함. 어드민·웹사이트는 `shadow-1`만).
- 구간 선택(`SegChoice`, `hg-seg hg-seg--block`, 2026-11-23): 꼭 하나를 고르는 입력(W-11·W-01e·W-01 줄 시트 ‘어떻게 챙겨요?’ 2~3칸). 너비를 꽉 채우고 칸은 같은 너비, `role="radiogroup"` + `role="radio"`(탭이 아니라 선택). 칸 높이 36px, 터치 44px.
- 탭 이름은 명사 1~2단어.
- `role="tablist"` + `button role="tab"` + `aria-selected`. 세그먼트 칸 높이 36px 이상, 터치 좁은 창 44px.

- 항목 앞 칸(`lead`, 선택): 사람 탭은 이름 앞에 작은 Avatar(22px).
- 밑줄 탭(`LineTabs`, `hg-linetabs`, 바탕 기준 2026-11-23 사용자 결정): 목록 위 거르기. 15px, 고른 탭 700 `ink` + 아래 2px `ink` 밑줄, 나머지 `stone` 400, 숫자는 글자 옆 같은 굵기(`hg-linetab__n`), 전체 폭 `hairline` 한 줄이 아래. 탭 높이 44. `role="tablist"` + `role="tab"` + `aria-selected`, 소비자가 `label`(묶음 화면 읽기 이름)을 줌. 쓰는 곳: W-02 전체·남음·완료. **이번 PR은 W-02만**; 알약 `Tabs`를 쓰는 다른 곳(자산 묶음, 목표 분류, S-20 도움말 칩 등)은 다음 PR ‘바탕 정리 2’에서 필요하면 옮김.
