# AppFrame

앱 화면 틀. 넓은 창은 맨 위 흰 상단 메뉴 줄 + (이번 달만) 회색 오늘 띠 + 가운데 두 단 본문, 좁은 창은 큰 제목 + 오늘 띠 + 내용 폭 하단 독과 같은 줄의 + 버튼.

- 소비자가 주는 것: 현재 메뉴, 화면 제목(또는 이번 달 인사), 날짜, 주 행동 1개, 숫자 타일 3개(이번 달), 본문, 알림 유무, 받은 제안 수, 저장 상태.

## 넓은 창 (768px 이상)

- 상단 메뉴 줄(`hg-topnav`, `surface`, 아래 `hairline-soft` 선): 왼쪽 워드마크 → 탭 4개(`hg-topnav__tab`: 이번 달, 목표, 우리 자산, 캘린더) → 빈칸 → 오른쪽 도구 묶음(`hg-topnav__tools`): 검색 칸(⌘K, 240px) → 눈(금액 가리기) → 알림(새 알림이면 `brand` 점) → 두 사람 아바타(`hg-topnav__me`, 누르면 설정).
- 메뉴 줄의 왼쪽 끝(워드마크)과 오른쪽 끝(아바타)은 오늘 띠, 본문과 같은 1120px 폭 안쪽 선에 맞춤.
- 오른쪽 도구는 모두 높이 40px, 가운데 정렬. 검색 칸은 `surface-alt` 바탕(테두리 없음), 아이콘 버튼은 테두리 없는 40px 원, 아바타는 28px. 사이 간격 4px, 검색 칸 뒤만 8px.
- 현재 탭은 `ink` 알약 + `on-ink` 글자, 탭은 `a` + `aria-current="page"`. 받은 제안이 있으면 ‘이번 달’ 탭 안 오른쪽에 숫자 알약.
- 저장 상태는 아바타에 마우스를 올리면 툴팁(“모두 저장됨”, “저장 중”). 오프라인은 Banner.
- 오늘 띠(`hg-today`, 이번 달 화면에만): `surface-alt` 바탕, 안쪽 최대 1120px 가운데.
  - 첫 줄: 날짜(`stone`) 위 인사 제목 30px(“찬우님, 10월 월급 나누기가 2곳 남았어요”) → 오른쪽 ‘추가’(보조 버튼) → 주 버튼 1개(지금 할 일: ‘월급 나누기’, 월말 정리 기간엔 ‘정리 시작’).
  - 둘째 줄: 숫자 타일 3개(`hg-stat`: 안 나눈 돈, 순자산 + 변화 알약, 다음 일정 D-n). 타일 바탕 `surface`.
  - 월급 나누기가 없는 사람(혼자 쓰기, 배우자 합류 전, ‘통장 하나로 써요’): 인사 “찬우님, 이번 달 생활비가 32만 원 남았어요”, 주 버튼 ‘지출 적기’(W-04j), 첫 타일 “이번 달 남은 생활비”. 월말 정리 기간에는 “월말 정리 D-n”과 ‘정리 시작’.
- 본문(`hg-body`): 최대 1120px 가운데, 두 단(`hg-body__col`, 단 사이 40px). 1100px 미만이면 한 단(왼쪽 단 다음 오른쪽 단 순서).
- 다른 메뉴 화면: 상단 메뉴 줄 아래 오늘 띠 대신 화면 제목 줄(제목 24px, 오른쪽 ‘추가’).

## 좁은 창 (768px 미만)

- 상단 메뉴 줄 없음. 위: 날짜 + 큰 제목 24px + 오른쪽 아이콘 버튼 4개(검색, 눈, 알림, 설정). 이번 달은 이 머리까지 오늘 띠 회색 바탕 안에 넣고, 인사 20px → 숫자 타일 3개(150px, 가로로 넘김) → 주 버튼 꽉 차게.
- 하단 독(`hg-dock`): 바닥 16px, 왼쪽 16px에 붙인 흰 알약, 폭은 내용만큼(칸 사이 4px). 현재 탭만 `ink` 알약 + 아이콘 + 이름(`aria-current="page"`), 나머지는 아이콘만(`aria-label`).
- 추가: 독과 같은 줄 오른쪽 16px에 검정 원 + 버튼(`hg-fab`, 52px, `aria-label="추가"`). 화면별 추가 대상: 이번 달, 목표 = 목표 / 우리 자산 = 자산, 부채 / 캘린더 = 챙길 날. 설정에서는 숨김.
- 본문 아래 여백 `space-22`(88px), 독에 가리지 않게.

## 실제 화면

- React 래퍼 `AppFrame`(packages/ui). 바깥 `hg-frame`(최소 화면 높이, `surface-alt` 바탕) 안에 상단 메뉴 줄, 좁은 창 머리(`hg-frame__mhead`, 이번 달은 `is-today`로 회색), 오늘 띠, 본문, 독, + 버튼.
- 좁은 창에서는 날짜를 머리에만(오늘 띠의 날짜 숨김).
- 좁은 창의 독과 + 버튼은 화면 아래 고정(`position: fixed`). 넓은 창에서는 숨김. 좁은 창 머리는 넓은 창에서 숨김.
- 오늘 띠의 버튼 묶음(`hg-frame__actions`)은 좁은 창에서 한 줄 꽉 차게, 주 버튼이 남은 폭을 채움.
- 아직 없는 메뉴·도구는 `aria-disabled`(탭) 또는 `disabled`(버튼)로 자리만.

## 공통

- 아이콘(현재 탭은 채운 모양): `house`(이번 달), `target`(목표), `wallet`(우리 자산), `calendar`(캘린더), `search`, `eye`, `bell`, `settings`, `plus`.
- 설정은 메뉴 탭에 두지 않음. 넓은 창은 아바타, 좁은 창은 톱니.
- 사이드바(`hg-side`, `hg-nav`)는 앱 틀에서 쓰지 않음(어드민 틀 AdminFrame만).
