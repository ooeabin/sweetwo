# AppFrame

앱 화면 틀. 흰 바탕(`canvas`) 위에 둥근 흰 카드(`hairline-soft` 테두리 + 그림자 `shadow-1`). 넓은 창은 왼쪽 흰 사이드바 + 가운데 본문. 좁은 창(2026-11-09 GCOO 앱 홈처럼, 사용자 승인)은 하단 탭 막대와 + 버튼이 없고, 홈 머리(워드마크 + 알림 + 설정 톱니 + ☰)의 메뉴 서랍(Drawer)과 홈 허브 상자(HomeHub)가 다른 메뉴 입구. 홈 밖 메뉴 첫 화면은 ‘‹(홈으로) 왼쪽 + 가운데 제목’ 머리(2026-11-17).

- 바탕(2026-11-09, `tone`): 기본은 흰 바탕(월급 W-01·W-02, 캘린더, 자산 관리, 설정, 2026-11-24 사용자 결정 “홈 화면을 제외하고는 다 흰 바탕을 디폴트로”). `tone="alt"`(`hg-frame--alt`)는 홈(H-01)만: 회색 바탕(`surface-alt`) + 테두리·그림자 없는 흰 상자. 흰 바탕 화면의 이어진 상자 사이는 8px 회색 띠. 회색 판 카드(`hg-card--fill`)와 제목 줄 보조 버튼은 회색 바탕 위에서 흰색.

- 소비자가 주는 것: 현재 메뉴, 화면 제목(또는 홈 인사), 날짜, 큰 숫자 하나(홈, 선택), 주 행동 1개, 본문, 알림 유무, 저장 상태.

## 넓은 창 (768px 이상)

- 사이드바(`hg-appside`, 232px, `surface`, 오른쪽 `hairline-soft` 선, 안쪽 `hg-appside__in`은 화면 높이에 붙어 있음): 위에서부터 워드마크 → 검색 칸(`hg-appside__search`: 돋보기 + “검색” + ⌘K, `surface-alt` 바탕) → 탭 4개(`hg-nav`: 홈, 월급, 자산 관리, 캘린더, 높이 44px. 2026-11-08 목표 자리에 월급, ADR 0007) → 빈칸 → 아래 줄(`hg-appside__foot`, 위 `hairline-soft` 선): 두 사람 아바타 + “설정”(`hg-appside__me`, 누르면 설정) → 눈(금액 가리기) → 알림(새 알림이면 `brand` 점).
- 현재 탭은 `surface-alt` 바탕 + `ink` 700 글자 + 채운 아이콘. 탭은 `a` + `aria-current="page"`.
- 저장 상태는 아바타 줄에 마우스를 올리면 툴팁(“모두 저장됨”, “저장 중”). 오프라인은 Banner.
- 인사 카드(`hg-today`, 홈에만): 흰 카드(`radius-2xl`, `hairline-soft` 테두리 + `shadow-1`, 안쪽 24px), 본문과 같은 1120px 폭.
  - 위 줄: 날짜(`stone` 12px) 위 인사(20px 700, “찬우님, 이번 달 월급 체크가 3개 남았어요”) → 오른쪽 끝에 큰 숫자 하나(`hg-today__value`, `display` 32px 700, `tabular-nums`).
  - 큰 숫자: 체크가 남았으면 한 개수/전체(“2/5”), 다 했으면 체크한 개수(2026-11-08 1순위 목표 % 없앰). 인사 문장과 같은 내용을 숫자로.
  - 그 아래 진행 막대(`hg-today__bar`, 10px, `surface-alt` 위 `ink` 채움, 큰 숫자와 같은 비율). 화면 읽기는 인사 문장으로(막대는 `aria-hidden`).
  - 맨 아래 오른쪽 버튼 묶음: ‘추가’(보조 버튼, 저금 항목 / 자산·부채 / 경조사) → 주 버튼 ‘월급날 확인하기’(체크 안 한 줄이 있을 때만, → W-02).
  - 숫자 타일 줄(`hg-stat`)은 틀에 남아 있지만 지금 홈은 안 씀.
- 본문(`hg-body`): 최대 1120px 가운데, 두 단(`hg-body__col`, 단 사이 24px, 카드 사이 24px). 1100px 미만이면 한 단(왼쪽 단 다음 오른쪽 단 순서).
- 본문 맨 위 띠(`hg-body__banner`, AppFrame `banner`): 두 단을 가로질러 한 줄(해제 대기 띠 등). Banner와 함께 씀.
- 다른 메뉴 화면: 인사 카드 대신 화면 제목 줄(`hg-pagetitle`: 제목 `hg-pagetitle__title` 22px 700 `h1`, 2026-11-09 24px에서, 오른쪽 동작 ‘추가’ 등, 본문과 같은 1120px 안쪽). 좁은 창은 머리 왼쪽에 메뉴 이름이 있어 제목은 숨기고 동작만.

## 좁은 창 (768px 미만)

- 사이드바 없음. 하단 탭 막대(`hg-dock`)와 + 버튼(`hg-fab`)은 2026-11-09 없앰(클래스도 지움).
- 머리(`hg-frame__mhead`, 높이 56px, 메뉴 첫 화면: 홈, 월급, 자산 관리, 캘린더, 설정 홈):
  - 홈: 왼쪽 워드마크(`hg-mhead__logo`, 사이드바와 같은 `Wordmark`, 높이 24px, 브랜드 오렌지 허용 자리), 오른쪽 아이콘 버튼 3개(22px `stone`, 누르는 칸 44px): 알림(새 알림이면 `brand` 점 + 화면 읽기 “알림, 새 알림이 있어요”, 2026-11-11) → N-02, 메뉴 ☰(`list`, `aria-label="메뉴"`, `aria-haspopup="dialog"`, `aria-expanded`) → 메뉴 서랍(Drawer). 알림과 ☰ 사이에 설정 톱니(`settings`, `aria-label="설정"`) → S-10(2026-11-16 서랍에서 머리로). 새 알림 점은 종 아이콘 오른쪽 위 어깨에 붙고 테두리는 머리 바탕색(홈은 `surface-alt`, `--dot-ring`).
  - 홈 밖 메뉴 첫 화면(월급, 자산 관리, 캘린더, 설정 홈 S-10): 왼쪽 ‹(`hg-mhead__back hg-back`, `chevron-left` 24px, `ink`, `aria-label="홈으로"`, 모든 뒤로 버튼의 기준 자리. `onBack`을 주면 그 동작, 2026-11-18 W-01 ↔ W-02 링크로 열었을 때 ‹ = 건너온 화면) + 화면 이름 가운데 제목(2026-11-18 서랍 줄 이름과 똑같이: 이번 달 월급 체크, 월급 계획 템플릿, 자산·부채, 달력. 서랍에 줄이 없는 첫 화면은 탭 이름. 넓은 창 제목 줄 `page.title`도 같은 이름, 사이드바 탭 이름은 그대로)(`hg-mhead__title`, `hg-frame__mhead--back` 3칸 그리드, 17px/24px 500 `ink`(2026-11-26 ‘머리 B안’ `--text-nav-title`), 높이 64px로 PageHeader·W-21 머리와 같음, 그 화면의 `h1`, 2026-11-17 사용자 결정: 왼쪽 정렬 굵은 큰 제목은 없앰). 오른쪽은 기본 비어 있고, 화면이 `narrowAction`을 주면 오른쪽 칸(`hg-mhead__action`)에 동작 하나(2026-11-26 W-01: 처음엔 글자 ‘편집’, 같은 날 ‘W-01 정리 A안’으로 ⋯ 메뉴, 아래 ‘머리 오른쪽 ⋯’). ‹는 홈으로 바꿔치기 이동(뒤로 쌓지 않음), 안드로이드 하드웨어 뒤로도 홈으로(브리지 `onBack`).
  - 두 사람 아바타와 이름은 머리에 없음(넓은 창 사이드바 아바타 줄은 그대로). 초대 입구는 홈 큰 상자 아래 코코아 초대 띠(2026-11-11), 서랍 ‘초대하기’(합류 전·혼자 쓰기만), 설정 › 우리 둘(S-12, 2026-11-16 서랍 ‘우리 둘’을 설정 홈 두 사람 카드 아래 줄로 옮김).
  - 제목(`h1`) 하나: 홈 밖 메뉴 화면은 머리 제목이 `h1`(제목 줄 `hg-pagetitle__title`은 좁은 창에서 숨김). 홈은 워드마크가 그림이고 `h1`은 제목 줄 “홈”(`today.plain`, 좁은 창은 화면 읽기용). 제목 줄이 없는 홈(합류 대기, 불러오는 중)은 머리에 화면 읽기용 `h1`(`hg-sr`) “홈”.
- 메뉴 서랍(Drawer, 2026-11-09, 2026-11-16 2단): ☰로 엶. 줄 묶음 월급(이번 달 월급 체크, 월급 계획 템플릿, 지난 달 모아보기. 2026-11-18 ‘저축·투자’ 줄은 W-01 묶음으로 합쳐 없앰), 자산 관리(자산·부채, 자산 순위), 캘린더(달력, 선물 기록)(2026-11-17 줄 정리), 하위 줄은 늘 펼침 / 초대하기(합류 전·혼자 쓰기만, 연결 중·해제 대기 중에는 묶음 없음) / 공지(앱 안 공지 화면 N-04, 보여 줄 공지가 하나라도 있을 때 늘 보임, 안 읽은 노출 중 공지가 있으면 새 알림 점), 도움말. ‘홈’·‘문의’·버전·알림 종은 없음. → Drawer.
- 본문: 좌우 16px, 카드 사이 12px, 섹션 사이 24px(2026-11-09 밀도). 카드는 흰색 `radius-xl` 안쪽 20px(목록 묶음은 행이 안쪽 여백을 가짐). 섹션 제목(SectionHeader)은 카드 밖. 본문 아래 여백은 `space-8` + 안전 영역(탭 막대 몫 없음).
- 안전 영역(2026-11-10, `viewport-fit=cover`): 틀(`hg-frame`)이 위·좌우에 `env(safe-area-inset-*)`만큼 안쪽 여백, 넓은 창 사이드바는 위 안전 영역 아래에 붙음. 로그인·질문·잠금 화면은 AuthLayout·QuestionLayout·LockScreen이 같은 방식으로.
- 추가(2026-11-09 + 버튼 대신): 화면 안 회색 글자 줄 AddRow(`hg-addrow`): 월급 W-02 저금 묶음 끝 ‘+ 추가’, 자산 관리 F-02 목록 끝 ‘+ 자산 추가’ / ‘+ 부채 추가’, 캘린더 Y-04 보기 필터 탭 아래 ‘+ 일정 추가’(2026-11-17, 2026-11-23 필터가 밑줄 탭이 되며 오른쪽 → 아래 줄). 넓은 창 제목 줄 ‘추가’(`hg-wide-only`)는 그대로, 좁은 창에서는 숨기고 제목 줄에 남는 동작이 없으면 줄째 숨김.
- 머리 공통화(2026-11-04, 2026-11-09 고침): 메뉴 첫 화면은 위 앱 머리, 상세·설정 하위·알림(`MainFrame sub`)은 앱 머리 없이 맨 위 “‹ 제목 ⋯”(PageHeader) 한 줄. 동작 없는 페이지 제목 줄(`hg-pagetitle`)은 좁은 창에서 숨김. 질문 화면(QuestionLayout)은 앱 머리 없이 ‘‹’ + 진행 막대 + 큰 질문 제목.
- 하위 화면(`AppFrame sub`, `hg-frame--sub`, `MainFrame sub="detail" | "settings"`, 2026-11-04): 좁은 창에서 앱 머리를 숨기고 본문 맨 위 “‹ 제목”(PageHeader, 위 여백 8px). 넓은 창은 그대로.

## 실제 화면

- React 래퍼 `AppFrame`(packages/ui). 바깥 `hg-frame`(흰 바탕, `tone="alt"`면 `hg-frame--alt` 회색, 넓은 창 두 칸 그리드) 안에 사이드바, `hg-frame__main`(좁은 창 머리, 인사 카드 또는 제목 줄, 본문). 2026-11-09 `onMenu`(☰), `menuOpen`, `onHome`(‹), `labels.menu`·`labels.home` 더함, `onAdd`·`labels.add`(+ 버튼) 없앰. 서랍은 소비자(`MainFrame`)가 Drawer로 그림.
- 맨 바깥 카드(Card, ListRow 묶음, Checklist, Calendar, 차트)와 인사 카드는 `hairline-soft` 테두리 + 아주 옅은 그림자(`shadow-1`). 카드 안의 카드는 원래 모양 그대로(그림자 없음).
- **머리 오른쪽 글자 동작**(2026-11-26 사용자 결정, 클래스 `hg-headaction`): 좁은 창 머리 오른쪽 글자 버튼은 모두 한 규칙 — 글자 15/400(`--text-body`, 2026-11-26 13에서 되돌림: 작으니 어색하다는 사용자 결정) `ink-2`(꺼짐 `muted`), 누르는 칸 높이 44, 글자 끝 = 화면 오른쪽 24(본문 끝: 머리 옆 16 + 버튼 안쪽 16 − 음수 margin 8). 지금 N-02 ‘모두 읽음’(NotificationPanel.md)과 W-01 순서 바꾸기 중 ‘완료’(2026-11-26). 넓은 창은 제목 줄 `page.actions`에 같은 동작(글자 버튼 `hg-btn--link`, `hg-wide-only`로 좁은 창에서는 숨김). W-01 ‘편집’은 같은 날 ‘W-01 정리 A안’으로 아래 ⋯로 바꿈(이 공통 규칙은 ‘모두 읽음’용으로 남음).
- **머리 오른쪽 ⋯**(2026-11-26 사용자 결정 ‘W-01 정리 A안’, W-01): 글자 동작 대신 `Menu` ⋯ 하나(IconButton ghost `ellipsis`, 화면 읽기 “더 보기”, 누르는 칸 44×44, `ink`, 버튼 오른쪽 끝 = 화면 오른쪽 8 → ‹(왼쪽 8)와 좌우 대칭, 열린 동안 `surface-alt` 원). 메뉴 순서: ‘순서 바꾸기’(줄이 하나라도 있고 고칠 수 있을 때, 2026-11-26 사용자 결정으로 예전 ‘편집’ 모드 대신) → ‘통장 잔액과 맞추기’(고칠 수 있는 저축·투자가 있을 때) → ‘수입 기록’ → ‘공유하기’(줄이 있을 때) → ‘추천값으로 다시 채우기’(줄이 있고 고칠 수 있을 때). 파트너 탭(각자)은 ‘공유하기’만. 순서 바꾸는 중에는 ⋯ 대신 같은 자리에 ‘완료’: 좁은 창 = `hg-headaction` 글자 동작(15/400 `ink-2`, 높이 44, 글자 끝 = 화면 오른쪽 24, 버튼 끝 = ⋯ 버튼 끝 = 화면 오른쪽 8)이라 바뀌어도 자리·높이가 같음. 넓은 창은 제목 줄 `page.actions`에 같은 ⋯ 메뉴, 순서 바꾸는 중에는 같은 자리 ‘완료’(`hg-btn--link`).
- 좁은 창 머리는 넓은 창에서 숨김. (2026-11-09 좁은 창 탭 막대·+ 버튼 없앰)
- 아직 없는 메뉴·도구는 `aria-disabled`(탭) 또는 `disabled`(버튼)로 자리만.

## 공통

- 아이콘(사이드바 현재 탭은 채운 모양): `house`(홈), `hand-coins`(월급, 2026-11-08, 채운 모양 2026-11-09 추가), `wallet`(자산 관리), `calendar`(캘린더), `search`(넓은 창 사이드바만), `eye`, `bell`, `settings`(넓은 창 아바타 줄 옆은 글자), `list`(좁은 창 ☰, 2026-11-09), `chevron-left`(좁은 창 ‹ 홈으로).
- 설정은 메뉴 탭에 두지 않음. 넓은 창은 사이드바 아래 아바타 줄, 좁은 창은 홈 머리 설정 톱니(2026-11-16, 서랍 ‘설정’·‘내 정보’ 줄은 없앰. 내 정보는 설정 홈 맨 위 줄). 넓은 창은 아바타 줄이 설정 입구라 톱니를 따로 두지 않음.
- 본문 단 수는 넘긴 `columns` 개수(`--cols`). 1100px 미만은 한 단. 맨 위 띠(`banner`)가 있어도 단 너비는 같음

- 홈 인사 카드 없음(2026-11-03, `today.plain`): 다른 메뉴와 같은 제목 줄(`hg-pagetitle hg-today--plain`, 넓은 창 “홈” + ‘추가’), 좁은 창은 제목을 화면 읽기용으로만(1px로 가림, 머리 왼쪽은 워드마크). Meter `started`, 새 화면은 맨 위부터(뒤로 가기 제외).

- ‘‹ 제목’ 줄(좁은 창, 2026-11-04): 하위 화면 맨 위(앱 머리 없음, 위 여백 8px). ‹ 왼쪽, 제목 17px 600 가운데, 동작(⋯, ‘모두 읽음’) 오른쪽.
- React 래퍼 탭 키(2026-11-08): `AppTab = 'month' | 'salary' | 'assets' | 'calendar'`(예전 `goals` 자리에 `salary`).
