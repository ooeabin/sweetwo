# AppFrame

앱 화면 틀. 흰 바탕(`canvas`) 위에 둥근 흰 카드(`hairline-soft` 테두리 + 그림자 `shadow-1`). 넓은 창은 왼쪽 흰 사이드바 + (홈만) 인사 카드 + 가운데 두 단 본문, 좁은 창은 머리 + 인사 카드 + 화면 아래 탭 막대와 + 버튼(2026-10-27, 좁은 창은 GCOO 느낌).

- 소비자가 주는 것: 현재 메뉴, 화면 제목(또는 홈 인사), 날짜, 큰 숫자 하나(홈, 선택), 주 행동 1개, 본문, 알림 유무, 저장 상태.

## 넓은 창 (768px 이상)

- 사이드바(`hg-appside`, 232px, `surface`, 오른쪽 `hairline-soft` 선, 안쪽 `hg-appside__in`은 화면 높이에 붙어 있음): 위에서부터 워드마크 → 검색 칸(`hg-appside__search`: 돋보기 + “검색” + ⌘K, `surface-alt` 바탕) → 탭 4개(`hg-nav`: 홈, 월급, 우리 자산, 캘린더, 높이 44px. 2026-11-08 목표 자리에 월급, ADR 0007) → 빈칸 → 아래 줄(`hg-appside__foot`, 위 `hairline-soft` 선): 두 사람 아바타 + “설정”(`hg-appside__me`, 누르면 설정) → 눈(금액 가리기) → 알림(새 알림이면 `brand` 점).
- 현재 탭은 `surface-alt` 바탕 + `ink` 700 글자 + 채운 아이콘. 탭은 `a` + `aria-current="page"`.
- 저장 상태는 아바타 줄에 마우스를 올리면 툴팁(“모두 저장됨”, “저장 중”). 오프라인은 Banner.
- 인사 카드(`hg-today`, 홈에만): 흰 카드(`radius-2xl`, `hairline-soft` 테두리 + `shadow-1`, 안쪽 24px), 본문과 같은 1120px 폭.
  - 위 줄: 날짜(`stone` 13px) 위 인사(22px 700, “찬우님, 이번 달 월급 체크가 3개 남았어요”) → 오른쪽 끝에 큰 숫자 하나(`hg-today__value`, 40px 700, `tabular-nums`).
  - 큰 숫자: 체크가 남았으면 한 개수/전체(“2/5”), 다 했으면 체크한 개수(2026-11-08 1순위 목표 % 없앰). 인사 문장과 같은 내용을 숫자로.
  - 그 아래 진행 막대(`hg-today__bar`, 10px, `surface-alt` 위 `ink` 채움, 큰 숫자와 같은 비율). 화면 읽기는 인사 문장으로(막대는 `aria-hidden`).
  - 맨 아래 오른쪽 버튼 묶음: ‘추가’(보조 버튼, 저금 항목 / 자산·부채 / 챙길 날) → 주 버튼 ‘월급 체크하기’(체크 안 한 줄이 있을 때만, → W-02).
  - 숫자 타일 줄(`hg-stat`)은 틀에 남아 있지만 지금 홈은 안 씀.
- 본문(`hg-body`): 최대 1120px 가운데, 두 단(`hg-body__col`, 단 사이 24px, 카드 사이 24px). 1100px 미만이면 한 단(왼쪽 단 다음 오른쪽 단 순서).
- 본문 맨 위 띠(`hg-body__banner`, AppFrame `banner`): 두 단을 가로질러 한 줄(해제 대기 띠 등). Banner와 함께 씀.
- 다른 메뉴 화면: 인사 카드 대신 화면 제목 줄(`hg-pagetitle`: 제목 `hg-pagetitle__title` 24px 700 `h1`, 오른쪽 동작 ‘추가’ 등, 본문과 같은 1120px 안쪽). 좁은 창은 머리에 메뉴 이름이 있어 제목은 숨기고 동작만.

## 좁은 창 (768px 미만)

- 사이드바 없음. 머리(`hg-frame__mhead`): 모든 화면(2026-11-04, 전에는 홈만) 왼쪽 두 사람(2026-11-03 워드마크 대신, 카카오뱅크처럼): 아바타 둘(`hg-avatars`, 미합류면 파트너 자리에 기본 그림 `hg-avatar--empty`: `surface-alt` 원 안 `stone` 사람 아이콘(2026-11-05 빈 자리 그림 파일은 만들지 않음). 사람 아바타는 `people[].src`(프로필 사진)가 있으면 사진. 이때 두 사람 묶음 전체가 버튼, 누르면 초대 S-12, 이름 “함께할 사람 초대하기”) + 이름 “찬우, 예빈”(`hg-mhead__names`, 2026-11-04 토스형: 칩 없이 15px 600 `ink`, 넘치면 …, 누를 수 없음). 메뉴 이름은 화면에 보이지 않는 제목(`hg-sr`)으로만 → 오른쪽 아이콘 버튼 3개(22px `stone`)(검색, 알림, 설정. 2026-11-03 금액 가리기 눈은 설정 S-10으로).
- 인사 카드: 좌우 16px, 안쪽 20px. 인사 20px 700, 큰 숫자 32px. 버튼 묶음은 한 줄 꽉 차게, 주 버튼이 남은 폭을 채움.
- 본문: 좌우 16px, 카드 사이 16px. 카드는 흰색 `radius-xl` 안쪽 20px(목록 묶음은 행이 안쪽 여백을 가짐). 섹션 제목(SectionHeader)은 카드 밖.
- 하단 탭 막대(`hg-dock`, 배민 느낌): 화면 아래 12px(+ 기기 안전 영역) 가운데에 떠 있는 흰 알약(`hairline-soft` 테두리, `shadow-2`, 안쪽 6px). 탭 4칸은 72×52px, 칸마다 아이콘 24px 위 + 이름 12px 아래. 2026-11-05 토스형: 네 칸 모두 채운 아이콘. 현재 탭은 바탕 없이 아이콘·이름 `ink`, 나머지는 아이콘 `muted` + 이름 `stone`(2026-11-03부터 바탕 없음).
- 추가: 탭 막대 위 오른쪽 16px에 검정 원 + 버튼(`hg-fab`, 52px, `aria-label="추가"`). 화면별 추가 대상: 월급 = 저금 항목(W-11a) / 우리 자산 = 자산·부채 / 캘린더 = 챙길 날. 홈(오늘 띠 ‘추가’ 메뉴가 같은 일, 2026-11-03)과 설정에서는 숨김.
- 추가 입구 하나로(2026-11-03): + 버튼은 메뉴 첫 화면(월급 W-02, 우리 자산 F-01·F-02, 캘린더 Y-01·Y-04)에만. 상세·하위 화면(`MainFrame sub="detail"`: W-01, W-10, F-04, Y-05, Y-09)에는 없음. 좁은 창에서는 제목 줄의 ‘+ 추가’(`hg-wide-only`)를 숨기고, 제목 줄에 남는 동작이 없으면 줄째 숨김. 빈 상태의 추가 버튼은 회색 보조. + 버튼이 있는 화면은 본문 아래 여백을 버튼 높이만큼 더 둬서 마지막 줄을 가리지 않음(2026-11-04).
- 머리 공통화(2026-11-04, 같은 날 고침): 메뉴 첫 화면(홈, 월급, 우리 자산, 캘린더, 설정)은 홈과 똑같은 좁은 창 앱 머리(왼쪽 두 사람 아바타 28px + 이름 15px 600 `ink`(칩 없음), 오른쪽 검색·알림·설정 아이콘 22px `stone`, 56px)를 두고(메뉴 이름은 화면 읽기용 제목 `hg-sr`로만), 상세·설정 하위·알림(`MainFrame sub`)은 앱 머리와 탭 막대 없이 맨 위 “‹ 제목 ⋯”(PageHeader) 한 줄. 동작 없는 페이지 제목 줄(`hg-pagetitle`)은 좁은 창에서 숨겨 머리와 ‘‹ 제목’ 사이 거리가 같음. 하위 화면에는 `page` 제목을 넘기지 않음(넓은 창도 상세와 같은 ‘‹ 이전’ + 제목). 질문 화면(QuestionLayout: 추가·고치기 흐름, 온보딩, 월급 체크리스트 W-01·W-02·W-05)은 앱 머리 없이 ‘‹’ + 진행 막대 + 큰 질문 제목.
- 하위 화면(`AppFrame sub`, `hg-frame--sub`, `MainFrame sub="detail" | "settings"`, 2026-11-04): 좁은 창에서 앱 머리와 탭 막대를 숨기고 본문 맨 위 “‹ 제목”(PageHeader, 위 여백 8px). 본문 아래 여백은 탭 막대 몫 없이 `space-8` + 안전 영역. 넓은 창은 그대로.
- 본문 아래 여백은 탭 막대와 + 버튼에 가리지 않게(`space-22` + 24px + 안전 영역).

## 실제 화면

- React 래퍼 `AppFrame`(packages/ui). 바깥 `hg-frame`(흰 바탕, 넓은 창 두 칸 그리드) 안에 사이드바, `hg-frame__main`(좁은 창 머리, 인사 카드 또는 제목 줄, 본문), 탭 막대, + 버튼.
- 맨 바깥 카드(Card, ListRow 묶음, Checklist, Calendar, 차트)와 인사 카드는 `hairline-soft` 테두리 + 아주 옅은 그림자(`shadow-1`). 카드 안의 카드는 원래 모양 그대로(그림자 없음).
- 좁은 창의 탭 막대와 + 버튼은 화면 아래 고정(`position: fixed`). 넓은 창에서는 숨김. 좁은 창 머리는 넓은 창에서 숨김.
- 아직 없는 메뉴·도구는 `aria-disabled`(탭) 또는 `disabled`(버튼)로 자리만.

## 공통

- 아이콘(현재 탭은 채운 모양): `house`(홈), `hand-coins`(월급, 2026-11-08), `wallet`(우리 자산), `calendar`(캘린더), `search`, `eye`, `bell`, `settings`, `plus`.
- 설정은 메뉴 탭에 두지 않음. 넓은 창은 사이드바 아래 아바타 줄, 좁은 창은 톱니.
- 본문 단 수는 넘긴 `columns` 개수(`--cols`). 1100px 미만은 한 단. 맨 위 띠(`banner`)가 있어도 단 너비는 같음

- 홈 인사 카드 없음(2026-11-03, `today.plain`): 다른 메뉴와 같은 제목 줄(`hg-pagetitle hg-today--plain`, 넓은 창 “홈” + ‘추가’), 좁은 창은 제목을 화면 읽기용으로만(1px로 가림). Meter `started`, 새 화면은 맨 위부터(뒤로 가기 제외).

- ‘‹ 제목’ 줄(좁은 창, 2026-11-04 토스형): 하위 화면 맨 위(앱 머리 없음, 위 여백 8px). ‹ 왼쪽, 제목 17px 600 가운데, 동작(⋯, ‘모두 읽음’) 오른쪽.
- React 래퍼 탭 키(2026-11-08): `AppTab = 'month' | 'salary' | 'assets' | 'calendar'`(예전 `goals` 자리에 `salary`).
