# AppFrame

앱 화면 틀. 회색 바탕(`canvas`) 위에 흰 카드. 넓은 창은 왼쪽 흰 사이드바 + (홈만) 인사 카드 + 가운데 두 단 본문, 좁은 창은 머리 + 인사 카드 + 화면 아래 탭 막대와 + 버튼(2026-10-27, 한국 금융 앱처럼 회색 바탕 + 흰 카드, 좁은 창은 GCOO 느낌).

- 소비자가 주는 것: 현재 메뉴, 화면 제목(또는 홈 인사), 날짜, 큰 숫자 하나(홈, 선택), 주 행동 1개, 본문, 알림 유무, 저장 상태.

## 넓은 창 (768px 이상)

- 사이드바(`hg-appside`, 232px, `surface`, 오른쪽 `hairline-soft` 선, 안쪽 `hg-appside__in`은 화면 높이에 붙어 있음): 위에서부터 워드마크 → 검색 칸(`hg-appside__search`: 돋보기 + “검색” + ⌘K, `surface-alt` 바탕) → 탭 4개(`hg-nav`: 홈, 목표, 우리 자산, 캘린더, 높이 44px) → 빈칸 → 아래 줄(`hg-appside__foot`, 위 `hairline-soft` 선): 두 사람 아바타 + “설정”(`hg-appside__me`, 누르면 설정) → 눈(금액 가리기) → 알림(새 알림이면 `brand` 점).
- 현재 탭은 `surface-alt` 바탕 + `ink` 700 글자 + 채운 아이콘. 탭은 `a` + `aria-current="page"`.
- 저장 상태는 아바타 줄에 마우스를 올리면 툴팁(“모두 저장됨”, “저장 중”). 오프라인은 Banner.
- 인사 카드(`hg-today`, 홈에만): 흰 카드(`radius-2xl`, 안쪽 24px), 본문과 같은 1120px 폭.
  - 위 줄: 날짜(`stone` 13px) 위 인사(22px 700, “찬우님, 이번 달 월급 체크가 3개 남았어요”) → 오른쪽 끝에 큰 숫자 하나(`hg-today__value`, 40px 700, `tabular-nums`).
  - 큰 숫자: 체크가 남았으면 한 개수/전체(“2/5”), 다 했으면 1순위 목표 %(“18%”). 인사 문장과 같은 내용을 숫자로.
  - 그 아래 진행 막대(`hg-today__bar`, 10px, `surface-alt` 위 `ink` 채움, 큰 숫자와 같은 비율). 화면 읽기는 인사 문장으로(막대는 `aria-hidden`).
  - 맨 아래 오른쪽 버튼 묶음: ‘추가’(보조 버튼, 목표 / 가진 돈·대출 / 챙길 날) → 주 버튼 ‘월급 체크하기’(체크 안 한 줄이 있을 때만, → W-02).
  - 숫자 타일 줄(`hg-stat`)은 틀에 남아 있지만 지금 홈은 안 씀.
- 본문(`hg-body`): 최대 1120px 가운데, 두 단(`hg-body__col`, 단 사이 24px, 카드 사이 24px). 1100px 미만이면 한 단(왼쪽 단 다음 오른쪽 단 순서).
- 본문 맨 위 띠(`hg-body__banner`, AppFrame `banner`): 두 단을 가로질러 한 줄(해제 대기 띠 등). Banner와 함께 씀. 회색 바탕 위라 안내 띠(`hg-banner--info`)는 흰색.
- 다른 메뉴 화면: 인사 카드 대신 화면 제목 줄(`hg-pagetitle`: 제목 `hg-pagetitle__title` 24px 700 `h1`, 오른쪽 동작 ‘추가’ 등, 본문과 같은 1120px 안쪽). 좁은 창은 머리에 메뉴 이름이 있어 제목은 숨기고 동작만.

## 좁은 창 (768px 미만)

- 사이드바 없음. 머리(`hg-frame__mhead`, 회색 바탕): 홈은 왼쪽 워드마크, 다른 메뉴는 메뉴 이름(24px) → 오른쪽 아이콘 버튼 4개(검색, 눈, 알림, 설정).
- 인사 카드: 좌우 16px, 안쪽 20px. 인사 20px 700, 큰 숫자 32px. 버튼 묶음은 한 줄 꽉 차게, 주 버튼이 남은 폭을 채움.
- 본문: 좌우 16px, 카드 사이 16px. 카드는 흰색 `radius-xl` 안쪽 20px(목록 묶음은 행이 안쪽 여백을 가짐). 섹션 제목(SectionHeader)은 카드 밖 회색 바탕 위.
- 하단 탭 막대(`hg-dock`, 배민 느낌): 화면 아래 12px(+ 기기 안전 영역) 가운데에 떠 있는 흰 알약(`hairline-soft` 테두리, `shadow-2`, 안쪽 6px). 탭 4칸은 72×52px, 칸마다 아이콘 24px 위 + 이름 12px 아래. 현재 탭은 `surface-alt` 알약 바탕 + `ink` + 채운 아이콘, 나머지는 `slate`.
- 추가: 탭 막대 위 오른쪽 16px에 검정 원 + 버튼(`hg-fab`, 52px, `aria-label="추가"`). 화면별 추가 대상: 홈, 목표 = 목표 / 우리 자산 = 가진 돈·대출 / 캘린더 = 챙길 날. 설정에서는 숨김.
- 본문 아래 여백은 탭 막대와 + 버튼에 가리지 않게(`space-22` + 24px + 안전 영역).

## 실제 화면

- React 래퍼 `AppFrame`(packages/ui). 바깥 `hg-frame`(회색 바탕, 넓은 창 두 칸 그리드) 안에 사이드바, `hg-frame__main`(좁은 창 머리, 인사 카드 또는 제목 줄, 본문), 탭 막대, + 버튼.
- 회색 바탕 위 맨 바깥 카드(Card, ListRow 묶음, Checklist, Calendar, 차트)는 테두리 없는 흰 카드. 카드 안의 카드는 원래 모양 그대로. 바탕에 바로 놓인 회색 판(`hg-card--fill`, `hg-stat`)은 흰색으로.
- 좁은 창의 탭 막대와 + 버튼은 화면 아래 고정(`position: fixed`). 넓은 창에서는 숨김. 좁은 창 머리는 넓은 창에서 숨김.
- 아직 없는 메뉴·도구는 `aria-disabled`(탭) 또는 `disabled`(버튼)로 자리만.

## 공통

- 아이콘(현재 탭은 채운 모양): `house`(홈), `target`(목표), `wallet`(우리 자산), `calendar`(캘린더), `search`, `eye`, `bell`, `settings`, `plus`.
- 설정은 메뉴 탭에 두지 않음. 넓은 창은 사이드바 아래 아바타 줄, 좁은 창은 톱니.
- 본문 단 수는 넘긴 `columns` 개수(`--cols`). 1100px 미만은 한 단. 맨 위 띠(`banner`)가 있어도 단 너비는 같음
