# ProgressSteps

질문 흐름의 진행 막대. 칸만 보이고 글자는 붙이지 않음.

- 소비자가 주는 것: 전체 칸 수, 끝낸 칸 수, 지금 칸 안에서 진행한 비율(`--fill`, 질문 수 기준).
- 칸 높이 6px, 알약 모양, 칸 사이 4px.
- 끝낸 칸 `ink`, 남은 칸 `hairline`. 지금 칸은 `ink`가 질문마다 차오르고, 채움 끝에 손잡이(14px 흰 원 + 3px `ink` 테두리)가 따라감(`dur-base` `ease-out`). 손잡이로 “지금 여기”를 보여 줌.
- `brand` 쓰지 않음.
- 배우자 합류 4칸, 결혼일 전환 3칸. 온보딩은 ChapterBar(챕터 이름 + 챕터 안 막대)를 씀.
