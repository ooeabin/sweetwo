# WeekStrip

이번 주 날짜 띠(2026-10-27, 현대카드 소비 캘린더 느낌). 2026-11-09부터 캘린더 Y-01 맨 위(‘목록/달력’ 탭 대신, 아래 보기 필터 줄 오른쪽 ‘달력 ›’). 예전 홈 ‘일정’(H-05) 자리는 없앰.

- 소비자가 주는 것: 오늘(KST), 일정이 있는 날 묶음, 공휴일(선택).
- 일요일부터 토요일까지 7칸. 칸마다 위 요일(12px `stone`), 가운데 날짜(15px 600, 34px 원), 아래 5px 점.
- 오늘은 `ink` 원 + `on-ink` 글자. 지난 날은 날짜 `stone`. 일요일·공휴일은 요일과 날짜를 `holiday-ink`. 일정이 있는 날만 점(2026-11-09 `accent-app` 오렌지 5px, 그래픽이라 뜻은 아래 목록 글자로). 주 넘기기 ‹ ›는 없음.
- 흰 카드(`hairline-soft` 테두리 + `shadow-1`, `radius-xl`). 아래 일정 목록이 같은 내용을 읽어 주므로 띠는 `aria-hidden`.
- React 래퍼 `WeekStrip`(packages/ui): `today`, `marked`, `holidays`.
