# AuthLayout

로그인, 가입 화면 틀(`hg-auth`). A-01 실행, O-01 시작, A-02 로그인 방법, A-03 브라우저 대기, A-08 세션 만료. 질문 하나를 받는 A-04, A-05, A-06 설정은 QuestionLayout.

- 소비자가 주는 것: 장면 자리(선택, SceneMedia, 지금은 비어 있음), 상태 아이콘(선택), 제목, 보조 1줄(선택), 안내 띠(선택), 버튼 묶음, 뒤로(선택), 아래 안내 1줄(선택).
- 가운데 한 열, 글자 가운데 정렬. 제목 `hg-auth__title`(24px 700, 줄바꿈 `\n` 그대로, 낱말 중간에서 끊지 않음 `keep-all`), 보조 `hg-auth__help`.
- 글자 링크(`hg-btn--link`, ‘업데이트 없이 보기만 할게요’ 등)는 파랑이 아니라 `slate`. O-01 ‘코드 입력하기’만 `ink` 700 밑줄(당근 ‘로그인’ 링크처럼 눈에 띄게).
- 상태 아이콘 `hg-auth__icon`(2026-11-02): 제목 위 72px `surface-alt` 원 + `ink` 아이콘 32px(`aria-hidden`). 글자만 있던 상태 화면을 하나의 모양으로 맞춤. 로그인 대기(A-03) `loader-circle`(천천히 돎 `is-busy`, ‘동작 줄이기’면 멈춤), 업데이트 필요 `download`, 점검 중 `settings`, 오프라인(로그인 전) `link`, 실행 오류 `circle-alert`, 세션 만료(A-08) `lock`, Face ID·Touch ID 켜기(A-06) `fingerprint`. 상태 화면 머리에 워드마크는 두지 않음.
- 안내 띠 `hg-auth__alert`(Banner `hg-banner--info` + `info` 16px, 최대 360px, `role="status"`): 버튼 묶음 바로 위. 로그인 취소, 다른 소셜로 가입함, 오프라인, 브라우저 열기 실패, 업데이트 실패. 화면 맨 아래 작은 회색 글씨로 두지 않음.
- 두 갈래 질문(A-06 Face ID 켜기): 버튼 두 개를 가로로(`hg-auth__actions--row`, 보조 ‘나중에 할게요’ 1 : 주 2). 현대카드 ‘다음에 | 설정’.
- 버튼 묶음 `hg-auth__actions`: 세로로 쌓고 최대 360px. 버튼은 꽉 차게(`hg-btn--block`). ‘최근 사용’ 배지는 버튼 안 오른쪽 `hg-tag`.
- 뒤로 `hg-auth__back`: 왼쪽 위. 좁은 창은 IconButton `chevron-left`, 넓은 창은 고스트 버튼 “‹ 이전”(`backLabel`, A-02는 “‹ 처음으로”).
- 좁은 창(768px 미만): 상태 화면은 아이콘 원 + 제목을 묶어 세로 가운데, 버튼 묶음(위 안내 띠 포함)은 아래 끝으로. 머리 자리에 아바타(`hg-avatar`)를 두면 아바타+제목을 묶어 세로 가운데로(A-02 초대로 들어왔을 때).
- 입력이 있는 화면(P-01 코드 직접 입력)은 입력 칸(`hg-field`)과 주 버튼을 함께 버튼 묶음 안에 둔다(좁은 창에서 같이 아래로).
- 소셜 버튼 왼쪽에 제공자 마크 `ProviderMark`(`hg-btn__mark`, 20px)를 글자 앞에 둔다.
  - 카카오는 공식 노란 브랜드 버튼 `hg-btn--kakao`(바탕 `#fee500` + 글자 `rgba(0,0,0,.85)`, 라이트·다크 모두 노랑). 마크는 말풍선 심볼로 `currentColor`(버튼의 어두운 글자색)를 따른다.
  - 구글·애플은 `hg-btn--secondary`(테두리). 마크는 구글 4색 G(고유색 그대로), 애플은 단색 `currentColor`(라이트 검정·다크 흰색, 애플 가이드).
  - 제공자 색(카카오 노랑, 구글 4색)은 워드마크 SVG처럼 토큰 예외다. 그 밖의 버튼은 디자인 토큰만 쓴다(→ 개발 가이드 ‘OAuth 앱과 리다이렉트’).
- 히어로 배치 `hg-auth--hero`(AuthLayout `className`): 워드마크 40px + 캐치프레이즈 제목 한 줄(20px 700) + (O-01만) 보조 2줄(`hg-auth__help` 15px `slate`)을 한 묶음으로, 좁은 창은 세로 가운데, 버튼은 아래 끝(2026-11-02 당근 시작 화면처럼). O-01은 보조 버튼 없이 주 버튼 아래 한 줄 `hg-auth__alt`(14px `slate` “초대를 받았나요?” + 글자 링크 ‘코드 입력하기’). O-01 시작·A-02 로그인이 같은 배치로 쓴다.
- A-02 로그인 전용 `hg-auth--login`(히어로와 함께 건다): 소셜 버튼은 마크를 버튼 왼쪽에 고정하고 글자는 가운데·굵기 700. 구글·애플(`hg-btn--secondary`)은 로그인에서 회색 채움 대신 중간 회색 테두리 버튼(바탕 투명)으로 둔다. 카카오 마크는 살짝 키운다(24px, 다른 마크는 20px). ‘최근 사용’은 버튼 안 배지(`hg-tag`)가 아니라 해당 버튼 위 오른쪽 말풍선 `hg-auth__recent`(꼬리 아래)로 둔다. 소셜 버튼 왼쪽 마크는 이 변형에서만 왼쪽 고정이고, 기본(다른 화면)은 글자 앞에 두는 평소 배치 그대로.

쓰는 곳: A-01, O-01, A-02, A-03, A-08, P-01, 웹 로그인 콜백.
