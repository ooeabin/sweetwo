# AuthLayout

로그인, 가입 화면 틀(`hg-auth`). A-01 실행, O-01 시작, A-02 로그인 방법, A-03 브라우저 대기, A-08 세션 만료. 질문 하나를 받는 A-04, A-05, A-06 설정은 QuestionLayout.

- 소비자가 주는 것: 장면 자리(선택, SceneMedia, 지금은 비어 있음), 제목, 보조 1줄(선택), 버튼 묶음, 뒤로(선택), 아래 안내 1줄(선택).
- 가운데 한 열, 글자 가운데 정렬. 제목 `hg-auth__title`(28px, 줄바꿈 `\n` 그대로), 보조 `hg-auth__help`.
- 버튼 묶음 `hg-auth__actions`: 세로로 쌓고 최대 360px. 버튼은 꽉 차게(`hg-btn--block`). ‘최근 사용’ 배지는 버튼 안 오른쪽 `hg-tag`.
- 뒤로 `hg-auth__back`: 왼쪽 위, IconButton `arrow-left`.
- 좁은 창(768px 미만): 위에서부터 쌓고 버튼 묶음은 아래 끝으로.
- 소셜 버튼(카카오, 구글, 애플)은 지금 `hg-btn--secondary`. 제공자 로고와 색(카카오 노랑, 애플 검정)은 각 제공자 버튼 가이드 확인 뒤 정함(→ 개발 가이드 ‘OAuth 앱과 리다이렉트’).

쓰는 곳: A-01, O-01, A-02, A-03, A-08, 웹 로그인 콜백.
