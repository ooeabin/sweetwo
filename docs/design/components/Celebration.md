# Celebration

목표 달성 화면. 브랜드가 말하는 몇 안 되는 순간. 위에 큰 달성 그림, 아래에 한 문장으로 정리.

- 소비자가 주는 것: 목표 이름, 모은 금액, 걸린 개월 수, 함께 모은 달 수, 달성 그림.
- 위(`hg-celebrate__hero`, 높이 260px): `surface` 바탕 그대로 그림 210px 가운데. 그림 아래 바닥 그림자(타원, `ink` 14%→0)와 그림 자체 그림자(`drop-shadow` 0 12px 16px, `ink` 16%)로 떠 있는 느낌. 바탕 틴트, 테두리 칸 없음.
- 아래(`hg-celebrate__body`), 가운데 정렬: 머리글 “목표 달성”(`brand-ink`) → 제목 1줄 “{목표}를 다 모았어요”(22px) → 큰 금액(40px) → 한 문장 “**{n}개월** 동안 둘이 **{m}번** 모았어요”(`slate`, 숫자만 `ink` 굵게) → 주 버튼(`hg-btn--primary`) 꽉 차게 → 글자 링크 1개.
- 혼자 모은 목표는 “**{n}개월** 만에 모았어요”.
- 브랜드 색은 머리글 글자(`brand-ink`)에만. 바탕, 버튼에는 쓰지 않음.
- 달성 그림: 목표 템플릿마다 1장(Illustrations 묶음, 바탕을 지운 512px PNG). 직접 만든 목표는 올린 사진(정사각, 모서리 24px로 잘라 그림자만), 사진이 없으면 회색 기본 그림(`hg-art--custom`).
- 다크 모드: 바탕 `surface`, 바닥 그림자는 검정 40%.
- 강조는 한 번만: 그림이 아래에서 8px 올라오며 0.96 → 1 크기 + 투명도로 `dur-slow` `ease-out`. 폭죽, 소리, 숫자 굴리기 없음. `prefers-reduced-motion`이면 바로 나타남.
- 목표당 한 번만 보여 줌. 다시 열면 목표 카드의 ‘달성’ 배지로만.
- 말투는 사실만, 감탄사, 이모지 없음.

- React 래퍼 `Celebration`(packages/ui): `art`, `eyebrow`, `title`, `value`, `story`, 버튼은 `children`. 기획서 G-05 축하 문구가 이 문서의 예시 문장보다 우선(제목 = 목표 이름).
