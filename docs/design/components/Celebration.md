# Celebration

저금 항목 목표 금액 달성 화면(W-12, 2026-11-08 ADR 0007). 브랜드가 말하는 몇 안 되는 순간. 위에 축하 그림, 아래에 한 문장으로 정리.

- 소비자가 주는 것: 저금 항목 이름, 모은 금액, 걸린 개월 수, 함께 모은 달 수, 그림.
- 배치(2026-11-03): 카드 틀 없이 QuestionLayout 가운데. 그림(`hg-celebrate__hero--plain`, 축하 그림 DoneMark `celebrate`, 파일이 생기기 전까지 빈 자리 `hg-artslot`) → 제목 자리에 작은 머리글 “목표 달성”(`brand-ink`) + 저금 항목 이름 → 큰 금액(40px) → 한 문장 “**{n}개월** 동안 매달 둘이 함께 모았어요” / “**{n}개월** 중 **{m}번**은 둘이 함께 모았어요”(`slate`, 숫자만 `ink` 굵게), 혼자 모은 항목은 “**{n}개월** 만에 모았어요” → 주 버튼 “다음”(→ W-12a)은 다른 질문 화면처럼 아래 고정.
- 저금 항목당 사람마다 한 번만 보여 줌. 다시 열면 W-10의 ‘달성’ 배지로만. 체크를 풀어 목표 금액 아래로 내려가 ‘모으는 중’으로 돌아가면 다시 닿을 때 한 번 더(2026-11-09).
- 축하로 넘어갈 때 떠 있는 Toast(체크 ‘되돌리기’)는 닫음(2026-11-09).
- 들어올 때 그림 움직임 한 번, ‘동작 줄이기’면 정지.
- React 래퍼 `Celebration`(packages/ui): `art`, `eyebrow`, `title`, `value`, `story`, 버튼은 `children`. 기획서 W-12 문구가 이 문서의 예시 문장보다 우선.
- 예전 목표 템플릿 그림·목표 사진(`hg-celebrate__photo`)은 2026-11-08 없앰(클래스만 남음).
