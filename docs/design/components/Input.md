# Input

글자 입력 칸과 금액 입력. 질문 화면의 금액은 `hg-amount`(큰 숫자 + 밑줄), 그 밖의 글자는 `hg-input`.

- 소비자가 주는 것: 값, 자리표시, 도움말 1줄, 오류 문구.
- 금액: 원 단위로 받고 아래 `hg-help`에 만 원 읽기(“312만 원”). 쉼표 자동. 칸 안 단위 “원”은 숫자에 붙임(2px).
- 자리표시는 `stone`.
- 오류: 칸에 `is-error`, 도움말에 `is-error` + 고치는 방법(“0원보다 큰 금액을 넣어 주세요”).
- 포커스는 2px `ink` 테두리(검색 칸도 같음). 파랑 `focus`는 키보드 포커스 링과 글자 링크에만, 분홍은 오류 빨강과 헷갈려 쓰지 않음.
- 여러 칸을 나란히 둘 때는 `hg-fields`(위쪽 정렬, 같은 너비)로 묶고 칸마다 라벨 `hg-field__label`·도움말 자리를 같게 둠.
