# Calendar

‘캘린더’ 메뉴의 달력. 챙길 날(생일·기념일·명절·양가 행사, 한 종류)과 돈 일정(월급날·목표 기한·만기일·월말 확인)을 함께 보여 줌. 카드 안에 월 보기 + 고른 날 일정.

- 소비자가 주는 것: 연·월, 날짜별 일정 종류, 오늘, 고른 날, 고른 날의 일정 목록.
- 머리: 큰 월(`22px`) + 작은 연도(`stone`), 오른쪽 둥근 이전·다음 버튼.
- 날짜 칸 56px. 오늘은 칸 전체 `brand-soft` + `brand-ink` 굵게, 고른 날은 숫자에 `ink` 원. 다른 달 날짜는 `stone`.
- 챙길 날은 숫자 아래 짧은 막대(14×4px), 한 가지 색 `chart-together`(종류를 나누지 않음). 하루 최대 3개, 넘치면 3개만.
- 돈 일정은 읽기 전용: 숫자 아래 `ink` 작은 점(막대와 모양이 달라 색 없이도 구분). 라벨(“예빈 월급날”)은 칸에 쓰지 않고 아래 일정 목록에 흐린 글자 + 오른쪽 “체크리스트 ›”처럼 갈 화면. 누르면 그 화면으로 이동하고 캘린더에서 고치지 않음.
- 맨 위 보기 필터 칩(Chip 필터형, `hg-chip--sm` + `aria-pressed`): “전체”, “챙길 날”, “돈 일정”.
- 범례는 항상 표시. 막대 색만으로 뜻을 전하지 않도록 아래 일정 목록에 이름·금액을 씀.
- 아래 일정 목록: 날짜(“11월 15일(일)”) + 줄마다 색 점, 이름, 오른쪽 금액(돈 일정은 갈 화면).
- 월말 확인 기간(다음 월급날 3일 전 ~ 전날)은 날짜 칸 바탕 `surface-alt` 띠(`is-band`, 오늘이면 오늘 바탕이 이김). 아래 일정 목록에 월말 확인 줄(→ W-05).
- 공휴일(`is-holiday`): 숫자 `holiday-ink`, 막대가 없으면 그 자리에 이름 작게(`hg-cal__hol`, 10px, 넘치면 말줄임). 막대가 있으면 이름은 아래 일정 목록 맨 위 한 줄(`hg-cal__event is-holiday`, 누르지 않음). 오늘·고른 날 숫자 색이 이김.
- 설·추석 연휴(`is-festive`): 날짜 칸 바탕 `family` 띠. 정리 기간 띠와 겹치면 연휴 띠, 오늘이면 오늘 바탕이 이김.
- 칸 이름은 짧게: 대체공휴일은 “대체공휴일”만(무엇의 대체인지는 아래 목록). 칸 너비는 7등분 고정(`minmax(0, 1fr)`), 넘치면 말줄임.
- 날짜 칸은 `button`, `aria-label`에 날짜와 일정 수, 고른 날 `aria-pressed`, 오늘 `aria-current="date"`.
- React 래퍼 `Calendar`(packages/ui): 연·월, 오늘, 고른 날, 날짜별 막대·점·띠, 이전·다음, 아래 일정 목록(children).
- 일정 목록 줄(`hg-cal__event`)은 누르면 이동하므로 `button`으로 써도 됨(기본 버튼 모양 리셋).
