# Calendar

‘캘린더’ 메뉴의 달력. 챙길 날(양가·기념일·명절)과 돈 날짜(월급날·만기일·월말 정리·제안 적용일)를 함께 보여 줌. 카드 안에 월 보기 + 고른 날 일정.

- 소비자가 주는 것: 연·월, 날짜별 일정 종류, 오늘, 고른 날, 고른 날의 일정 목록.
- 머리: 큰 월(`22px`) + 작은 연도(`stone`), 오른쪽 둥근 이전·다음 버튼.
- 날짜 칸 56px. 오늘은 칸 전체 `brand-soft` + `brand-ink` 굵게, 고른 날은 숫자에 `ink` 원. 다른 달 날짜는 `stone`.
- 일정은 숫자 아래 짧은 막대(14×4px), 영역 차트색: 양가 `chart-family`, 우리 둘 `chart-together`, 목표 `chart-goal`. 하루 최대 3개, 넘치면 3개만.
- 돈 날짜는 읽기 전용: 숫자 아래 `ink` 작은 점(막대와 모양이 달라 색 없이도 구분), 일정 목록에서는 흐린 글자 + 오른쪽 “월급 플랜 ›”처럼 갈 화면. 누르면 그 화면으로 이동하고 캘린더에서 고치지 않음.
- 맨 위 보기 필터 칩(Chip 필터형, `hg-chip--sm` + `aria-pressed`): “전체”, “챙길 날”, “돈 날짜”.
- 범례는 항상 표시. 막대 색만으로 뜻을 전하지 않도록 아래 일정 목록에 이름·금액을 씀.
- 아래 일정 목록: 날짜(“11월 15일(일)”) + 줄마다 색 점, 이름, 오른쪽 금액(돈 날짜는 갈 화면).
- 월말 정리 기간(기준일 3일 전 ~ 전날)은 날짜 칸 바탕 `surface-alt` 띠(`is-band`, 오늘이면 오늘 바탕이 이김). 첫날에 돈 날짜 점과 “정리 시작”.
- 날짜 칸은 `button`, `aria-label`에 날짜와 일정 수, 고른 날 `aria-pressed`, 오늘 `aria-current="date"`.
- React 래퍼 `Calendar`(packages/ui): 연·월, 오늘, 고른 날, 날짜별 막대·점·띠, 이전·다음, 아래 일정 목록(children).
- 일정 목록 줄(`hg-cal__event`)은 누르면 이동하므로 `button`으로 써도 됨(기본 버튼 모양 리셋).
