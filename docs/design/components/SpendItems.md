# SpendItems

항목별 지출 입력. 월말에 카드 명세서를 보며 항목별 합계만 적는 한 화면 목록(질문 화면 패턴 Q6). 월말 정리 지출 입력(W-04j)과 홈 ‘지출 적기’에 씀. 결제 하나하나를 적지 않음.

- 소비자가 주는 것: 고정지출 목록(이름, 그룹, 금액), 켜 둔 변동 항목(이름, 지난달 값, 이번 달 값, 미리 채운 출처), 합계.
- 묶음 2개, 순서 고정: 고정지출(확인만) → 변동 지출(입력). 묶음 머리 오른쪽에 묶음 합계(만 원).
- 고정지출 줄(`is-fixed`): 이름 + 그룹 / 오른쪽 금액(원). 플랜 값을 그대로 보여 주고, 이번 달만 다르면 줄을 눌러 고침(그달만 바뀜). 3줄 넘으면 “고정지출 n개 더 보기”.
- 변동 지출 줄: 이름(라벨) + 보조 1줄 / 오른쪽 금액 칸 160px(`hg-input`, 오른쪽 정렬, 뒤에 “원”, `inputmode="numeric"`, 세 자리 쉼표).
  - 보조 줄: 기본 “지난달 41만”. 챙길 날 기록(Y-08)에서 미리 채웠으면 “챙길 날에서 채웠어요” + 일정 이름 태그. 미리 채운 값은 고칠 수 있고 따로 더하지 않음.
  - 비운 칸은 0으로 셈. 0원 항목은 정산에서 숨김.
- 항목: 기획서 데이터 항목 6-3 기본 칩. 사용자가 켜고 끄기, 이름 바꾸기, “항목 추가”로 직접 추가.
- 변동 지출에는 공동 생활비(통장 하나 모드면 그 통장)에서 낸 돈만 적음. 각자 용돈으로 쓴 돈과 큰 지출(BigExpense)은 여기 적지 않음.
- 맨 아래 합계(`hg-spend__total`, `aria-live`): “이번 달 쓴 돈(용돈, 큰 지출 빼고)” = 고정 + 변동. 입력할 때마다 바뀜.
- 저장: 칸을 벗어날 때마다 자동 저장(draft). 둘이 같은 칸을 고치면 나중 저장이 이기고 Toast.
- 접근성: 줄마다 `label for` 연결. 묶음은 `role="group"` + 머리 제목.
- 좁은 창: 금액 칸 132px.
