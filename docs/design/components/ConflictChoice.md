# ConflictChoice

충돌 선택(기획서 13 공통 상태 11번, 30 동기화 2장). 배우자가 1분 안에 같은 칸을 다른 값으로 바꿨을 때, 나중에 저장한 사람에게만 저장 버튼 위에 띄움.

- 소비자가 주는 것: 제목, 설명 1줄, 보조 1줄(선택: 오프라인 대기 입력일 때), 두 선택지(이름 + 값).
- 틀 `hg-conflict`: `surface` 바탕 + `hairline` 1px 테두리, `radius-lg`. 위 → 아래: 제목(“어느 쪽으로 할까요?”, 16px 600) → 설명(“예빈님이 방금 이 값을 바꿨어요”, 14px `slate`) → 버튼 두 개.
- 버튼은 같은 크기 2칸(`hg-conflict__actions`), 둘 다 보조 버튼. 위 줄 이름(“내 값” / “예빈님 값”), 아래 줄 값(`small`, `slate`). 어느 쪽도 `brand`나 `danger`로 칠하지 않음(옳은 답이 없는 선택).
- 고르면 바로 저장(내 값) 또는 그대로 둠(배우자 값). 닫기 버튼 없음, 뒤로 가면 저장 안 함.
- 접근성: `role="group"` + `aria-labelledby`(제목). 띄울 때 제목으로 포커스를 옮기지 않고 `role="status"`로 알림.
- React 래퍼 `ConflictChoice`(packages/ui).
