# Badge

상태·영역을 짧게 알리는 알약. 글자 1~4자.

- 소비자가 주는 것: 글자, 종류.
- `hg-badge--temp` ‘임시’·‘추정’(회색 테두리 알약), `hg-badge--done` ‘확정’, `hg-badge--achieved` ‘달성’, `hg-badge--warn` ‘D-2’·‘마감 임박’(검정 알약).
- 영역 배지(`together`·`family`·`goal`·`safety`·`invest`)는 영역 이름을 글자로 함께 씀.
- 글자는 한 줄(줄바꿈 없음), 좁은 줄에서도 줄어들지 않음.
- 달성(`hg-badge--achieved`)과 완료(`hg-badge--done`, S-19a 문의 ‘답변 완료’): 2026-11-09부터 옅은 오렌지 판 `accent-app-soft` + `accent-app-ink`(= `brand-ink`) 글자. 12px 글자라 오렌지 글자 대신 AA를 지키는 `brand-ink`. 파랑(`success`)은 사용자 앱에서 없앰(2026-11-04 연한 파랑, 완료는 파랑 채움이었음).
- 매달·매년(`hg-badge--brand`, 2026-11-04): 목표 카드의 ‘매달’ ‘매년’ 배지. `brand-soft` 바탕 + `brand-ink` 글자.
