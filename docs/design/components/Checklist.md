# Checklist

첫 주 할 일처럼 끝내야 할 일 목록 카드.

- 소비자가 주는 것: 제목, 할 일(이름, 보조 1줄, 걸리는 시간, 완료 여부).
- 머리 오른쪽에 남은 개수 “3개 남았어요”. 월급 체크 묶음(W-02, 홈 H-03)은 제목 앞에 진행 원 Ring(“2/5”)을 둠(2026-10-27). 완료한 일은 체크(`success`) + `stone` 취소선, 목록 아래로 내리지 않고 제자리.
- 할 일 줄 전체가 `button`, 누르면 그 화면으로 이동. 줄 오른쪽에 ‘내일 할게요’ 같은 다른 버튼이 있으면 글자 부분(`hg-task__text`)만 `button`(버튼 안에 버튼을 넣지 않음). 체크 표시는 상태 그림(`role="img"` + “끝냄/남음”). 모두 끝나면 카드가 접히고 ‘이번 달’ 첫 화면에서 사라짐.
