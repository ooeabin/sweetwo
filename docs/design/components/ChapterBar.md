# ChapterBar

온보딩 진행(`hg-chapterbar`). 온보딩 질문 화면 맨 위 얇은 막대.

- 2026-10-26 재기획(ADR 0003)부터 온보딩은 챕터 없이 막대 하나: 이름을 빈 값으로 주면 이름 줄 없이 막대만(화면 읽기 이름 “온보딩 진행”), 채움 = 온보딩 질문 전체(O-03~O-32) 중 지금까지. O-10, O-60에는 없음. 아래 챕터 설명은 이름을 줄 때의 동작(지금 쓰는 곳 없음).

- 소비자가 주는 것: 챕터 순서, 전체 챕터 수, 챕터 이름, 챕터 안 진행 비율(0~100).
- 윗줄: 왼쪽 뒤로(<, 36px), 가운데 챕터 이름 “목표”(15px 600, `ink`). “2/4” 같은 순서 숫자는 붙이지 않음. 뒤로가 없는 화면도 이름은 가운데 그대로.
- 아랫줄: 열 너비 막대, 높이 4px, 알약 모양. 바탕 `hairline`, 채움 `brand`. 손잡이 없음.
- 채움은 챕터 안에서만: 챕터 시작 안내 0%, 질문마다 늘고 다음 챕터에서 0부터.
- 바뀔 때 `dur-base` `ease-out`으로 늘어남. ‘동작 줄이기’면 바로.
- 화면 읽기: 막대는 `progressbar`(이름 “{챕터} 진행”, 값 %), 윗줄 글자는 그대로 읽힘.
- 넓은 창(데스크톱 앱)은 QuestionLayout 위 바 가운데에 “목표”(13px) + 칸 막대(`hg-segs`, Meetup식): 챕터 안 질문마다 1칸(시작 안내는 칸 없음), 연 질문까지 `brand`. 뒤로 꺾쇠는 넣지 않고 아래 바 ‘이전’으로.
- 쓰는 곳: 모든 질문 흐름(2026-11-03). 온보딩(O-03~O-32), 파트너 합류(P-03~P-05b), 저금 항목 추가(W-11), 자산 추가(F-03), 챙길 날 추가·기록(Y-07, Y-08) 등. QuestionLayout에 `steps`를 주면 이름 없는 이 막대로 그림(칸 막대 ProgressSteps는 질문 화면에서 안 씀). 화면 읽기 이름 “질문 진행”.

## ChapterList

온보딩 첫 화면(O-10) 챕터 목록(`hg-chapters`, `ol`). `plate` 판 위에 챕터마다 번호 원(28px, `surface` 바탕, `ink` 숫자) + 이름(16px 600) + 한 줄 설명(14px `slate`). 줄 사이 16px, 판 안쪽 20px, `radius-xl`. `brand` 쓰지 않음.

- O-10은 상태 없이 네 줄 모두 설명까지.
- 챕터 시작 안내(예전 O-20·O-30·O-50, 재기획으로 없앰. 지금 쓰는 곳 없음)는 상태를 보여 줌(`now`): 끝난 챕터 `ink` 원 + 흰 체크, 이름 `slate`(화면 읽기 “끝남”) / 지금 챕터 2px `ink` 테두리 원 + 이름 진하게 + 설명(`aria-current="step"`) / 남은 챕터 이름과 숫자 `stone`, 설명 없음.
