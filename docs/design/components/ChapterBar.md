# ChapterBar

온보딩 챕터 진행(`hg-chapterbar`). 온보딩 질문 화면 맨 위에서 지금 챕터와 챕터 안 진행을 보여 줌. 레퍼런스: MacroFactor(헤더에 챕터 이름, 챕터마다 새로 차는 막대), Lemonade(챕터 이름 + 짧은 막대).

- 소비자가 주는 것: 챕터 순서, 전체 챕터 수, 챕터 이름, 챕터 안 진행 비율(0~100).
- 윗줄: 왼쪽 뒤로(<, 36px), 가운데 “2/4 목표”(15px 600). 숫자 “2/4”는 `brand`, 이름은 `ink`. 뒤로가 없는 화면도 이름은 가운데 그대로.
- 아랫줄: 열 너비 막대, 높이 4px, 알약 모양. 바탕 `hairline`, 채움 `brand`. 손잡이 없음.
- 채움은 챕터 안에서만: 챕터 시작 안내 0%, 질문마다 늘고 다음 챕터에서 0부터. 결과 화면(O-61~67)은 막대를 빼고 “4/4 나누기와 플랜” 글자만(결과 7장 동안 꽉 찬 막대가 멈춰 보이지 않게).
- 바뀔 때 `dur-base` `ease-out`으로 늘어남. ‘동작 줄이기’면 바로.
- 화면 읽기: 막대는 `progressbar`(이름 “{챕터} 진행”, 값 %), 윗줄 글자는 그대로 읽힘.
- 쓰는 곳: 온보딩(O-03~O-67)만. 배우자 합류, 결혼일 전환, 첫 주 할 일, 자산 추가 같은 다른 질문 흐름은 ProgressSteps 그대로.

## ChapterList

온보딩 첫 화면(O-10) 챕터 목록(`hg-chapters`, `ol`). `plate` 판 위에 챕터마다 번호 원(28px, `surface` 바탕, `ink` 숫자) + 이름(16px 600) + 한 줄 설명(14px `slate`). 줄 사이 16px, 판 안쪽 20px, `radius-xl`. `brand` 쓰지 않음.

- O-10은 상태 없이 네 줄 모두 설명까지.
- 챕터 시작 안내(O-20·O-30·O-50)는 상태를 보여 줌(`now`): 끝난 챕터 `ink` 원 + 흰 체크, 이름 `slate`(화면 읽기 “끝남”) / 지금 챕터 2px `ink` 테두리 원 + 이름 진하게 + 설명(`aria-current="step"`) / 남은 챕터 이름과 숫자 `stone`, 설명 없음.
