# Toast

잠깐 떴다 사라지는 알림. 상대가 같은 값을 방금 바꿨을 때, 저장 직후 되돌리기.

- 소비자가 주는 것: 문장 1줄, 선택적인 행동 1개.
- 4초 뒤 사라짐, 행동이 있으면 6초. 화면(경로)이 바뀌면 바로 닫힘(2026-11-11, O-07 ‘복사했어요’가 O-11·O-30까지 남던 문제). 저장하고 돌아가기처럼 결과를 알리고 바로 다른 화면으로 옮기는 동작만 다음 화면 하나까지 남김(app `carryToast`), 그다음 이동에서 닫힘. 화면 아래 가운데, `shadow-3`. `role="status"`.
- 쌓기: 최대 2개, 새 것이 아래. 3번째가 오면 가장 오래된 것을 바로 닫음. 사이 `space-2`.
- 좁은 창은 하단 독 위 16px(주 버튼 하단 고정 화면은 주 버튼 위 16px).
- 아래 고정 바(2026-11-23 사용자 결정, 토스트가 W-02 ‘모두 계획대로 됐어요’ 같은 주 버튼을 가리던 것): 화면 아래 고정 주 버튼 바는 자기 높이를 `--hg-bottom-bar-h`로 알린다(ui `StickyBar`, `hg-stickybar`가 쓰는 컴포넌트가 ResizeObserver로 `:root`에 넣고 사라지면 지움). `.hg-toasts`는 `bottom: max(space-8 + 안전 영역, 바 높이 + space-4)`라 바가 있으면 그 위 16px, 없으면 지금 위치. 화면마다 따로 처리하지 않는다: 새 고정 바는 `StickyBar`를 쓴다(질문 화면 아래 바 `hg-q__foot`는 2026-11-25 구역 6부터 `QuestionLayout`이 주 버튼 + 안내 한 줄(O-31·P-05 공개 고지) 높이를 같은 `--hg-bottom-bar-h`로 알려 토스트가 안내 줄까지 피해 그 위로 뜸. 예전에는 주 버튼 높이만 계산해 안내 줄을 가렸음). 키보드가 열려 화면이 줄어도 바와 토스트가 같은 아래 끝을 따라가 겹치지 않는다. 시트가 열려 있으면 위쪽(아래 줄).
- 모양(2026-11-02 다시): 화면 아래 가운데 작은 검은 알약(`radius-full`, 높이 44px 이상, 좌우 20px), 글자 길이만큼(최대 440px), 글자 14px 500 가운데, 두 줄까지(2026-11-11 QA 3구간 S3-33: 320px에서 오류 문구와 ‘다시 시도’가 같이 나오면 잘리던 것, 넘치면 말줄임, 화면 읽기는 전체). 문구는 한 줄에 들어가게 짧게(행동이 있으면 16자 안팎). 행동(되돌리기)은 글자 바로 옆 14px 700 링크(밑줄, 화살표 없음). 아래에서 16px 올라오며 나타남(`dur-base`, ‘동작 줄이기’면 없음). 투명도는 바꾸지 않아 나타나는 동안에도 글자 대비가 유지됨.
- `ink` 바탕이라 다크에서 밝게 뒤집힘, 테두리 없음.
- 로그인 화면(A-02)은 아래 버튼을 가리지 않게 버튼 묶음 위 알약(`hg-auth__toast`, → AuthLayout).
- AuthLayout 화면(A-02 등)도 화면 아래에 붙은 버튼 묶음(과 그 위 안내 띠)이 있으면 그 위쪽까지의 높이를 `--hg-bottom-bar-h`로 알려 전역 Toast(예: 로그아웃 “로그아웃했어요”)가 버튼을 가리지 않고 그 위로 뜸(2026-11-25 구역 7, 예전엔 Apple 버튼 위에 겹침). 태블릿 가운데 묶음처럼 화면 아래에 붙지 않으면 알리지 않아 기본 자리.
- 되돌릴 수 있는 동작(보관, 나누기 줄 빼기, 칩 해제)은 확인 없이 바로 하고 Toast에 “되돌리기”.
- 행동 버튼(‘되돌리기’ 등)을 누르면 토스트는 바로 닫힘(2026-11-12 QA 5구간 S5-03: 남아 있으면 한 번 더 눌려 같은 줄이 두 번 생김). 닫기는 app `ToastHost`가 맡음(ui `Toast`는 모양만).
- 금액 가리기 중 문구의 “•••”는 보이기만 하고 화면 읽기는 “가려진 금액”(app `speakMasked`, ui `Toast` `message`는 글자나 노드, 2026-11-12).
- (2026-11-09 좁은 창 + 버튼(FAB)과 탭 막대를 없애 토스트는 늘 화면 아래 `space-8` + 안전 영역.)
- 결과 알림(2026-11-06 점검): 되돌리기 토스트의 ‘되돌리기’처럼 결과를 따로 알리지 않던 서버 동작이 실패하면 “저장하지 못했어요”(13 공통 상태 10번, app `quietly`). 성공은 화면이 바로 바뀌어 따로 알리지 않음. 오류 문구에 기술 용어 없음.
- 자리(2026-11-03): 아래 버튼과 겹치지 않게. 좁은 창 질문 화면은 아래 바(주 버튼) 바로 위, 바텀시트가 열려 있으면 화면 위쪽.
- 어드민(2026-11-06): 저장됨, 승인 요청됨, 오류 같은 결과는 화면 안 작은 글 대신 이 Toast로 4초(apps/admin/src/toast.tsx `useToast`). 로그인 화면의 오류는 칸 아래 글 그대로.
