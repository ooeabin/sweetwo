# PaydayPicker

월급날 고르기(`hg-payday`, 코드 `PaydayPicker`, `question/PaydayPicker.tsx`). 2026-11-25 사용자 결정 A안 ‘자주 쓰는 날 칩 + 직접 입력’(시안 `work/w02-design/payday.png` 왼쪽). 휠(`DayWheel`)과 펼친 1~31 날짜 칸(`DayChips`·`DayGrid`, 2026-11-25 구역 6)을 이것 하나로 바꿈. 월급날 일(1~31 또는 말일)을 고르는 모든 곳이 씀: O-32, P-05b, S-11c, W-01 월급 금액 시트(월급날이 없고 금액이 0보다 클 때). W-01 줄 ‘나가는 날’은 월급날이 아니라 그대로 `DayWheel`(칩 ‘월급날’·‘다음 날’ + 휠).

- 구성(위에서 아래, 간격 16): 칩 줄 + 직접 적기 칸 + (오류 또는 29~31일 안내 한 줄). 오류·안내 줄은 직접 적기 칸에 붙여 8px(2026-11-25).
- 칩: 10일, 15일, 20일, 21일, 25일, 말일(말일 값은 ‘말일’). 회색 알약(`choice-plate`, 높이 48, 좌우 20, 칸 사이 12, 줄이 넘치면 줄바꿈), 안 고른 칩 17/400 `ink-2`. 고른 칩은 흰 칸(`choice-on`) + `choice-on-shadow` + 17/700 + 오렌지 글자 `accent-app-text`(2026-11-25 사용자 결정. 17px 700 짧은 말이라 대비 예외, axe 선택자 예외 `.hg-payday__chip.is-on`). 테두리 없음. 누르는 칸 44px 이상(높이 48).
- 직접 적기 칸: 회색 판(`choice-plate`, 높이 56, radius 16, 테두리 없음). 자리표시이자 이름 “다른 날 직접 적기”, 오른쪽 끝에 ‘일’. 숫자만(`inputMode="numeric"`, 최대 2자리). 1~31이면 그 값, 칸이 비었거나 범위 밖이면 값 없음(null). 유효한 숫자가 들어 있으면 칸이 흰 칸 + 그림자 + 700 + 오렌지 숫자(`accent-app-text`, `.hg-payday__custom.is-on`).
- 칩과 직접 적기는 서로 배타: 칩을 고르면 직접 적기 칸을 비우고, 칸에 글자를 넣으면 칩 선택을 풀어 줌. 직접 적은 숫자가 칩 날짜와 같아도(예: 15) 칸에 적은 것으로 둠.
- 오류: 1~31 밖(0, 32 이상)이면 칸 아래 빨강 한 줄 “1~31 사이로 적어 주세요”(`hg-help is-error`, `role="alert"`, 칸은 `danger` 1px 안쪽 선, 포커스 중에는 같은 빨간 선이 2px로 포커스 표시를 겸하고 ink 링은 겹치지 않음) + 칩 선택 없음. 소비자는 값이 null이면 주 버튼을 끔.
- 29~31일(칩이 아니라 직접 적기로만) 안내 `hint` 한 줄 “그날이 없는 달은 말일로 계산해요”(`hg-payday__hint`, body slate). O-32·P-05b·S-11c·W-01 시트 모두 같음.
- 처음 값: 소비자가 값을 안 주면 `initial`(25일)을 바로 알려 줌(25일 칩이 골라진 채). 이미 값이 있으면 칩 날짜(10·15·20·21·25·말일)는 그 칩, 그 밖의 날(예: 17일, 31일)은 직접 적기 칸에 숫자.
- 끔 `disabled`(O-32·P-05b ‘날짜가 정해져 있지 않아요’): 흐리게 0.4 + `inert`(누르기·키보드·화면 읽기에서 빠짐, `aria-disabled`). 값은 그대로 두었다가 풀면 되돌아옴. 꺼진 동안은 고른 칩·직접 적은 숫자의 고른 표시(흰 칸·오렌지 글자)와 오류를 보이지 않고 모든 칸이 같은 꺼진 회색(2026-11-25).
- 접근성: 칩 묶음 `role="radiogroup"`(이름은 질문 문장), 칩 `role="radio"` + `aria-checked`, 이름 “25일”, “말일”. 고른 칩만 탭 순서(없으면 첫 칩). ←↑ 앞, →↓ 다음, Home/End 처음·말일(고르는 것과 같음). 직접 적기 칸 이름 “다른 날 직접 적기”, 오류는 `aria-invalid` + `aria-describedby`. 포커스 링 `focus-ring`.
- 다크 모드는 토큰(`choice-plate`, `choice-on`)이 처리. 동작 줄이기에서 전환 없음.
- O-32·P-05b는 질문 아래 보조 줄 없음(2026-11-25 사용자 결정). S-11c·W-01 시트는 섹션 제목·시트 안이라 따로 없음.
