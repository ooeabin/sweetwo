# SectionHeader

본문 안 묶음 제목. ‘이번 달’ 첫 화면의 ‘목표’, ‘다가오는 챙길 날’ 같은 섹션 머리.

- 소비자가 주는 것: 제목, 개수(선택), 더 보기 링크(선택), 제목 앞 칸(`lead`, 선택: 묶음 진행 Ring).
- 제목 18px 600, 개수는 같은 크기 `stone`. 링크는 오른쪽 끝 “전체 보기” + 오른쪽 화살표.
- 오른쪽 끝 글자 버튼(`action`, 2026-11-09 round 3): W-02 묶음 머리 ‘모두 보냈어요’처럼 묶음 전체에 하는 일. 파란 글자 버튼(`hg-btn--link`), `hg-sechead__action`이 오른쪽 끝으로 밈. `more`와 같이 쓰지 않음.
- 누르는 제목(`onTitle`, 2026-11-09 round 3): 제목 자체가 버튼(`hg-sechead__link`)이고 뒤에 작은 꺾쇠(16px, `slate`). W-02·W-01 저금 묶음 머리 → 저금 목록(W-13). 제목 글자만으로 갈 곳이 불분명하면 화면 읽기 이름(`titleLabel`)을 줌.
- 아래 내용과 `space-3`, 위 섹션과 `space-8`.
- 보조 설명 줄은 두지 않음. 필요하면 내용 쪽 빈 상태나 카드 보조 줄로.
