# SectionHeader

본문 안 묶음 제목. ‘이번 달’ 첫 화면의 ‘목표’, ‘다가오는 경조사’ 같은 섹션 머리.

- 소비자가 주는 것: 제목, 개수(선택), 더 보기 링크(선택), 제목 앞 칸(`lead`, 선택: 묶음 진행 Ring).
- 제목 18px 600, 개수는 같은 크기 `stone`. 링크는 오른쪽 끝 “전체 보기” + 오른쪽 화살표(`hg-sechead__more`, 14px 500 `slate`. 2026-11-09 오렌지는 동작 글자 버튼만, 이동 링크는 회색).
- 오른쪽 끝 글자 버튼(`action`, 2026-11-09 round 3): W-02 묶음 머리 ‘모두 보냈어요’처럼 묶음 전체에 하는 일. 오렌지 글자 버튼(`hg-btn--link`, 2026-11-09), `hg-sechead__action`이 오른쪽 끝으로 밈. `more`와 같이 쓰지 않음.
- 누르는 제목(`onTitle`, 2026-11-09 round 3): 제목 자체가 버튼(`hg-sechead__link`)이고 뒤에 작은 꺾쇠(16px, `slate`). W-02·W-01 저금 묶음 머리 → 저금 목록(W-13). 제목 글자만으로 갈 곳이 불분명하면 화면 읽기 이름(`titleLabel`)을 줌.
- 아래 내용과 `space-3`, 위 섹션과 `space-6`(2026-11-09 밀도, `space-8`에서).
- 카드 안 묶음 머리(`variant="group"`, `hg-sechead--group`, 2026-11-09 밀도): W-02 저금·지출 묶음. 진행 원(Ring) 없이 한 줄 “저금 0/2 ›”: 제목 15px 600 + 개수(`count`) 15px 400 `stone`을 제목 바로 뒤(한 개수는 `<b>`로 감싸 오렌지 600, `hg-sechead__count b`, 2026-11-09. 0이면 감싸지 않음)(누르는 제목이면 버튼 안, 꺾쇠 앞). 보이는 “0/2”는 화면 읽기에서 숨기고 `countLabel` 문장(“2개 중 0개 완료”)을 `hg-sr`로. 높이 40px, 오른쪽 `action`(‘모두 보냈어요’) 그대로. 제목 버튼은 누르는 칸 44px 이상(음수 margin + padding).
- 제목 아래 조용한 한 줄(`meta`, `hg-sechead__titles` + `hg-sechead__meta` 13px `stone`, 2026-11-09): W-02 맨 위 “9월 월급” 아래 “09.25 ~ 10.24. 5개 중 0개 완료”, 오른쪽 `action`에 지난 달·다음 달 ‹ ›(한 머리로, 진행 원 없음).
- 보조 설명 줄은 두지 않음. 필요하면 내용 쪽 빈 상태나 카드 보조 줄로.
