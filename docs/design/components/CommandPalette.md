# CommandPalette

Ctrl/⌘+K로 여는 검색, 빠른 실행.

- 소비자가 주는 것: 검색어, 결과 묶음(바로 하기, 저금 항목, 경조사 등), 결과마다 이름, 보조 정보, 단축키(선택).
- 위 입력 줄(60px) + 오른쪽 Esc 표시. 결과는 묶음 이름(`stone`) 아래 52px 줄: 앞 아이콘 원 32px(`hg-cmd__lead`, `plate` 바탕) + 이름(보조 정보는 아래 12px), 고른 줄 `surface-alt` 가득 차게.
- 안쪽 여백(2026-11-03, Devin·Base44 팔레트처럼 넉넉히): 입력 줄, 묶음 이름, 줄 아이콘이 왼쪽 24px에 맞음(좁은 창 20px). 카드 최대 560px, 결과는 화면 60%까지 스크롤.
- 아래 키 안내 줄(`hg-cmd__foot`, 넓은 창만): “↑ ↓ 이동” “Enter 열기” “Esc 닫기” [확인 필요].
- 뒤 막은 body에 붙여(portal) 화면 전체를 어둡게.
- ↑↓로 이동, Enter 실행, Esc 닫기. 결과 목록 `role="listbox"`, 고른 줄 `aria-selected`.
- 다크에서 보이도록 `hairline` 테두리. 모달과 같은 층(`z-modal`), 뒤 막 `scrim`.

## 바로 하기 묶음

- 검색어가 없을 때 맨 위 묶음 “바로 하기”, 순서 고정: “월급 체크하기”, “저금 추가”, “자산 추가”, “금액 가리기”(켜져 있으면 “금액 보이기”), “잠그기”(→ 기획서 19 앱 틀 12번).
- 검색어가 있으면 이름이 맞는 동작만 남기고, 그 아래 저금 항목, 자산·부채, 경조사 묶음(최대 5개씩). 없으면 빈 상태 “찾는 게 없어요”(`hg-cmd__empty`).
- 입력 줄 입력칸은 `hg-cmd__input input`, 뒤 막은 위쪽에 붙임(`hg-scrim hg-scrim--top`).
- React 래퍼 `CommandPalette`(packages/ui).
- “잠그기”는 앱 잠금(PIN)을 켰을 때만 보임. 실행하면 바로 LockScreen.
- 단축키가 있는 동작은 줄 오른쪽에 `hg-kbd`(고른 줄은 “Enter”).

## 단축키 표시(`hg-kbd`)

- 회색 작은 칸(`surface-alt` + `hairline` 테두리, `micro` 글자 `slate`). 높이 22px.
- 쓰는 곳: 입력 줄 오른쪽 “Esc”, 고른 줄 “Enter”, 사이드바 검색 칸 “⌘K”(Windows “Ctrl K”).
- 키 이름만, 설명 문장 없음. 좁은 창, 터치 기기에서는 숨김.
- 웹은 브라우저 키와 겹치지 않게 데스크톱 앱과 따로 정한 키 표를 씀(예: ⌘L, Ctrl L은 주소창 키라 웹에서는 잠그기에 쓰지 않음). 웹에서는 그 표의 키만 표시.

쓰는 곳: 데스크톱 앱과 넓은 창 웹 어디서나. 사이드바 검색 칸을 눌러도 열림.
