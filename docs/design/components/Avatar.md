# Avatar

사람 표시. 프로필 사진(직접 올린 사진, 또는 카카오·구글 계정 사진을 처음 한 번 가져온 것) → 사람 색 원 + 실루엣(2026-11-05). 2026-11-05 지정 아바타 그림 없앰.

- 소비자가 주는 것: 이름, 사람 번호(1·2), 크기(24·32·40·72), 사진 주소(선택).
- 사진 없음(2026-11-05): 사람 색 원 + 사람 실루엣(머리 + 어깨, 사람 글자색을 원 색에 45% 섞어 옅게). 이름 첫 글자는 DOM에만 남고 보이지 않음. 배우자 빈 자리(`hg-avatar--empty`)도 같은 실루엣을 `surface-alt` 원 + `muted`로.
- 색은 사람마다 고정. 먼저 시작한 사람(찬우) `person-1` 연한 코랄, 합류한 사람(예빈) `person-2` 하늘. 누가 보든 같은 사람은 같은 색.
- 글자는 짝이 되는 `person-*-ink`. 영역 틴트와 섞어 쓰지 않음.
- 사진 있음: `hg-avatar--photo` 안에 `<img>`, 원으로 잘라 `object-fit: cover`. `alt`는 이름. 사람 색은 쓰지 않음.
- 사진을 불러오지 못하면 글자 아바타로 바꿔 보여줌.
- 둘이 함께는 `hg-avatars`로 겹침(바깥 2px `surface` 고리). 사진과 글자가 섞여도 됨.
- 크기: 24(목록), 32(기본), 40(카드), 72(`hg-avatar--xl`, 설정 S-11 내 정보, A-02 초대로 들어왔을 때 초대한 사람).
- 사진 바꾸기: S-11에서만 `hg-avatar-edit`로 감싸고 오른쪽 아래 카메라 버튼(`aria-label` “사진 바꾸기”). 사진을 끌어 놓는 동안 `is-drop` 테두리. 누르거나 놓으면 S-11e 자르기 화면.
- 쓰는 곳: 체크리스트 줄 체크한 사람, 배우자 활동, 두 사람 카드, 설정, A-02 초대 로그인.

## 사람 줄, 사람 탭 (2026-10-27)

- 사람 줄(`hg-person`, 카카오뱅크 모임통장 멤버 줄처럼): `plate` 바탕 둥근 줄(`radius-lg`) 안에 Avatar → 문장(“예빈님 3개 중 1개”) → 진행 원 Ring → `stone` ›. 줄 전체가 `button`. 홈 H-03 배우자 체크 현황.
- 사람 탭: Tabs 항목 `lead`에 작은 Avatar(22px)를 이름 앞에(W-01 월급 계획, W-02 체크리스트의 찬우·예빈 탭).
