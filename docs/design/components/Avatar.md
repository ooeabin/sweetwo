# Avatar

사람 표시. 프로필 사진(직접 올린 사진, 또는 카카오·구글 계정 사진을 처음 한 번 가져온 것) → 사람 색 원 + 빵모자 실루엣(2026-11-09, 그 전 2026-11-05는 머리 + 어깨 실루엣). 2026-11-05 지정 아바타 그림 없앰.

- 소비자가 주는 것: 이름, 사람 번호(1·2), 크기(24·32·40·72), 사진 주소(선택).
- 사진 없음(2026-11-09 빵모자 실루엣): 사람 색 원 + 얼굴 없는 사람(머리, 원에 잘린 어깨)이 요리사 모자(봉긋한 세 덩이 + 몸통)를 쓴 모양. 모자는 테두리 하나로 이은 한 덩어리(안쪽 선 없음), 모자와 머리 사이에 원 색의 가는 틈. 모양은 64 칸 path 하나(`packages/ui` `AVATAR_FIGURE_PATH`), 화면은 CSS mask, 영수증 이미지(W-01 공유하기)는 같은 path를 canvas에. 24px에서도 또렷하게. 이름 첫 글자는 DOM에만 남고 보이지 않음, 이름은 `alt`·`aria-label`이나 옆 글자로.
  - 색(2026-11-11 사용자 결정, 민트 + 라벤더, 진한 톤 실루엣): 라이트는 원 `person-1` #cdeee4·`person-2` #e2dbfc + 실루엣 #7fcfb8·#a996f2(같은 색의 진한 톤. 흰 실루엣은 흰 바탕에서 어깨가 녹아 원 아래가 잘려 보여 없앰). 다크는 원 #173a31·#2a2450 + 실루엣 #a6e3d0·#c9beff. 예전 코랄 #fecdbb·하늘 #bacefe + 흰 실루엣. 토큰 `person-1-figure`·`person-2-figure`가 이 실루엣 색.
  - 대비: 실루엣은 꾸밈 그림(aria-hidden)이라 글자 대비 기준 밖(라이트 진한 톤과 원 약 1.6:1, 원 모양은 실루엣 색으로도 보임, 다크 8:1 이상). 사람 구분은 늘 이름 글자로도. `person-*-ink` 글자를 원 위에 쓰면 라이트 6.3:1·6.7:1.
  - 파트너 빈 자리(`hg-avatar--empty`): 같은 빵모자 실루엣을 `surface-alt` 원 + `muted`로.
- 색은 사람마다 고정. 먼저 시작한 사람(찬우) `person-1` 민트, 합류한 사람(예빈) `person-2` 라벤더(2026-11-11). 누가 보든 같은 사람은 같은 색.
- 짝이 되는 진한 색은 `person-*-ink`(글자 색, 이니셜은 보이지 않음). 영역 틴트와 섞어 쓰지 않음.
- 사진 있음: `hg-avatar--photo` 안에 `<img>`, 원으로 잘라 `object-fit: cover`. `alt`는 이름. 사람 색은 쓰지 않음.
- 사진을 불러오지 못하면 사람 색 원 + 빵모자 실루엣으로 바꿔 보여줌.
- 둘이 함께는 `hg-avatars`로 겹침(바깥 2px `surface` 고리). 사진과 실루엣이 섞여도 됨.
- 크기: 24(목록), 32(기본), 40(카드), 72(`hg-avatar--xl`, 설정 S-11 내 정보, A-02 초대로 들어왔을 때 초대한 사람).
- 사진 바꾸기: S-11에서만 `hg-avatar-edit`로 감싸고 오른쪽 아래 카메라 버튼(`aria-label` “사진 바꾸기”). 사진을 끌어 놓는 동안 `is-drop` 테두리. 누르거나 놓으면 S-11e 자르기 화면.
- 쓰는 곳: 체크리스트 줄 체크한 사람, 파트너 활동, 두 사람 카드, 설정, A-02 초대 로그인.

## 사람 줄, 사람 탭 (2026-10-27)

- 사람 줄(`hg-person`, 카카오뱅크 모임통장 멤버 줄처럼): `plate` 바탕 둥근 줄(`radius-lg`) 안에 Avatar → 문장(“예빈님 3개 중 1개”) → 진행 원 Ring → `stone` ›. 줄 전체가 `button`. 홈 H-03 파트너 체크 현황(2026-11-09 홈 체크 목록 카드와 함께 없앰, 지금 쓰는 화면 없음). 홈 큰 상자(HomeHub)는 겹친 Avatar 36px만.
- 사람 탭: Tabs 항목 `lead`에 작은 Avatar(22px)를 이름 앞에(W-01 월급 계획, W-02 체크리스트의 찬우·예빈 탭).
