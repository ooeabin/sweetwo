# Avatar

사람 표시. 프로필 사진이 있으면 사진, 없으면 이름 첫 글자 1자.

- 소비자가 주는 것: 이름, 사람 번호(1·2), 크기(24·32·40·72), 사진 주소(선택).
- 사진 없음: 색은 사람마다 고정. 먼저 시작한 사람(찬우) `person-1` 연한 코랄, 합류한 사람(예빈) `person-2` 하늘. 누가 보든 같은 사람은 같은 색.
- 글자는 짝이 되는 `person-*-ink`. 영역 틴트와 섞어 쓰지 않음.
- 사진 있음: `hg-avatar--photo` 안에 `<img>`, 원으로 잘라 `object-fit: cover`. `alt`는 이름. 사람 색은 쓰지 않음.
- 사진을 불러오지 못하면 글자 아바타로 바꿔 보여줌.
- 둘이 함께는 `hg-avatars`로 겹침(바깥 2px `surface` 고리). 사진과 글자가 섞여도 됨.
- 크기: 24(목록), 32(기본), 40(카드), 72(`hg-avatar--xl`, 설정 S-11 내 정보).
- 사진 바꾸기: S-11에서만 `hg-avatar-edit`로 감싸고 오른쪽 아래 카메라 버튼(`aria-label` “사진 바꾸기”). 사진을 끌어 놓는 동안 `is-drop` 테두리. 누르거나 놓으면 S-11e 자르기 화면.
- 쓰는 곳: 나누기 줄 담당, 배우자 활동, 제안 보낸 사람, 두 사람 카드, 설정.
