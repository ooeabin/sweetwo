# Avatar

사람 표시. 직접 올린 프로필 사진(소셜 계정에서 직접 지정한 사진을 처음 한 번 가져온 것 포함) → 사람 색 원 + 닉네임 앞 최대 3자(2026-11-18, 그 전 2026-11-09는 빵모자 실루엣, 2026-11-05는 머리 + 어깨 실루엣). 2026-11-05 지정 아바타 그림 없앰. 소셜 계정 기본 이미지(구글 글자 원, 카카오 기본 이미지)와 계정이 준 사진 주소(`user_metadata.avatar_url`·`picture`)는 쓰지 않음.

- React: `Avatar`(`packages/ui`) 하나로 모든 곳. 소비자가 주는 것: 이름(`name`), 사람 번호(`no` 1·2), 크기(`size` sm 24·md 32·lg 40·xl 72), 사진 주소(`src`, 선택), 파트너 빈 자리(`empty`). 앱 화면은 `PersonDot`(`shared/person.tsx`)이 사진 주소를 찾아 `Avatar`에 넘김. 손으로 `hg-avatar` span을 만들지 않음.
- 사진 인정 범위(2026-11-18): 우리 저장소 `avatars/{공간}/{사람}.jpg`만. 앱은 `fetchAvatars`에서 이 모양의 경로만 서명 주소로 바꾸고 그 밖의 값(소셜 사진 주소 등)은 무시. 외부 이미지 출처가 없어 앱 CSP `img-src`에 소셜 출처를 두지 않음.
- 글자(2026-11-18): 닉네임 앞에서부터 최대 3자. 한글·영문·숫자 모두 글자(그래핌) 수로 세고, 이모지 같은 조합 문자가 깨지지 않게 `Intl.Segmenter`를 씀. 공백은 빼고 셈. 영문은 대문자로 바꾸지 않고 그대로. 규칙은 `packages/core` `avatarInitials`(`avatarInitialCount`) 하나. ‘예빈’ → 예빈, ‘윤예빈’ → 윤예빈, ‘김철수바보’ → 김철수, ‘Chanwoo’ → Cha.
- 글자가 없으면(닉네임 없음) 사람 아이콘(Phosphor `user`, 원 지름의 56%) 사람 색 원 위에. 파트너 빈 자리(`hg-avatar--empty`)도 같은 사람 아이콘을 `surface-alt` 원 + `muted`로.
- 글자 크기(원 지름 기준, 글자 수에 따라 원 안에 맞게 줄임): 1자 40%, 2자 38%(`hg-avatar--n2`), 3자 28%(`hg-avatar--n3`, 자간 -0.02em), 굵기 600. 크기는 `--avatar` 하나로 정하고 글자·아이콘이 따라감(24px 3자는 약 6.7px로 아주 작아 꾸밈 수준, 사람 구분은 늘 이름 글자나 옆 글자로도).
- 색(사람마다 고정, 새 토큰 없음): 먼저 시작한 사람(찬우) `person-1` 민트 바탕 + `person-1-ink` 글자, 합류한 사람(예빈) `person-2` 라벤더 바탕 + `person-2-ink` 글자. 누가 보든 같은 사람은 같은 색. 오렌지는 쓰지 않음.
  - 대비: 글자와 바탕 라이트 6.3:1(`person-1`)·6.7:1(`person-2`), 다크 8:1 이상. 모두 4.5:1 이상.
  - 예전 빵모자 실루엣 색 토큰 `person-1-figure`·`person-2-figure`는 없앰(2026-11-18).
- 글자는 꾸밈이라 `aria-hidden`. 이름은 옆 글자나 `aria-label`로(기존 규칙 그대로). 사진은 `alt`가 이름(S-11 내 정보만 `alt` 있음, 나머지는 꾸밈).
- 사진 있음: `hg-avatar--photo` 안에 `<img>`, 원으로 잘라 `object-fit: cover`. 사람 색은 쓰지 않음. 사진을 불러오지 못하면 글자 아바타로 바꿔 보여줌.
- 사진을 지우면 글자 아바타로 돌아감(S-11 ‘사진 지우기’).
- 둘이 함께는 `hg-avatars`로 겹침(바깥 2px `surface` 고리). 사진과 글자가 섞여도 됨. 쌓는 순서: 뒤 원이 위, 겹침 유지(2026-11-20 앞 원을 위로 올렸다가 되돌림).
- 크기: 22(탭, `hg-tab`), 24(`sm`, 목록), 28(사이드바·같이 모으기·어드민 계정), 32(`md`, 기본), 40(`lg`, 카드), 72(`xl`, 설정 S-11 내 정보, A-02 초대로 들어왔을 때 초대한 사람). 문맥별 크기는 CSS가 `--avatar`만 바꿈.
- 어드민은 같은 컴포넌트(사이드바 아래 계정 원, 잉크 바탕 + `on-ink` 글자). 어드민 회원 화면에는 사람 원이 없음.
- 영수증 이미지(W-01 공유하기)는 같은 글자·크기 단계·색(`person-*`, `person-*-ink`)을 canvas에 그림(`receipt-image.ts`).
- 사진 바꾸기: S-11에서만 `hg-avatar-edit`로 감싸고 오른쪽 아래 카메라 버튼(`aria-label` “사진 바꾸기”). 사진을 끌어 놓는 동안 `is-drop` 테두리. 누르거나 놓으면 S-11e 자르기 화면.
- 쓰는 곳: 체크리스트 줄 체크한 사람, 파트너 활동(알림), 두 사람 카드(홈 같이 모으기), 설정, 우리 둘, 휴지통, A-02 초대 로그인, 넓은 창 사이드바, 영수증, 어드민 계정.

## 사람 줄, 사람 탭 (2026-10-27)

- 사람 줄(`hg-person`, 카카오뱅크 모임통장 멤버 줄처럼): `plate` 바탕 둥근 줄(`radius-lg`) 안에 Avatar → 문장(“예빈님 3개 중 1개”) → 진행 원 Ring → `stone` ›. 줄 전체가 `button`. 홈 H-03 파트너 체크 현황(2026-11-09 홈 체크 목록 카드와 함께 없앰, 지금 쓰는 화면 없음). 홈 큰 상자(HomeHub)는 겹친 Avatar 36px만.
- 사람 탭: Tabs 항목 `lead`에 작은 Avatar(22px)를 이름 앞에(W-01 월급 계획, W-02 체크리스트의 찬우·예빈 탭).
- 같이 모으기(홈 H-10, 바탕 기준 2026-11-23 사용자 지적): 겹친 원 지름 32, 안 글자 12px 700(3글자 11px, 원 안쪽에 여유), 겹침 −8·뒤 원이 위·2px `surface` 고리 그대로. 이름표 “같이 모으기”(13) 아래 12, 원 묶음과 이름(17/400) 사이 8(세로 가운데), 이름 아래 금액(22/700)까지 8. 같은 쌍을 쓰는 다른 곳도 같은 크기·간격.
