# FileAttach

파일 첨부 칸. 골라 넣거나 끌어 놓고, 올라간 파일을 작은 목록으로 보여 주고 뺄 수 있음.

- 소비자가 주는 것: 라벨, 받는 형식과 한도(개수, 장당 크기), 파일마다 이름, 크기, 미리보기 그림, 올리는 진행 비율, 오류.
- 위 → 아래: 라벨(`hg-field__label`) → 한 줄 올리기 칸(`hg-drop hg-drop--row`, `paperclip` 아이콘 + “파일을 끌어 놓거나” + 글자 링크 “골라 주세요”) → 한도 1줄(`hg-help`) → 파일 목록(`hg-files`).
- 한도 글자는 늘 보임: 문의 첨부 “사진과 PDF 3개까지, 하나에 10MB 이하”, 챙길 날 사진 “사진 1장, 10MB 이하”.
- 파일 줄(`hg-file`): 40px 미리보기(사진은 그림, 그 밖은 아이콘) → 이름(한 줄 말줄임) + 보조 1줄(크기) → 빼기 버튼(`hg-file__remove`, `x` 아이콘, `aria-label` “{파일 이름} 빼기”).
- 올리는 중: 보조 줄 자리에 “올리는 중” + 얇은 막대(`hg-file__bar`, 채움 `ink`). 막대 옆에 % 글자를 붙이지 않음. 0.3초 안에 끝나면 막대를 보여 주지 않음.
- 오류: 줄 테두리 `danger` 45% + 보조 줄 `danger` 글자와 `circle-alert` 아이콘. “10MB 이하 파일만 올릴 수 있어요”, “이 형식은 올릴 수 없어요”, “3개까지 올릴 수 있어요”, 올리기 실패면 “올리지 못했어요” + 글자 링크 “다시 시도”.
- 한도를 다 채우면 올리기 칸은 비활성 모양(`stone` 글자), 끌어 놓으면 “3개까지 올릴 수 있어요”.
- 빼기는 묻지 않고 바로, 보내기 전이라 되돌리기 Toast 없음.
- 사진은 기기에서 줄여서 올림(긴 변 2048px). 메모와 같은 수준으로 암호화해 보관.
