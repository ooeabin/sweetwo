# CycleStepper

월 사이클의 지금 위치: 월급 플랜 → 월급 나누기 → 생활비 체크 → 월말 정리.

- 소비자가 주는 것: 단계 이름, 날짜, 현재 단계.
- 끝낸 단계 `ink` 막대, 지금 단계 `ink` 50% 막대, 남은 단계 `hairline`. `brand` 쓰지 않음. 이름은 막대 아래(진행 막대와 달리 사이클은 이름이 정보).
- 이름 아래 줄은 날짜나 “지금”만. “2/3 완료” 같은 분수 글자는 쓰지 않음.
- 생활비 체크가 꺼져 있으면 3단계로.
- ‘이번 달’ 맨 위 카드와 월급 플랜 화면 머리에 씀.
