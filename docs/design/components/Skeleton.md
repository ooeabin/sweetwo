# Skeleton

불러오는 동안 자리를 잡는 회색 틀. 실제 화면과 같은 배치로.

- 소비자가 주는 것: 너비·높이, 모양(줄·카드·원).
- 줄 높이는 글자 크기만큼, 카드는 실제 카드 높이. 300ms 안에 오면 보여 주지 않음.
- 움직임 줄이기 설정이면 반짝임 없음.


## 로딩 상태 4가지(2026-11-04, 카카오뱅크·카카오페이·토스·당근 참고)

빈 흰 화면은 없음. 0.3초 안에 오면 아무것도 그리지 않음(깜빡임 방지, `useDelayed`).

| 언제 | 모양 | 컴포넌트 |
| --- | --- | --- |
| 화면 불러오기 | 실제 화면 모양 뼈대. 설정·상세 하위(`list`): 맨 위 제목 자리 + 줄 카드(`hg-skelcard`, 이름 + 오른쪽 값) 2개. 홈(`home`): 작은 이름 + 큰 숫자 자리 + 카드. 그 밖(`cards`): 카드 3줄 | `LoadingFrame shape` (app), `Skel`, `SkelRows` |
| 질문 화면 불러오기 | 제목·도움말은 바로(정해진 문구, 데이터에 따라 바뀌면 제목도 뼈대), 입력 칸 56px 뼈대 + 아래 버튼 자리 뼈대 | `QuestionSkeleton` |
| 오래 걸리는 처리 | 가운데 그림 자리(112px 회색 원. 그림 이름(`art`)을 주면 그림이 들어올 때까지 원 전체가 빈 자리 `hg-artslot`(안쪽 1px `hairline-soft`, 2026-11-09), 아이콘만 주면 아이콘이 천천히 위아래) + 한 문장 20px 굵게 + 보조 15px `slate`. 파일 만들기(S-18) 등 | `ProcessingState` (`hg-busy`) |
| 버튼 동작 | 버튼 안 로딩(`is-loading`) | `Button` |

- 다른 데서 할 일을 기다릴 때(A-03 브라우저 로그인 대기)는 제목 위 + 작은 표시(`AuthLayout busy`) 그대로.
- 숫자로 진행을 크게 보여 주는 화면(카카오뱅크형)은 쓰지 않음(2026-11-04 시안에서 뺌).
- 화면 제목 줄이나 탭이 따로 있는 화면(2026-11-06): 제목 줄·탭은 그대로 두고 본문 자리에만 `SkelBody shape`(app). `rows` = 줄 카드 2개(F-02 자산·부채, Y-01 캘린더 목록), `tiles` = 요약 카드 + 타일 4개(`hg-goaltiles`, 예전 목표 탭 G-01용, 2026-11-08 목표 탭을 없애 지금 쓰는 곳 없음), `calendar` = 달력 카드(높이 320px) + 줄 카드(Y-04), `cards` = 카드 2줄(F-01).
- 질문 흐름(온보딩, 합류, 월급 계획 W-01, 월급 체크 끝 W-02, 월급 전 확인 W-05, 저금 추가 W-11, 달성 축하 W-12)도 불러오는 동안 빈 화면 대신 `QuestionSkeleton`(2026-11-06). 온보딩·합류는 진행 막대(`chapter`)를 같은 자리에 두고, 흐름의 첫 화면은 뒤로 버튼 없음(`onBack={null}`). 입력 칸이 없는 안내 화면(O-10, O-60)은 `fields={0}`.
- 앱 시작: 모바일은 네이티브 실행 화면(흰 바탕 가운데 워드마크, 다크는 surface 다크, 2026-11-05, 04 브랜드) 다음 A-01 워드마크. 데스크톱은 A-01 워드마크.
