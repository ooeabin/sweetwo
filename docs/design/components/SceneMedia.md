# SceneMedia

장면 자리. 정해진 다섯 화면에서 장면 그림이 들어가던 자리. 지금은 그림 없이 영역만 잡아 비워 둠(2026-10-19 장면 그림·영상 제거).

- 소비자가 주는 것: 비율(1:1 또는 3:4), 너비(선택).
- 구조: 빈 `figure.hg-scene`(`aria-hidden`). 안에 그림이나 영상 없음.
- 비율: 기본 1:1(`hg-scene`), P-01만 3:4(`hg-scene--tall`). 너비는 화면이 정함(최대 320px).
- 칸에 테두리, 바탕, 모서리 둥글림, 그림자 없음. 글자를 겹치지 않음.

쓰는 곳: W-04 월말 정리 끝, P-11 배우자 합류 완료, P-01 초대받은 사람 첫 화면(3:4), H-T1 결혼일 전환 축하. A-02 로그인 첫 화면은 이 자리에 영어 워드마크(`Wordmark`)를 넣어 SceneMedia를 쓰지 않음.
