# Banner

화면 위 안내 띠. 지금 상태 때문에 할 수 있는 일이 달라질 때만.

- 소비자가 주는 것: 문장 1줄, 행동 링크 1개(선택).
- `hg-banner--info`(`surface-alt`): 오프라인, 연결 해제 대기, 혼자 쓰기, 월급 전 확인할 때(“10월 월급, 빠진 게 있는지 확인할 때예요”). 띠에는 브랜드 색을 쓰지 않음.
- 화면당 1개. 닫기는 상태가 풀리면 저절로.

## 할 일 카드 (`hg-banner--todo`, 2026-10-27, 카카오뱅크 알림 카드 느낌)

- 홈 할 일 한 줄(H-06)만. 흰 카드(`hairline-soft` 테두리 + `shadow-1`, `radius-xl`, 안쪽 16px 20px, 좁은 창 16px), 글자 15px 600.
- 맨 앞 그림 원(`hg-banner__icon`, 40px `surface-alt` 원 + `ink` 아이콘): 연결 해제·다시 연결 `link`, 월급 전 확인 `check`, 초대 `user`, 금액 정하기 `pencil`, 만기 `piggy-bank`, 챙길 날 `gift`. 그림은 `aria-hidden`.
- 오른쪽 보조 버튼 1개(‘열기’, 초대는 ‘코드 복사’) → 닫을 수 있는 것만 끝에 X 아이콘 버튼(`IconButton` ghost small, 이름 “닫기”).

- 제목은 한 줄, 넘치면 말줄임(`hg-banner__one`). ‘보기’로 펼치면 줄바꿈해서 다 보임.
- 할 일 카드(H-06, 2026-11-02): 그림 + 글자 + 화살표가 한 버튼(`hg-banner__main`, 띠 전체를 누르면 이동, ‘열기’ 버튼 없음). 글자 15px 500. 닫기(×)와 초대의 ‘코드 복사’는 옆에 따로. 네이버·GCOO 홈처럼.

- 할 일 띠·초대 띠·공지 띠(2026-11-09, 2026-11-03 연한 파랑에서 바꿈): 옅은 오렌지 `accent-app-soft`(= `brand-soft`) 바탕 + `ink` 글자(600), 앞 아이콘·꺾쇠·초대 빈 자리 점선 원은 `accent-app` 오렌지, 테두리·그림자 없음, 버튼은 흰 작은 버튼 + 오렌지 글자(‘초대하기’, ‘펼치기’), 닫기(× 또는 ‘닫기’)는 `slate`. 띠 바탕을 진한 오렌지로 칠하지 않음. 좁은 창은 한 줄 높이(48px)로 본문 양옆 여백 없이 꽉 차게(모서리 없음), 앞 아이콘 24px(원 없음), 글자 14px 한 줄(넘치면 …). 초대 띠는 앞에 점선 빈 자리(+) 하나(`hg-banner__pair`, `hg-banner__slot`, 2026-11-03 머리 줄에 내 아바타가 있어 빼냄).
- 회색 한 줄 띠(2026-11-03, `hg-banner--info hg-banner--strip`, 앱 `LineBand`): 홈 해제 대기·알림 메일 반송·PC 안내, 앱 틀 오프라인. 앞 아이콘 16px `slate` + 굵은 제목(넘치면 …) + 보조 문장(넓은 창은 같은 줄, 좁은 창은 제목 아래 13px 둘째 줄) + 흰 작은 버튼(할 일 띠 ‘초대하기’와 같은 모양, `surface` 바탕). 좁은 창은 할 일 띠처럼 최소 48px 높이로 양옆 여백 없이 꽉 차게(모서리 없음).
