# Banner

화면 위 안내 띠. 지금 상태 때문에 할 수 있는 일이 달라질 때만.

- 소비자가 주는 것: 문장 1줄, 행동 링크 1개(선택).
- `hg-banner--info`(`surface-alt`, 회색 바탕 화면 위에서는 `surface` 흰 판, 2026-11-11 D1): 오프라인, 연결 해제 대기, 혼자 쓰기, 월급 전 확인할 때(“10월 월급, 빠진 게 있는지 확인할 때예요”). 띠에는 브랜드 색을 쓰지 않음.
- 화면당 1개. 닫기는 상태가 풀리면 저절로.

## 맨 위 띠 하나 (2026-11-11, QA 4구간 D3)

- 본문 맨 위(`hg-body__banners`)에는 띠를 하나만 둠. 여러 상태가 겹치면 순서대로 하나: 오프라인 > 연결 해제 대기 > 필독 공지 > 알림 메일 반송 > 일반 공지(core `pickTopBanner`, 19 홈 ‘맨 위 띠’). 오프라인은 앱 틀(MainFrame)이 맨 앞에 두고 그동안 화면이 준 띠는 숨김. 앞 띠가 풀리면 다음 띠가 보임.
- 글자는 두 줄까지 보이고 그 뒤 말줄임(D2): `hg-banner__one`(이름은 그대로, 2026-11-11부터 두 줄), 좁은 창 회색 띠는 제목·보조 문장 각각 두 줄. 320px에서도 핵심 말이 잘리지 않게.

## 한 번 확인 띠 (`hg-banner--check`, 2026-11-11)

- 질문 화면에서 ‘말이 안 되는 값’을 한 번 확인할 때(O-31 “한 달에 {금액}이 맞나요?”, P 화면 “입력한 값이 맞나요?”). 막지 않음: 주 버튼을 다시 누르면 넘어감. 값을 바꾸면 사라짐.
- 입력 칸 아래, 본문 폭. `surface-alt` 판, `radius-lg`, 안쪽 12px 16px, 앞 Phosphor `circle-alert` 20px `ink` + 문장 `ink` 15px 600(`text-body-strong`). 작은 회색 글(`hg-banner--info` 13px)로 두지 않음. 오렌지·노랑 판을 쓰지 않음(사용자 앱 포인트는 오렌지 하나, 경고색은 어드민만).
- `role="alert"`로 나타날 때 바로 읽음. 아이콘은 `aria-hidden`.

## 할 일 카드 (`hg-banner--todo`, 2026-10-27, 카카오뱅크 알림 카드 느낌)

- 홈 할 일 한 줄(H-06)만. 2026-11-09부터 홈 할 일은 HomeHub 할 일 띠(`hg-hubband`)이고, 2026-11-11부터 초대 할 일도 같은 코코아 HomeHub 띠라 홈에서는 이 옅은 띠를 쓰지 않음(어드민 공지 미리보기 등 남은 곳만). 흰 카드(`hairline-soft` 테두리 + `shadow-1`, `radius-xl`, 안쪽 16px 20px, 좁은 창 16px), 글자 15px 600.
- 맨 앞 그림 원(`hg-banner__icon`, 40px `surface-alt` 원 + `ink` 아이콘): 연결 해제·다시 연결 `link`, 월급 전 확인 `check`, 초대 `user`, 금액 정하기 `pencil`, 만기 `piggy-bank`, 경조사 `gift`. 그림은 `aria-hidden`.
- 오른쪽 보조 버튼 1개(‘열기’, 초대는 ‘코드 복사’) → 닫을 수 있는 것만 끝에 X 아이콘 버튼(`IconButton` ghost small, 이름 “닫기”). 홈 할 일·초대 띠(HomeHub `hg-hubband`)는 2026-11-11부터 닫기 없음.

## 공지 한 줄 (`hg-banner--line`, 현대카드 공지 띠 느낌)

- 어드민 공지(AD-10) 띠. `surface-alt` 바탕, `radius-xl`, 맨 앞 `info` 16px(`slate`).
- 제목은 두 줄까지, 넘치면 말줄임(`hg-banner__one`, 2026-11-11 D2 전에는 한 줄). ‘보기’로 펼치면 줄바꿈해서 다 보임.
- 할 일 카드(H-06, 2026-11-02): 그림 + 글자 + 화살표가 한 버튼(`hg-banner__main`, 띠 전체를 누르면 이동, ‘열기’ 버튼 없음). 글자 15px 500. 닫기(×)와 초대의 ‘코드 복사’는 옆에 따로. 네이버·GCOO 홈처럼.

- 공지 띠(2026-11-09, 2026-11-03 연한 파랑에서 바꿈. 홈 할 일·초대 띠는 2026-11-11부터 HomeHub 코코아 띠): 옅은 오렌지 `accent-app-soft`(= `brand-soft`) 바탕 + `ink` 글자(600), 앞 아이콘·꺾쇠는 `accent-app` 오렌지, 테두리·그림자 없음, 버튼은 흰 작은 버튼 + 오렌지 글자(‘초대하기’, ‘펼치기’), 닫기(× 또는 ‘닫기’)는 `slate`. 띠 바탕을 진한 오렌지로 칠하지 않음. 좁은 창 흰 바탕 화면은 최소 48px 높이로 본문 양옆 여백 없이 꽉 차게(모서리 없음), 회색 바탕 화면(홈·자산 관리, `hg-frame--alt`)은 흰 상자들과 같은 폭의 둥근 판(`radius-xl`, 최소 52px, 2026-11-10부터 구현 그대로, 2026-11-11 S4-16 문서를 맞춤). 앞 아이콘 24px(원 없음), 글자 13px 두 줄까지(넘치면 …, D2). 초대 띠의 점선 빈 자리(+)(`hg-banner__pair`, `hg-banner__slot`)는 2026-11-11 없앰(클래스도 지움).
- 회색 띠(2026-11-03, `hg-banner--info hg-banner--strip`, 앱 `LineBand`): 홈 해제 대기·알림 메일 반송, 앱 틀 오프라인. 앞 아이콘 16px `slate` + 굵은 제목 + 보조 문장(넓은 창은 같은 줄, 좁은 창은 제목 아래 12px 둘째 줄), 둘 다 두 줄까지(넘치면 …, 2026-11-11 D2) + 흰 작은 버튼(`surface` 바탕). 좁은 창 흰 바탕 화면은 최소 48px 높이로 양옆 여백 없이 꽉 차게(모서리 없음). 회색 바탕 화면(홈·자산 관리, `hg-frame--alt`)은 흰 상자와 같은 폭의 둥근 판(`radius-xl`, 최소 52px)이고 판은 흰색(`surface`, 2026-11-11 QA 4구간 D1: 회색 바탕 위 회색 판이 안 보여서), 그 위 작은 버튼은 회색(`surface-alt`).
- 띠 자리 `hg-body__banners`(2026-11-03): 본문 맨 위 띠 자리. 2026-11-11부터 띠는 하나만(위 ‘맨 위 띠 하나’)이라 여러 띠 사이 간격(`space-2`, 좁은 창 1px)은 남은 규칙.
