# AddRow

+ 추가 줄(2026-11-09, 좁은 창 + 버튼(FAB)을 없애고 그 자리). 목록 끝이나 묶음 머리 오른쪽에 두는 회색 글자 버튼.

- 모양(`hg-addrow`): Phosphor `plus` 16px + 글자(`label` 14px 600 `ink-2`, 글자 버튼 `hg-btn--link`와 같은 회색), 사이 6px, 높이 44px(누름 영역). 바탕·테두리 없음, 마우스 올림 글자 `ink`. 포커스 ink 링.
- 글자는 ‘+’ 없이(“저금 추가”), 아이콘이 ‘+’를 대신함. 화면 읽기 이름도 “저금 추가”.
- `--block`: 한 줄 꽉 차게(목록 끝, 안쪽 좌우 16px). W-02 저금 묶음 카드 안에서는 안쪽 여백 없이 줄 앞 칸과 같은 선.
- SectionHeader `action` 자리에 넣으면 오른쪽 끝(높이 32px).
- 쓰는 곳: W-02 저금 묶음 끝 ‘+ 저금 추가’(→ W-11a), F-02 목록 끝 ‘+ 자산 추가’ / ‘+ 부채 추가’(→ F-03a), Y-01 ‘일정’ 머리 오른쪽 ‘+ 경조사 추가’(→ Y-07). 넓은 창 제목 줄 ‘추가’ 버튼은 그대로.
- 오렌지 쓰지 않음(글자 버튼은 모두 회색, 2026-11-09).
- React 래퍼 `AddRow`(packages/ui): `label`, `onClick`, `block`.
