# AddRow

+ 추가 줄(2026-11-09, 좁은 창 + 버튼(FAB)을 없애고 그 자리). **2026-11-27 ‘버튼·색 정리’ 사용자 결정 4: 앱의 ‘+ … 추가’는 이 한 모양**(예전 W-01·W-20b `PlanAdd`(`hg-plan__block`), Y-04 점선 원 ListRow(`hg-cal__add`), 원 없는 + 글자 줄을 합침).

- 모양(`hg-addrow`): 왼쪽 회색 원 32(`hg-addrow__icon`, `surface-alt`, 왼쪽 = 본문 시작) 안 Phosphor `plus` 16 `slate` + 원과 글자 사이 12 + 글자 15/400 `ink-2`. 줄 높이 48(누르는 칸 44 이상). 바탕·테두리 없음, 마우스 올림 글자 `ink`. 포커스 ink 링.
- 글자는 ‘+’ 없이(앞 ‘+’는 떼고 원 안 아이콘이 대신함). 화면 읽기 이름은 보이는 글자, 원래 글자(“+ 지출 추가”)를 그대로 읽혀야 하는 곳은 `ariaLabel`. ‘저축·투자’ 말(2026-11-17): 묶음이나 화면 안에서는 “추가”, 묶음 밖은 “저축·투자 추가”. 줄마다 ‘저축·투자’를 되풀이하지 않는다.
- `block`: 한 줄 꽉 차게(목록·묶음 끝). 기본은 글자 폭만(inline).
- SectionHeader `action` 자리에 넣으면 오른쪽 끝(누르는 칸 44, 같은 원 + 글자).
- `expanded`: 펼침 상태가 있는 추가면 `aria-expanded`.
- 쓰는 곳: W-01 ‘저축·투자’ / ‘지출’ 묶음 끝 ‘+ 저축·투자 추가’ / ‘+ 지출 추가’(아래 묶음 끝까지 8), W-20b 큰 금액 아래 ‘+ 수입 입력하기’, F-02 목록 끝 ‘+ 자산 추가’ / ‘+ 부채 추가’, Y-04 고른 날 ‘이 날에 경조사 추가’(예전 점선 원)와 ‘다가오는 일정’ 머리 오른쪽 ‘+ 일정 추가’(좁은 창), W-14 메모 목록 끝 ‘메모 추가’. 넓은 창 제목 줄 ‘추가’ 버튼은 그대로.
- 오렌지 쓰지 않음(글자 버튼은 모두 회색, 2026-11-09).
- React 래퍼 `AddRow`(packages/ui): `label`, `onClick`, `block`, `ariaLabel`, `expanded`.
- 좁은 창만(2026-11-12 `hg-narrow-only`): 넓은 창 제목 줄 버튼과 겹치는 자리는 768px 미만에서만 보임.
- + 아이콘 규칙(2026-11-19): 글자 앞 +는 문자가 아니라 `PlusIcon` 아이콘 하나(Button.md ‘+ 아이콘 규칙’). AddRow는 그 아이콘을 회색 원 안에 둔다. 금액 앞 +50만 원 같은 숫자 부호는 글자 그대로.
