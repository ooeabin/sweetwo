# PeriodBar

날짜 없는 사람의 기간 막대(2026-11-13, ADR 0009 결정 3, G8). 홈 H-11 자리(H-13)와 월급 탭 ‘이번 달’ 자리에서 “들어온 돈 / 필요한 돈”을 나란히 보여 줌. 기획 → 07 6장, 계산 → 06 2-2. 클래스는 PR 9에서 `bundle.css`에 더하고 `pnpm ds:sync`.

- 틀(`hg-periodbar`): HubLine 문장 자리 안. 위 한 줄 “들어온 돈 340만 원 / 필요한 돈 380만 원”(15px 600 `ink`, 금액만 숫자 너비 같게), 아래 막대, 막대 아래 회색 “10월 3일부터”(13px 500 `slate`)
- 막대: 8px 둥근 막대, 바탕 `surface-alt`, 채움 **`ink-2`**(중립. 저금 진행이 아니라 오렌지 아님, CLAUDE.md 색 규칙). 채움 = 들어온 돈 ÷ 필요한 돈, 0~100%
- 판정 문장·빨강·경고 아이콘 없음(‘모자라요’ 쓰지 않음). 다 차면 막대 꽉 참 + 보조 “남는 돈은 저금에 넣을 수 있어요”
- 금액 가리기: 금액 “•••”, 막대는 그대로(비율만이라 [확인 필요])
- 화면 읽기: “이번 기간 들어온 돈 340만 원, 필요한 돈 380만 원, 10월 3일부터” 한 문장, 막대는 `aria-hidden`
- React(packages/ui `PeriodBar.tsx`): `PeriodBar`(`inLabel`, `needLabel`, `percent`, `since`, `full`)
