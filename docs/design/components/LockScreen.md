# LockScreen

앱 잠금 화면. 앱을 다시 열 때, Ctrl/⌘+L.

- 소비자가 주는 것: 입력한 자릿수, 틀린 횟수, Touch ID 사용 여부(macOS만).
- 가운데 한 열: 제목(24px 700, 늘 두 줄: 문구에 줄바꿈을 넣음. “앱을 열 때 쓸 / PIN 6자리를 정해 주세요”, “한 번 더 / 입력해 주세요”, “PIN을 / 입력해 주세요”) + 보조 1줄 “PIN 6자리를 눌러 주세요” → 6칸 점(제목과 사이 40px) → 점 바로 아래 작은 알약 버튼 “PIN을 잊었어요”(`assist`, 높이 32px, `hairline` 테두리, 13px 500 `slate`, 카카오T처럼) → 숫자 키패드(AmountInput의 `hg-keypad` 그대로, 마지막 줄 빈칸, 0, 지우기) → 글자 링크 “Touch ID로 풀기”(`fingerprint` 아이콘, Face ID면 `scan-smiley`. `touchId.icon`으로 넘김).
- PIN은 6자리 숫자. 점: 18px(사이 20px), 입력한 칸 `ink` 채움, 남은 칸 `border-control` 테두리. 숫자는 보여 주지 않음.
- “Touch ID로 풀기”는 Touch ID가 켜진 macOS에서만 보임. Windows Hello는 출시 뒤, 그 전까지 Windows는 PIN만.
- 틀리면 점을 비우고 점 아래 1줄 “PIN이 맞지 않아요”(`danger` + `circle-alert` 아이콘, `role="alert"`). 흔들기 움직임 없음.
- 3번째 틀림부터 다음 줄에 남은 횟수: “{n}번 더 틀리면 다시 로그인해야 해요”(기획서 A-06).
- 5번 틀리면 로그아웃하고 로그인 화면(A-02)으로, 위에 안내 “PIN을 5번 틀려서 다시 로그인해 주세요”. 다시 로그인하면 PIN을 새로 정함.
- 로고는 넣지 않음. 잠금 동안 금액, 이름, 목표는 아무것도 보이지 않음. 앱 전환 미리보기도 같은 화면.
- 아래 글자 링크(‘나중에 할게요’, ‘Touch ID로 풀기’)는 `slate`. 아래 링크 자리(`hg-lock__foot`)는 링크가 없어도 44px를 지켜 PIN 정하기와 잠금 해제의 키패드 위치가 같음(2026-11-02).
- 숫자 키는 높이 64px, 글자 26px 600.
- 넓은 창: 흰 카드(320px) 가운데. 좁은 창(768px 미만, 2026-11-02): 카드 테두리 없이 화면 전체. 제목과 보조 줄은 질문 화면 제목(`hg-q__title`)과 같은 자리(왼쪽 정렬, 같은 높이), 점은 가운데, 키패드는 화면 아래 끝(카카오뱅크 PIN 화면 느낌).
- 데스크톱은 키보드 숫자 입력, 키패드는 그대로 보여 줌.

쓰는 곳: 앱 잠금(A-06, 설정 S-15에서 바꿈), PIN 정하기(A-06 설정: 제목만 “앱을 열 때 쓸 PIN 6자리를 정해 주세요”), 앱을 다시 열 때, Ctrl/⌘+L, 트레이 위젯의 잠김 상태와 짝.
