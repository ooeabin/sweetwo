# ProposalCard

상대가 보낸 제안 묶음. 바뀌기 전·후를 항목별로 보여 주고 한 번에 응답.

- 소비자가 주는 것: 보낸 사람, 마감(D-n), 항목 목록(이름, 전 값, 후 값), 적용 날짜.
- 머리(`surface-alt`): “월말 정리 제안” + 개수 알약 + 오른쪽 D-n 검정 알약·마감일, 아래 제목 1줄.
- 머리는 무채색. 넓은 면이라 브랜드 색을 쓰지 않음.
- 항목 줄: 왼쪽 정보(영역 색 점 + 이름 / “80만 → 90만 원”: 전 값 취소선, 후 값 굵게, 단위는 끝에 한 번), 오른쪽 `반대` 버튼(`aria-pressed`). 누를 수 있는 건 이 버튼과 아래 두 버튼뿐.
- `반대`를 누르면 검정 “✓ 반대함”, 값은 지금 값만 남김. 다시 누르면 취소.
- 아래: ‘다르게 해볼래요’(보조) + ‘모두 좋아요’(주). 반대가 있으면 주 버튼 글자가 “나머지 {n}개 좋아요”.
- 아래 1줄 고정 문구: “좋아요면 바로, 반대 없으면 {날짜}부터 적용돼요”.
- ‘함께 정하기’ 항목은 `hg-badge--together` 배지를 붙이고, 응답 없으면 적용하지 않음.
