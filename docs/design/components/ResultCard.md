# ResultCard

결과 요약 카드(`hg-card hg-resultcard`). O-62 온보딩 결과, P-11 합류 완료의 결론 숫자.

- 소비자가 주는 것: 이름(“한 달에 모을 수 있는 돈”), 큰 금액, 오른쪽 위 표시(선택, ‘추정’), 금액 아래 한 줄(선택, 취소선 이전 값 등), 체크 줄 목록(이름 + 금액).
- 흰 카드(`hairline-soft` 테두리, `radius-xl`) 안에 금액 하나만 크게(36px 700, 표 숫자). 숫자 카드 여러 장 대신 이 카드 하나.
- 체크 줄: 금액 아래 `hairline-soft` 선 다음, 줄마다 24px `brand-soft` 동그라미 + `brand` 체크(꾸밈, 화면 읽기에서 숨김), 이름(15px `ink-2`), 오른쪽 금액(600).
- 버튼은 카드 안에 두지 않고 틀 아래 주 버튼 하나(QuestionLayout).
- 쓰는 곳: O-62, P-11.
