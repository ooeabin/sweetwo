# MonthSummary

월 정산 요약. 한 달에 소득에서 얼마를 쓰고, 모으고, 남겼는지를 한 카드로 보여 줌. 월말 정리 결과(W-04g) 맨 위와 우리 자산(F-01) 17번에 씀. 무료.

- 소비자가 주는 것: 달, 소득(그달 실제), 고정지출, 변동 지출 합계(신용카드 주사용이면 보조 글자 “지난달 카드 사용분”, O-38b), 용돈(사람별), 큰 지출(이름), 저축(상품별 납입), 지난달 대비 항목 증감, 계획 대비 저축 %, 보정 제안(있을 때), 부부 상태.
- 계산(기획서 계산·배분 7장): 쓴 돈 = 고정 + 변동 + 용돈 + 큰 지출. 남은 돈 = 소득 − 쓴 돈 − 저축. 사용 비율 = 쓴 돈 ÷ 소득(소수 첫째 자리).
- 순서 고정: 머리(“10월 정산” + “소득의 59.3%를 썼어요”) → 막대 → 숫자 4칸(소득, 쓴 돈, 저축, 남은 돈) → 쓴 돈 나눠 보기(고정, 변동, 용돈, 큰 지출, 저축 한 줄. 회색 판, 줄 사이 선 없음 → InfoPlate와 같은 판) → 지난달보다 → 보정 제안 카드.
- 막대(`hg-sum__bar`, 12px): 쓴 돈 `ink`, 저축 `chart-goal`, 남은 돈 `hairline`. 칸 사이 2px. 원형 차트 쓰지 않음. 색만으로 뜻을 전하지 않도록 숫자 4칸에 같은 색 점을 붙임.
- 숫자는 만 원 단위로 반올림해 보여 주고, 누르면 원 단위(F-01 상세). `brand` 쓰지 않음.
- 지난달보다(`hg-sum__chg`): 차이가 큰 항목 4개까지. “+8만”, “−5만”(빼기는 −). 늘었다고 빨간색으로 경고하지 않음(평가하지 않고 사실만).
- 보정 제안(`hg-sum__fix`): 최근 3개월 평균이 예산과 10% 넘게 다를 때만 1장. 큰 지출로 적은 돈은 평균에서 뺌. 오른쪽에 “그대로 두기”(글자 링크) + “맞추기”(보조 버튼).
- 예외
  - 소득이 0이거나 없음: 제목은 “이번 달 212만 원을 썼어요”, 비율과 남은 돈은 “—”, 아래 “소득을 넣으면 비율을 보여 드려요”.
  - 배우자 합류 전: “예빈님이 합류하기 전이라 찬우님 돈만 셌어요”.
  - 예비부부: 저축 줄 이름을 “결혼 자금”으로.
  - 첫 정산 전(F-01): 카드 대신 빈 상태 “첫 월말 정리 뒤에 보여드려요”.
- 접근성: 막대는 `role="img"` + 숫자 4개를 읽는 `aria-label`. 제목은 `h2`.
