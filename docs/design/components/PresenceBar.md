# PresenceBar

함께 모드 표시(W-04). 월말 정리를 둘이 같이 열고 있을 때 누가 있고 누가 입력 중인지 한 줄 알약으로 보여 줌.

- 소비자가 주는 것: 함께 있는 사람(이름, 사람 번호, 사진), 입력 중인 사람, 연결 상태(연결, 다시 연결 중, 끊김).
- 자리: W-04 화면 머리 아래, 진행 막대 위. 왼쪽 정렬, 내용 너비만큼(`hg-presence`, 높이 40px, `surface-alt` 알약).
- 함께: 겹친 Avatar 2개(`hg-avatars`, 24px) → “함께 정리 중”(600) → 상대가 입력하면 보조 “예빈님이 입력 중” + 점 3개(`hg-presence__typing`).
- 입력 중 표시는 입력이 멈추고 3초 뒤 사라짐. 같은 칸을 고치고 있으면 그 칸 라벨 옆에 작은 Avatar(24px) + “입력 중”.
- 혼자 남음: 상대가 나가면 Avatar 1개 + “예빈님이 나갔어요” 보조 줄, 5초 뒤 알약 숨김. 정리는 혼자 이어서 할 수 있음.
- 다시 연결 중(`is-reconnecting`): Avatar 대신 도는 `loader-circle` 아이콘 + “다시 연결하는 중이에요”. 10초 넘으면 “연결이 끊겼어요” + 글자 링크 “다시 시도”. 그 사이 입력한 값은 기기에 남았다가 연결되면 보냄.
- 색: 사람 색은 Avatar에만. 알약 바탕 `surface-alt`, 글자 `ink`와 `slate`. 브랜드, 영역색 쓰지 않음.
- 움직임: 점 3개 깜빡임과 도는 아이콘만. `prefers-reduced-motion`이면 멈춘 점, 멈춘 아이콘.
- 접근성: 알약 `role="status"` + `aria-live="polite"`. 입력 중 바뀜은 읽지 않고 들어옴, 나감, 연결만 읽음.

쓰는 곳: 월말 정리 W-04 함께 모드. 제안 카드를 둘이 같이 볼 때(출시 뒤).
