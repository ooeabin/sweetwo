# DayChips

월급날 숫자 판(`hg-daygrid`). O-32, P-05 월급날, 설정 월급날(F-05), 온보딩 결과 기준일.

- 소비자가 주는 것: 이름, 값(1~31 또는 ‘말일’), 말일 글자(기본 “말일”).
- `plate` 판(`radius-xl`, 안쪽 16px) 위에 1~31을 7칸씩. 칸은 44px 원, 테두리 없음, 숫자만(16px 500, 표 숫자).
- 고른 날만 `ink` 원 + `on-ink` 700. 올려 두면 `surface-alt` 원.
- ‘말일’은 판 아래 가운데 한 줄 알약(같은 고름 규칙).
- 묶음 `role="radiogroup"`, 칸 `role="radio"` + `aria-checked`, 이름은 “25일”, “말일”. 고른 칸만 탭 순서(없으면 1일). ←→ 하루, ↑↓ 일주일, Home/End 1일/말일.
