# RankRow

자산 순위 줄(2026-11-04, 23 F-01 0번. 19 H-01 1a 홈 줄은 2026-11-11 없앰). 혜택 줄처럼 한 줄: 제목 + 보조 줄 + 오른쪽 ›(2026-11-24 왼쪽 44px 원 “?%”·“중간”·“38%”는 없앰, 글자만. 예전: 원 + 제목 + 회색 글자 버튼 2026-11-09).

- (없앰 2026-11-24) 원 `hg-rankrow__badge`: 2026-11-16 4차 검토 중립 원(`surface` 바탕 + `hairline` 안쪽 테두리 + `ink` 13px 800, 예전 `invest` 초록 바탕은 파랑·초록이 사용자 앱 포인트가 아니라 없앰). 안 봄·자산 없음 “?%”, 본 뒤 “38%”.
- 제목 `hg-rankrow__title`: 17/700 `ink`(`--text-amount`), keep-all. **보조 줄 없이 제목만인 줄(“또래 가구 중간값 보기”, 빈 상태 “자산 입력하고 순위 보기”)은 이동만 하는 줄**(2026-11-27 강약 기준 2차): `hg-rankrow--link`, 15/400 `ink-2` + ›, 높이 56. 보조 줄이 있는 줄(“상위 38%예요”)은 값이 주인공이라 17/700 그대로. ›가 다음 줄로 떨어지지 않게 글자 칸이 남는 폭을 쓰고 › 는 오른쪽 끝(`hg-chevron`).
- 보조 줄 `hg-rankrow__action`: 13/400 `slate`(예전 14px 600 `ink-2`(글자 버튼 `hg-btn--link`와 같음. 2026-11-09 500 `focus` 파랑 → 오렌지 → 회색)(“확인하기”, “10월 기준, 자세히 보기”, “새로 확인하기”). 자산이 없으면 보조 줄 없음(2026-11-26: 제목 “자산 입력하고 순위 보기” 자체가 행동, 예전 “자산을 입력하면 상위 몇 %인지 알려 드려요” + 홈 “자산 입력하기”).
- 광고 표시 `hg-rankrow__ad`: 광고가 나오는 상태(안 봄, 지난번)에만 글자 버튼 앞 작은 회색 ‘광고’(`surface-alt` 바탕, 11px 600 `slate`). AdMob 보상형 광고 정책상 누르기 전에 광고를 알림(ADR 0006).
- 누를 수 있으면 `button`(포커스 링 2px `focus-ring`), 누를 수 없으면 `div`(2026-11-26부터 자산 관리 빈 상태도 누르면 F-03a).
- React: `RankRow({ title, action, ad, adLabel, onClick })`(누를 수 있으면 오른쪽 ›를 그림, “또래 가구 중간값 보기”는 제목만). 앱은 `RankBanner`(frame)가 상태(7-7)와 광고 흐름을 맡음.
