# QuestionLayout

한 화면 한 질문 틀. 온보딩·배우자 합류·결혼일 전환·월말 정리 단계가 모두 이 틀.

- 소비자가 주는 것: 진행 칸 수와 현재 칸, 질문 제목, 보조 1줄(선택), 입력 영역, 주 버튼 글자.
- 위: 진행 막대(ProgressSteps, 글자 없음)를 열 너비 그대로, 그 아래 뒤로 아이콘(왼쪽 끝을 열 가장자리에 맞춤). 가운데 480px 한 열.
- 제목 `hg-q__title`(28px), 보조 1줄 `hg-q__help`. 제목과 입력 사이 `space-6`.
- 아래 `hg-q__foot`: ‘나중에 할게요’ 링크(허용된 곳만) + 주 버튼 오른쪽. 좁은 창은 주 버튼 꽉 차게 하단 고정(`position: sticky`).
- Enter = 다음, Esc = 뒤로.

## 결과 화면

- 온보딩 결과(O-61\~67)는 같은 틀의 넓은 모양 `hg-q--wide`(960px). 진행 막대 6칸을 모두 채우고 ‘나중에 할게요’ 없음.
- 본문은 `hg-q__cols` 2열: 왼쪽 결론·조정, 오른쪽 근거·목록. 768px 미만은 1열, 주 버튼 하단 고정(위와 같음).
