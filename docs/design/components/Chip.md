# Chip

선택 칩. 여러 개를 고르는 질문(온보딩 목표 고르기)과 필터에 씀.

- 소비자가 주는 것: 글자, 선택 상태(`is-selected`), 순서가 뜻이 있으면 순번.
- 고른 칩은 `ink` 바탕. 고른 순서가 우선순위인 질문(목표 우선순위 정하기)은 `hg-chip__order`에 순번(1, 2, 3)을 작은 원으로 표시(`ink` 원, 고른 칩 안에서는 흰 원).
- 칩 높이 40px, 사이 `space-2`. 줄바꿈 허용. `button` + `aria-pressed`.

## 필터 칩

- 목록·달력 보기를 거르는 한 줄(캘린더 “전체 / 챙길 날 / 돈 날짜” 등). `hg-chip--sm`(32px, 13px), 묶음은 `role="group"` + `aria-label`.
- 첫 칩은 “전체”, 하나만 고름(고른 칩 `ink`). 4개를 넘으면 마지막을 `list-filter` 아이콘 + “더 보기”로 BottomSheet.
- 거른 결과가 없으면 EmptyState 한 줄(“이 날짜엔 없어요”).
- 터치 좁은 창은 누르는 높이 44px(작은 칩 포함).
