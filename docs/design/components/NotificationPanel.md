# NotificationPanel

알림 패널(N-01). 상단 줄 종 아이콘을 누르면 오른쪽에서 열리는 360px 패널, 알림을 ‘오늘, 이번 주, 이전’으로 묶어 보여 줌.

- 소비자가 주는 것: 알림 목록(보낸 사람 또는 종류, 문구, 시각, 읽음 여부, 이동할 화면), 새 알림 수.
- 데스크톱, 넓은 창: 오른쪽 끝에 붙는 패널(`hg-noti`, 너비 360px, 높이 창 전체), 왼쪽 `hairline` 선 + `shadow-3`, 층은 `z-sheet`. 막(`scrim`) 없음, 본문은 그대로 보임. 좁은 창은 전체 화면 페이지.
- 머리: “알림”(`title-3`) → 글자 버튼 “모두 읽음”(`hg-btn--ghost`) → 닫기(IconButton `x`). Esc로 닫고 포커스는 종 아이콘으로 돌아감.
- 묶음 이름(`hg-noti__group`, `stone` 13px 600): “오늘”, “이번 주”, “이전”. 빈 묶음은 숨김. 90일 지난 알림은 지움(기획서 14 보관·읽음).
- 줄(`hg-noti__item`, 줄 전체가 `button`): 왼쪽 32px(사람이 한 일은 Avatar, 앱 안내는 `hg-noti__icon` 회색 원 + 아이콘) → 문구(사람 이름으로, 해요체 1~2줄) → 시각(“2시간 전”, 7일 넘으면 날짜). 누르면 그 화면으로 가고 읽음.
- 새 알림 점(`hg-noti__dot`): 줄 오른쪽 위 8px `brand` 점. 브랜드 색을 쓰는 몇 안 되는 자리(새 알림 점). 읽은 줄은 점 없음 + 문구 `slate`.
- 상단 줄 종 아이콘에도 새 알림이 있으면 같은 점(`hg-iconbtn--dot`). 숫자는 쓰지 않음.
- 빈 상태(`hg-noti__empty`): `bell` 아이콘 → “새 알림이 없어요” → 보조 “배우자 활동과 챙길 날 소식이 여기에 와요” [확인 필요]. 그림 없음.
- 불러오는 동안 줄 모양 Skeleton 3줄.

- 놓이는 곳: 넓은 창 `hg-noti--sheet`(오른쪽 끝 고정, 위아래 끝까지), 좁은 창 `hg-noti--page`(전체 화면, 선·그림자 없음). 좁은 창 페이지는 머리에 뒤로(< 꺾쇠) + “알림” + “모두 읽음”, 맨 아래 줄 “알림 설정”(`hg-noti__foot`).
- 머리 오른쪽: “모두 읽음” → 알림 설정(IconButton `settings`) → 닫기(`x`). 줄 문구가 넘치면 `title`로 전체 문구.
- 키보드: 열리면 첫 줄 포커스, ↑↓로 줄 이동, Enter로 열기.
- React 래퍼: `NotificationPanel`(packages/ui).

쓰는 곳: 앱 상단 줄 알림(N-01), 좁은 창 알림 화면(N-02). 알림 설정은 S-14.
