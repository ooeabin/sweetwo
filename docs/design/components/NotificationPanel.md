# NotificationPanel

알림 패널(N-01). 상단 줄 종 아이콘을 누르면 오른쪽에서 열리는 360px 패널, 알림을 ‘오늘, 이번 주, 이전’으로 묶어 보여 줌.

- 소비자가 주는 것: 알림 목록(보낸 사람 또는 종류, 문구, 시각, 읽음 여부, 이동할 화면), 새 알림 수.
- 넓은 창(태블릿): 오른쪽 끝에 붙는 패널(`hg-noti`, 너비 360px, 높이 창 전체), 왼쪽 `hairline` 선 + `shadow-3`, 층은 `z-sheet`. 막(`scrim`) 없음, 본문은 그대로 보임. 좁은 창은 전체 화면 페이지.
- 머리: “알림”(`title-3`) → 글자 버튼 “모두 읽음”(`hg-btn--ghost`) → 닫기(IconButton `x`). Esc·닫기로 닫으면 포커스는 연 종 아이콘으로 돌아감(앱 N-01 `n-01-panel.tsx`, 2026-11-12 S10-09).
- 묶음 이름(`hg-noti__group`, `stone` 12px 600): “오늘”, “이번 주”, “이전”. 빈 묶음은 숨김. 90일 지난 알림은 지움(기획서 14 보관·읽음).
- 줄(`hg-noti__item`, 줄 전체가 `button`, 높이 64px, 2026-11-12 QA 10구간 S10-12): 왼쪽 32px(사람이 한 일은 Avatar, 앱 안내는 `hg-noti__icon` 회색 빈 원 `hg-lead--slot`, 2026-11-10. 종류는 `data-art`(ListRow ‘Lead 종류 표’ `noti`), 2D 그림이 들어오면 채움. 아이콘이 있는 알림(목표 금액 달성 등)은 사람이 있어도 아이콘 자리, 2026-11-12 S10-05) → 문구(사람 이름으로, 해요체 1줄, 넘치면 말줄임 + 줄 `title` 툴팁으로 전체 문구, 2026-11-12 D4) → 시각(“2시간 전”, 7일 넘으면 날짜). 누르면 그 화면으로 가고 읽음.
- 새 알림(2026-11-09, 당근 알림처럼): 안 읽은 줄은 2026-11-11 사용자 결정(A)으로 판 없이 굵은 글자(600) + 줄 오른쪽 위 8px `brand` 점(옅은 오렌지 판은 없앰, 마우스 올림은 다른 줄처럼 `surface-alt`)(`hg-noti__dot`, 화면 읽기 ‘안 읽음’). 글자는 `ink`. 읽은 줄은 판·점 없음 + 문구 `slate`. 색만으로 말하지 않고 점과 화면 읽기 이름이 함께 있음.
- 상단 줄 종 아이콘에도 새 알림이 있으면 같은 점(`hg-iconbtn--dot`). 숫자는 쓰지 않음.
- 빈 상태(`hg-noti__empty`, N-03): 그림 자리 120px(`hg-empty__art hg-artslot`, 2D 그림이 들어올 때까지 회색 빈 자리, 2026-11-12 QA 10구간 D2, 종 아이콘 대신) → “새 알림이 없어요”(제목 한 줄, 보조 문구 없음).
- 불러오는 동안 줄 모양 Skeleton 3줄.

- 놓이는 곳: 넓은 창 `hg-noti--sheet`(오른쪽 끝 고정, 위아래 끝까지), 좁은 창 `hg-noti--page`(전체 화면, 선·그림자·바탕 없음 = 화면 바탕 그대로, 다크에서 판이 떠 보이지 않게 2026-11-12 S10-12). 좁은 창 페이지는 머리에 뒤로(< 꺾쇠, `hg-back`) + “알림” + “모두 읽음”, 맨 아래 줄 “알림 설정”(`hg-noti__foot`).
- 머리 오른쪽: “모두 읽음” → 알림 설정(IconButton `settings`) → 닫기(`x`). 안 읽은 알림이 없으면 “모두 읽음”은 꺼짐: 회색 판 없이 글자만 `muted`(2026-11-12 S10-12). 줄 문구가 넘치면 `title`로 전체 문구.
- 종 점(`hg-iconbtn--dot`)은 지름 8px(기획 14 알림 버튼 2번, 2026-11-12 S10-12에서 7px → 8px).
- 키보드: 열리면 첫 줄 포커스, ↑↓로 줄 이동, Enter로 열기.
- React 래퍼: `NotificationPanel`(packages/ui).

쓰는 곳: 앱 상단 줄 알림(N-01), 좁은 창 알림 화면(N-02). 알림 설정은 S-14.
