# Breakdown

전체를 나눈 구성(월급 플랜 배분, 자산 구성). 큰 합계 → 알약 막대 → 2열 타일.

- 소비자가 주는 것: 이름, 합계, 항목(영역), 금액.
- 막대 12px, 양 끝만 둥글게, 칸 사이 2px 틈. 원형·도넛 차트 쓰지 않음.
- 색은 영역 차트색 고정 순서: `chart-goal` → `chart-together` → `chart-safety` → `chart-family` → `chart-invest`. 항목이 빠져도 남은 색은 그대로.
- 타일(`surface-alt`): 색 점 + 이름(`slate`) / 금액(굵게), 오른쪽 비율(`stone`). 범례 겸 표.
- 5개를 넘으면 작은 것부터 ‘기타’.
