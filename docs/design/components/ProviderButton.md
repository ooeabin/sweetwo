# ProviderButton

A-02 소셜 로그인 버튼. `Button` + `ProviderMark`를 한 줄로 묶는다(기획서 15장).

- 소비자가 주는 것: `provider`(kakao·google·apple), 글자(children), `recent`·`recentLabel`(‘최근 사용’ 말풍선), `disabled`·`onClick`.
- 변형: 카카오는 공식 노란 브랜드 버튼(`hg-btn--kakao`), 애플은 채움 버튼(`hg-btn--apple`, 2026-11-10: 라이트 `ink` 바탕 + `on-ink` 글자·마크 = 검정 바탕 흰 글자, 다크는 흰 바탕 검정 글자, 애플 로그인 가이드 Black/White 스타일), 구글은 테두리 버튼(`hg-btn--secondary`). 이메일 충돌로 그 제공자를 알려 줄 때는 버튼 색은 그대로 두고 버튼 위 가운데에 흰 말풍선 `hg-auth__bubble`(12px 500, 안쪽 8px 16px, `hairline-soft` 테두리 + `shadow-2`, 꼬리 아래)로 “이미 {카카오}로 가입한 이메일이에요”(`bubble`)를 띄운다(2026-11-02 지그재그 ‘지금 가입하고…’ 말풍선). 이때 ‘최근 사용’은 숨김. 오렌지 주 버튼으로 바꾸지 않음.
- 마크(`ProviderMark`, `hg-btn__mark`)는 글자 앞. `hg-auth--login` 영역에선 버튼 왼쪽 고정·글자 가운데, 카카오 마크는 24px, 구글은 중간 회색 테두리(바탕 투명)로 바뀐다(애플은 채움 그대로)(→ AuthLayout).
- ‘최근 사용’은 버튼 안 배지가 아니라 해당 버튼 위 오른쪽 말풍선 `hg-auth__recent`(꼬리 아래).
- 글자(2026-11-10, 제공자 공식 문구 그대로): “카카오 로그인”(카카오 로그인 디자인 가이드), “Google로 계속하기”, “Apple로 계속하기”. 홍보 문구(‘3초 만에’)는 버튼에 넣지 않음.
- 비활성(오프라인, 다른 버튼 처리 중): 카카오도 회색으로 바꾸지 않고 공식 노랑 그대로 + 흐리게(`opacity: .45`). 애플도 채움 그대로 흐리게. 구글은 공통 비활성.
- 말풍선(‘최근 사용’, 이메일 충돌)은 버튼 이름에 붙지 않게 `aria-hidden` 글자 + 버튼 `aria-describedby`(화면 읽기: “Apple로 계속하기, 버튼, 최근 사용”).
- A-02(`hg-auth--login`)에서는 왼쪽 고정 마크가 큰 글자(130%)에서 글자를 덮지 않게 좌우 안쪽 여백 56px(`hg-btn--provider`).
- 애플 버튼은 다른 버튼과 같은 크기·높이, 스크롤 없이 보이는 자리(애플 로그인 가이드 ‘다른 로그인 방법보다 작지 않게’).
- 쓰는 곳: A-02 로그인.
