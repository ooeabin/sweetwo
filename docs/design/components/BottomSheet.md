# BottomSheet

좁은 창(768px 미만)에서 아래에서 올라오는 시트. 모달과 고르기 메뉴를 대신함.

- 소비자가 주는 것: 제목 1줄, 내용(선택지 목록 또는 짧은 폼), 주 버튼(선택).
- 쓰는 곳: 배우자 초대 시트, 낸 곳 고르기, 확인 대화상자의 좁은 창 판.
- 위 손잡이를 아래로 끌거나 막을 누르면 닫힘. 높이는 내용만큼, 최대 화면 90%.
- 주 버튼은 꽉 차게(`hg-btn--block`) 맨 아래.
- 다크에서 보이도록 위·옆 `hairline` 테두리.

React 컴포넌트 `BottomSheet`(2026-11-02):

- 받는 것: 제목, 닫기(`onClose`), 내용, 맨 아래 버튼(`actions`, 꽉 차게).
- 막(`hg-scrim--sheet`) 위 화면 아래에 붙음. 위 손잡이 + 제목 줄 오른쪽 닫기(×). 막 누르기, Esc, ×로 닫힘. 포커스는 시트 안에서 돎, 닫으면 원래 자리로.
- 넓은 창(768px 이상)은 손잡이 없이 가운데 카드(최대 440px).
- 올라올 때 24px 올라오는 움직임(‘동작 줄이기’면 없음).
- 쓰는 곳: O-07 초대 코드(뒤에 O-06 화면이 그대로 보임, 누를 수 없음).
- 닫기(2026-11-02): 제목 줄 오른쪽 28px 회색 원(`surface-alt`) 안 16px ×(`hg-sheet__close`, 카카오페이·현대카드처럼). 제목 20px 700.
