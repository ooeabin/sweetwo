# EmptyState

내용이 없을 때의 화면. 무엇이 생길지와 첫 행동 1개만.

- 소비자가 주는 것: 제목 1줄, 보조 1줄, 주 버튼(선택). 2026-11-11 제목도 선택: 행동 버튼 이름만으로 뜻이 충분한 자리(예전 Y-01 경조사 빈 상태 그림 자리 + ‘경조사 추가’)는 제목 없이.
- 위에 빈 상태 그림(`hg-empty__art`, 120px, 부스러기만 남은 빈 디저트 접시) → 글자 2줄 → 버튼. 그림은 모든 빈 상태에 같은 한 장.
- 가운데 정렬이 허용되는 몇 안 되는 자리. 간격은 `gap`(`space-3`)만.

- 2026-11-05 그림 `empty-plate`(빈 디저트 접시) 들어옴(120px `hg-empty__art`).

- 2026-11-08: 그림·아이콘 자리는 2D 플랫으로 다시 만들 때까지 빈 자리(회색 판 `hg-artslot`이나 빈 원·빈 칸). 이 문서의 3D·사진·Phosphor 그림 설명은 다시 만들 때의 주제(→ Illustrations ‘나중 과제’). (2026-11-15 3차 검토 사용자 결정: 그림이 들어올 때까지 숨김, 자리도 비우지 않음)
- 목록 자리의 빈 안내(2026-11-20 사용자 결정): 목록이 비었을 때 한 줄 글자(“지금은 공지가 없어요”, “새 알림이 없어요”, “아직 …이 없어요”)는 진한 `ink`가 아니라 `slate`. `EmptyState`에 `list`를 주면 `hg-empty--list`(제목 글자 slate), 한 줄 `<p>`는 `hg-help hg-empty__line`, 알림 패널은 `hg-noti__empty b`, 명령 팔레트는 `hg-cmd__empty`. 쓰는 곳: N-04 공지, N-02 알림, S-21 휴지통, S-19a 내 문의, Y-09 선물 기록, F-02 자산·부채 목록, F-04 수정 내역, W-10 모은 내역, W-14 쓸 곳 메모, W-20b 수입 목록, W-21 지난 달, W-01d 자동 고르기, Y-04 일정, 다가오는 일정 목록, S-13p 미리 보기, S-20 검색 결과 없음. 큰 그림이 있는 빈 상태 제목(W-02 0b 주인공 문구, 상태 화면 A-xx)은 그대로 `ink`. slate는 흰 바탕 6.8:1.
- W-02 템플릿 줄 0개 안내(2026-11-20, `hg-empty--plan`): 같은 `hg-empty`에 그림 자리(`w02-empty`, 파일이 올 때까지 숨김) + 제목 두 줄(`hg-empty__title`을 `text-title-2`로, 문장 자리가 앱 틀 남는 높이를 채워 주 버튼이 화면 아래에 오게(본문 `hg-body`는 `align-items: stretch`로 주 버튼이 본문 폭을 꽉 채움, 2026-11-20), 줄마다 `span` 블록 “350만 원을 나눠서” / “월급 계획 템플릿을 완성해 주세요”) + 화면 아래 고정 주 버튼(`hg-stickybar`) “월급 계획 템플릿 채우기”. 오렌지 강조 없음. 기획 → 20 W-02 0b
