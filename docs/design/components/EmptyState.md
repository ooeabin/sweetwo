# EmptyState

내용이 없을 때의 화면. 무엇이 생길지와 첫 행동 1개만.

- 소비자가 주는 것: 제목 1줄, 보조 1줄, 주 버튼(선택). 2026-11-11 제목도 선택: 행동 버튼 이름만으로 뜻이 충분한 자리(Y-01 경조사 빈 상태 그림 자리 + ‘경조사 추가’)는 제목 없이.
- 위에 빈 상태 그림(`hg-empty__art`, 120px, 부스러기만 남은 빈 디저트 접시) → 글자 2줄 → 버튼. 그림은 모든 빈 상태에 같은 한 장.
- 가운데 정렬이 허용되는 몇 안 되는 자리. 간격은 `gap`(`space-3`)만.

- 2026-11-05 그림 `empty-plate`(빈 디저트 접시) 들어옴(120px `hg-empty__art`).

- 2026-11-08: 그림·아이콘 자리는 2D 플랫으로 다시 만들 때까지 빈 자리(회색 판 `hg-artslot`이나 빈 원·빈 칸). 이 문서의 3D·사진·Phosphor 그림 설명은 다시 만들 때의 주제(→ Illustrations ‘나중 과제’).
