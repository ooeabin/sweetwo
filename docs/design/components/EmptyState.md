# EmptyState

내용이 없을 때의 화면. 무엇이 생길지와 첫 행동 1개만.

- 소비자가 주는 것: 제목 1줄, 보조 1줄, 주 버튼(선택). 2026-11-11 제목도 선택: 행동 버튼 이름만으로 뜻이 충분한 자리(예전 Y-01 경조사 빈 상태 그림 자리 + ‘경조사 추가’)는 제목 없이.
- 위에 빈 상태 그림(`hg-empty__art`, 120px, 부스러기만 남은 빈 디저트 접시) → 글자 2줄 → 버튼. 그림은 모든 빈 상태에 같은 한 장.
- 가운데 정렬이 허용되는 몇 안 되는 자리. 간격은 `gap`(`space-3`)만.

- 2026-11-05 그림 `empty-plate`(빈 디저트 접시) 들어옴(120px `hg-empty__art`).

- 2026-11-08: 그림·아이콘 자리는 2D 플랫으로 다시 만들 때까지 빈 자리(회색 판 `hg-artslot`이나 빈 원·빈 칸). 이 문서의 3D·사진·Phosphor 그림 설명은 다시 만들 때의 주제(→ Illustrations ‘나중 과제’). (2026-11-15 3차 검토 사용자 결정: 그림이 들어올 때까지 숨김, 자리도 비우지 않음)
- 목록 자리의 빈 안내(2026-11-20 사용자 결정): 목록이 비었을 때 한 줄 글자(“지금은 공지가 없어요”, “새 알림이 없어요”, “아직 …이 없어요”)는 진한 `ink`가 아니라 `slate`. `EmptyState`에 `list`를 주면 `hg-empty--list`(제목 글자 slate), 한 줄 `<p>`는 `hg-help hg-empty__line`, 알림 패널은 `hg-noti__empty b`, 명령 팔레트는 `hg-cmd__empty`. 쓰는 곳: N-04 공지, N-02 알림, S-21 휴지통, S-19a 내 문의, Y-09 선물 기록, F-02 자산·부채 목록, F-04 수정 내역, W-10 모은 내역, W-14 쓸 곳 메모, W-20b 수입 목록, W-21 지난 달, W-01d 자동 고르기, Y-04 일정, 다가오는 일정 목록, S-13p 미리 보기, S-20 검색 결과 없음. 큰 그림이 있는 빈 상태 제목(W-02 0b 주인공 문구, 상태 화면 A-xx)은 그대로 `ink`. slate는 흰 바탕 6.8:1.
- 화면 전체가 빈 목록(2026-11-23 사용자 결정, W-21 지난 달 모아보기, W-14 쓸 곳 메모, W-20b 수입 목록): `EmptyState list page`(`hg-empty--page`, 높이 45dvh 이상 + 세로 가운데)로 화면 가운데쯤에 둠. 왼쪽 위에 작은 글자 한 줄로만 두지 않는다. W-20b는 ‘수입 적기’ 버튼을 `action`으로. 카드·묶음 안의 빈 한 줄(W-10 모은 내역, W-01d 자동 고르기)은 `hg-empty__line` 그대로.
- **빈 상태 = 제목 한 줄 + 다음 행동 하나, 설명은 기본으로 쓰지 않음**(2026-11-25 사용자 결정, 첫 사용 화면 공통): 설명 문장은 정말 필요할 때만 13px 한 줄. 새 빈 상태는 `body` 없이 `title` + `action`(회색 보조 버튼)만 만든다. 이미 이렇게 정리한 곳: Y-09 선물 기록, W-21 지난 달 모아보기, N-01 알림 목록 아래, 홈 캘린더 타일.
- W-02 월급 계획이 없을 때 안내(2026-11-25 사용자 확정 ‘첫 사용 화면’ B안 최종, 예전 2026-11-20 한 문장 `hg-empty--plan` + 그림 자리 `w02-empty`는 없앰): `EmptyState`가 아니라 W-02 전용 구역 `hg-w02guide`(왼쪽 정렬). 날짜 태그(`hg-w02guide__tag` 13/400 `slate`) → 큰 제목(`__title`, `text-amount-lg` 22/700, 한 줄에 안 들어가면 `text-wrap: balance`로 쉼표 뒤에서 끊김) → 번호 3줄(`ol.hg-w02guide__steps` > `li.__step`: 번호 `__num` 13/700 `slate`(원 없음), 문구 `__step-title` 15/400 `ink-2`, 보조 줄 없음, 줄 사이 24) → 예시 판(`__sample`, 2026-11-25 사용자 결정 A ‘실제 화면 조각’: 흰 카드 `surface` radius 20 + `shadow-2` + `hairline-soft` 1px 고리, 바탕 기준 ‘카드 테두리 없음’의 예외로 이 판 한 곳만, `aria-hidden`, 오른쪽 위에 걸친 배지 `__sample-badge` “예시” 13/700 `ink-2` 바탕 `surface` 글자, 머리 `__sample-head` 13 `slate` “확인할 것 2개”, 줄 `__sample-row` 높이 48 + 위 구분선: 확인할 줄은 6px `brand` 점 + 이름 17/400 + 금액 17/700 + `slate` ›, 자동 줄 `.is-auto`는 점 없이 `slate` “자동으로 나가요”) + 화면 읽기 전용 `hg-sr` 한 줄 → 아래 고정 주 버튼(`hg-stickybar`) “월급 계획 세우기”. 영역 간격 `--gap-area`. 오렌지는 주 버튼뿐, 그림 자리 없음. 문장 자리(`hg-w02guide`)가 앱 틀 남는 높이를 채워 주 버튼이 화면 아래에 오고, 내용이 더 길면 본문만 스크롤. 기획 → 20 W-02 0b
- 빈 상태의 다음 행동 하나(2026-11-25 사용자 확정): 버튼이 없던 빈 화면에 `EmptyState`의 `action`으로 회색 보조 버튼(`hg-btn--secondary hg-btn--sm`, 글자 700, 누르는 칸 44px: `.hg-empty .hg-btn--sm { min-height: 44px }`)을 보조 문구 아래에 둔다. 쓰는 곳: Y-09 선물 기록 “+ 기념일 적기”(→ Y-07), W-21 지난 달 모아보기(월급 계획 없으면 “+ 월급 계획 세우기” → W-01, 있으면 문구 “첫 월급날이 지나면 여기에 모여요”만). N-01 알림은 빈 상태가 아니라 목록 아래(NotificationPanel ‘알림이 거의 없을 때’). 공지(N-04)는 운영 내용이라 버튼 없음. 오렌지 채움 금지(주 버튼만)
