# EmptyState

내용이 없을 때의 화면. 무엇이 생길지와 첫 행동 1개만.

- 소비자가 주는 것: 제목 1줄, 보조 1줄, 주 버튼(선택). 2026-11-11 제목도 선택: 행동 버튼 이름만으로 뜻이 충분한 자리(예전 Y-01 경조사 빈 상태 그림 자리 + ‘경조사 추가’)는 제목 없이.
- 위에 빈 상태 그림(`hg-empty__art`, 120px, 부스러기만 남은 빈 디저트 접시) → 글자 2줄 → 버튼. 그림은 모든 빈 상태에 같은 한 장.
- 가운데 정렬이 허용되는 몇 안 되는 자리. 간격은 `gap`(`space-3`)만.

- 2026-11-05 그림 `empty-plate`(빈 디저트 접시) 들어옴(120px `hg-empty__art`).

- 2026-11-08: 그림·아이콘 자리는 2D 플랫으로 다시 만들 때까지 빈 자리(회색 판 `hg-artslot`이나 빈 원·빈 칸). 이 문서의 3D·사진·Phosphor 그림 설명은 다시 만들 때의 주제(→ Illustrations ‘나중 과제’). (2026-11-15 3차 검토 사용자 결정: 그림이 들어올 때까지 숨김, 자리도 비우지 않음)
- 목록 자리의 빈 안내(2026-11-20 사용자 결정): 목록이 비었을 때 한 줄 글자(“지금은 공지가 없어요”, “새 알림이 없어요”, “아직 …이 없어요”)는 진한 `ink`가 아니라 `slate`. `EmptyState`에 `list`를 주면 `hg-empty--list`(제목 글자 slate), 한 줄 `<p>`는 `hg-help hg-empty__line`, 알림 패널은 `hg-noti__empty b`, 명령 팔레트는 `hg-cmd__empty`. 쓰는 곳: N-04 공지, N-02 알림, S-21 휴지통, S-19a 내 문의, Y-09 선물 기록, F-02 자산·부채 목록, F-04 수정 내역, W-10 모은 내역, W-14 쓸 곳 메모, W-20b 수입 목록, W-21 지난 달, W-01d 자동 고르기, Y-04 일정, 다가오는 일정 목록, S-13p 미리 보기, S-20 검색 결과 없음. 큰 그림이 있는 빈 상태 제목(W-02 0b 주인공 문구, 상태 화면 A-xx)은 그대로 `ink`. slate는 흰 바탕 6.8:1.
- 화면 전체가 빈 목록(2026-11-23 사용자 결정, W-21 지난 달 모아보기, W-14 쓸 곳 메모, W-20b 수입 목록): `EmptyState list page`(`hg-empty--page`, 높이 45dvh 이상 + 세로 가운데)로 화면 가운데쯤에 둠. 왼쪽 위에 작은 글자 한 줄로만 두지 않는다. W-20b는 ‘수입 입력하기’ 버튼을 `action`으로(2026-11-26부터 아래 고정 주 버튼, 위 ‘다음 행동 자리’). 카드·묶음 안의 빈 한 줄(W-10 모은 내역, W-01d 자동 고르기)은 `hg-empty__line` 그대로.
- **빈 상태 = 제목 한 줄 + 다음 행동 하나, 설명은 기본으로 쓰지 않음**(2026-11-25 사용자 결정, 첫 사용 화면 공통): 설명 문장은 정말 필요할 때만 13px 한 줄. 새 빈 상태는 `body` 없이 `title` + `action`(회색 보조 버튼)만 만든다. 이미 이렇게 정리한 곳: Y-09 선물 기록, W-21 지난 달 모아보기, N-01 알림 목록 아래, 홈 캘린더 타일(2026-11-25), 2026-11-26 남은 긴 문구도 정리: F-02 자산·부채 빈 상태와 첫 입력 칩 안내 “아직 입력한 자산이 없어요”·“아직 입력한 부채가 없어요”, 홈 H-04 타일 “아직 입력한 자산이 없어요”, F-08·F-01 순위 줄(제목 “아직 입력한 자산이 없어요” + 버튼 글자 “자산 입력하고 순위 보기”: 결과를 약속하는 ‘왜’는 버튼 글자에), 기간 줄 “아직 입력한 수입이 없어요”(+ “수입 입력하기”, 2026-11-26부터 보조 버튼, 아래 ‘화면 일부만 빈 상태’ 표), W-10 “아직 목표 금액이 없어요”, W-02 줄 없는 달 “확인할 항목이 없어요”, F-04a “옮길 통장이 없어요”(+ “통장 추가하기”, 2026-11-26부터 글자 버튼에서 보조 버튼), W-20a “넣을 저축·투자가 없어요”, O-60 날짜 없음 “수입은 월급 ‘이번 달’에서 입력해요”. H-10 칩 질문(`emptyAsk`)은 질문이라 그대로.
- **다음 행동 자리 = 둘 중 하나(2026-11-26 사용자 결정 ‘빈 상태 A안’)**: 빈 상태 버튼 위치가 화면마다 달라 보여서(W-02는 아래 고정, 다른 곳은 문구 아래) 기준을 하나로 정함. `EmptyState`의 `actionPlacement`로 고른다.
  - `bottom` = **화면 전체가 빈 상태**(그 화면에 보여 줄 게 아무것도 없음): 다음 행동은 아래 고정 주 버튼(`StickyBar` 안 `Button variant="primary" block`, 오렌지 채움 + `on-accent-app-text`). 제목은 `list page`로 화면 가운데쯤, 빈 상태(`hg-empty--fill`)가 앱 틀 남는 높이를 채워 주 버튼이 화면 아래에 옴(`bundle.css` ‘빈 상태 A안’ 묶음, `hg-w02guide`와 같은 방식). W-02(전용 구역 `hg-w02guide`, 아래 그대로)와 같은 자리. 쓰는 곳: W-21 지난 달 모아보기(월급 계획이 없을 때만 “월급 계획 세우기”, 예전 회색 “+ 월급 계획 세우기”), W-14 쓸 곳 메모(“메모 추가”, 예전 문구 바로 아래 AddRow, 목록 아래 AddRow는 빈 상태에서 안 그림), W-20b 수입 기록(“수입 입력하기”, 예전 회색 보조 버튼. 이때 맨 위 요약의 “+ 수입 입력하기”는 숨겨 다음 행동 하나), F-08 자산 순위 자산 없음(“자산 입력하고 순위 보기”, 예전에도 아래 고정이었고 제목만 왼쪽 `hg-help` 글자에서 공통 빈 상태로).
  - `inline`(기본) = **화면 일부(묶음·구역)만 빈 상태**(위에 탭·요약·칩 같은 다른 내용이 있음): 제목 바로 아래 그 자리 회색 보조 버튼(`hg-btn--secondary`, 보통 크기, 글자 700, sm 쓰지 않음). 쓰는 곳: F-02 자산·부채 목록(자산/부채 탭 아래), Y-09 선물 기록(밑줄 탭 아래, 예전 sm에서 보통 크기로).
  - 버튼 없는 빈 상태(N-04 공지, S-19a 내 문의, S-21 휴지통, 묶음 안 빈 한 줄 `hg-empty__line`)는 그대로.
- **화면 일부만 빈 상태의 다음 행동은 모두 보조 버튼(2026-11-26 사용자 결정, ‘빈 상태 A안’ 보충)**: 위 `inline`과 같은 모양(회색 `hg-btn--secondary`, 보통 크기, 글자 700, 글자 길이만큼 왼쪽 맞춤, 제목 아래 12). 글자 버튼(`hg-btn--link`)·안내 글자 + ›·상자 전체 버튼으로 두지 않는다. 문구는 그대로(생김새만). `EmptyState`를 쓰지 않는 자리도 같은 규칙:
