# AmountInput

금액 넣기. 큰 숫자 칸 + 빠른 추가 칩 + (좁은 창) 숫자 키패드.

- 소비자가 주는 것: 질문 라벨, 현재 값, 빠른 추가 단위(기본 1만·10만·50만·100만).
- 숫자 칸은 Input의 금액형(`hg-amount`): 원 단위 + 아래 만 원 읽기.
- 빠른 추가 칩은 누를 때마다 더함. 처음 값을 0으로 되돌리려면 지우기 길게 누르기.
- 바꾸기 칩(`quickSet`, 2026-11-09 W-11b 매달 금액 “10만 원 / 30만 원 / 50만 원”): 누르면 더하지 않고 그 금액으로 바꿈. 지금 값과 같은 칩은 고른 표시(`is-selected`, `aria-pressed`). 모양은 빠른 추가 칩과 같고, 고른 칩은 흰 바탕 + 오렌지 테두리(`accent-app` 1px 테두리 + 안쪽 1px) + 오렌지 글자 600(`accent-app-text`, 2026-11-09 브랜드 색 규칙, round 3의 잉크 테두리에서 바꿈).
- 키패드는 좁은 창에서만, 시스템 키보드 대신 화면 아래에 둠. 3열 × 4줄, 마지막 줄은 00, 0, 지우기. 키 56px.
- 키보드가 있으면(키보드를 붙인 태블릿, 개발 브라우저) 키보드 입력도 받음. 숫자 외 글자는 무시.
- 한 화면에 입력이 여럿이면(O-31 금액 + ‘매달 금액이 달라요’, F-04 금액 고치기 등) 앱 키패드와 처음 포커스 없이 기기 숫자 자판(`embedded`).
- 두 번째 금액 칸(`second`, 2026-11-09 round 3, W-11c ‘이미 모은 금액’): `extra` 바로 아래에 칸 이름(`hg-field__label`)과 함께 둠. 좁은 창 키패드는 하나만 화면 아래(두 칸 사이에 끼지 않음)에 두고 마지막으로 누른 칸에 씀. 칸이 새로 생기면 그 칸이 활성. 쓰지 않는 칸은 밑줄을 옅게(`is-idle`, `border-control`). 칸 아래 오류(`error`)는 만 원 읽기 자리에.
- 최대 999억 원. 넘으면 칸 아래 `danger` 도움말.
- `extra`: 빠른 금액 칩과 링크 바로 아래, 키패드 위에 둘 것(O-31 ‘매달 금액이 달라요’ 체크, 2026-11-02)
- 2026-11-02 레퍼런스(당근, 카카오페이, 카카오뱅크): 금액 32px 700 표 숫자(2026-11-09 글자 단계를 줄일 때 숫자 입력이라 예외로 그대로, 단위 18px도 그대로). 빠른 금액 칩은 한 줄 같은 폭 회색 버튼(`surface-alt`, 높이 40px, `radius-md`, 14px 600).
