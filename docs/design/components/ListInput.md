# ListInput

Q6 목록 입력(`hg-listin`). O-23 연간 고정 지출처럼 한 화면에 여러 항목(이름 + 월 + 금액). 문구와 규칙은 기획서 Q6.

- 소비자가 주는 것: 묶음 이름, 행 목록, 합계 문구, 이름 자리표시, 한도(기본 10).
- 행마다 둥근 회색 판(`plate`, `radius-xl`, 안쪽 12px). 좁은 창은 두 줄: 위 이름(꽉 차게) + 지우기(×), 아래 월 고르기(7.5em) + 금액(오른쪽 정렬, 표 숫자). 넓은 창은 한 줄: 월, 이름, 금액(10em), ×. 2026-11-02, 한 줄에 다 넣으면 좁은 창에서 이름이 잘려서 바꿈.
- 일부만 채운 행은 빈 칸만 빨강. 금액이 빠졌을 때만 아래에 “금액을 넣어 주세요”.
- ‘+ 항목 추가’는 판 아래 왼쪽 작은 글자 버튼. 합계는 그 아래 15px 600 `ink`(없으면 “—”).
