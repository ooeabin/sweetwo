# Widget

앱 밖에서 보는 요약. 위젯 하나 = 큰 숫자 하나 + 보조 1줄. 진행 막대는 쓰지 않음(여러 개면 어지럽고 숫자가 묻힘). 홈 화면 위젯 4종(WG-01~04), 잠금 화면 위젯(WG-05), 데스크톱 트레이. 보기만 하고 고치지 않음.

- 소비자가 주는 것: 위젯 종류, 크기, 값, 다음 월급날, 목표(이름, %, 남은 금액, 그림), 다가오는 날(D-n, 이름, 날짜, 종류), 금액 보이기 설정, 앱의 금액 가리기 상태, 앱 잠금 상태, 부부 상태(연결, 예비부부, 혼자 쓰기, 해제 대기).
- 기준은 기획서 ‘위젯’ 탭. 이 문서와 다르면 위젯 탭을 따름.

## 크기

- Small 158×158(`hg-wg--s`), Medium 338×158(`hg-wg--m`), Large 338×354(`hg-wg--l`). 기기 크기에 맞춰 비율 유지.
- 모서리 `radius-2xl`, 안쪽 16px(Large 20px). 흰 위젯은 `hairline-soft` 테두리 + `shadow-1`.
- 위 → 아래 순서 고정: 라벨(`hg-wg__label`) → 값(`hg-wg__value`, 28px) → 보조 1줄(`hg-wg__meta`, `hg-wg__note`).

## 내용

- WG-01 이번 달(Small): “이번 달 안 나눈 돈” + 남은 금액 + 보조 줄 “다음 월급날 25일”(`hg-pair`). 다 하면 “월급을 다 나눴어요”. 월말 정리 기간에는 보조 줄 대신 “월말 정리 D-2”.
- WG-01, 월급 나누기가 없는 사람(혼자 쓰기, 배우자 합류 전, ‘통장 하나로 써요’): “이번 달 남은 생활비” + 남은 금액 + 보조 줄 “다음 월급날 25일”(월말 정리 기간에는 “월말 정리 D-2”). 가림이면 “생활비 n% 남았어요”. 누르면 W-04j(월말 정리 기간에는 W-04). 트레이도 같음.
- WG-02 목표(Small, Medium): `hg-wg--goal`(goal 틴트, 라벨과 그림 `goal-ink`). 큰 %, “6,880만 원 남았어요”. 막대 없음.
  - Small: 오른쪽 위 목표 그림 40px(`hg-wg__art`).
  - Medium: 왼쪽에 라벨, 큰 %, 남은 금액, 오른쪽에 목표 그림 96px(`hg-wg__art--lg`).
- WG-03 다가오는 날(Medium): 3줄 고정. 줄마다 D-n 검정 알약 → 표시 → 이름 → 오른쪽 날짜(`hg-wg-day`). 챙길 날은 Calendar 막대색, 돈 날짜는 `ink` 점 + 흐린 이름. 같은 날이면 챙길 날 먼저.
- WG-04 우리 한눈에(Large): 순자산(큰 숫자) + 예상, 안 판 수익 1줄 → 아래 이름과 값 4줄(`hg-wg__row`): 이번 달 단계, 다음 월급날, 목표 2개 %. 막대 없음, 값은 오른쪽 굵게.
- WG-05 잠금 화면: 아래 ‘잠금 화면’ 참고.
- 트레이(`hg-wg-tray`, 340px): 머리(워드마크 + 저장 상태 점) → WG-01 내용 → 다음 할 일 줄(`hg-wg-tray__task` + chevron) → 다가오는 날 2줄 → 아래 “n분 전 업데이트” + “앱 열기”. `shadow-3` + `hairline` 테두리, 위 꼭지(`--notch`로 위치).

## 금액 표시

- 기본은 가림. 가릴 때는 “•••” 대신 같은 자리에 비율, 건수로 바꿔 보여 줌(빈 칸처럼 보이지 않게). 라벨 오른쪽에 작은 `eye-off` 아이콘.
  - WG-01: “월급 나누기” + 큰 “67%” + “3곳 중 2곳 나눴어요”.
  - WG-02: 큰 % 그대로, 남은 금액 대신 목표 날짜(“2030년 3월까지”).
  - WG-03: 원래 금액 없음, 그대로.
  - WG-04: 순자산 대신 변화율(“지난달보다 +2%”), 아래 줄은 그대로(금액 줄은 비율로).
  - 트레이: WG-01과 같은 방식.
- 설정 S-22 ‘위젯에 금액 보이기’를 켜면 금액. 기기마다 따로 기억.
- 금액 가리기는 앱 설정을 따름: 앱에서 금액 가리기를 켜면 S-22 설정과 상관없이 위젯도 가림.
- 잠금 화면 위젯(WG-05)은 설정과 상관없이 금액 없음.
- 위젯에는 보는 사람이 앱에서 볼 수 있는 값만(공개 범위, 서프라이즈 일정 그대로).

## 상태

- 앱 잠김(트레이): 내용 없이 가운데 “잠겨 있어요” + 주 버튼 “앱 열기”만(`hg-wg-tray--locked`). 금액, 이름, 할 일, 날짜 모두 숨김. 홈 화면 위젯은 금액 가림 상태로 보여 줌.
- 예비부부(결혼 전): WG-01 라벨이 “결혼 준비 통장”, 값은 지금 모인 금액, 보조 줄 “다음 월급날 25일”. WG-04 순자산 자리는 결혼 준비 통장, 아래 줄에 결혼 비용 목표 %. WG-03에 결혼식 날이 함께 나옴.
- 혼자 쓰기: 상대 이름과 상대 나누기 줄이 빠지고 내 나누기만 셈. WG-04 라벨 “한눈에”. 초대 안내는 위젯에 넣지 않음.
- 해제 대기: 값은 그대로, 라벨 오른쪽에 작은 태그 “해제 대기”(`hg-tag`). 제안 관련 줄은 숨김. 누르면 앱의 연결 해제 화면(S-12).
- 로그인 전, 로그아웃 뒤: 모든 위젯이 같은 카드 “sweeTwo를 열어 로그인해 주세요”, 누르면 A-01.
- 오프라인: 마지막 값 + 오른쪽 아래 작은 시각 “오전 10:30 기준”.
- 목표 없음(WG-02, WG-04): “목표를 하나 정해 보세요” → G-03. 다가오는 날 없음(WG-03): “다가오는 날이 없어요” → Y-01. 온보딩 전(WG-01): “온보딩을 마치면 보여요”.

## 잠금 화면(WG-05)

- 기기가 단색으로 그림(배경화면 위 반투명). 우리는 모양과 글자만 정함, 색 토큰을 쓰지 않음.
- 한 줄형: 날짜 옆 “어머니 생신 D-4”(가장 가까운 챙길 날).
- 원형: 고른 목표 1개 %(게이지 + 아이콘 + 숫자).
- 사각형: “월급 나누기” + “2곳 남았어요” + “다음 월급날 25일”.
- 금액 없음. 미리보기는 밝은 바탕에 `ink` 한 색으로 모양만 보여 줌.

## 동작

- 누르면 그 화면으로 바로(딥 링크). Small, Medium은 위젯 전체가 하나의 탭 영역(`a`), WG-03과 WG-04는 줄마다 따로.
  - WG-01: 이번 달 월급 나누기(W-02). 월말 정리 기간에는 W-04.
  - WG-02: 그 목표(G-02).
  - WG-03: 챙길 날 줄은 캘린더 그 날짜(Y-05), 돈 날짜 줄은 캘린더(Y-01).
  - WG-04: 내용에 따라 순자산 F-01, 이번 달과 다음 월급날 W-02, 목표 줄 G-02.
  - 트레이: 이번 달 W-02, 다가오는 날 Y-05 또는 Y-01, 할 일 줄은 그 할 일 화면, “앱 열기”는 앱 창을 앞으로.
- 앱이 꺼져 있으면 앱 실행 → 앱 잠금 해제 → 그 화면. 대상이 지워졌으면 그 목록(G-01, Y-01).
- 새로 고침: 앱에서 값이 바뀔 때 + 30분마다 + 자정(D-n). 실패하면 이전 값 그대로, 트레이 아래 줄에 마지막 업데이트 시각.
- 숫자는 굴리지 않음. 위젯 안 입력 없음(트레이의 “앱 열기”만 버튼).

## 색

- `brand`는 달성 순간에만(목표 100% → 배지 “달성”). 잠금 화면 게이지 채움은 `ink`, 진행 중 목표는 goal 틴트까지.
- 틴트는 뜻대로, 위젯 하나에 1가지. D-n 알약은 모두 `ink`.
- 다크 모드: 토큰 `dark` 값 그대로. 트레이는 `hairline` 테두리 필수. 잠금 화면은 기기 단색 처리에 맡기고 `ink` 한 색으로 그림.

## 접근성

- VoiceOver 라벨 = 위젯 이름 + 핵심 값: “이번 달 안 나눈 돈, 240만 원, 다음 월급날 25일”. 가림이면 “금액 가림”.
- 게이지는 `role="img"` + “내 집 마련 31%”. 아이콘, 색 막대는 장식(`aria-hidden`), 뜻은 글자가 전함.
- 글자 12px 이상. 큰 글씨 설정에서도 WG-03은 3줄, 긴 이름은 말줄임.

쓰는 곳: iOS, Android 홈 화면(WG-01~04), iOS 잠금 화면(WG-05), 데스크톱 트레이 창. 설정은 S-22.
