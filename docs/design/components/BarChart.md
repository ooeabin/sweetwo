# BarChart

월별 저축이 계획보다 얼마나 많거나 적었는지. 가운데 계획선을 기준으로 위(더 모음), 아래(덜 모음)로 뻗는 막대.

- 소비자가 주는 것: 이름, 요약 값(평균), 계획 대비 알약, 월 목록, 값, 계획 값.
- 계획 대비 알약: 100% 이상이면 `invest` 바탕 `invest-ink` 글자(`is-up`), 미만이면 `goal` 바탕 `goal-ink`(`is-down`). 그래프 자체 색은 바꾸지 않음.
- 머리 아래 한 줄 설명(`hg-chart__note`, `stone`): “가운데 선이 계획 {계획}만 원. 더 모은 만큼 위, 덜 모은 만큼 아래(만 원)”.
- 가운데 계획선 `slate` 1.5px 실선. 막대는 선에서 시작, 끝 모서리만 6px 둥글게. 막대 폭 44px(좁은 창 32px), 칸 가운데.
- 색: 더 모은 달 `invest-ink` 30%(`dev-up`), 덜 모은 달 `ink` 14%(`dev-dn`), 계획과 같은 달은 4px 가로 막대(`dev-eq`). 이번 달은 방향과 상관없이 `ink`(`is-now`).
- 막대 끝에 차이 숫자(+30, −30, 0), 이번 달 숫자와 월 글자만 굵게. 총액은 툴팁과 목록 화면에서.
- 덜 모은 달에 `danger`, 경고 아이콘을 쓰지 않음. 숫자로만.
- 막대마다 툴팁: “7월 190만 원, 계획보다 30만 원 덜”.
- 차이 크기 기준은 화면에서 가장 큰 차이가 위아래 80px 안에 들어가게 맞춤.
