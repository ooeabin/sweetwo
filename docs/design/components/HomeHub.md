# HomeHub

홈 허브(2026-11-09, GCOO 앱 홈처럼, 사용자 승인한 그림 기준). 회색 바탕(`surface-alt`, AppFrame `tone="alt"`) 위에 크기가 다른 흰 상자를 쌓아 각 화면으로 잇는 홈(19 H-02~H-09).

- 격자(`hg-hub`): 상자 사이 12px(`space-3`). 좁은 창·중간 창은 2열(`hg-hub__wide`·`hg-hub__full`은 두 칸), 넓은 창(1100px 이상)은 4열(`hg-hub__wide` = 두 칸, `hg-hub__full` = 한 줄, 할 일 띠는 맨 위로 `order`). 상자는 모두 흰색 `radius-xl`, 테두리·그림자 없음(마우스 올림만 `shadow-2`), 누름 98%, 키보드 포커스 ink 링 2px.
- 큰 상자(`hg-hubhero`, HubHero, 두 칸): 안쪽 20px. 위 줄 작은 캡션(13px 500 `slate`, “10월 25일 월급날까지”) + 제목(`title-2` 20px 700) + 오른쪽 겹친 Avatar(`hg-avatars`, 36px). 진행 줄: 굵은 둥근 막대(`hg-hubhero__track`, 10px, 바탕 `surface-alt`, 채움 `accent-app`) + 막대 아래 13px `slate` 이름 + 오른쪽 큰 숫자(`hg-hubhero__count`, `number-lg` 24px 700, “/ 5”는 15px 500 `slate`). 맨 아래 상자 끝까지 닿는 두 칸(`hg-hubhero__split`, 위·사이 `hairline-soft` 선, 14px 500 `slate` 이름 + 700 `ink` 값). 상자 전체가 버튼, 화면 읽기는 문장 하나(`label`).
- 할 일·초대 띠(`hg-hubband`, HubBand, 한 줄, 큰 상자 바로 아래): `radius-lg`, 높이 52px 이상, 코코아 채움(`band-cocoa`, 라이트 #3b2a22, 다크 #4a352b) + 글자 `on-band-cocoa`(라이트 12.5:1, 다크 10.1:1). 2026-11-11 사용자 결정(2026-11-09~11-10은 오렌지 채움). 왼쪽 문장 15px 600(넘치면 …) + 오른쪽 이동 글자 15px 500 + 꺾쇠(“체크하기 ›”, “확인하기 ›”, 초대는 “초대하기 ›”). 닫기 ✕ 없음(2026-11-11 사용자 결정: 이동 글자만, 할 일은 끝내거나 기간이 지나면 사라지고 초대는 다른 할 일이 없을 때만 맨 끝 순서로 나옴). 띠 전체가 이동 버튼. 마우스 올림은 코코아를 `on-band-cocoa` 쪽으로 10% 밝게. 초대 띠(“함께할 사람을 초대해 주세요”, → S-12)도 같은 띠(앞 점선 + 원은 없앰), 할 일은 한 번에 하나라 둘이 같이 나오지 않음. 공지·해제 대기·메일 반송 띠는 Banner·LineBand 그대로(본문 맨 위).
- 타일(`hg-hubtile`, HubTile, 한 칸): 안쪽 18px. 제목 `title-3` 17px 600 + 회색 보조 13px 500 `slate`. 큰 타일은 높이 164px 이상 + 오른쪽 아래 72px 그림 자리(`hg-artslot`, `radius-xl`, 2D 그림이 들어올 때까지 회색 빈 자리, Illustrations ‘나중 과제’ 9번). 작은 타일(`--sm`)은 104px 이상 + 값 한 줄(17px 700, 숫자 너비 같게).
- 타일 배지(`hg-hubtile__badge`, HubTile `badge`, 2026-11-11): 보조 줄 바로 오른쪽(`hg-hubtile__subrow`, 간격 `space-2`) 작은 알약, 바탕 `plate`, 글자 `ink-2` 12px 600, 높이 18px, 숫자 너비 같게. 홈 자산 관리 타일의 “상위 38%”만(순위를 본 적이 있을 때). 화면 읽기는 타일 `label`에 함께.
- 포인트 상자(`hg-hubtile--point`, HubTile `point`, 2026-11-11 사용자 결정): 홈 ‘월급 계획’ 타일 하나만 브랜드 오렌지 채움(`accent-app`). 제목 `on-accent-app-text`(라이트 `ink` 6.5:1, 다크 어두운 `on-brand` 7.6:1, 흰 글자 금지), 보조 줄 `on-accent-app-sub`(라이트 4.7:1, 다크 5.3:1), 72px 그림 자리는 반투명 밝은 네모(`accent-app-slot`, 선 없음). 마우스 올림·누름 `brand-pressed`. ‘캘린더’와 다른 상자는 흰색.
- 저금 상자(`hg-hubsave`, HubSaving, 두 칸): 안쪽 20px. 왼쪽 56px 그림 자리(`hg-artslot`, `radius-lg`) + 이름(17px 600, 넘치면 …)과 오른쪽 % + 회색 “6,000만 / 1억 5,000만 원” + 얇은 막대(8px, 바탕 `surface-alt`, 채움 `ink-2`, 2026-11-09 사용자 그림대로 오렌지가 아님).
- 다크: 토큰 그대로(회색 바탕 `surface-alt` 다크 #232325, 상자 `surface`).
