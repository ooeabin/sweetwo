# Band

구역을 나누는 굵은 회색 띠(2026-11-04, 23 F-08 대형 금융 앱형). 카드로 감싸지 않은 긴 상세 화면에서 내용 묶음 사이에 둠.

- `hg-band`(`hr`, 장식이라 `aria-hidden`): 2026-11-27 ‘간격 정리’로 흰 화면 띠는 이 하나. `surface-alt` 8px(`--band`), 좁은 창은 본문 옆 24를 넘어 화면 끝까지(넓은 창은 본문 폭). 옛 `hg-page__band`(W-10, F-04)도 `Band`로 바꿈(CSS는 같은 규칙).
- 위아래 보이는 간격(글자 줄 기준): 위 32(`--gap-band-above`), 아래 24(`--gap-band-below`). 둘러싼 스택 간격(`--pg`)과 닿는 줄 안쪽(16)은 CSS가 빼 줌. 이어진 묶음(카드·목록·제목 있는 묶음) 사이는 `Band` 없이 같은 규칙의 `::before`가 그음(DESIGN.md ‘간격 정리 2026-11-27’).
- 다크 모드는 `surface-alt` 토큰이 처리.
- React: `Band()`.

쓰는 곳: 자산 순위(F-08), 달력(Y-04), 저축·투자 상세(W-10), 자산 상세(F-04).
