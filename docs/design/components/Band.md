# Band

구역을 나누는 굵은 회색 띠(2026-11-04, 23 F-08 토스형). 카드로 감싸지 않은 긴 상세 화면에서 내용 묶음 사이에 둠.

- `hg-band`(`hr`, 장식이라 `aria-hidden`): `surface-alt` 10px. 좁은 창(768px 미만)은 본문 좌우 여백(`space-4`)을 넘어 화면 끝까지, 넓은 창은 본문 폭 안에서 8px 둥근 띠.
- 위아래 간격은 둘러싼 `hg-stack`의 간격 + `space-2`.
- 카드 묶음 사이에는 쓰지 않음(카드끼리는 간격만).
- 다크 모드는 `surface-alt` 토큰이 처리.
- React: `Band()`.

쓰는 곳: 우리 자산 순위(F-08).
