# Meter

목표 진행. 이름, 금액 + 큰 퍼센트 + 두 줄로 쌓이는 10칸 + 회색 상태 칩(2026-10-27, 카카오뱅크 26주적금처럼 칸이 쌓이는 모양).

- 소비자가 주는 것: 이름, 모은 금액, 목표 금액, 계획상 지금 비율, 영역(목표, 비상금, 투자, 우리 둘, 양가).
- 오른쪽 위 큰 퍼센트(28px 700, `ink`).
- 쌓이는 칸: 10% 칸 10개를 5개씩 두 줄(높이 22px, 칸 사이 6px, 모서리 `radius-sm`). 아래 줄(0~50%)부터 왼쪽에서 오른쪽으로 차고, 다 차면 위 줄(50~100%)로 올라감. 찬 칸은 영역 차트 색, 빈 칸은 같은 영역 틴트. 걸친 칸은 비율만큼 채움.
  - 기본(목표) `chart-goal` / `goal`, `hg-meter--safety` 비상금 `chart-safety` / `safety`, `hg-meter--invest` 투자, `hg-meter--together` 우리 둘, `hg-meter--family` 양가.
- ‘지금’ 눈금(`pace`): 틀에 남아 있지만 두 줄 칸에서는 위치가 맞지 않아 지금 쓰는 곳 없음.
- 아래 상태 칩(`hg-meter__chip`): 앞섬, 늦음 모두 항상 `surface-alt` 바탕 `ink-2` 글자. 색으로 상태를 말하지 않음, 글자로만(“계획보다 3% 앞서 있어요”, “계획보다 2달 늦어요”).
- 여러 개는 한 카드 안에 구분선으로 쌓음.
- 이름 앞 아이콘 칸(`lead`, Lead, 48px): 목표 3D 그림(직접 만든 목표는 깃발 아이콘). 홈 목표(H-02)에서 씀.
