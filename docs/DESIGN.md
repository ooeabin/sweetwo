## 원칙

- 흰 화면 바탕(`canvas`) + 흰 카드(`hairline-soft` 1px 테두리, `radius-xl` 20px, 좁은 창은 카드 대신 12px 회색 띠 `band`로 구획) + 오렌지 주 버튼(`brand`, 둥근 사각형)이 기본. 한 화면에 주 버튼은 1개.
- 브랜드 색은 아껴 씀. 화면의 기본은 `ink`와 무채색, 브랜드 오렌지는 주 버튼과 점처럼 한두 곳만.
- `brand`(브랜드 오렌지 #FF7716, 다크 #FF9045)는 주 버튼 바탕과 작은 점, 글자에만: 워드마크, 주 버튼, 달성 배지, 새 알림 점, 순자산 차트 끝점, 온보딩 챕터 진행 막대(ChapterBar 채움). 카드·띠·패널 같은 넓은 면, 보조 버튼, 숫자 알약(`ink`), 다른 진행 막대(ProgressSteps, `ink`)에는 쓰지 않음.
- `brand-soft`는 달력의 오늘 날짜 칸, 카드 안 보조 버튼, O-01 ‘초대받았어요’ 보조 버튼, 결과 카드(ResultCard) 체크 동그라미에만. 월말 정리 띠, 제안 카드 머리, 변화 알약은 `surface-alt`.
- 영역 틴트는 뜻이 정해져 있음: `together` 우리 둘(공동), `family` 양가, `goal` 목표, `safety` 비상금, `invest` 투자·부동산. 뜻 없이 장식으로 쓰지 않음.
- 버튼은 둥근 사각형(`radius-btn` 14px, 작은 버튼 `radius-btn-sm` 10px), 칩·배지·탭은 알약(`radius-full`). 카드와 목록 묶음은 `radius-xl`(20px, 테두리 없음), 영역 틴트 강조 카드는 `radius-2xl`(28px).
- 대부분 평평하게. 그림자는 떠 있는 것(드롭다운·모달·토스트)에만 `shadow-2`·`shadow-3`.
- 앱(데스크톱, 웹)과 웹사이트(기획서 L 화면) 모두 같은 토큰과 컴포넌트를 씀.

## 말투

- 해요체, 짧게. 제목 1줄 + 꼭 필요할 때만 보조 1줄. 인사·부연·자명한 안내 금지.
- 사람 이름으로 말함: “찬우님이 바꿨어요”, “예빈님 응답을 기다려요”. ‘사용자’, ‘배우자 계정’ 같은 시스템 말 금지.
- 압박·죄책감 금지. 미달은 “이번 달은 30만 원 덜 모였어요”처럼 사실만. 손실 금액도 경고색 없이 “−800만”.
- 버튼은 하는 일을 그대로: “좋아요”, “다르게 해볼래요”, “팔았어요”, “나중에 할게요”.
- 반영 시점 문구는 하나로: “좋아요면 바로, 반대 없으면 {날짜}부터 적용돼요”.
- 금액: 원 단위 입력 + 만 원 읽기 표시(칸에 “3,120,000원”, 아래 작은 회색 줄에 “312만 원”). 표·카드 숫자는 `font-variant-numeric: tabular-nums`.
- 이모지 쓰지 않음.
- 한 줄에 정보 여럿을 둘 때 가운데 점(·)으로 잇지 않음. 이름표는 작고 흐리게(`stone`), 값은 진하게(`ink-2` 600), 묶음 사이는 16px 간격(`hg-meta` + `hg-pair`). 종류는 작은 회색 알약(`hg-tag`), 개수는 숫자 알약(`hg-count`).

## 색

- 글자: 제목·본문 `ink`, 보조 1줄 `slate`, 캡션·회색 보조 줄·자리표시·다른 달 날짜 `stone`, 비활성 `muted`(읽어야 하는 글자에는 안 씀). `ink`·`slate`·`stone`은 `surface`·`surface-alt` 위에서 4.5:1 이상.
- 비활성 버튼: `hairline` 바탕 + `stone` 글자(3:1 이상).
- 바탕: 화면(앱 틀, 오늘 띠), 상단 메뉴 줄, 카드 모두 흰색(`canvas`, `surface`). 카드·목록 묶음·숫자 타일·차트·달력·할 일·제안·정산 요약은 1px `hairline-soft` 테두리로 구분하고, 목록 행 사이에는 선을 긋지 않음. 좁은 창은 카드 틀 없이 묶음 사이 12px 회색 띠(`band`). 채움(보조 버튼, 아이콘 칸, 검색 칸) `surface-alt`, 표 머리 `surface-sunk`. 카드 안 보조 버튼은 옅은 오렌지(`brand-soft` + `brand-ink`).
- 회색 판(`plate`, 테두리 없음)은 가볍게 둘 내용에만: 숫자 타일(`hg-stat`), 안내·빈 상태 카드(`hg-card--fill`), 카드 안 요약 칸. 주요 내용은 흰 카드, 한 화면에 회색 판만 늘어놓지 않음.
- 회색은 따뜻한 기운 없는 중립 회색(살짝 차가운 쪽). 글자 `ink`·`slate`·`stone`도 같은 계열.
- 행 앞 아이콘 칸(`hg-lead`): 영역 색 원 + 아이콘, 목표는 3D 그림. 화면에 색을 주는 곳은 이 아이콘 칸과 영역 틴트뿐, 파스텔 타일 바탕은 쓰지 않음.
- 주 버튼 `brand` 바탕 + `on-brand` 글자(라이트 흰 글자, 다크 어두운 글자), 누름 `brand-pressed`. 라이트의 흰 글자 대비는 2.7:1로 WCAG AA(4.5:1)에 못 미치는 걸 알고 씀(2026-10-25 결정, 당근처럼 쨍한 오렌지 우선). 그래서 e2e axe는 주 버튼과 달성 배지의 color-contrast만 예외(`e2e/axe.ts`), 나머지는 그대로 검사. 보조 버튼 `surface-alt` 바탕(카드 안과 O-01 시작 화면에서는 `brand-soft` + `brand-ink`), 테두리 없음. 영구 삭제 확인 버튼만 `danger` 바탕.
- 달성 배지 글자는 `on-brand`(라이트 흰 글자, 다크 어두운 글자). `brand-soft` 위 글자와 축하 머리글은 `brand-ink`.
- `danger`는 기본 빨강(#DC2626, 다크 #F87171, 2026-10-25 짙은 빨강 #B91C1C에서 바꿈). 흰 바탕과 회색 판 위 4.5:1 이상. 그래도 항상 아이콘·문구와 같이 씀.
- `holiday-ink`는 캘린더 공휴일 숫자와 이름에만(기획서 ‘빨간 글자’). 오류 `danger`와 브랜드 오렌지와 섞지 않음. 이름이나 일정 목록 글자가 함께 있어 색만으로 뜻을 전하지 않음.
- 영역 틴트 위 글자는 짝이 되는 `*-ink`(`together-ink` on `together` 등). 본문 `ink`도 모든 틴트 위에서 읽힘.
- 상태: 완료·확정 `success` + `on-success`, 입력 오류·저장 실패, 되돌릴 수 없는 확인 버튼만 `danger`, 마감 임박은 검정 배지(`ink`), 오프라인은 `surface-alt` 안내 띠. 상태는 색만으로 말하지 않고 글자나 아이콘을 함께 둠.
- 포커스: 2px `focus` 링, 바깥 2px 간격. 글자 링크도 `focus`. 입력 칸과 검색 칸에 입력 중일 때 테두리는 2px `ink`.
- 사람 색: Avatar만 `person-1`(찬우, 연한 코랄)·`person-2`(예빈, 하늘). 보는 사람과 상관없이 사람마다 고정.

## 간격·모양

- 4px 단위: `space-1`(4) ~ `space-16`(64), 독 높이 `space-14`(56), 독 위 여백 `space-22`(88). 카드 안쪽 `space-4`~`space-6`, 카드 사이 `space-5`, 섹션 사이 `space-8`.
- 입력 칸·복사 칸·Select 높이 48px, 버튼 48px(작은 버튼 36px).
- 폭: 본문 최대 `content-max` 720px, 질문 화면 한 열 `question-max` 480px, 웹사이트 본문 `site-max` 1200px.

## 정렬

- 글자·카드 내용은 왼쪽 정렬이 기본. 가운데 정렬은 빈 상태·완료 화면의 한 묶음에만.
- 금액: 카드 안에서는 왼쪽, 목록 행·표에서는 오른쪽 정렬. 숫자는 항상 `tabular-nums`.
- 한 줄짜리 행(목록, 칩, 배지 + 글자, 아이콘 + 글자)은 세로 가운데 정렬. 두 줄 이상 섞이는 행은 위 정렬.
- 나란히 놓는 입력 칸·카드는 위 정렬, 같은 너비. 라벨 → 칸 → 도움말 자리를 칸마다 같게 둠.
- 카드는 상단 줄(24px) → 값 → 보조 줄 순서 고정(Card 참조). 같은 줄의 카드는 같은 구성.
- 간격은 부모의 `gap`으로만. 자식 요소에 margin 쓰지 않음.
- 버튼 묶음: 데스크톱은 오른쪽 끝에 주 버튼, 보조는 그 왼쪽. 좁은 창은 주 버튼 꽉 차게 하단 고정, 보조는 그 위 글자 링크.

## 영역 틴트 쓰는 곳

| 틴트 | 뜻 | 예 |
| --- | --- | --- |
| `together` | 우리 둘 | 공동 생활비 나누기 줄, 함께 정하기 배지 |
| `family` | 양가 | 챙길 날의 양가 일정, 양가 비용 목표 |
| `goal` | 목표 | 목표 카드, 목표자금 |
| `safety` | 비상금 | 비상금 카드, ‘비상금 → 공동 생활비’ 줄 |
| `invest` | 투자·부동산 | 투자 묶음, 평가 손익 줄 |

- 제안 카드 머리는 틴트도 브랜드 색도 아닌 `surface-alt`.

## 차트

- 계열색은 영역 차트색, 순서 고정: `chart-goal` → `chart-together` → `chart-safety` → `chart-family` → `chart-invest`. 항목이 빠져도 남은 색은 그대로. 6번째는 ‘기타’로 묶음.
- 한 계열은 `ink`: 순자산은 `ink` 곡선 + `ink` 8% 그라디언트 면 + `brand` 끝점, 월별 저축은 이번 달만 `ink`·지난 달 `border-control` 45%. 예상 값은 `stone` 점선.
- 차트는 카드 안에: 라벨 → 큰 값 → 변화 알약(`surface-alt`) → 그림 → 범례.
- 축·격자 `hairline-soft`, 눈금 글자 `stone`, 값 글자는 글자 토큰(계열색으로 글자 쓰지 않음).
- 선: 순자산 대표 선 2.5px, 그 밖 2px, 예상 점선 1.5px. 막대 끝 모서리 4px(월별 저축 위아래 막대는 6px), 쌓은 칸 사이 2px 틈. 직접 라벨은 마지막 값 1개. 순자산 차트는 눈금 없이 말풍선으로 값을 읽음.
- `chart-goal`처럼 흰 바탕 3:1 미만인 색의 작은 표시(달력 막대·범례)는 옆에 라벨 필수.
- 계열 2개 이상이면 범례 필수. 마우스를 올리면 툴팁. y축은 하나만.
- 원형·도넛 차트 쓰지 않음(구성은 Breakdown). 미달·손실을 색으로 칠하지 않음.

## 금액 표기

- 원 단위가 기본: “1,240,000원”. 카드·차트 큰 값은 ‘억·만’: “1억 2,220만 원”, “156만 원”.
- 만 원 미만은 버리지 않고 원으로: “8,500원”. 만 원 이상 화면 요약은 만 원 단위 반올림, 상세·입력·표는 원 단위.
- 늘어남 “+120만”, 줄어듦 “−800만”(빼기 기호 −). 색은 그대로 `ink`·`stone`.
- 0원은 “0원”, 아직 모르는 값은 “—”. 비율은 정수 %(“31%”), 분담은 “60:40”.
- 숫자는 항상 `tabular-nums`. 금액 끝 “원”은 띄어 씀(“156만 원”), 입력 칸 단위만 붙임.
- 숫자가 주인공: 금액의 단위(억·만·원)는 작게(큰 숫자 0.62배, 목록 0.82배), `stone`으로(`hg-unit`). 틴트 카드 위는 `slate`. 입력 칸 “원”도 `stone`.

## 날짜·시간 표기

- 기본 “11월 25일(수)”. 올해가 아니면 “2027년 3월 2일”. 월만은 “11월”, 연·월은 “2030년 3월”.
- 가까운 때는 말로: “오늘”, “어제”, “내일”, “3일 전”, “2시간 전”(7일 넘으면 날짜).
- 마감은 “D-2” 알약 + 날짜, 당일은 “오늘까지”. 시간은 “오전 9시”, “오후 2:30”.

## 그림(앱 아이콘 3D)

- 목표 카드 그림, 목표 달성 화면, 온보딩 결과, 빈 상태, 장면 그림은 모두 지금 목표 그림과 같은 무광 3D 그림체(앱 아이콘은 같은 무광 3D지만 한 색이고 형상 수치로 만듦).
- 부드러운 무광 3D, 단순하고 통통한 둥근 모양, 은은한 그라데이션, 디테일 최소. 물건 1개, 흰 바탕, 가운데 정렬과 넉넉한 여백. 사람 얼굴·글자·로고 없음(달력의 연도 숫자만 예외).
- 색은 3~4가지로 적게. 체리색을 포인트로, 나머지는 크림, 흰색, 모래색 같은 밝은 중간색. 물건 고유색이 분명한 것(금반지, 하늘색 금고, 베이지 머그잔 등)은 그 색.
- 목표 종류마다 1장(내 집, 신혼여행, 차, 결혼 준비, 아이, 비상금 등), 사용자가 고르지 않음.
- 1:1, 1024px로 만들고 바탕을 지운 512px PNG로 배포. 56px·48px에서도 물건이 알아보이게 단순한 물건을 고름.
- 한 세트처럼: 힉스필드에서 기존 목표 그림 한 장을 그림체 참고로 넣고, 같은 프롬프트 틀(부록)에 물건 이름만 바꿔 생성.
- 확정 그림은 Illustrations 묶음(목표 21장, 빈 상태 1장, 장면 5장). 직접 만든 목표는 회색 기본 그림(`flag-pennant`(깃발) 아이콘)으로 시작하고, 사용자가 올린 사진으로 바꿀 수 있음(Card ‘그림 자리’).
- 실사 사진, 반짝이는 유광, 플랫 일러스트는 쓰지 않음.

## 장면 자리(비어 있음)

- 다섯 화면(W-04 월말 정리 끝, P-11 배우자 합류 완료, P-01 초대받은 사람 첫 화면, H-T1 결혼일 전환 축하, A-02 로그인 첫 화면)의 장면 그림과 영상은 모두 없앰(2026-10-19). W-04·P-11·P-01·H-T1은 그 자리를 그림 없이 비워 둠.
- SceneMedia는 빈 `figure.hg-scene`으로 영역만 잡음. P-01만 3:4(`hg-scene--tall`), 나머지는 1:1. 너비는 화면이 정함(최대 320px).
- A-02 로그인 첫 화면만 그 자리에 영어 워드마크(`Wordmark`, 높이 40px)를 넣음.
- 다른 큰 자리(목표 카드, 위젯, 빈 상태, 목표 달성)는 정지 그림만(Illustrations 묶음).

## 그림 자리

- 지금 정해진 큰 자리(목표 카드, 위젯, 목표 달성, 빈 상태)는 모두 그림이 있음: Illustrations 묶음. 장면 화면 5곳은 그림 없이 비워 둠(SceneMedia).
- 새 화면에 아직 없는 그림 자리를 설계할 때만 영역을 잡아 둠: 큰 칸은 `hg-art`(점선 테두리 + 이미지 아이콘 + “○○ 그림” + 크기), 작은 칸(56px 이하)은 `hg-art-slot`(점선 테두리 + 아이콘).
- 그림이 들어오면 점선은 사라지고 `<img>`가 칸을 채움. 새 그림은 위 ‘그림’ 장 규칙과 부록 프롬프트 틀로 만듦.
- 직접 만든 목표처럼 그림이 없는 목표는 Icons 묶음 아이콘으로 채움(점선 자리를 남기지 않음).

## 아이콘

- 작은 아이콘: Phosphor 세트(MIT 라이선스, Icons 묶음)의 굵은 둥근 선. 채운 모양은 현재 메뉴·독 칸·켜진 상태에만.
- 큰 자리(빈 상태, 카테고리, 온보딩, 축하) 그림: 앱 아이콘 같은 3D 그림(‘그림’ 장).
- 화면에서는 `hg-ico` + 아이콘 클래스(CSS mask)로 써서 글자 색을 따라감. 크기 16·20·24.
- 아이콘만으로 뜻을 전하지 않음: 라벨이나 `aria-label`을 같이.

## 브랜드

- 이름: sweeTwo(스위투), sweet + two. T는 늘 대문자.
- 워드마크: 둥근 붓 필기체 “sweeTwo”(Damion 바탕, 글자 이음과 굵기를 다듬음). 기본 색 `brand`(브랜드 오렌지), 오렌지 바탕 위에는 흰색. T와 w 사이는 다른 글자 사이와 같은 간격.
- 브랜드 상징: 파이 차트(원 고리 + 빠져나온 파이 조각). 앱 아이콘, 심볼, 파비콘이 모두 이 그림(모두 말랑 점토 3D, 벡터 symbol.svg만 평면).
- 앱 아이콘: 파이 차트: 두꺼운 원 고리(`brand` #FF7716)와 오른쪽 아래로 빠져나온 파이 조각 하나. 조각은 끝이 원 가운데를 향한 삼각형 몸통과 틈 뒤 둥근 크러스트 띠. 고리, 몸통, 크러스트 모두 `brand` 한 색이고 흰 틈으로만 나뉨. 틈은 작게 줄여도 보이게 넓게(심볼 좌표 80, 고리 바깥 반지름 694 기준), 크러스트 두께 170. 앱 아이콘 계열(app-icon, app-icon-macos, apple-touch, symbol.png, og)은 말랑 점토 3D(Blender 렌더): 둥근 모서리와 둥근 단면, 반무광. 그늘은 브랜드 색(#FF7716) 그대로이고 왼쪽 위 빛을 받는 곳만 밝은 살구빛으로 올라감(검정·갈색 음영과 바닥 그림자 없음). 흰 바탕. 심볼은 아이콘 폭의 72%, 바운딩 박스 가운데. Android 적응형 아이콘은 가운데 66%만 안전해서 전경을 따로 폭 62%로 만듦(모바일 앱 아이콘 작업 때). 파비콘도 같은 3D를 줄여 씀(평면 한 색은 앱 아이콘보다 짙어 보여서). symbol.svg만 같은 형상의 평면 한 색(벡터가 필요한 곳용). 모두 `scripts/brand-icons/build.py`가 형상 수치에서 만듦(3D는 `blender_scene.py`, AI로 다시 그리지 않음). 글자 없음. ‘함께 구워 더 달콤한 자산파이’에서 떼어 낸 한 조각.
  - `app-icon.png`(1024px, 꽉 찬 정사각형, iPhone·Android가 모서리를 깎음), `app-icon-macos.png`(Mac 독용, 둥근 사각형과 여백·그림자를 파일에 넣음).
  - 다시 그리거나 색을 바꾸지 않음. 설치 파일용 .icns/.ico는 개발할 때 만듦.
- 심볼과 파비콘: 같은 파이 차트를 바탕 없이 씀(`symbol.png` 3D, `favicon-32.png`·`favicon-48.png` 3D를 줄임, `apple-touch-icon.png`는 앱 아이콘과 같음). 트레이, 알림, SNS 공유 이미지, L-01 랜딩도 이 심볼.
- 체리 타르트 그림(장면 그림·영상)은 없앰(2026-10-19). A-02 로그인 첫 화면 장면 자리에는 영어 워드마크(`Wordmark`)를 넣음.
- 화면에서는 `hg-wordmark`(워드마크 모양 마스크, `brand` 칠). 작게 둠: 기본 높이 24px, 큰 자리 40px, 트레이 20px. 최소 높이 16px.
- 워드마크는 `brand`. 한 화면에 워드마크 하나.

## 움직임

- 바뀜(색·토글·체크) `dur-fast` 150ms, 드롭다운·툴팁·아코디언 `dur-base` 200ms, 모달·바텀시트 `dur-slow` 250ms.
- 들어올 때 `ease-out`, 나갈 때 `ease-in`. 크기·위치는 transform과 opacity만 움직임.
- 숫자는 굴리지 않음(금액이 바뀌면 바로 새 값). 축하(목표 달성)만 한 번 짧은 강조 허용(Celebration). 장면 자리는 비어 있어 움직임 없음(‘장면 자리’ 장).
- `prefers-reduced-motion`이면 움직임 없이 바로 나타남, Skeleton 반짝임 끔.

## 반응형

- 기준점 `bp-narrow` 768px, `bp-wide` 1100px.
- 768px 미만: 내용 폭 하단 독 + 같은 줄 오른쪽 추가 버튼, 상단 줄 아이콘 4개, 모달·Select → BottomSheet, 주 버튼 하단 꽉 차게, 카드 묶음 1열.
- 768~1100px: 상단 메뉴 줄 유지, 본문은 한 단(오른쪽 단은 왼쪽 단 아래로).
- 1100px 이상: 상단 메뉴 줄 + 본문 최대 1120px 두 단(AppFrame).

- 어드민: 기준 너비 1440px, 최소 1280px. 좁은 창 대응 없음(AdminFrame).

## 겹침 순서

- 아래에서 위로: 본문 → 상단 줄·하단 독 `z-topbar` → 드롭다운·툴팁·날짜 고르기 `z-dropdown` → 바텀시트 `z-sheet` → 모달·명령 팔레트 `z-modal` → 토스트 `z-toast`.
- 그림자도 짝: 누를 수 있는 카드 `shadow-1`, 떠 있는 메뉴·툴팁 `shadow-2`, 모달·시트·토스트 `shadow-3`. 막은 `scrim`.
- 한 번에 열리는 겹침은 하나. 모달 위에 다른 모달 금지(토스트만 예외).

## 포커스·키보드

- 포커스 링: 2px `focus`, 바깥 2px 간격. 마우스 클릭에는 숨기고 키보드에만(`:focus-visible`). 잘리는 묶음 안 줄(목록·메뉴)은 안쪽 2px.
- 누를 수 있는 것은 `button`·`a`. 상태는 `aria-pressed`·`aria-checked`·`aria-selected`·`aria-expanded`·`aria-current`로.
- Tab 순서 = 읽는 순서(위 → 아래, 왼쪽 → 오른쪽). 숨은 요소는 Tab에서 빠짐.
- 단축키: Ctrl/⌘+K 명령 팔레트, Enter 다음·확인, Esc 뒤로·닫기, ←/→ 슬라이더·달력, Ctrl/⌘+L 앱 잠금.
- 모달·시트·명령 팔레트는 열리면 첫 입력에 포커스, 안에서만 맴돌고, 닫히면 연 자리로 돌아감.

## 다크 모드

- MVP는 기기 설정을 따름.
- 라이트, 다크를 직접 고정하는 설정(설정 > 화면)은 (출시 뒤).
- 색은 토큰의 `dark` 값만 씀. 화면에서 색을 뒤집거나 따로 고르지 않음.
- 다크에서는 그림자가 잘 안 보이므로 떠 있는 것(메뉴·모달·시트·명령 팔레트·날짜 고르기·독)에는 `hairline` 테두리를 꼭 둠. `ink` 바탕(토스트·툴팁)은 다크에서 밝게 뒤집혀 테두리 없음.
- `ink` 알약 위 포커스 링은 바깥 2px 간격으로 바탕과 떨어져 두 테마 모두 보임.
- 다크에서 브랜드 오렌지는 밝게(`brand` 다크 값), 달성 배지 글자는 어두운 글자. 사진·목표 그림은 그대로.
