## 말투

- 해요체, 짧게. 제목 1줄 + 꼭 필요할 때만 보조 1줄. 인사·부연·자명한 안내 금지.
- 사람 이름으로 말함: “찬우님이 바꿨어요”, “예빈님 응답을 기다려요”. ‘사용자’, ‘파트너 계정’ 같은 시스템 말 금지.
- 압박·죄책감 금지. 미달은 “이번 달은 30만 원 덜 모였어요”처럼 사실만. 손실 금액도 경고색 없이 “−800만”.
- 버튼은 하는 일을 그대로: “좋아요”, “다르게 해볼래요”, “팔았어요”, “나중에 할게요”.
- 반영 시점 문구는 하나로: “좋아요면 바로, 반대 없으면 {날짜}부터 적용돼요”.
- 금액: 원 단위 입력 + 만 원 읽기 표시(칸에 “3,120,000원”, 아래 작은 회색 줄에 “312만 원”). 표·카드 숫자는 `font-variant-numeric: tabular-nums`.
- 이모지 쓰지 않음.
- 한 줄에 정보 여럿을 둘 때 가운데 점(·)으로 잇지 않음. 이름표는 작고 흐리게(`stone`), 값은 진하게(`ink-2` 600), 묶음 사이는 16px 간격(`hg-meta` + `hg-pair`). 종류는 작은 회색 알약(`hg-tag`), 개수는 숫자 알약(`hg-count`).

## 색

- 글자: 제목·본문 `ink`, 보조 1줄 `slate`, 캡션·회색 보조 줄·자리표시·다른 달 날짜 `stone`, 비활성 `muted`(읽어야 하는 글자에는 안 씀). `ink`·`slate`·`stone`은 `surface`·`surface-alt` 위에서 4.5:1 이상.
- 비활성 버튼: `surface-alt` 바탕 + `muted` 글자(누를 수 있는 보조 버튼보다 옅게, 2026-11-02).
- 바탕: 앱 틀, 사이드바, 카드 모두 흰색(`canvas`, `surface`). 예외(2026-11-09): 홈과 자산 관리 첫 화면은 회색 바탕(`surface-alt`) + 테두리·그림자 없는 흰 상자(`hg-frame--alt`). 카드·목록 묶음·차트·달력은 1px `hairline-soft` 테두리로 구분하고, 앱 틀의 맨 바깥 카드는 옅은 그림자(`shadow-1`)를 더함. 목록 행 사이에는 선을 긋지 않음. 채움(보조 버튼, 아이콘 칸, 검색 칸, 구간 탭 바탕, 칩, W-01 영수증 뒤 회색 판, 그림 빈 자리) `surface-alt`, 표 머리 `surface-sunk`. `surface-alt`는 2026-11-09 사용자 요청(“살짝만 연하게”)으로 흰색 쪽으로 약 35% 옮김: 라이트 #EDEEF0 → #F3F4F6, 다크 #28282A → #232325(바탕 `surface`에 조금 더 가깝게, 관계는 그대로). `slate`·`stone`은 그 위에서 대비가 오히려 커짐(라이트 6.8:1·5.0:1, 다크 7.2:1·5.4:1). 고른 구간 탭 칸은 흰 바탕 + `shadow-1`에 1px `hairline` 테두리를 더해 구분. `hairline-soft`는 선 색이라 #EDEEF0 그대로. 어드민·웹사이트는 예전 값 그대로(tokens.css의 `hg-admin`·`hg-site` 묶음). 카드 안 보조 버튼은 옅은 오렌지(`brand-soft` + `brand-ink`).
- 회색 판(`plate`, 테두리 없음)은 가볍게 둘 내용에만: 숫자 타일(`hg-stat`), 안내·빈 상태 카드(`hg-card--fill`), 카드 안 요약 칸. 주요 내용은 흰 카드, 한 화면에 회색 판만 늘어놓지 않음.
- 회색은 따뜻한 기운 없는 중립 회색(살짝 차가운 쪽). 글자 `ink`·`slate`·`stone`도 같은 계열.
- 행 앞 칸(`hg-lead`, 2026-11-10): 2D 그림이 들어올 때까지 회색 빈 원(`hg-lead--slot`), 한 종류 = 그림 하나(ListRow ‘Lead 종류 표’, 코드는 `lead-kinds.ts` 한 곳). 2026-11-09 ‘C’(영역 색 원 + Phosphor)에서 바꿈. 목표 금액이 있는 저금 줄(체크리스트 W-02, 홈 H-03, W-05)은 아이콘 대신 진행 원(`surface-alt` 둘레 + `accent-app` 오렌지 고리, 2026-11-09, 장식)이고 그 줄에는 이름 아래 막대를 두지 않음. 줄 앞 칸도 2D 그림 대상(Illustrations 4·6·7번). 파스텔 타일 바탕은 쓰지 않음, 파스텔 타일 바탕은 쓰지 않음.
- 주 버튼 `brand` 바탕 + `on-brand` 글자(라이트 흰 글자, 다크 어두운 글자), 누름 `brand-pressed`. 라이트의 흰 글자 대비는 2.7:1로 WCAG AA(4.5:1)에 못 미치는 걸 알고 씀(2026-10-25 결정, 당근처럼 쨍한 오렌지 우선). 그래서 e2e axe는 주 버튼과 달성 배지의 color-contrast만 예외(`e2e/axe.ts`(mobile, admin, site)), 나머지는 그대로 검사. 보조 버튼 `surface-alt` 바탕(카드 안에서는 `brand-soft` + `brand-ink`), 테두리 없음. 영구 삭제 확인 버튼만 `danger` 바탕.
- 대비 예외(2026-11-09, 당근처럼 알고 씀): 흰 바탕 위 오렌지 글자는 약 2.7:1로 WCAG AA(4.5:1)에 못 미침. 그래서 오렌지 글자는 14px 이상 + 굵기 600 이상의 짧은 말(강조 숫자, 띠 안 흰 작은 버튼, 고른 바꾸기 칩)에만 쓰고(글자 버튼은 2026-11-09부터 모두 회색이라 예외에서 뺌) 긴 문장에는 쓰지 않음. 체크 원, 진행 원·막대는 그래픽. 모두 뜻을 색만으로 전하지 않음(체크 표시 모양, 숫자, 이름·문구가 함께 있음). 다크는 `brand` 다크 값(#FF9045)이라 어두운 바탕 위에서 4.5:1을 넘음. e2e axe(`apps/mobile/e2e/axe.ts`)는 이 오렌지 글자 요소만 선택자로 color-contrast에서 빼고(`ORANGE_TEXT`), 규칙 자체는 끄지 않음.

## 정렬

- 글자·카드 내용은 왼쪽 정렬이 기본. 가운데 정렬은 빈 상태·완료 화면의 한 묶음에만.
- 금액: 카드 안에서는 왼쪽, 목록 행·표에서는 오른쪽 정렬. 숫자는 항상 `tabular-nums`.
- 한 줄짜리 행(목록, 칩, 배지 + 글자, 아이콘 + 글자)은 세로 가운데 정렬. 두 줄 이상 섞이는 행은 위 정렬.
- 나란히 놓는 입력 칸·카드는 위 정렬, 같은 너비. 라벨 → 칸 → 도움말 자리를 칸마다 같게 둠.
- 카드는 상단 줄(24px) → 값 → 보조 줄 순서 고정(Card 참조). 같은 줄의 카드는 같은 구성.
- 간격은 부모의 `gap`으로만. 자식 요소에 margin 쓰지 않음(누르는 칸을 넓히는 음수 margin만 예외, 2026-11-09).
- 버튼 묶음: 넓은 창(태블릿)은 오른쪽 끝에 주 버튼, 보조는 그 왼쪽. 좁은 창은 주 버튼 꽉 차게 하단 고정, 보조는 그 위 글자 링크. 두 갈래 질문(예: Face ID 켜기)은 보조 1 : 주 2 가로 나란히.

## 금액 표기

- 원 단위가 기본: “1,240,000원”. 카드·차트 큰 값은 ‘억·만’: “1억 2,220만 원”, “156만 원”.
- 만 원 미만은 버리지 않고 원으로: “8,500원”. 만 원 이상 화면 요약은 만 원 단위 반올림, 상세·입력·표는 원 단위.
- 늘어남 “+120만”, 줄어듦 “−800만”(빼기 기호 −). 색은 그대로 `ink`·`stone`.
- 0원은 “0원”, 아직 모르는 값은 “—”. 비율은 정수 %(“31%”), 분담은 “60:40”.
- 숫자는 항상 `tabular-nums`. 금액 끝 “원”은 띄어 씀(“156만 원”), 입력 칸 단위만 붙임.
- 숫자가 주인공: 금액의 단위(억·만·원)는 작게(큰 숫자 0.62배, 목록 0.82배), `stone`으로(`hg-unit`). 틴트 카드 위는 `slate`. 입력 칸 “원”도 `stone`.

## 날짜·시간 표기

- 기본 “11월 25일(수)”. 올해가 아니면 “2027년 3월 2일”. 월만은 “11월”, 연·월은 “2030년 3월”.
- 가까운 때는 말로: “오늘”, “어제”, “내일”, “3일 전”, “2시간 전”(7일 넘으면 날짜).
- 마감은 “D-2” 알약 + 날짜, 당일은 “오늘까지”. 시간은 “오전 9시”, “오후 2:30”.

- 심볼과 파비콘: 앱 아이콘과 같은 오렌지 둥근 사각 + 흰 Two(`symbol.png` 512, `symbol.svg`, `favicon-32.png`·`favicon-48.png`, `apple-touch-icon.png`). 랜딩 첫 화면, 공유 이미지.
- 체리 타르트 그림(장면 그림·영상)은 없앰(2026-10-19). A-02 로그인 첫 화면 장면 자리에는 영어 워드마크(`Wordmark`)를 넣음.
- 화면에서는 `hg-wordmark`(워드마크 모양 마스크, `brand` 칠). 작게 둠: 기본 높이 24px, 큰 자리 40px. 최소 높이 16px.
- 워드마크는 `brand`(어드민만 `ink`, `Wordmark ink`, 2026-11-06). 한 화면에 워드마크 하나.

## 움직임

- 바뀜(색·토글·체크) `dur-fast` 150ms, 드롭다운·툴팁·아코디언 `dur-base` 200ms, 모달·바텀시트 `dur-slow` 250ms.
- 들어올 때 `ease-out`, 나갈 때 `ease-in`. 크기·위치는 transform과 opacity만 움직임.
- 숫자는 굴리지 않음(금액이 바뀌면 바로 새 값). 축하(목표 금액 달성)만 한 번 짧은 강조 허용(Celebration). 장면 자리는 비어 있어 움직임 없음(‘장면 자리’ 장).
- 모달(2026-11-06): 뒤판 색이 차오르고 상자가 12px 아래, 98% 크기에서 올라옴(`dur-slow`). 투명도는 쓰지 않음(나타나는 동안에도 글자 대비 유지, 접근성 검사).
- `prefers-reduced-motion`이면 움직임 없이 바로 나타남, Skeleton 반짝임 끔.
- 앱 인터랙션(2026-11-06 점검, 어드민과 같은 원칙): 글자가 있는 것의 투명도는 움직이지 않고 transform만(나타나는 동안에도 글자 대비 유지, 접근성 검사).
  - 화면 들어옴: 앱 틀의 본문 단(`hg-body__col`)과 질문 화면의 제목·내용이 6px 아래에서 올라옴(`dur-base`, `ease-out`). 머리, 메뉴, 질문 화면 아래 버튼은 그대로. 메뉴 서랍(Drawer)은 오른쪽에서 미끄러져 들어옴(`dur-slow`, ‘동작 줄이기’면 바로).
  - 펼침: 아코디언 답, W-01 그만 모은 저금 항목 접힌 목록, ⋯ 메뉴는 4px 위에서 내려옴(`dur-base`). 새로 넣은 입력 줄(ListInput)은 98%에서 커짐.
  - 누름: 버튼·칩·탭·카드·타일은 98%, 작은 원 버튼·체크는 92%(홈 허브 상자·할 일 띠는 98%), 꽉 찬 목록 줄은 바탕 `hairline-soft`(`dur-fast`). 마우스 올림은 마우스가 있는 기기만.
  - 체크·토글·칩: 누른 쪽 모양을 바로 보여 주고 서버에 저장하는 동안 다시 누르기를 막음(`aria-busy`). 실패하면 원래대로 + 토스트. 색 바뀜 `dur-fast`.
  - ‘동작 줄이기’면 위 움직임과 전환 모두 없음.

## 겹침 순서

- 아래에서 위로: 본문 → 상단 줄·하단 독 `z-topbar` → 드롭다운·툴팁·날짜 고르기 `z-dropdown` → 바텀시트 `z-sheet` → 모달·명령 팔레트 `z-modal` → 토스트 `z-toast`.
- 그림자도 짝: 누를 수 있는 카드 `shadow-1`, 떠 있는 메뉴·툴팁 `shadow-2`, 모달·시트·토스트 `shadow-3`. 막은 `scrim`.

## 포커스·키보드

- 포커스 링: 2px `focus-ring`(사용자 앱 `ink`, 어드민 `focus`, 2026-11-09), 바깥 2px 간격. 마우스 클릭에는 숨기고 키보드에만(`:focus-visible`). 2026-11-11 사용자 결정: 손가락·마우스로 누른 뒤에는 대화상자·시트·서랍이 포커스를 돌려줘도 테두리 없음(앱이 마지막 입력을 `<html data-input="pointer|keyboard">`에 적고 pointer면 숨김, `@sweetwo/ui` `trackInputModality`). 입력 칸 포커스는 그대로. 잘리는 묶음 안 줄(목록·메뉴)은 안쪽 2px.
- 누를 수 있는 것은 `button`·`a`. 상태는 `aria-pressed`·`aria-checked`·`aria-selected`·`aria-expanded`·`aria-current`로.
- Tab 순서 = 읽는 순서(위 → 아래, 왼쪽 → 오른쪽). 숨은 요소는 Tab에서 빠짐.
- 단축키: Ctrl/⌘+K 명령 팔레트, Enter 다음·확인, Esc 뒤로·닫기, ←/→ 슬라이더·달력, Ctrl/⌘+L 앱 잠금.
- 모달·시트·명령 팔레트는 열리면 첫 입력에 포커스, 안에서만 맴돌고, 닫히면 연 자리로 돌아감.

## 다크 모드

- MVP는 기기 설정을 따름.
- 라이트, 다크를 직접 고정하는 설정(설정 > 화면)은 (출시 뒤).
- 색은 토큰의 `dark` 값만 씀. 화면에서 색을 뒤집거나 따로 고르지 않음.
- 다크에서는 그림자가 잘 안 보이므로 떠 있는 것(메뉴·모달·시트·명령 팔레트·날짜 고르기·독)에는 `hairline` 테두리를 꼭 둠. `ink` 바탕(토스트·툴팁)은 다크에서 밝게 뒤집혀 테두리 없음.
- `ink` 알약 위 포커스 링은 바깥 2px 간격으로 바탕과 떨어져 두 테마 모두 보임.
- 다크에서 브랜드 오렌지는 밝게(`brand` 다크 값 #FF9045, `accent-app` 계열도 같이 바뀜). 오렌지 채움 위 체크·아이콘은 `on-brand` 다크 값(어두운 색), 옅은 판은 `brand-soft` 다크 값. 사진·그림은 그대로.

## 금액 가리기

- 상단 줄 눈 아이콘(IconButton `eye`/`eye-off`)으로 켜고 끔. 켜면 모든 금액이 “•••”(`hg-masked`, `stone`), 비율·날짜·이름은 그대로(Meta).
- 켠 상태는 기기마다 기억. 앱 잠금 화면, 앱 전환 미리보기에서는 자동으로 가림.
- 입력 화면은 가리지 않음(넣는 중인 값은 보여야 함).

## 되돌리기 우선

- 되돌릴 수 있는 동작(보관, 지우기 → 휴지통, 칩·줄 빼기, 순서 바꾸기)은 묻지 않고 바로 하고 Toast “되돌리기”(6초).
- 확인 Modal은 되돌릴 수 없는 것만: 영구 삭제, 연결 끊기, 계정 삭제. 버튼은 하는 일 그대로(“지울게요”), 실행 버튼은 `danger` 바탕(`hg-btn--danger`), 취소는 `secondary`.
- 상대에게 영향 가는 수정도 확인 없이 바로 반영 + 상대 알림, 고친 사람에게 Toast ‘되돌리기’(제안·승인 없음, ADR 0003).

## 하지 말 것

- `brand`로 카드·띠·패널 같은 넓은 면을 채우기(띠는 옅은 `brand-soft`나 홈 허브 코코아 띠만, 상자 예외는 홈 ‘월급 계획’ 포인트 상자 하나), 주 버튼·홈 ‘월급 계획’ 포인트 상자·체크 원이 아닌 것을 오렌지로 채우기, 오렌지 채움 위에 흰 글자 쓰기(라이트), 긴 문장이나 14px 미만·600 미만 글자를 오렌지로 쓰기, 파랑을 포인트로 쓰기.
- 영역 틴트를 뜻과 다른 곳에 쓰기, 한 화면에 틴트 3가지 이상.
- 손실·미달을 `danger`로 칠하기.
- 버튼 모서리를 각지게 하기(알약이 기본).
- 진행 막대(ProgressSteps) 옆에 ‘3/6’, 단계 이름 같은 글자 붙이기. 온보딩 챕터 진행(ChapterBar, 넓은 창 위 바의 칸 막대 포함)만 챕터 이름(“목표”)을 붙임. 순서 숫자(‘2/4’)는 붙이지 않음.
- 넓은 창 질문 화면에서 주 버튼을 열 너비로 늘리거나 꺾쇠만 있는 뒤로 두기(아래 바 “‹ 이전” + 글자 길이 주 버튼, → QuestionLayout).
